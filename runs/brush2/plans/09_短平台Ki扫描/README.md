# 短平台 Ki 参数扫描

## 目的

在当前非线性前馈与受限 PI 结构下，从 **Ki=0.025、0.05、0.10** 中选择适合的积分强度。三个值分别为已完成试验值 0.05 的一半、原值、两倍。这是有界候选比较，不是根据准确动态模型计算的理想 Ki，也不能确定所有工况下的全局最优值。

先前两笔 Ki=0.05 的最大积分约 0.069 mm，未达到 ±0.2 mm 上限，说明本次适合固定积分上限、单独比较 Ki。每组都在本批重新采集，原来的四笔只用于背景判断，不混入本批主评分。

## 路径与固定条件

**160 µT保持8 s → 3 s平滑升至240 → 保持8 s → 3 s平滑回到160 → 保持8 s。**

![同一目标路径](preview/stroke_00.png)

- 测量 30 s、300 mm；X 速度 10 mm/s，纸面总行程 350 mm。
- 等待位姿 XYZ **[-370,500,130] mm**，RPY **[0,15,0]°**。
- 沿用已执行的 Z36、Ry30°→15°旋转接触、1 s滑动、3 s加载，再进入测量；随后抬至Z130并高位回程。
- 每笔轨迹 112.6 s，另加基线采集和手动准备。六笔轨迹时间合计 675.6 s，即约11.3分钟。
- Kp=1；总反馈修正±0.8 mm；积分单独±0.2 mm；修正速度2 mm/s、加速度30 mm/s²；首尾渐变1 s。
- 原非线性表的数值保持相同；新表文件仅更新本批试用范围和来源说明。
- 每笔积分从零开始，笔内跨平台保留，测量结束后清零；保留最终输出约束下的条件积分抗饱和。
- EMA α=0.3、20 ms控制周期、独立10 Hz实际TCP采集和所有既有保护保持相同。

## 预先约定怎样选 Ki

时间从第一拍 `measure_00` 开始：

| 窗口 | 时间 | 核心观察 |
|---|---|---|
| 首次160平台 | 5–7 s | 初始偏差是否减小 |
| 深压240平台 | 16–18 s | 稳定后误差与波动 |
| 返回160平台 | 27–29 s | 加载历史与残留积分 |
| 上升与恢复 | 8–16 s | 跟随及恢复过程 |
| 下降与返回恢复 | 19–27 s | 超调、恢复和积分释放 |

平台窗口均为2 s、包含端点。误差定义为 **目标－实测**，使用记录的 EMA α=0.3；不删首段，不重新平移或滤波。

1. **主评分**：每笔三个平台 MAE 等权平均，再对同一 Ki 的两笔等权平均；保留各平台及逐笔结果。不能用正负偏差抵消评分，也不对平均曲线评分。
2. **返回与全程检查**：比较19–27 s误差、最大偏高、|误差|>50 µT的时长，以及完整30 s的MAE、±20比例和P95。若较大Ki使平台评分下降，却反复增加返回偏离，不据主评分单独选它。
3. **积分与执行检查**：积分是否到±0.2 mm、冻结是否主要来自动态约束、实际修正是否频繁到顶、TCP误差及运行状态。积分限幅若长时间生效，得到的是本固定限制下的控制表现，不是未受限 Ki 的性能。
4. **接近时取较小值**：若平台主评分差≤2 µT，且返回与全程表现相近，优先较小Ki。2 µT是事先约定的工程取舍阈值，不是统计显著性检验。
5. 若笔间差异大于参数间差异或各指标明显冲突，结论写“本批尚不能区分”，不强行选出最优。选中的Ki仍需在原难曲线上验证。

Ki 增大并不保证积分实际增长成比例：冻结、误差变化及积分限幅都会参与。不要根据当前冻结比例直接把Ki按比例放大。
