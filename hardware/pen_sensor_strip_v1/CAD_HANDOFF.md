## 用户确认的供电行为

SW1 选择的是供电来源。只有所选电源存在时主供电通路接通，所选电源缺失时不从另一来源自动回退。USB/BAT 选择不会自行改变固件的通信模式。

| 已接电源 | SW1=USB | SW1=BAT |
|---|---|---|
| 仅 USB | USB 供电 | 不上电 |
| 仅电池 | 不上电 | 电池供电 |
| USB 和电池 | USB 供电 | 电池供电 |
| 都未接 | 断电 | 断电 |

表中是原理图主供电通路的设计行为，尚非实测。外部信号端口反向供电、启动浪涌、低电池电压和切换瞬态仍需实物确认。

电路：`BAT_P → Q1 → BAT_IN → SW1.1/2 → VSYS → U5 IN+EN → 3V3`；`USB_5V → D4 → USB_IN → SW1.3/2 → VSYS → U5 IN+EN → 3V3`。Q1 改作电池反接保护，D4 保留 USB 防倒灌；没有板载充电器，电池仍板外充电。

上一轮电源改版仅有七个引脚网络变更及删除冗余 R11：Q1.2→GND、Q1.3→BAT_IN、D4.1→USB_IN、SW1.1→BAT_IN、SW1.2→VSYS、SW1.3→USB_IN、U5.4→VSYS。本轮全部保留。U5.6 已为 VSYS，EN 与 IN 直接同网。R9 的 USB_5V 下拉保留。Q1 专用封装盘号仍是 1=D、2=G、3=S，对应厂家实际脚 3=D、1=G、2=S；没有换成普通编号封装。

SW1 仍是三个外接开关手焊盘。外接 SPDT 必须**先断后接（break-before-make）**，承载供电全电流；设计选型条件为 DC 至少 1 A / 5 V，并核验实际浪涌。具体开关型号未指定。切换可能短暂掉电复位，不提供无缝切换。板上 USB/BAT 表示焊盘侧别，不据此推定外接开关机械拨向。

设计复核来源：[TI TLV755P 数据手册](https://www.ti.com/lit/ds/symlink/tlv755p.pdf)、[Diodes DMP2165UW 数据手册](https://www.diodes.com/_files/datasheets/DMP2165UW.pdf)。主电源行为、逐脚 ECO 与八种输入组合记录于 [电源行为记录](verification/20261104/power_behavior_review.json)。
