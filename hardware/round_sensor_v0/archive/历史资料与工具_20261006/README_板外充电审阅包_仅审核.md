## 接线和使用

插USB由电脑供电并烧录/串口/传数据；拔USB由电池供电及蓝牙采集。J2=1/BAT_P正、2/GND负；电池从板外短引线可拆插头拔下后单独充电，板上不充电。电池必须带保护且匹配外置充电器，具体型号暂未选。SW2=BOOT、SW3=RESET；J4=1/3V3、2/GND、3/SDA、4/SCL，模块针序按实物核对。
