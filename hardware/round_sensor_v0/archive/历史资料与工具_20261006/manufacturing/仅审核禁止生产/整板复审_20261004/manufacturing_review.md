## 1. 确定需要处理的丝印收尾｜P2

按最终Gerber的极性顺序做独立几何布尔合成，丝印与阻焊开窗交叠面积：顶层约 **0.130mm²**、底层约 **1.674mm²**。进一步与实际铜PAD相交，找到31处物理焊盘记录，包括C30两盘、C1/C2/C3/C5/C6/C7/C10两盘、R1.2、R6.1、R3/R4、U6.2/.3、U2.4、D1/D2/D3、SW1.1和一个USB固定脚。完整逐盘面积见JSON。叠图已实际查看，红色为丝印侵入开窗；不是仅按元件外框推测。

这通常会被工厂裁剪，不能等同于铜短路。但既有报告“12层可视检查完成”没有解释这些交叠，尚不能称丝印收尾完整。国内嘉立创当前能力表要求字符距露铜焊盘至少0.15mm，不足时会裁字。[嘉立创工艺参数](https://www.jlc.com/portal/vtechnology.html)

**具体修法**：优先把压盘的无极性阻容外框移到文档层或删掉不必要的局部外框；芯片脚1/极性及接口识别标记保留并移离开窗；再导出Gerber检查。不要改铜、焊盘、封装坐标和规则。若由工厂裁剪，则须看生产稿，不能把裁剪后的可读性默认为已经通过。

## 2. J1的CPL基准未闭环｜P2，证据是基准差异而非已证实贴错

现有J1 `Mid X/Y=22.99/74.86mm`，来自原生LIB及焊盘范围中心。按GCT USB4105 Rev B4图纸第1页的壳体7.35mm与前固定脚距开口2.60mm，将当前4固定脚、12个实际信号铜位置、NPTH注册后，本体中心为 **(22.987,73.560504)mm**（CPL正Y），相差约 **1.299496mm**。图纸两页已查看，第2页给编带方向，未看到明确吸嘴/吸取点坐标。[GCT产品与图纸入口](https://gct.co/connector/usb4105)

**不能仅凭本体中心就说现有CPL必然错位**：工厂机器库可以使用有偏移的定义原点；吸取点也不必等于几何中心。但当前“中心校正CPL”只校正ANT1，而没有记录J1的原点偏移，属于实际交付资料缺项。应给工厂同时提供焊盘基准、壳体中心及脚1/开口方向，明确最终机器库采用哪一基准。如采用本体中心，候选CPL为 **Mid X=22.99、Mid Y=73.56mm，角度0°不变**；未经基准确认不得盲改生产坐标。

**其他37件**：ANT1校正后的29.15/80.67mm与Hirose同轴轴线相符；其余36件的CPL与当前LIB及对称PAD阵列中心吻合到导出0.01mm的四舍五入精度，最大单轴误差0.005mm。38件角度均符合当前原生导出约定：顶层=LIB角，底层=(LIB角+180) mod360。该一致性不是工厂料站、编带或吸嘴角度验收。

**排除的疑点**：最初手算怀疑U1偏0.20mm，经程序及原厂PICO第30页对称封装核查已排除。U1中央PAD/脚阵列与LIB只有约0.00015mm舍入差，不能保留为问题。

## 3. C30/C31不装，但4个锡膏开口仍存在｜P3，装配意图需明确

BOM/CPL正确排除了C30/C31；最终顶层锡膏仍覆盖其4个焊盘约100%。这不会自动装入器件，也不必然造成电气故障，但“DNP不装”未等于“不印锡”，目前钢网意图没有闭合。

**具体处理**：若本轮明确不装，通常把这4个钢网开口关闭，铜和阻焊保留作射频调试焊盘；或给工厂明确“不装但保留印锡”的理由和验收要求。建议前者。只能改锡膏层，不能顺带删掉RF调试铜PAD。三个手焊接口J2/J4/SW1的9盘无锡膏，本轮再次确认。

## 4. U4细间距钢网需要具体工艺定义｜P1制造约束，不是已证实焊接失败

当前U4六个WLCSP锡膏孔直径约0.200mm，间距0.4mm。面积比 `开口面积/(开口周长×钢网厚度)`：

| 钢网厚度 | 面积比 |
|---|---:|
| 0.07mm | 0.714 |
| 0.08mm | 0.625 |
| 0.09mm | 0.556 |
| 0.10mm | 0.500 |
| 0.12mm | 0.417 |

Panasonic EVPBB第2页给SW2/SW3锡量厚度0.08±0.01mm；当前按键锡膏孔约0.45×0.45mm，与其图纸一致。若直接选择0.08mm普通钢网，U4面积比低于常见0.66转印参考值。TI的钢网设计指导指出低于0.66需要更有利的开口制造/转印方案；这是通用过程筛选，**不是SGM保证阈值，也不证明0.625必然失败**。[TI QFN/SON贴装指导，第10–11页](https://www.ti.com/lit/an/slua271c/slua271c.pdf)

**具体收口**：在装配说明写明U4直径/面积比，要求厂方确定0.07mm局部厚度、适合细间距的钢网/表面处理与锡膏方案，或给出既有0.08mm工艺的转印依据；同时兼顾USB和较大焊点锡量。不能仅列一句“WLCSP待确认”，也不能擅自扩大铜PAD来凑面积比。SGM40567第14页的0.19–0.21mm推荐铜盘范围包含现有0.20mm，未发现这一铜盘本身尺寸错误。

## 5. Q1、PICO盘中孔及双面回流仍是制造条件

- **Q1**：既有独立测量0.1398524mm铜距与0.13985mm名义阻焊桥保留，规则0.1500124mm。它是实际规则不满足，不是渲染误报。国内1oz绿色等油墨保桥设计条件支持0.10mm级间距，但工厂能力表不自动批准这一实例；保留原厂焊盘，得到工厂工艺结论，或另行选择有足够间距的适配器件。[嘉立创工艺参数](https://www.jlc.com/portal/vtechnology.html)
- **PICO**：中央4×4mm铜盘内10过孔、约3.2×3.2mm单锡膏窗（约64%覆盖）仍存在。实际钻孔输出为9个0.305mm加1个0.151mm，顶面孔截面全部开窗、底面盖油。另ANT1.3地焊盘边缘有1个0.201mm过孔（CPL坐标27.075/80.150mm），约34.8%孔截面处于顶面开窗内、底面盖油，也应纳入同一漏锡/盖孔工艺审查。应明确填孔/盖帽或其他被接受的防漏锡方案；“有64%开窗”本身不证明空洞率、器件浮高或漏锡通过。参考资料中的填孔和多窗口建议是工艺设计依据，不能机械替代乐鑫及工厂具体判断。
- **回流**：乐鑫PICO数据手册第31页要求单次回流。当前顶层有PICO，应安排底面先、顶面后，使PICO只经过一次；需厂方确认底面器件第二次受热、夹持与顶面USB装配可行。若厂方只能反向顺序，必须调整工艺方案，不能把该约束隐去。[PICO原厂数据手册](https://www.espressif.com/sites/default/files/documentation/esp32-s3-pico-1_datasheet_en.pdf)
- **0.8mm USB壳脚**：-060为壳脚0.60±0.15mm，板厚候选0.8±0.1mm，不能凭3D模型说穿出板底；需要明确通孔回流/补焊或允许的焊缝工艺。本轮没有擅自更换-095或-120。
