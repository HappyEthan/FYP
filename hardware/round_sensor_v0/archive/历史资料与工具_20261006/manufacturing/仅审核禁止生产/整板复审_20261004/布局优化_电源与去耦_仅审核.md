# 布局布线优化机会：电源、去耦与启动｜仅审核

2026-10-04。来源：`PCB_手焊禁钢网_保存重开_20261004.json`，SHA256 `a8684a5901e8e6eeb518c6be978b76a4d726909f01af73e78e8c9d96e2d8a9c8`。本轮只读，未改源文件/原理图/云端、未运行历史生成器、未改变架构。

## 简要判断

**还有具体优化空间，值得优先试排的是主控储能/去耦的接入路径、R10充电设定支路、C1复位RC位置。** 不需要为此推翻18mm布局。当前尺寸数据只能证明有绕行和可改善的方向，不能把某个毫米数当成芯片不能工作的阈值。

优先级按收益/改动风险排序：

1. C20/C21与U1电源脚的直接接入和C21回地。
2. U4的R10/IREF局部缩短，并顺手评估C6/C7靠近U4。
3. C1/R7向U1.4靠近的RC局部试排。
4. C3方向、C5与U3去耦、小范围I2C/BOOT绕行整理，作为有顺手空间才做的第二轮。

先保留已经优化的 **C2、C9、C10**；不以SW1长支线为理由重做主电源。

## 数据怎么读

[路径及距离数据](布局优化_电源路径数据_仅审核.json)由当前源码重新提取。走线长度是**已经解析出的显式铜走线路径见证**，忽略焊盘/铜环内距离。它不解并联电流，不计过孔电阻/电感；算法可能漏掉中段搭接，**不宣称全板唯一或最短物理路径**。未解析出的路径不是开路发现。3块源码铺铜全部为GND，没有3V3铺铜；这不免除继续核对焊盘/线段并联的要求。

“焊盘中心直距”只是空间比较，不是已经可用的新路线。新增局部路线仍须避让NC铜盘、其他网络、过孔反焊盘、原厂封装与板边，并重铺铜、跑原生DRC。

## 1. 第一优先：C20/C21真正靠近主控的供电接入

| 当前连接 | 焊盘中心直距 | 当前已解析显式走线路径 |
|---|---:|---:|
| C20.1 → U1.55/VDDA | 2.388mm | 8.690mm |
| C20.1 → U1.46/VDD3P3_CPU | 2.353mm | 11.860mm |
| C21.1 → U1.46 | 2.763mm | 16.353mm |

源码与四层走线图交叉查看：C20/C21位于U1上方，但3V3从顶层接入内层22，绕到U1左侧，再由现有顶层网络回到供电脚。例如C20路径涉及 `ggeRF0928T247/T246/T245`，C21涉及 `T250/T251/T246/T245`；U1上沿供电横向支线包含 `ggeRF0928T254`。这些是可定位的绕行，不是单纯看外观说“电容近就好”。

C21.2到最近GND过孔中心约2.697mm；C20.2到最近GND过孔中心约0.949mm。这个最近距离不是回流长度，也不代表某个孔已与该焊盘直接相连；用于定位需要核查的地返回。

**建议试排**：保留C20/C21/U1中心和现有器件值，先评估在U1上沿增加/重构直接的3V3接入支线，让储能电容不必经过上述内层绕行才接近芯片；同时评估C21地端的近处接地孔/地支线，组成短供电与返回回路。优先保留完整内层1地参考，不为这条支线割裂参考地。

**收益**：降低储能/高频去耦路径寄生，收益通常比把已经短的MLX去耦再缩零点几毫米更明显。**代价**：U1上沿0.4mm节距、C20大焊盘及相邻NC脚造成布线限制；须联动查铜距、孔与焊盘、锡膏和回流。不保证一条直线就能放下；属于**保持器件布局的局部布线试排**。现数据不足以断言现板会复位，也没有理由直接换大电容。

## 2. 第二优先：R10到U4.IREF绕行，以及充电去耦

| 当前连接 | 焊盘中心直距 | 当前已解析显式走线路径 |
|---|---:|---:|
| R10.1 → U4.C1/IREF | 2.761mm | 7.398mm，0.10mm线宽、顶/底换层 |
| C6.1 → U4.A2/VIN | 2.562mm | 4.194mm、顶/底换层 |
| C7.1 → U4.A1/BAT | 2.278mm | 3.340mm，底层 |
| C7.2 → U4.C2/GND | 1.424mm | 1.389mm，底层 |

R10的3个图元 `ggeUSB0928T354/T353/T352` 本身总长也是7.397866mm，与上表路径一致；绕到USB壳下再返回。IREF为高阻设定/控制节点，不是负载供电主干，原厂要求设定电阻靠近C1脚。它的直流压降不是主要收益，重点是缩小易耦合的环路、减少换层。

**建议试排**：先以U4位置不变，给R10→C1寻找同面更直接短线；若通道被U6/D3/USB附近走线占据，则仅移动/旋转R10到U4.C1附近，同步让R10地端靠U4地返回。不要先移动充电芯片或USB插座。C6/C7在同一局部顺手比较“电源端朝芯片”的方向和更近位置，保留1µF原值；不单为这点收益大搬元件。

**收益**：设定节点更安静，输入/电池端去耦回路更紧凑。**代价**：需查WLCSP扇出、USB数据/ESD、D3和手焊J2空间。R10是**小范围器件/布线试排**；C6/C7属第二步，不能未经试排承诺无需动其他线。

## 3. 第三优先：C1/R7复位RC移近U1.4

- C1.1→U1.4/MCU_EN：焊盘中心直距5.404mm，已解析路径7.620mm，0.09mm线宽，经 `ggeUSB0928T341/T242` 换层。
- R7.2→U1.4：直距6.435mm，已解析路径7.262mm。
- SW3.1→U1.4按钮支路已解析约19.961mm。按钮可保留机械位置；不能把“按钮远”当作必须移动按钮的理由。

**建议试排**：保持BOOT/RESET实体位置，优先把C1的EN端及接地回路靠近U1.4，再看R7是否一起靠近。复位按钮长支路接到芯片侧RC节点；C1是复位延时/滤波电容，**不是3V3电源去耦电容**，不能和C2功能混淆。

**收益**：芯片侧复位滤波更直接，减少长EN高阻线受耦合的敏感性。**代价**：U1.4附近上下层已有U2、C2、SW1及多条扇出；要试排局部0402位置和回地，不能盲目将C1与C2互换。7.6mm本身不是失败阈值，属于EMI/启动健壮性优化。

## 6. I2C/BOOT普通信号：可整理，优先级较低

- U1到U2的SDA/SCL已解析分别2.540/2.518mm，主控与板载MLX很近，保留。
- U1到U3的两线已解析约14.057/14.065mm；到J4的SDA/SCL见证路径约18.371/10.441mm，涉及内22。存在绕行，但总线最高400kHz，**不需要做差分等长**；优先核真实模块上拉/线缆电容，不为了几毫米新增过孔或削弱地面。
- R8→U1.5/BOOT的已解析路径约18.125mm，按钮SW2→U1.5约7.960mm。若C1/R7局部试排时有自然通道，可顺手让R8靠近芯片并简化支路；不要只为了BOOT整齐移动两个实体按键。

## 7. 有限实施顺序

建议只先做**一个局部候选：C20/C21供电接入＋R10短支路**；若现有通道不允许，则记录障碍，第二候选再评估C1/R7位置。C2/C9/C10及USB/RF已验证部分尽量保留。

每个候选先在独立未保存文档验证：不改变器件/网络/规则，检查铜、地回流及原厂禁布；重铺铜；原生网络21/21与DRC；比较是否新增错误；保存重开回读；重新导出Gerber差异核验。**本报告仅建议，没有实施或宣称候选可直接生产。**
