# 电气独立复审｜仅审核

日期：2026-10-04。范围：当前 PCB 的器件功能、脚序/网络、供电/充电/启动、USB、传感器。只读检查；没有修改 PCB、原理图、BOM、固件或云端，也没有重跑旧生成器。

## 结论

**基本电路连接合理，未找到新证据证明主控必然无法启动或 USB 数据脚接反。但“设计已经全部闭合、只剩工厂工艺”过强。** 当前还存在 USB 能力边界、电源工作范围/有效去耦证据不足、外接电池和模块条件未核定。可作为注明限制的工程验证样板交给博后评审，不能凭纸面网表一致宣布“各种电脑、所有电量、边充边用均已可靠可用”。

明确区分：

- **确认存在的设计缺口**：没有 VBUS 监测到主控的硬件；充电支路固定开启且不能由 USB 枚举/暂停状态控制。工厂接贴通过不能解决这两项。
- **尚未证明满足、也尚未证明失败**：整机峰值电源余量、低电量/切换瞬态/温升、C9/C10 有效容量、外接模块总线条件。
- **未发现接错**：PICO 供电和 PSRAM 留空、BOOT/RESET、USB D±和 CC、SGM/TLV/Q1/D4 脚序、两颗板载传感器的模式脚与设计地址。
- Q1 0.14/0.15mm 原生 DRC 属铜间距/制造审核；电气拓扑正确不能消除此问题。

## 2. 需要明确处理的事项

### E1｜高优先级：缺少电池自供电 USB 的 VBUS 监测

**确定证据**：当前 `USB_5V` 只连接 J1.A4/A9/B4/B9、U4.A2、D1.1、D4.2、Q1.2、C6.1、R9.1，没有 U1 GPIO，也没有分压/比较器或另一条 VBUS 有效信号。电池供电时主控仍可工作，因此不能从“主控有电”判断 USB 是否有 VBUS。

[Espressif 当前 USB Device Stack 文档](https://docs.espressif.com/projects/esp-usb/en/latest/esp32s3/usb_device.html#self-powered-device)要求自供电 USB 设备监测 VBUS，ESP32-S3 不耐受 5V，需分压/比较器等接口，并要求拔出后检测脚在3ms内变低。当前板不具备该硬件能力。这是已确认的能力缺口。

**不能过度推断**：这不等于 ROM USB Serial/JTAG 一定不能枚举或下载；USB-OTG 应用栈的自供电合规、ROM 下载功能、具体主机的实际兼容性是不同验收项。现有 BOOT/RESET 与数据连接支持后续试验，但没有本板实测证据。

**局部修法范围，尚未实施**：

1. 若需要电池运行时正常 USB 热插拔/自供电应用，选择一个未占用、非 strapping/PSRAM 的 GPIO，增加 VBUS 检测电路，配置相应 USB 栈。优先局部增加分压/检测和必要放电措施；不预设重构整套电源。
2. 不能直接把 USB_5V 接 GPIO，也不能随便选两个高阻电阻就宣布修好：须计 C6、R9、充电器状态、GPIO 阈值、3V3 关闭时的反灌及拔线3ms放电。现有 R9=100kΩ 与 C6=1µF 的名义 RC 是100ms，虽真实还有其他负载，不能据它保证快速检测。
3. 若本轮只做受限验证样板，交接单需明确 USB 自供电热插拔尚未闭合；博后接受验证范围后决定是否先打样。不得把该项转成工厂 DFM 验收。

### E2｜高优先级：固定充电不具备 USB 端口功率状态控制

**确定证据**：U4.C1/IREF 仅连 R10=220kΩ 到地；B2/nCHG 空置；没有控制脚接主控。按 SGM 手册，标称充电电流为 `24000/220=109.09mA`，且 IREF 拉高到足够阈值才可禁止充电。现电路没有此控制通路。

对于普通 USB 2.0 标准下行端口，未配置状态100mA限制已有官方测试定义；在正常恒流充电时，109mA这一支路已高于该值，还没计算主控和传感器。暂停时也不能依靠软件停止这条支路。现板没有 BC1.2 或 CC 电流能力检测，所以不能用“USB-C都能供大电流”关闭该项。[USB-IF Full/Low-Speed 测试规程 C-14/C-15](https://www.usb.org/sites/default/files/USB-IFTestProc1_3.pdf)、[USB-IF 暂停电流更新](https://compliance.usb.org/index.asp?UpdateFile=Electrical)。

这是**特定端口条件下不受控制的设计限制**，不是声称每个主机必然拒绝、也不是声称电池满充时始终109mA。支持充电的端口/适配器可能有其他允许条件，须逐类确认；没有识别能力时不作通用兼容承诺。

**局部修法范围，尚未实施**：若要求普通电脑端口的一般兼容性，需要在现有 SGM40567 IREF 附近增加默认安全的禁止/使能控制，并把整机枚举前、配置后、暂停时电流预算与固件行为一起闭合。利用 IREF 功能不必自动换充电架构，但必须设计复位/未上电时的默认状态和电平隔离。**仅把 R10 改到充电电流小于100mA不能解决总电流与暂停问题**。若采用受限验证用途，应明确供电端口和充电状态约束；工厂不能替代这个设计决策。

### E3｜中优先级：电源能否覆盖实际负载和低电量尚未闭合

电源连接正确，但不能只凭 TLV755 的500mA额定值判断整机余量。PICO 手册建议电源能力至少500mA，而本板还共享给两个 MLX 模块和 IMU；实际 BLE 负载尚未形成可验证的峰值包络。Q1 在 VGS=-2.5V 的25℃最大导通电阻0.67Ω，与 LDO 压差叠加，低电量时可能离开3.3V稳压区。

复算历史条件示例仍成立：300mA时 Q1 约0.201V，按500mA/215mV线性筛查 LDO 约0.129V，保持3.3V需电池端约3.63V，尚未计线阻/保护板/电池内阻。它不是关机电压或全温保证。USB 5V、D4假设0.3V、负载300mA、3V电池充109mA时，U5/D4/U4合计约0.728W损耗；18mm小板在笔杆内的热不能套用标准评估板热阻直接验收。

下一步：给验证样板指定允许电池工作区间和真实负载场景，测启动、BLE发送峰值、USB插拔时 BAT_P/VSYS/3V3 谷值和温升，再决定是否需局部换 Q1/LDO。**现有证据不支持立即换主控或重做架构，也不支持承诺整电量范围都稳定**。

### E4｜中优先级：C9/C10 的有效容量证据仍缺，不能只转为供货问题

当前 C9/C10 均为 `GRM155R61A105KE15D`、1µF/10V/0402。TI 明确要求输入/输出脚有效容量满足其下限（第3页注释要求有效值大于0.47µF，第15页稳定性阈值为0.47µF或更大），并考虑直流偏压。当前准确料号已补齐，但尚无对应工作偏压、容差/温度/老化组合或等效实证来关闭该项；C20远端22µF不能直接当作U5本地C10的证明。

这是“未证明符合”，不是已证明电容不合格；不能据资料缺失直接增容。下一步限定为核准这两处准确料号的有效容量/等效证据，或首板稳定性测试。如果确需替换，先在同封装可用料中选有明确依据的型号，再评估浪涌与焊盘，不自动扩大电容/板径。[TI TLV755P](https://www.ti.com/lit/ds/symlink/tlv755p.pdf)。

### E5｜中优先级：外接器件条件要在接线/首上电前落实

- 电池未选：U4是4.2V型，F硬接地；板上无独立过放保护、NTC或反接保护。因此必须使用与充电电压/电流匹配、放电能力足够、保护和允许温度明确的电池。109mA只是标称值，1%电阻公差不是总误差。可以先完成板级图纸，但不能先给任意裸电芯充电。
- SW1是三焊盘而非已选开关：1=GND、2=REG_EN、3=VSYS。若三线SPDT使用，应选先断后接类型；先接后断会瞬时把VSYS和GND接在一起。已有R11默认下拉，也可用两线SPST只接2/3并留1不用。接线要求可在装配说明解决，无需先改PCB。
- J4仅共享3V3/GND/SDA/SCL，没有独立供电或热插拔保护。外接模块不要同时由另一电源供电；应核对模块丝印、上拉并联、电容/线长后再上电。这不是要求新增连接器或测试点。

## 4. MLX 地址必须按封装区分

原厂 [MLX90393 Rev012](https://www.melexis.com/-/media/files/documents/datasheets/mlx90393-datasheet-melexis.pdf)第4页型号表明确：

- **LQ/UTDFN-8、ABA-011：0010000，即7位0x10。** 第8页脚表没有 A0/A1；U2.4/6/7不是地址脚。
- **LW/QFN-16、ABA-011：00011xx，即0x0C–0x0F**，A1/A0决定低两位。不能把LW基址0x0C套用给板载LQ。

J4笔头0x0E是冻结设计目标，并出现在当前原理图注释“笔头实测地址0x0E”和旧 `firmware/mlx90393_sensor/mlx90393_sensor.ino` 的 `SENSOR_ADDRESS=0x0E` 中。**本轮没有找到针对当前要接的具体笔头模块的扫描记录，这两处文字/配置不是实物扫描证据。** 若笔头实际为LW-011且A1=1/A0=0，0x0E成立；否则按实物识别。现有板载0x10与预期0x0E不冲突，但不能把“两颗同时已实测通过”写进验收。

旧固件目前只服务一颗0x0E MLX，使用 `Wire.begin(D1,D2)`，不应直接视为当前 GPIO1/GPIO2、双MLX＋IMU＋BLE 的验收固件。此为样板测试准备项，不是要求在本次PCB画图任务内把应用固件全部重写。

## 5. 对交付文字的建议

可以写：**“图纸、连线和仅审核制造资料已形成；未见本次可确认的接反/缺关键供电脚。保留Q1制造提示；USB自供电/端口电流控制与电源范围等条件尚未闭合，供博后决定验证样板范围或局部修正。”**

不宜继续写成：**“板已全部完成，只剩工厂确认和实测。”** 工厂能够确认铜间距、钢网、填孔和贴装，不能补上缺失的 VBUS 信号、充电使能控制或定义系统允许工作电压。

首板测试最小集合：已装配板首上电先用受控限流的5V供电，核3V3和充电支路；再用匹配电池验证BOOT/RESET、两插向USB枚举/下载；扫描0x10/0x6A/笔头实际地址；在实际BLE负载下测冷启动、低电量、USB插拔与温升。以上是明确有限的验收步骤，不增加续航时长或笔杆重画要求。
