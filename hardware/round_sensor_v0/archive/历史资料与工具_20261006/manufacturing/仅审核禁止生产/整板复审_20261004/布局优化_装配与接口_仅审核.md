# 布局优化：装配、接口与按键｜仅审核

日期：2026-10-04。输入为最终保存重开PCB，SHA256 `a8684a5901e8e6eeb518c6be978b76a4d726909f01af73e78e8c9d96e2d8a9c8`。本轮只读分析，没有改板、重新布线或原生试排。

## 建议顺序

| 优先级 | 有证据支持的改善 | 改动范围与收益 |
|---|---|---|
| 先做 | 清理压焊盘的丝印；明确C30/C31本轮不印锡 | 只动丝印/锡膏，保留铜、走线、元件位置；已经有最终Gerber证据。 |
| 先做资料 | 底面装配图画出USB四个贯穿壳脚焊区；给J1补贴装坐标基准说明 | 防止把壳脚区域误认为底面空白；不改变PCB。 |
| 可选改善 | 如果需要集中操作BOOT/RESET，验证SW3移动到SW2附近 | 找到有限几何预筛位置；仍需重连EN/GND、原生DRC及结构操作空间核验。 |
| 保持位置 | J2/J4/SW1手焊接口、USB主体及现有紧密阻容区 | 没有找到需要为装配而立即挪动的证据；优先规定接线、应力释放及测试方式。 |

## 1. 按键能否放在一起

SW2=BOOT、SW3=RESET，目前中心距 **12.5997mm**。靠拢可能方便设置同侧操作孔及下载时连续操作，但两个小按键太近也可能误触，是否更方便仍取决于笔杆压杆/操作孔。它是可选的人机改善，不是电路完整性缺陷。

这次实际做了有限只读空间筛查：保持SW2和其余全部元件不动，在顶视投影左侧区域，试算SW3中心 `X=15.5～18.5mm、CPL Y=73.0～82.0mm`、0.1mm网格、相对0°/90°，共 **5642种**几何位置。

筛查条件：

- 原尺寸铜PAD，不缩焊盘；铜到板框中心线至少0.30mm。
- 与现有底面PAD/TRACK/VIA异网显式铜至少0.15mm，不放宽原间距。
- 按键最大本体1.7×2.7mm；与其他同面器件本体、USB四个贯穿壳脚焊区、9个手焊焊盘之间，另设0.20mm装配筛查余量。该0.20mm是本次选用的筛查条件，不冒充器件厂家强制值。
- 不把可重铺的地铜缓存视为永久不能挪动的实体；因此还必须重新铺铜和核查电气连通。

**加强全部接口障碍后只有3个网格点通过几何预筛**，均需相对旋转90°，中心CPL坐标为 `(17.6,74.5)`、`(17.7,74.5)`、`(17.8,74.5)mm`。以第一点为例：

| 指标 | 只读预筛结果 |
|---|---:|
| 与SW2中心距 | 3.7662mm |
| 最大本体至器件/USB壳脚焊区最小间隙 | 0.26445mm |
| 异网显式铜最小间隙 | 0.38173mm |

这个位置处于USB左侧两个壳脚焊区之间，是**值得正式局部试排的区域**。还没有验证新RESET走线能接回原MCU_EN而不造成新冲突，也没有验证底面实际焊缝、按键压杆与笔杆开孔。因此**不能给出“直接把它拖过去就完成”的操作承诺**。

现SW3脚边直接接触的EN导线是 `ggeUSB0928T240`、`ggeUSB0928T244`；移动时它们及旧EN支路需要重整，两只地脚需要重新接地。两段是直接接触项，不代表总共只需改两段。后续正式尝试须保存新恢复点、局部改线、重铺铜、原生DRC/未连接检查，再保存重开和更新坐标；仍不移动USB或改变板径。

初筛曾给出更近的 `(17.0,75.6)mm`，但其本体可能覆盖USB壳脚焊区，已在加强筛查后**撤销**；不得把该点或早期98个弱筛结果当作可行方案。源板没有被写入任何候选。

证据：[按键靠拢_有限空间筛查.json](按键靠拢_有限空间筛查.json)。坐标是CPL正Y的未镜像顶视投影，从底面实际观看左右相反。有限网格无解或只有3点不代表整个布局全局无解。

## 2. USB壳脚与装配图

USB为顶装，但4个金属化固定槽及其底面铜盘占用底面焊接空间。现有装配图按“元件所属面”筛选，会把顶装J1的这4处从底图漏掉；它们在真实Gerber中存在。

建议下次更新图纸时把这些贯穿铜盘在底图标成“J1壳脚焊区”，并保留其到相邻器件的维修/焊缝通道。不能因底图没画而在这里塞一个电容或按键。这项是图纸补足，不需要改现有铜。

现有USB外伸、固定槽、NPTH几何没有给出必须整体挪动接口的证据。-060壳脚与0.8mm板的焊接、USB插拔支撑交给具体制造/结构方案确认；不是默认更换插座或扩大圆板的理由。J1机器坐标基准差异另见[制造复审](manufacturing_review.md)。

## 3. 手焊接口与测试可达性

当前接口PAD没有被同面器件本体覆盖，独立筛查的最小名义/部分最大本体间隙为：

- J2：约0.640mm。
- J4：约0.740mm。
- SW1：约0.563mm，三者中最紧。

这些是平面几何，并不是烙铁头和绝缘线已试装。**目前优先保留接口位置**，在装配说明规定先完成飞线和检查、再装入笔杆；控制露铜线头，避免邻盘跨锡；线束在结构中做应力释放，让拉力由固定点承担。未取得线径/线头和笔杆实装证据前，不把J4的0.6×1.0mm焊盘称作已验证的最小手焊方案。

测试可利用已有接口：J2可接测试电源/量电池支路，J4可测3V3/GND及I2C，SW1公共端可检查使能；USB配合SW2/SW3验证下载。现阶段没有证据要求恢复已取消的J3或增加专用测试排针。量小型芯片脚的风险应通过转接线和现有大焊盘降低，不为这一轮审核添加新PCB功能。

## 4. 密集器件区不建议为“看起来整齐”盲目挪动

当前38件SMT的同面名义本体筛查未发现互相覆盖；最紧两对为R10/U6、R3/R4，约0.30mm。它们在USB和保护器件局部区域，移动可能牵动数据线、参考地和保护支路。0.30mm不等于已完成焊接/返修公差验收，但现有证据也不要求单纯把它们摊开。

如果下一轮因USB回流、去耦或电源性能必须局部重布，应把这些器件作为相关局部一起处理；不要先为了视觉对齐移动它们，再迫使数据线绕远。电气优化优先级由整板电气/USB专项决定。

**本子审核结论：**现在最划算的是丝印、DNP锡膏和装配图/基准说明收尾；按键靠拢有实际几何探索空间，但仍是可选的正式试排任务。未发现为了手焊或名义器件本体覆盖而必须增大板径、改USB位置或重画整体布局的证据。
