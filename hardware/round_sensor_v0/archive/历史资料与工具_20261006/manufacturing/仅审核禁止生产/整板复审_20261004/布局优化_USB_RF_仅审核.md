# 当前布局优化机会：USB / RF｜仅审核

2026-10-04。针对源 `a8684a5901e8e6eeb518c6be978b76a4d726909f01af73e78e8c9d96e2d8a9c8` 直接读取铜图元，重绘局部顶/底面图查看。未改 PCB、元件、规则、云端或原理图；没有执行重布线生成器。坐标为源码转换后的毫米、顶视投影、Y 向下，与同目录独立复审报告相同。

## 简要判断

**有优化空间，最值得试排的是 USB 的局部换层回流与插座侧分支。没有发现可直接删掉两个过孔、直接拉直 RF 就能无代价改善的机会。** 以下按收益和局部改动量排序；只有有明确收益并通过原生铺铜、DRC、参考地和保存回读的候选才值得纳入。

| 顺序 | 区域与建议 | 预期收益 | 代价 / 当前结论 |
|---|---|---|---|
| 1 | U1 USB 两换层孔 V300/V303 周围，审查是否能增加有效的共同回流孔或调整现地孔 | 缩短信号跨 L1/L4 时 L2/L3 之间的回流绕行 | 已找到局部铜间距够的候选点，但离 PICO 中央铜盘太近；不能直接新增，需先解决焊盘/钻孔工艺问题 |
| 2 | J1–U6 的 DM 分支及 V314 区域局部试排；必须同时看 D+ 两分支及回流 | 缩短绕到连接器前侧再返回底面 ESD 的分支，减少不对称 | D3、U6、DP 横线及反焊盘限制明显；尚无通过的替代路径，不声称只挪一个孔就可解决 |
| 3 | 若必须减少信号换层，再试排 R3/R4 移到顶层两侧可用区域 | 理论上有机会减少主控侧的两个信号孔 | 当前 U1/J1 正中缝隙放不下电阻，也放不下新差分通道；要连带改布局，收益未必胜过代价 |
| 4 | 保留现有 RF 主绕行；只在有实测/明确几何改善时局部微调 C30/R30 一侧 | 避免为“线更直”破坏 50 Ω参考地及已有边距 | 当前长段绕开 U1 及其焊盘，贴近行进走廊；未验证出值得改的缩短方案，优先级低 |

## 1. USB 主控侧回流：有具体试排点，但还不是可直接添加的孔

当前 V300/DP_SOC 在 `(23.8501,−79.3600)`，V303/DM_SOC 在 `(23.0500,−79.3600)`。两信号孔间距约 0.8001 mm。已有有效地孔：V326 `(24.3502,−79.4799)`、V316 `(22.4500,−79.3999)`，分别位于信号对外侧。最近回流距离约 0.514/0.601 mm，次近约 1.401/1.201 mm。并非完全没有回流孔，但还没有形成经验证的完整过渡设计。

**只读探针结果：** 使用板上已有的外径 0.25 / 孔径 0.15 mm，试查 `(23.4500,−79.5600)`：

- 到 V300/V303 中心均约 0.447 mm。
- 与已解析异网铜最小约 0.1974 mm；与现有钻孔孔边最小约 0.2972 mm。
- 点位在当前 L2、L3 的实际地铜内。
- 但是 U1 中央大焊盘外缘位于 Y≈−79.73997 mm，新孔孔边距它仅约 **0.105 mm**，小于本项目当前采用的0.20mm制造筛查值；具体同网大焊盘邻孔条件仍须国内工厂确认，不把历史0.254mm或一般0.25mm指南当作现行统一门槛。不能因同为 GND 就忽略焊接影响。此点虽然没有钻进中央铜盘，仍可能影响附近焊接，不能直接批准。

向下移到 `(23.4500,−79.4000)` 以远离大焊盘，则被 USB 顶层扇出挡住：最小异网铜距仅约 **0.101 mm**，而且该点不落在当前两个内层的完整地铜内。右侧 `(24.10,−79.80)` 又与底面 3V3 的 `ggeUSB0928T326` 相交。

**可执行方向：** 若继续优化，应在这一区域同时试排 USB 扇出/既有回流孔和少量 3V3 支线，保持 U1 与 R3/R4 主位置；以补到有效回流、且不增加盘中孔/焊接负担为验收目标。上述坐标是障碍证据和起点，不是建议直接落孔的生产坐标。

## 2. 插座侧分支：优先缩短 DM，但不要重复已失败的单孔试挪

当前结构是：J1 的四个 USB 数据焊脚沿 X 方向交错为 DM、DP、DM、DP；同极性脚需要分别合并。DP 通过 V308 `(22.7371,−75.9000)` 与 V310 `(23.7371,−75.9000)` 在底面合并；DM 在顶面合并，再绕到 V314 `(22.0599,−75.1401)`，底面返回 U6.2 `(22.2000,−76.3001)`。

因此，**插座端的三个信号孔有当前拓扑原因**。直接删除 DP 其中一个孔，无法保持两种插向的原有连接；只留下 USB-C 一组数据触点会破坏另一插向，不是可选的省孔方案。

试排范围建议限制为 X≈21.8–23.9、Y≈−76.7至−74.9 mm，涉及 J1 数据脚、U6、D3、R10，以及 U4 IREF 附近孔 V324。目标是让 DM 的合并点/换层点更接近 U6，并检查能否保持 DP/DM 更接近共同的返回通道。

当前具体限制：

- U6 在底面 `(22.5500,−76.8000)`；其 DP/DM 盘在 Y≈−76.3001，GND 盘在 Y≈−77.3001。将换层孔挪到保护盘附近会遇到钻孔到 SMT 盘/锡膏的限制。
- D3 占据 DM 分支左侧，底面 DP 横线占据右侧；顶面 DM 合并支线也限制新增回流孔。
- V308/V310 最近地孔分别约 0.750/0.460 mm，次近约 1.413/1.240 mm。仅缩短信号线而让它经过两个信号孔合并后的反焊盘缺口，可能使参考地退步。
- 历史 J/K 单孔短路程候选已经因原生铺铜后的新中心线缺地被拒绝。此次未重复生成这些候选，也没有把历史失败方案重新称为优化。

这项优化需要小范围联合试排，可能要挪 U6/R10 或调整 IREF 周边，代价中等；本次只读审核尚无通过的替代几何。若用户希望尽快交博后打首板，可保留现版并保留明确 USB 风险，不必为理论线长强行重做。

## 3. 减少 5 个 USB 信号孔：当前布局不能只删孔，需要摆件先让路

当前 R3/R4 在底面，中心分别 `(23.8500,−78.4000)`、`(23.0500,−78.4000)`。主控侧两个信号孔把顶面 U1 引脚引到这两个底面电阻；插座侧三个孔又与底面 U6 及交错触点连接有关。

从最终铜盘边界实读：U1 USB 所在行外缘 Y≈−77.99979 mm，J1 数据焊盘最近端 Y≈−77.81549 mm，中央裸铜间隙只有 **0.18430 mm**。单根 0.17 mm 线加两侧各约 0.15 mm 间距已需要约 0.47 mm，0402 电阻焊盘占用更大。因此不能把 R3/R4 直接翻到 U1 与 J1 之间，也不能从这条缝再穿一对线。

在重新寻找两侧顶面位置并联合调整保护/走线后，理论上可能利用插座既有换层合并而减少主控侧两个孔；**当前没有已验证的 5→3 或 5→4 方案**。这会触及摆件、ESD路径、CC/电源支线和贴装空间，不能仅凭孔数下降判断更优。只在前两项局部优化不能达到目标时再试排，不建议作为本轮必须完成的改板任务。

## 4. RF：12.4 mm 有绕行，但不是任意多余绕线

RF_SOC 当前 12.396462 mm，从 U1 左侧 RF 脚 `(18.4494,−84.3399)` 绕过 U1 上侧，再到 C30/R30。最长直段是 `(18.15,−85.73)` 至 `(24.75,−85.73)`，约 6.60 mm；线边到 U1 顶侧焊盘的实际最近距离约 **0.17510 mm**，距 0.15001 mm 规则仅多约 0.025 mm。

从 RF 脚到 R30.1 的无障碍直线仅约 9.319 mm，但会穿过 U1 本体/焊盘区域；这个数字不能作为可实现的缩短目标。当前绕 U1 的主路径没有明显无用途回折，RF 全顶层、无信号孔，L2参考地已有较完整取样证据。为了省几毫米旋转主控、挪天线或引入 RF 换层，会牵动电源、USB和传感器通道，超出低代价优化。

R30_2 当前为 2.815264 mm，连接 C31 调谐位与 ANT1；比历史2.771 mm略长。末端有非45°的小段，但不能只为外观改直而越入 U.FL 净空、减少参考地或改变调谐盘连接。若将来已有实际 RF 测量指出问题，再联合匹配位和最终层叠处理；此次没有发现值得优先改铜的 RF 缩短方案。

## 接纳任何候选前的有限验证

只需要针对发生变化的区域重新核查：各插向连通、异网间距/孔距、实际 L2/L3 参考地与回流、SMT钻孔/锡膏、原生 DRC/网络、保存回读及制造输出差异。不得为纳入候选放宽规则，不能以“孔更少”或“线更短”替代上述检查。
