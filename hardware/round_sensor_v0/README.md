文档更新：2026-10-08；当前板图及审核记录日期：2026-10-06。先看当前入口；历史文件不用于下单。

## 板子的用途与功能

这块圆形板是 FYP 传感毛笔的采集与通信核心，目标是安装在笔杆内，读取笔头和板载磁传感器、采集笔杆运动信息，并通过 USB 或蓝牙把数据传给电脑。上位机再结合书写图像、标定和算法，用于人类书写示范记录与后续机器人复现。

下表依据当前[五页原理图](easyeda_std/Q1直接修复_20261006/SCH_Q1替料_最终五页回读_20261006.json)、[原生网表](easyeda_std/Q1直接修复_20261006/SCH_Q1替料_原生整图网表_20261006.net)及[准确BOM](manufacturing/仅审核禁止生产/Q1直接修复_20261006/BOM_36件准确料号_Q1修复_仅审核_20261006.csv)，描述已画入板图的硬件与预期用途；整板功能仍待固件和首板实测。

| 功能 | 对应硬件 | 用途 |
|---|---|---|
| 传感器采集与处理 | U1：ESP32-S3-PICO-1-N8R8 | 通过 I²C 读取传感器，由固件完成时间戳、基线处理和数据打包，再送往电脑 |
| 笔头磁场采集 | J4 外接 MLX90393 模块，设计地址 `0x0E` | 读取笔头三轴磁场；结合磁体与柔性结构记录接触/形变相关变化，后续经标定提取触觉指标 |
| 板载磁场采集 | U2：MLX90393，设计地址 `0x10` | 提供第二组三轴磁场数据，供后续与笔头信号对照；参考补偿方法及效果待实验确定 |
| 笔杆运动采集 | U3：LSM6DSOX，设计地址 `0x6A` | 读取三轴加速度和三轴角速度，供后续分析笔杆倾斜、转动与运动状态 |
| USB 有线连接 | J1：侧插 USB-C；ESP32-S3 原生 USB Serial/JTAG CDC 路线 | 电脑供电、固件烧录/恢复、串口调试及传感器数据传输；枚举、下载与数据链路待到板验证 |
| 电池与蓝牙使用 | J2 电池输入；U1 蓝牙能力；ANT1 板上 U.FL 接口及外接 FPC 天线 | 在不插 USB 时由电池独立供电，计划通过 BLE 发送传感器数据；BLE 采集固件与无线性能待验证 |
| 电源选择与稳压 | Q1：DMP2165UW-7；D4：LMBR4010；U5：TLV75533 | USB 优先的供电路径选择，将系统电源稳压为 3.3 V 供主控和传感器使用；插拔、电流与温升待实测 |
| 启动、复位与关机操作 | SW2：BOOT；SW3：RESET；SW1 外接开关焊盘 | BOOT/RESET 用于下载恢复和复位；SW1 控制主系统 3.3 V 使能。正常应用启动后短按 BOOT 选择蓝牙的行为仍是固件方案 |
| USB 接口保护 | CC 下拉、USB 数据线 ESD 器件及电源入口保护器件 | 提供 USB 接口所需连接与保护电路；保护器件已画入，整机 USB 电气条件仍待审核和实测 |

### 两种计划使用方式

- **USB 采集**：连接电脑，电脑端明确开始后采集并传输。USB 掉线、电脑断电或会话结束时停止任务，不自动转为蓝牙继续采集。
- **电池/BLE 采集**：不插 USB，接入受保护单节电池，启动时人工选择蓝牙；接收端连接并明确开始后采集。连接丢失或明确停止时结束任务，再次采集需人为启动。

上述启动、停止及三器件采集流程尚未实现。Q1/D4 的硬件供电选择与固件任务选择是两个层面：USB 拔除后电池仍可能给电路供电，结束采集不等于断电，关闭主系统 3.3 V 使用 SW1。当前板不具备板载充电功能，电池取下后用匹配的外置充电器充电。

### 外部接线与数据边界

| 接口 | 接线定义 |
|---|---|
| J1 | USB-C：接电脑供电、烧录、调试与数据传输 |
| J2 | `1 = BAT_P（电池正极）`，`2 = GND（电池负极）`；通过板外可拆连接接入受保护单节电池 |
| J4 | `1 = 3V3`，`2 = GND`，`3 = SDA`，`4 = SCL`；四个飞线焊盘接笔头模块，模块端按实物丝印核对 |
| ANT1 | 板上 U.FL 插座，连接外置 FPC 天线 |
| SW1 | 外接三线 SPDT 开关：公共 `2 = REG_EN`，两端 `1 = GND`、`3 = VSYS` |

I²C 设计引脚为 `GPIO1/SDA`、`GPIO2/SCL`，三个地址仍待实物扫描。磁传感器直接提供磁场数据，压力/接触指标需机械标定；IMU 的原始加速度与角速度也不能直接当作绝对笔尖 XY 轨迹。现有[单 MLX 采集草图](../../firmware/mlx90393_sensor/mlx90393_sensor.ino)和[Delta-B 记录工具](../../tools/record_delta_b.py)可作迁移参考，其旧硬件 100 Hz 记录不代表本板三器件采样或 BLE 链路已经通过。完整状态与验收事项见[当前交接](CAD_HANDOFF.md)。
