# 冻结需求：XIAO 功能体验的小型圆板

更新：2026-10-06。用户后续明确要求优先；本页描述目标和已确认选择，不代表工程已全部修改或实物验证。

## 保留功能

- 参考 XIAO ESP32-S3 已满足需求的 USB/电池使用体验，重绘尽可能小的圆形板，放入 3D 打印笔杆。
- 主控沿用 `ESP32-S3-PICO-1-N8R8` 方案；暂时保留板载侧插 USB-C，允许插座外壳局部超出圆板，由笔杆结构配合。暂停 USB 转 UART 替换方案。
- 电池独立开机，用蓝牙传输传感器数据；保留3.3V供电。2026-10-05确认可拆电池取下后板外充电，取消板载充电目标。不要求两小时续航，不新增续航门槛。
- 外接 FPC 天线，通过 U.FL 接口；保持右上角、顶层。2026-09-29 用户允许为满足板边间距做局部内移，已验证位移 (-0.15,+0.03) mm，不改变天线方案。
- 板载 LSM6DSOX IMU 和 MLX90393；笔头另有 MLX90393 模块，两颗均保留。
- BOOT、RESET 为实体按键；取消独立下载/测试焊盘 J3，但保留必要功能接口。
- 2026-10-05用户确认USB用途包含烧录、串口调试和传感器数据传电脑。当前实现路线采用ESP32-S3原生USB Serial/JTAG CDC；USB数据功能的选择不替代系统USB电流及电池自供电插拔审核；板载充电支路已删除。

## 笔头接口 J4

四个表面飞线焊盘：1＝3V3、2＝GND、3＝I2C_SDA、4＝I2C_SCL；不加中断线、连接器、排针或穿线孔。按实物模块丝印接线，不假定模块物理针序与本板一致。

当前铜几何候选为每焊盘 0.6×1.0 mm、节距 0.9 mm、铜包围框 3.3×1.0 mm。保留禁开钢网设置并在制造输出复核；线径、手焊、间距和笔杆内应力释放仍需实物验证，不能宣称已经最小。

笔头固件地址 0x0E，板载 MLX90393 设计地址 0x10，IMU 设计地址 0x6A。这些不是三器件实物扫描结果；总线上拉、电平、线长/电容与反灌仍须验证。

## 电源和精简边界

2026-10-05用户先澄清插USB由电脑供电，随后确认电池取下后单独充电。2026-10-06进一步澄清：启动时选择USB采集或电池/BLE采集；USB模式中电脑断电/拔USB表示人为结束任务，停止采集和传输，不自动转BLE继续。电池仍能独立启动运行，板子不充电。保留USB优先的硬件供电选择；该硬件选择不代表固件自动切换任务，也不代表端口总电流、暂停及插拔条件已验证。

本次已完成的局部改动：删除SGM40567充电器U4、设定电阻R10及专用支路；保留Q1/D4供电切换（2026-10-06 Q1已从LP0404N3换为DMP2165UW-7，D4仍LMBR4010）、TLV75533稳压及C6/C7电源滤波。本轮已在原工作工程实施并保存重开，41元件/20网络原生核验，详见CAD_HANDOFF.md。J2保留两焊盘，电池拆装通过板外短引线的可插拔连接实现，具体插头随电池落实；电池仍需带保护，外置充电器须匹配电芯。不得用反复拆焊电池线替代可拆连接。不恢复早期复杂USB唤醒、比较器或充电管理网络。

必要保护、去耦、启动电路、载流/热约束不得为省面积删除。USB、电池供电及板外充电的目标体验不等于全部已验证，边界工况须基于现电路审核，不套用已淘汰架构的结论。
