# 五类笔画离线识别模型

最终模型：`model.joblib`，StandardScaler＋linear SVC，使用十次随机实验的50个有效笔画训练。

## 查看成果

打开 `训练成果可视化.html`，无需网络。下拉选择50个样本，可看留出预测、模型输入和五类判别分数；其中的样本展示使用未见过该次运行的折模型，不是最终模型的训练集成绩。

完整结果见 `训练报告.md`。固定linear的开发分组CV为48/50；包含内层选核的建模流程外层CV为47/50。最终全量模型仍需全新实验验收。

## 离线预测一笔

在含有 requirements.txt 的本成果目录下，使用 Python 3.10 环境安装依赖：

```bash
python -m pip install -r requirements.txt
```

原始单笔CSV需保留 seq、sensor_t_us、dBx_uT、dBy_uT，以及至少100个连续有效的写前采样；提供active开始、结束的seq。没有额外的真实标签输入。

可直接运行的接口示例：

```bash
python predict_stroke.py --sensor-csv example_single_stroke.csv --seq-start 5689 --seq-end 6942
```

此例来自训练数据，只验证模型加载与接口，不是新的准确率验证。

对新实验归档选择一笔：

```bash
python predict_stroke.py --archive /绝对路径/新实验.brushrun --stroke 3
```

`--stroke`只选择measure窗口边界，笔顺编号不进入128维输入。

也可以输入已经按本模型定义处理好的128点Δr向量（.npy）：

```bash
python predict_stroke.py --features-npy /绝对路径/单笔特征.npy
```

输入不是图片，也不是直接把原始dBx/dBy或日志a_control列当作128点特征。严格计算定义见 model_metadata.json；不同预处理不能混用。

## 输出

输出预测标签和五类OVR判别分数；分数不是概率。类别为右点、横折钩、横撇、撇、捺。模型没有自动切段或未知类别拒识功能。本轮没有改动现有机器人控制代码或设置。

本次训练的隔离解释器位于 `/tmp/fyp-stroke-training-20261106/bin/python`；如该临时环境被清理，可在新的独立环境中按requirements.txt重建。
