# StrokePlan 中笔杆倾斜与旋转的获取方案

## 1. 项目目标修正

本项目不采用 Guo 论文中的：

\[
\text{笔画宽度}\rightarrow Z\text{压入高度}
\]

而采用磁式软触觉信号直接描述并控制毛笔接触状态：

\[
\text{目标触觉状态}\rightarrow Z\text{前馈与反馈控制}
\]

因此 `width_target` 不是 StrokePlan 的必要字段。笔画宽度可以在实验结束后作为视觉评价指标，但不参与当前控制参考的生成。

当前真正需要的 StrokePlan 是：

\[
\mathcal S=
\{t_i,s_i,x_i,y_i,g_{d,i},z_{ff,i},\mathbf R_{d,i}\}
\]

其中 \(\mathbf R_{d,i}\) 表示沿笔画变化的目标笔杆姿态。

## 2. 必须区分的三个量

### 2.1 笔杆绝对姿态

它表示笔杆相对于纸面或机器人世界坐标系的方向：

\[
\mathbf R_{WB}(t)\in SO(3)
\]

它包含：

- 向哪个方向倾斜；
- 倾斜多少；
- 绕自身轴旋转多少。

### 2.2 毛笔相对弯曲/触觉状态

磁传感器主要反映磁铁相对于传感器的位移或方向变化，例如：

\[
\Delta\mathbf B(t)
=
[\Delta B_x,\Delta B_y,\Delta B_z]^T
\]

它更接近笔毫/柔性触须相对笔杆的弯曲状态，不天然等于笔杆在世界坐标系中的绝对姿态。

### 2.3 机器人实际末端姿态

执行时，Elfin 编码器和正运动学可以返回：

\[
\mathbf R_{WE}(t)
\]

它能告诉系统机械臂实际把工具保持成什么姿态，但不能凭空告诉系统示范者原本希望采用什么姿态。目标姿态仍需要由示范、规则或优化产生。

## 3. 磁触觉信号能不能直接得到倾斜和旋转

不能直接认为：

\[
(\Delta B_x,\Delta B_y,\Delta B_z)
\equiv
(roll,pitch,yaw)
\]

原因是磁场同时受到以下因素影响：

- Z 压缩；
- XY 方向弯曲；
- 毛笔与纸面的摩擦；
- 笔杆倾斜；
- 磁铁和传感器装配误差；
- 变形历史和迟滞。

尤其是绕笔杆自身轴旋转时，如果毛笔、磁铁和传感结构接近轴对称，旋转可能几乎不可观测。

因此磁触觉适合获取“接触状态和弯曲方向”，但在没有专门标定之前，不适合单独作为笔杆绝对姿态测量装置。

## 4. 目标倾斜和旋转从哪里获得

有三条路线。

### 路线 A：直接记录人的毛笔示范

人在纸面书写时，同时记录：

- 笔尖 XY；
- 笔杆六自由度姿态；
- 磁触觉信号；
- 统一时间戳。

这样可以直接生成：

\[
x(t),y(t),\mathbf R_d(t),\mathbf B_d(t)
\]

这是最符合“复刻示范笔画”目标的路线。

#### 可选测量方法

| 方法 | 能获得的信息 | 主要限制 |
|---|---|---|
| 双相机/多相机 + 非对称标记 | 完整 6D 笔杆位姿 | 标定和遮挡处理较复杂 |
| 单相机 + AprilTag/ArUco 标记板 | 近似 6D 位姿 | 深度、遮挡和抖动较敏感 |
| 光学运动捕捉系统 | 高质量 6D 位姿 | 成本高 |
| IMU | 重力方向，因此可测倾角 | 单独使用时绕竖直轴的 yaw 会漂移 |
| 编码式旋转套环 | 轴向旋转角 | 需要改造毛笔结构 |

#### 推荐的低成本组合

在笔杆上固定一个非轴对称的刚性标记架，例如多个不共面的 AprilTag/ArUco 标记，再使用两台已标定相机：

```text
相机1 ─┐
       ├─→ 标记架6D姿态 → 笔杆姿态
相机2 ─┘

磁传感器 ─────────────→ 接触/弯曲状态

纸面图像/笔尖检测 ────→ XY路径
```

非对称标记非常重要。只有笔杆中心线时，可以测得倾斜方向，却无法唯一确定绕笔杆轴的旋转角。

### 路线 B：用机器人进行示教

如果允许人引导机械臂或通过界面逐段设置姿态，可以直接记录机器人 TCP：

\[
[x,y,z,R_x,R_y,R_z,t]
\]

优点是数据可以直接回放，坐标转换更简单。缺点是 Elfin 是否支持足够顺畅、安全的拖动示教，以及毛笔接触时人能否自然表达细微调锋，需要实际验证。

### 路线 C：从目标墨迹反求姿态

可以把姿态作为优化变量：

\[
\min_{\mathbf R(t),g_d(t),v(t)}
L(I_{robot},I_{target})
\]

但同一个墨迹可能由不同的姿态、速度和接触状态产生，因此这是一个不唯一的逆问题，需要大量实验或学习模型。它不适合作为当前项目的第一种数据来源。

## 5. 推荐的采集坐标关系

定义：

- \(W\)：机器人世界坐标系；
- \(P\)：纸面坐标系；
- \(M\)：相机标记坐标系；
- \(B\)：笔杆/工具坐标系；
- \(E\)：机器人末端坐标系。

示范采集时，相机测得：

\[
\mathbf T_{CM}(t)
\]

通过纸面相机标定得到：

\[
\mathbf T_{PC}
\]

通过标记架到笔杆的固定外参得到：

\[
\mathbf T_{MB}
\]

则笔杆在纸面坐标系中的位姿为：

\[
\mathbf T_{PB}(t)
=
\mathbf T_{PC}\mathbf T_{CM}(t)\mathbf T_{MB}
\]

再通过纸面到机器人世界的标定：

\[
\mathbf T_{WB}(t)
=
\mathbf T_{WP}\mathbf T_{PB}(t)
\]

这条变换链必须固定并记录，否则人的姿态数据不能直接变成机器人姿态命令。

## 6. 姿态如何存入 StrokePlan

推荐保存单位四元数：

\[
\mathbf q_i=[q_w,q_x,q_y,q_z]
\]

而不是把 Euler 角作为唯一原始数据。原因是：

- Euler 角存在 \(180^\circ/-180^\circ\) 跳变；
- 某些姿态附近存在奇异性；
- 四元数更适合连续插值。

数据结构建议为：

```python
Stroke(
    t,                    # (M,)
    s,                    # (M,)
    xy,                   # (M, 2)
    g_target,             # (M,)
    z_ff,                 # (M,)
    orientation_quat,     # (M, 4)，可选
    g_vector_target=None, # (M, 2/3)，可选
)
```

执行时按当前 50 Hz 控制时刻同步插值：

- 标量和 XY：线性或样条插值；
- 姿态四元数：SLERP；
- 最终转换成 Elfin `ServoP` 需要的 `Rx, Ry, Rz`。

## 7. 倾斜和旋转不能一步全部闭环

建议先区分前馈和反馈：

### 姿态前馈

\[
\mathbf R_{cmd}(t)=\mathbf R_d(t)
\]

目标姿态来自人的示范，机器人用自身编码器跟踪。第一阶段先做到这一点。

### 触觉反馈

当前磁触觉先只修正 Z：

\[
z_{cmd}=z_{ff}+z_{fb}
\]

等完成方向标定并证明可观测后，才能考虑用 \(\Delta B_x,\Delta B_y\) 修正倾角：

\[
\begin{bmatrix}
\delta\theta_x\\
\delta\theta_y
\end{bmatrix}
=
\mathbf K_b
\left(
\begin{bmatrix}
\Delta B_x^*\\
\Delta B_y^*
\end{bmatrix}
-
\begin{bmatrix}
\Delta B_x\\
\Delta B_y
\end{bmatrix}
\right)
\]

绕笔杆轴旋转通常不能仅靠当前磁强模长反馈，需要机器人编码器、视觉标记或额外旋转传感结构。

## 8. 当前最可行的实施路线

### 阶段 1：固定姿态验证基础闭环

- 圆形 XY；
- 固定笔杆姿态；
- `g_target(s)` 控制接触状态；
- 验证磁触觉 Z 控制。

### 阶段 2：记录而不控制人的姿态

- 在毛笔杆安装非对称视觉标记；
- 同步记录 XY、姿态和磁场原始向量；
- 分析倾角、轴向旋转与 \(\Delta B\) 的关系。

### 阶段 3：姿态开环复现

- 将示范四元数存入 StrokePlan；
- 使用 SLERP 重采样到 50 Hz；
- 通过 ServoP 下发完整 6D 位姿；
- 磁触觉仍只闭环修正 Z。

### 阶段 4：判断是否需要方向性触觉反馈

- 比较姿态跟踪正确时，实际磁场向量是否仍偏离示范；
- 如果偏差稳定且可标定，再增加倾角反馈；
- 轴向旋转优先由机器人姿态跟踪，而不是从磁强模长推断。

## 9. 最终建议

当前不要用笔画宽度生成 Z，也不要试图只用当前的磁强模长反推出完整倾斜和旋转。

推荐的职责划分是：

```text
视觉/多相机标记：获取示范笔杆绝对姿态
磁式软触觉传感器：获取接触程度与笔锋相对弯曲
机器人编码器：测量执行时的实际工具姿态
StrokePlan：同步保存 XY、目标触觉和目标姿态
```

这能够体现项目的核心创新：用触觉状态代替静态的“笔宽到 Z”映射，同时保留倾斜和旋转对细节复刻的贡献。
