# 图像到 StrokePlan：无学习基线

## 项目目的

建立不依赖学习模型的“目标字帖图像 → 可执行 StrokePlan”基线，为完整汉字生成提供第一条可运行路径，也为后续 Transformer 提供必须超过的对照组。

## 当前状态

已实现第一步[整字图片到 XY 几何路径](character-xy-extraction.md)：保留分离部件、分叉区域、环路与点状部分，导出可复核的几何数据和交互式报告。它可在方向校准和磁响应关联之外独立离线使用。

完整计划生成仍待实现。几何路径段尚未定义笔画连接、笔顺、速度与磁目标；后续在几何复核和模板数据的基础上装配 StrokePlan，再进行可执行性验证。

后续已新增[分段模板离线工具](stroke-template-design.md)：从字名/字库先验或人工描点建立有向笔画，输出分段适配和整体缩放对照。横/竖原型覆盖“土、王、干、士”；永字五笔初始模板已支持折/钩锚点分段适配，以及保留正确路径的局部拖动、撤销和整字直接导出。永字自身原型不作为独立保留评价；真实字帖、时间和磁目标仍待独立验证。

## 范围

- 图像去背景、透视校正、尺度归一化和汉字区域分割。
- 笔画分解、笔顺确认、中心线提取、交叉点处理和弧长重采样。
- 标准笔画模板库的检索与参数化管理。
- 通过平移、旋转、尺度和样条形变完成模板迁移。
- 根据路径长度和曲率生成时间/速度，并装配多笔画 CharacterStrokePlan。
- 在执行前进行字段完整性、连续性、工作空间和安全范围检查。

本项目不修改 StrokePlan 数据契约，不训练 Transformer，也不负责真机控制和最终系统评价。

## 输入、输出与依赖

- 输入：目标字帖图像、标准笔画模板、StrokePlan 契约和可选人工笔画标注。
- 输出：完整的 StrokePlan、处理中间结果、失败原因和基线生成指标。
- 依赖：StrokePlan 契约已经冻结；Data Acquisition 提供模板数据；Robot Control 或 MuJoCo 提供可执行性验证。


## 最近一个可验收里程碑

当前几何里程碑：从整字图片提取完整骨架图及 XY 路径段，保留处理依据，能够在 HTML 中选择路径、开关图层并沿弧长检查坐标。字库整字示例覆盖“字、中、永、人、口”，不读取字库笔顺或中心线。

后续端到端里程碑：选择一个结构简单的目标汉字，不使用神经网络生成完整 StrokePlan，通过离线安全检查，并由现有 Runtime 或 MuJoCo 完整执行；同时保存图像处理、笔画分解和模板迁移的中间产物。

## 已知限制与后续讨论

- 单张最终墨迹不能唯一确定速度、提按和笔杆姿态，第一版沿用模板先验。
- 自动笔画分解不可靠时允许人工校正，但必须记录人工介入位置。
- Transformer 只能在同一数据划分和评价口径下与本基线比较。
