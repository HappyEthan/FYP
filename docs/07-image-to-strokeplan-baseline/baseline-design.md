# 图像到 StrokePlan：无学习基线

## 项目目的

建立不依赖学习模型的“目标字帖图像 → 可执行 StrokePlan”基线，为完整汉字生成提供第一条可运行路径，也为后续 Transformer 提供必须超过的对照组。

## 当前状态

项目已经确定边界，但尚未进入实现。应在 StrokePlan 契约和底层执行接口稳定后启动，并先完成少量目标汉字的端到端基线。

## 范围

- 图像去背景、透视校正、尺度归一化和汉字区域分割。
- 笔画分解、笔顺确认、中心线提取、交叉点处理和弧长重采样。
- 标准笔画模板库的检索与参数化管理。
- 通过平移、旋转、尺度和样条形变完成模板迁移。
- 根据路径长度和曲率生成时间/速度，并装配多笔画 CharacterStrokePlan。
- 在执行前进行字段完整性、连续性、工作空间和安全范围检查。

本项目不修改 StrokePlan 数据契约，不训练 Transformer，也不负责真机控制和最终系统评价。

## 输入、输出与依赖

- 输入：目标字帖图像、标准笔画模板、StrokePlan 契约和可选人工笔画标注。
- 输出：完整的 StrokePlan、处理中间结果、失败原因和基线生成指标。
- 依赖：StrokePlan 契约已经冻结；Data Acquisition 提供模板数据；Robot Control 或 MuJoCo 提供可执行性验证。


## 最近一个可验收里程碑

选择一个结构简单的目标汉字，不使用神经网络生成完整 StrokePlan，通过离线安全检查，并由现有 Runtime 或 MuJoCo 完整执行；同时保存图像处理、笔画分解和模板迁移的中间产物。

## 已知限制与后续讨论

- 单张最终墨迹不能唯一确定速度、提按和笔杆姿态，第一版沿用模板先验。
- 自动笔画分解不可靠时允许人工校正，但必须记录人工介入位置。
- Transformer 只能在同一数据划分和评价口径下与本基线比较。
