# 笔画模板库与整字 XY 生成系统介绍

本文介绍截至 2026-10-19 已实现的离线系统，以及如何浏览、检查和使用生成结果。详细算法、参数约定和验证记录见[分段笔画模板设计](stroke-template-design.md)。

## 这个系统解决什么问题

系统将笔画写法保存为可复用的模板，再按照一个字的布局，把这些模板组合成有笔顺的 XY 路径。一个字由哪些笔画组成、每笔放在哪里、主体有多长，以及如何起笔和收笔，都可以分别检查和调整。

当前工作的重点是建立可靠、可修正、来源明确的平面路径，为后续书写计划和磁响应分析提供几何基础。现阶段的结果是 **XY 几何候选**；Z 高度、书写速度、停顿、接触状态和磁响应目标需要在后续阶段补充。

## 模板、布局和配方分别负责什么

| 对象 | 负责的信息 | 例子 |
|---|---|---|
| 笔画模板 | 一种写法的有向 XY、起行收阶段、折钩等特征及参考尺度。 | 长横、短横、左点、卧钩。 |
| 整字布局 | 每笔的位置、方向、主体范围、折转位置及标称宽度。 | “好”中女旁与子旁的位置关系。 |
| 合成配方 | 按笔顺指定每笔使用的模板版本及调整参数。 | 为“好”的第五笔指定竖钩模板和局部尺度。 |

生成过程可以按以下顺序理解：

1. 准备字形图片和有序分笔布局。
2. 确认每笔类型，标出起行收边界以及必要的折、弯、钩位置。
3. 为每笔选择库中的具体写法和模板版本。
4. 根据布局适配模板的主体跨度、弯曲及局部尺度，组合成整字路径。
5. 在 HTML 中检查、局部修正并导出 XY。

目前五字练习集的布局来自本地 Make Me a Hanzi 字体轮廓和有序中线，笔画类型、阶段及折钩标签由人工指定。图片提供布局对照，生成路径采用所选模板的写法。任意网络图片仍需要布局初始化、分笔和人工复核，不能保证自动恢复真实笔顺与笔锋运动。

## 笔画库里保存了哪些信息

一个模板包含笔画类型与写法、来源图片或参考样本、有方向的 XY 点列、起笔／行笔／收笔边界、适用的折钩特征、参考宽度、适配范围和版本标识。检查页还提供来源叠加、阶段显示及相应导出入口。

当前默认笔画库有 **28 类基本笔画、38 套写法候选**：其中 27 套依据教程原图的运笔引导线追踪，11 套保留为有明确标记的规则重建候选。原图引导线与规则曲线都属于几何参考，尚未验证为实测笔尖运动。

同一种模板可以用于不同长度或尺度的同类笔画。例如，较长的横可以主要增加行笔主体跨度，起收笔则按参考宽度缩放并随端部方向旋转。长横和短横在库中也分别保存，适配时可以选择合适的写法。

这里的宽度用于模板归一化和几何适配。调整宽度尺度会影响局部路径形状，不能直接解释为真实墨迹宽度，更不能直接换算成 Z 高度或磁响应。

## 怎样打开和检查结果

打开[笔画与字的资料库首页](../../outputs/stroke_templates/index.html)，即可离线浏览。

1. 首页默认打开“笔画库”。先选择一个写法，检查原图依据、路径方向和起收笔细节。
2. 切到第二个页签“字库”，按照“心 → 永 → 好 → 我 → 建”依次检查。默认来源为“模板合成字”；历史字体样例保存在“全部资料（含旧测试）”中。
3. 点击“查看／修正整字”。先看纯 XY 的结构，再勾选“布局参考”核对位置；“永”当前默认显示布局叠加。
4. 选择有问题的一笔，在曲线上拖动即可修改邻近的一小段。支持撤销、重做和恢复选中笔画，交叉处的其他笔画不会随所选笔画一起移动。
5. 检查完成后，保存整字 JSON 或导出当前 XY CSV。保存的 JSON 可以通过对应页面的“继续上次修正”重新载入。

导出文件保存的是当前修正结果，不会自动替换字库原包或改变首页状态。需要保留多个方案时，应生成独立的新版本。

检查时要区分路径与墨迹轮廓：报告中的“轮廓内行程”用于发现布局差异，无法预测实际墨迹。部分起收笔路径超出参考墨迹的情况会保留提示；仅凭 XY 不能判断那里是否提笔离纸，也不能把所有轮廓外路径一律视为错误。

## 怎样微调和复用模板

配方支持逐笔调整以下参数，具体范围和限制见[合成参数说明](stroke-template-design.md#合成参数与永字示例)。

| 参数 | 作用 |
|---|---|
| `body_scale` | 调整行笔主体的弦方向跨度。 |
| `span_scales` | 调整折、钩等特征之间的指定分段跨度。 |
| `width_scale` | 调整参考宽度和局部特征的几何尺度。 |
| `rotation_deg` | 调整笔画方向。 |
| `offset_xy_px` | 调整笔画位置，X 向右、Y 向上，单位为像素。 |

四个新增字的可编辑布局和配方位于 [practice_20261019_v1](../../configs/stroke_templates/practice_20261019_v1/)，分为 `xin`、`hao`、`wo`、`jian` 四个目录。“永”的配方为 [yong_from_library_v2.json](../../configs/stroke_templates/yong_from_library_v2.json)。

例如，在仓库根目录修改“好”的配方后，可生成一个新版本：

```bash
PYTHONPATH=src:. python scripts/stroke_templates.py compose \
  --recipe configs/stroke_templates/practice_20261019_v1/hao/recipe.json \
  --output-dir outputs/stroke_templates/characters/hao_my_v2
```

输出目录须尚未存在。默认资料库内通过 CLI 成功生成后会刷新首页；手动复制完整结果包后，可以运行：

```bash
PYTHONPATH=src:. python scripts/stroke_templates.py catalog
```

每个合成包保存布局、来源图、模板快照和相对路径配方，便于离线重建并追溯每笔采用的版本。参数仍受适配范围和画布边界限制，并非所有组合都能生成。

## 后续怎样接入磁响应和 StrokePlan

同一份笔画库可以作为几何入口，用于单笔试写、整字组合，以及 XY 与磁响应曲线的配对分析。后续应为确定版本的路径采集同步实验数据，并记录实验批次、时间、命令与实测角色、毛笔及方向校准条件、磁特征定义和滤波方式。

对齐时可以利用笔画 ID、起行收阶段和折钩事件作为参照。当前路径中的归一化弧长及阶段内进度描述的是空间行程，不代表时间；停顿、速度变化和抬笔过程需要实际时间信息。

从笔宽推测高度也需要对应毛笔、装配和书写条件下的实验标定。模板中的收笔形状本身不能确定“Z 很高、磁响应很小”。完成这些关联后，才能进一步建立包含速度、Z、磁目标及接触切换的实际 StrokePlan。

## 当前结果应怎样理解

系统已经具备模板浏览、整字合成、局部修正、导出和版本追溯能力。现有字体布局参与了适配调整，几何叠加检查及软件测试用于验证本批流程与数据一致性，书法质量、真实笔锋运动和磁响应迁移仍需要独立样本与真机实验验证。

日常检查从[资料库首页](../../outputs/stroke_templates/index.html)开始；需要了解实现细节、证据来源和历次验证时，阅读[分段笔画模板设计](stroke-template-design.md)。
