# 触觉毛笔书法机器人——项目介绍（教授汇报版）

> 汇报对象：教授 / 委员会。保留技术细节（Transformer、z-control 闭环），但组织成"问题→方案→技术→现状→成果口径"的叙述线。

---

## 一、项目要回答的问题

机械臂写字不难停在"能干"这一步，但书法能否被机器人**真正复现**？复现一个汉字，不止是把笔挪到对的位置（路径跟踪），更在于**提按**——笔画粗细、起笔收笔的笔锋，全由下笔轻重决定。现有机器人书法系统（如 CalliRewrite）绝大多数是**纯开环位置控制**：按预设轨迹移动、用固定笔高"凑"宽度。它写得出字形，但写不出轻重变化，更谈不上复刻一个人真实的书写手法。

我们的核心主张是：**把"提按"从位置控制升级为触觉反馈闭环**——让机械臂像人手一样，边写边感知下压力度、实时校正。这对应种子论文（Ren et al., Nat. Commun. 2025）的触觉形变感知路线，但把它的"刷涂"任务推进到"书法书写"，并以闭环形变控制取代其开环用法。

## 二、总体架构：示教 → 解释 → 复刻

项目分两部分协作：A（硬件+数采）与 B（算法+模型），由两个接口契约对齐：

- **契约1：实时触觉流** `g_meas`。毛笔刷毛内嵌微型磁场传感器（MLX90393，霍尔），笔毛变形带动磁铁，传感器测量磁场随形变的变化；`|ΔB|` 即"当下压深"的代理量，实时低延迟喂入控制环。
- **契约2：StrokePlan**。一个"可执行笔画单位" `{每笔折线路径, 提按曲线 g_press(s)}`——接住示范数据，并成为执行侧的唯一输入。

整条链路：**人执笔手写**（传感器录时序 + 收笔后拍一张照片）→ **Transformer 融合解释**（用照片的几何与触觉的时序，把"墨"与"笔"对应起来，产出 StrokePlan）→ **Elfin5 复刻**（沿每笔路径移动，z 轴由触觉闭环跟踪示范的提按曲线）。

```
[示范侧] 人执笔手写：触觉流 t,Bx,By,Bz + 收笔后一张照片
   │
   ▼
[解释侧] Transformer（唯一学习核心）
   输入：照片特征(CNN) + 骨架图 G（纯几何，无学习） + 触觉笔画 token
   任务：骨架路由（每笔↔图中的边序列）+ 字识别（辅助）
   输出：StrokePlan {每笔折线/类型/长宽位/按压曲线}
   │
   ▼
[复刻侧] Elfin5：沿每笔折线按弧长匀速走，z 轴 |ΔB| 闭环跟示范按压曲线
```

## 三、控制侧：z-control 闭环（已建好）

- 控制律 **`z_cmd = z_surface + z_ff(g_d) + kp·S_cal·e + 积分`**：前馈查表为主（E2 标定得 `ΔB↔z` 反查压深），积分仅补残差。闭环稳定分析给出：闭环跟踪 RMS 9.47% vs 开环基线 18.91%（裸态仿真口径），相位裕度 116°，三笔内跨笔画收敛。
- 控制环滤波器定稿 EMA α=0.3（在环评估口径下跟踪最优；相位滞后是选型否决 OneEuro 的原因）。真实噪声数据回放保 1/f 谱。
- 配套安全：接触/悬空 freeze、NaN/Inf 防护、输出绝对位置+速率双重钳位。
- 真机侧 `write_air.py` 已在纸上写出实测汉字，"永"字 z 带实测 296/287/275 mm（刚触纸/正常压深/损坏下限），伺服 20ms 周期 + 50ms 前瞻，流式 3000+ 拍零报错。

## 四、智能侧：Transformer 示教-复刻（设计定稿，待实现）

**输入**：① 照片经 CNN 提图像特征；② CV 前端（阈值→连通域→骨架化→**拓扑图**）给出真实墨迹几何；③ 触觉流切出每笔{顺序、类型、按压曲线}。

**核心任务 = 骨架路由**：把每支示范笔画在骨架图上"路由"出一条边序列（从哪条边进、穿不穿交叉点、哪条边出）。交叉/粘连笔画的归属在像素层面无解，但触觉提供的笔画顺序与方向（φ）提供了强线索——这正是 Transformer 的 cross-attention 与多模态对齐最擅长的任务。

**原则：Transformer 不生成任何几何坐标**。所有坐标来自照片与触觉的真实测量，模型只学"墨↔笔"的对应，外加字识别辅助头。几何永远是真实的，不引入幻觉。

**数据策略**：真实手写量级不足以端到端训练，采用**合成预训练**（用数千字字形模板渲染墨迹、走同一套 CV 前端，路由真值按构造已知）+ 真实手写微调 + 独立人工标注 eval 集。合成路径不依赖传感器，可与硬件并行推进。

## 五、现状与下一步

软件执行链路（StrokePlan → z 闭环 → 华沿伺服）已就绪并真机验证；单颗传感器已在 ESP32-S3 验通 333Hz；开环写字已在真纸验证。当前卡点集中在**真实传感流的装配与滤波**（契约1 落地、E0/E2 装配态标定），之后即为 Transformer 复刻的闭环系统层验证，以**字形 IoU/SSIM + 提按复现误差**为机器断言口径。

## 附录 · 备追问要点

- **z-control 公式推导**：前馈 `z_ff(g_d)` 来自 E2 标定 `(ΔB↔z)` 插值反查；`S_cal` 把 µT 误差折算成米（无量纲增益）；稳态残差 `e_ss = d/(1+kp)`，kp=1.208 → 理论残留 ~45%，与实测一致。
- **Transformer 为何选跨模态路由**：笔画归属"哪段墨属哪笔"在纯空间上无解（交叉），触觉的顺序与方向（φ）是唯一强线索；模型只学这份对应，几何保持真实。
- **合成预训练为何成立**：合成与真实共享同一套 CV 前端，域差只剩墨迹质感 → 学习成本压到只剩"跨模态路由"一项，数据需求可负担。
- **跨臂按压传递（关键假设）**：示范臂 `|ΔB|(s)` 相对归一后当复刻臂 `g_d` 目标，复刻臂用自己 E2 标定表落回 mm；两支笔各一支传感器。此项待 E2 装配态专项验证。
