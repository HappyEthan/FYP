# 从 Guo 2026 三维轨迹规划强化本项目的 StrokePlan

## 1. 对当前想法的验证结论

你的核心判断成立：只复现 XY 中心线，只能保证笔画的几何骨架接近，不能充分复现毛笔笔画的宽度变化、转折细节、运动节奏和笔锋状态。因此 `StrokePlan` 应从“二维路径点集合”升级为“完整的可执行笔画参考”。

但需要纠正一个前提：Guo 2026 论文没有完整实现连续的笔杆倾角控制。它的主要可执行输出是：

\[
\mathbf p(t)=[x(t),y(t),z(t)]^T
\]

其中 Z 由目标笔画宽度通过 CCD-BSM 模型转换为毛笔压入高度：

\[
w_i\rightarrow H_i\rightarrow z_i
\]

论文提到了倾角 \(\alpha\) 和笔杆旋转，但没有完整给出：

- `roll(t), pitch(t), yaw(t)`；
- 姿态的连续插值方法；
- 姿态速度和加速度约束；
- 姿态与 XYZ 的同步执行；
- 姿态变化对墨迹改善的独立实验。

因此，论文可以作为三维位置和时间前馈的参考，倾角与旋转只能作为本项目需要进一步验证的扩展方向。

## 2. 论文真正说明了什么

论文最重要的启示不是“应该直接复制它的开环控制器”，而是：

> 视觉路径的二维中心线不是完整的毛笔书写参考，目标墨迹的局部宽度和运动时间也必须进入机器人轨迹规划。

它构建的链路是：

```text
目标笔画图像
   ├── 中心线 ─────────────→ XY路径
   └── 局部笔画宽度 → 毛笔模型 → Z压入高度
                                      │
                           五次多项式时间规划
                                      │
                               XYZ开环轨迹
```

这也解释了为什么仅有 XY 的方法容易写成“硬笔骨架”：相同的 XY 中心线可以对应多种不同宽度的毛笔墨迹。

## 3. 本项目应该怎样超过论文

Guo 的方法主要是开环：

\[
z_{cmd}(t)=z_{ff}(t)
\]

你的项目可以把论文生成的 Z 压入作为前馈，再用磁触觉反馈修正：

\[
z_{cmd}(t)
=
z_{surface}
+s_z\left[z_{ff}(t)+z_{fb}(t)\right]
\]

其中：

\[
z_{ff}(t)=f_{cal}^{-1}\bigl(g_{target}(t)\bigr)
\]

\[
z_{fb}(t)=K_Pe_g(t)+K_I\int e_g(t)dt
\]

\[
e_g(t)=g_{target}(t)-g_{xy}(t)
\]

这样形成：

```text
StrokePlan三维/姿态前馈
           +
磁触觉接触状态反馈
           ↓
连续ServoP位姿命令
```

论文负责告诉机器人“理想情况下应该怎样运动”，触觉闭环负责补偿毛笔软体变形、纸面误差、装配偏差和动态滞后。

## 4. 强化后的 StrokePlan 应包含什么

建议把每条笔画定义为同步参考信号：

\[
\mathcal S=
\{t_i,s_i,\mathbf p_i,g_{d,i},z_{ff,i},\mathbf R_i\}_{i=0}^{M-1}
\]

其中：

### 必需字段

| 字段 | 含义 | 作用 |
|---|---|---|
| `t` | 逐点时间戳 | 表达速度、减速和停顿 |
| `s` | 归一化弧长 | 提供设备无关的路径索引 |
| `xy` | 二维中心线位置 | 复现笔画几何骨架 |
| `g_target` | 目标磁触觉状态 | 复现沿路径变化的接触/变形 |
| `z_ff` | 标定生成的前馈压深 | 提供主要 Z 运动趋势 |

### 非必需的视觉评价量

| 字段 | 含义 | 作用 |
|---|---|---|
| `width_target` | 每个位置的目标笔画宽度 | 记录最终希望复现的墨迹特征 |

本项目明确不使用 `width_target` 生成 Z；触觉目标替代论文的笔宽到压深映射。若保留该字段，它也只用于书写后的视觉评价，不属于控制器必需输入：

1. 可以比较实际墨迹和目标墨迹；
2. 可以作为系统评价指标；
3. 不用于生成 `g_target` 或 `z_ff`。

### 可选姿态字段

| 字段 | 含义 | 启用条件 |
|---|---|---|
| `orientation` | 四元数或旋转矩阵形式的笔杆姿态 | 固定姿态无法复现锋向时 |
| `tilt_target` | 笔杆倾角 | 需要控制侧向弯曲或宽度不对称时 |
| `twist_target` | 绕笔杆轴旋转 | 需要主动调锋时 |
| `g_vector_target` | 目标磁场变化向量 | 磁强模长无法区分弯曲方向时 |

不建议长期使用 Euler 角作为唯一存储格式，因为角度存在跳变和奇异性。执行接口仍可转换为 `Rx, Ry, Rz`，数据集内部更适合保存单位四元数：

\[
\mathbf q_i=[q_w,q_x,q_y,q_z]
\]

## 5. 推荐的最终样本定义

一个支持扩展的采样点可定义为：

```python
StrokeSample(
    t_s,                    # 必需
    s,                      # 必需
    xy_m,                   # 必需: (2,)
    g_target_uT,            # 必需
    z_ff_m,                 # 必需但可重新标定生成
    width_target_m=None,    # 可选评价量，不参与当前控制
    orientation_quat=None,  # 可选
    g_vector_target_uT=None # 可选
)
```

为了计算效率，文件中仍建议使用列式 NumPy 数组，而不是保存大量 Python 对象。

## 6. “更细节”不只等于增加姿态

影响复刻质量的信息至少分为四层：

### 第一层：几何

\[
x(s),y(s)
\]

决定笔画中心线和结构。

### 第二层：墨迹宽度/接触

\[
w_{target}(s),g_{target}(s),z_{ff}(s)
\]

决定局部粗细和主要压入趋势。

### 第三层：时间

\[
s(t),v(t),a(t)
\]

决定转折处是否过冲、墨液停留时间以及动态变形。

### 第四层：姿态与弯曲方向

\[
\mathbf R(t),\quad
(\Delta B_x^*,\Delta B_y^*)
\]

决定侧向用锋、旋转和方向性变形。

项目应该依次验证，而不是直接同时控制全部自由度。

## 7. 折笔应怎样表示

折笔不应只表示为一个尖锐 XY 拐点。一个可执行的折角区域至少要联合描述：

```text
折角前：逐渐减速 + 调整目标接触状态
折角处：使用连续曲率过渡 + 必要时调整姿态
折角后：平滑加速 + 恢复新的接触/姿态参考
```

可以使用曲率决定速度上限：

\[
v_{ref}(s)=
\min\left(
v_{max},
\sqrt{\frac{a_{n,max}}{|\kappa(s)|+\epsilon}}
\right)
\]

这不是对“折笔”做书法语义分类，而是根据路径曲率生成物理可执行的速度参考。

## 8. 五次多项式应该怎样借鉴

论文的五次时间律适合用在：

- 整条笔画开始和结束；
- 明确需要平滑速度变化的局部段；
- 姿态变化的最小 jerk 过渡。

不应对相邻的每两个采样点都施加零速度、零加速度边界，否则机器人会在每个点附近减速甚至停顿。

对一般路径，更合理的结构是：

\[
\mathbf p=\mathbf p(s),\qquad s=s(t)
\]

先用弧长参数化确定空间路径，再用平滑时间律控制路径进度。这样几何路径与速度规划相互独立。

## 9. 与当前 ServoP 控制的兼容性

增强后的 StrokePlan 与当前控制方式兼容。执行时在每个 20 ms 周期插值得到：

\[
x_i,y_i,g_{target,i},z_{ff,i},\mathbf R_i
\]

然后产生：

\[
\mathbf u_i=
[x_i,y_i,z_{cmd,i},R_{x,i},R_{y,i},R_{z,i}]
\]

通过 `HRIF_PushServoP` 连续下发。

若当前阶段不启用姿态轨迹，则：

\[
\mathbf R_i=\mathbf R_{fixed}
\]

所以增加可选姿态字段不会破坏现有圆形实验和固定姿态控制。

## 10. 建议的验证路线

### E1：XY 基线

- 固定 Z；
- 固定姿态；
- 验证几何路径。

### E2：XY + 变化的 Z/磁强

- 增加 `width_target(s)`；
- 通过标定生成 `g_target(s)` 和 `z_ff(s)`；
- 证明宽度参考优于只有 XY 的轨迹。

### E3：XY + 接触 + 时间规划

- 在高曲率和折角区域减速；
- 比较恒速与曲率相关速度的转折误差。

### E4：加入姿态前馈

- 先只改变一个倾角自由度；
- 比较固定姿态与变化姿态的锋向和边缘误差；
- 仍使用磁触觉控制 Z 接触状态。

### E5：方向性触觉控制

- 如果 \(g_{xy}\) 模长不能区分需要的笔锋方向；
- 再使用 \((\Delta B_x,\Delta B_y)\) 向量进行状态估计或反馈。

## 11. 定稿建议

你的 StrokePlan 应定位为：

> 一套面向毛笔笔画复现的多模态、带时间的可执行参考数据，至少联合描述二维中心线、目标磁触觉接触状态和 Z 前馈，并允许扩展为完整工具姿态和方向性磁触觉参考。笔画宽度仅作为可选评价量，不用于控制映射。

Guo 论文最值得直接借鉴的是 `XY + 局部宽度 → Z + 平滑时间律`。姿态变化是合理的下一步研究，但不能声称该论文已经给出一套完整可复现的姿态控制算法。
