# Z 轴闭环控制（Phase 0/1 定稿）

> 本模块用磁触觉 |ΔB| 信号闭环控制毛笔 Z 轴压深（标定表前馈 + 无量纲 PI 反馈），实现提按跟踪。代码：`src/brushbot/z_control.py`（控制器）、`src/brushbot/sim_loop.py`（仿真 harness / 唯一闭环路径）、`scripts/sweep_z_gains.py`（层 1 增益扫描）、`scripts/compare_z_arms.py`（层 2 开环/闭环对比）、`scripts/demo_z_control.py`（演示）。过程细节见 docs/archive/ 与 git 历史。

## 做了什么（Phase 0/1 交付概览）

- **Phase 0**：`ZController` 标量 |ΔB| 跟踪——前馈查表为主、积分只补残差，含积分限幅（±dz_margin）、接触/悬空 freeze、NaN/Inf guard。合成 plant 恒定目标跟踪 RMS 2.1%。
- **Phase 1**：滤波器接入反馈通路并重扫增益；增益无量纲化（S_cal 换算）；`sim_loop.run_loop` 成为全部实验的唯一闭环路径——开环对照臂 = 同一代码增益置零、同噪声种子，"开环 vs 闭环差异 = 触觉反馈贡献"由代码结构背书。层 1：{none, EMA0.3, Butter8, OneEuro} × {kp×ki 几何网格} 扫描出稳定边界与双工作点（wp_P / wp_PI）；层 2：开环 / 闭环-P / 闭环-PI 在标定偏差 ±20%、纸面阶跃 ±0.5mm、传感器漂移 ±1µT/s 下对比，加 freeze 毛刺判据与 8 笔连写多笔画积分评估。
- 噪声用 V0 idle 真实数据连续切片回放（保 1/f 谱）；**全部数字为裸态（未装配）仿真口径**。

## 控制律与关键概念

```
z_cmd = z_surface + z_ff(g_d) + kp·S_cal·e + z_fb
z_fb += ki·S_cal·e·dt（限幅 ±dz_margin）      e = g_d − |ΔB_meas|
```

- **前馈为主**：`calib_lookup_z`（全项目唯一反查实现）由标定表 `calib_z_mm ↔ calib_abs_dB` 插值反查压深；内部按 abs_dB 排序容忍非单调输入；越界饱和保护（低于下界→0，超上界→最大压深）。
- **无量纲增益**：`S_cal = 标定表 z 跨度 / |ΔB| 跨度`（m/µT），kp/ki 表示"每拍把误差的该比例折算为压深修正"——数字直观、换标定表不用重调、仿真扫出的安全范围可迁移。
- **freeze**：`|ΔB| < 3·noise_std 或 g_d < 3·noise_std`（悬空/起收笔）→ 冻结积分器；**Kp 项 freeze 期间仍作用**（层 2 Q4 判据通过，spec fallback 未触发，行为维持）；笔画间 `z_fb` **保持不清零**——跨笔画自适应正是靠它。NaN/Inf 输入 → freeze 并返回安全 z_cmd（滤波器的 NaN 透传策略就是为触发它设计的，别破坏）。
- **两个解析锚点**：① 恒定偏差 d 下 P 闭环稳态残差 `e_ss = d/(1+kp)`——kp=1.208 → 理论残留 45.3%，层 2 paper_step（近加性扰动）实测 ≈45% 吻合；② 积分时间常数 `τ_i = (1+kp)/ki`——决定跨多少笔收敛，ki=0.134 → τ_i≈16.5s ≈ 2.7 笔。
- **坑：先滤向量再取 norm**——norm 非线性，先取 norm 再滤会把零均值噪声整流成正偏置。滤波作用在 (3,)/(N,3) 向量上，控制器内部才取 norm。
- **坑：控制/显示双滤波实例**——控制环滤波器与监控显示滤波器必须是两个实例；控制环实例整段连续运行、笔画中途永不 reset（freeze 期间也照常 update 保持跟踪）。
- **双通路架构**：目标曲线（前馈端）用离线零相位滤波（`sim_loop.fft_lowpass`）洗净，不经过实时滤波；实时滤波器只管反馈通路。两种滤波各司其职，不混用。

## 定稿结论与数字（裸态仿真口径）

| 项 | 定稿值 | 依据/备注 |
|---|---|---|
| 控制环滤波器 | **EMA α=0.3** | 在环闭环评估口径：EMA RMS 9.47% vs OneEuro 11.83%（OneEuro 滞后压低可用 kp 上限，降噪收益被反超） |
| 显示端滤波器 | OneEuro mc=0.5 β=0.03 | 孤立指标口径（|σ| 6.94→2.67 µT），与控制环选型是两个口径，别混用 |

## 已知局限与待验证

### 口径警告（2026-08-10 审计，docs/review-2026-08-10.md）

1. 闭环 RMS 9.47%、相位裕度 116°、Q4 freeze PASS 均为 **ki=0/0.005 口径**；出厂默认 ki=0.134 未全场景复跑，且出厂配置下多笔画 freeze 毛刺 **0.2434 mm 超 0.2 mm 暂定上限**。
2. `z_control.py` 的 `noise_std` 默认值仍是裸态全带宽 **7.0**，未回填滤后 3.31——接滤波后必须显式传，否则接触判定过度保守，降噪收益白费。
3. **z_cmd 无限幅**（安全项未做）——真机前必须加 clamp。
4. `S_cal` 用标定表**整表割线**，隐含线性标定假设；E2 真实标定（非线性曲线）后需重审换算与全域稳定性。
5. `compare_z_arms.py` 的 `--filter` 默认值是 **OneEuro**，与定稿 EMA 相反——复跑必须显式传参。

### 装配态复测清单（E0 数据到位后）

- 重跑 `sweep_z_gains.py` 与 `compare_z_arms.py`（换 `--csv-dir`）：σ_f、增益工作点、滤波选型（控制环 EMA 与显示端 OneEuro 两个口径）全部重裁，任一结论都可能翻盘（裸态 σ 是乐观下界；EMA 支配 Butterworth 依赖 1/f 谱形状，装配态 EMI 可能改变）。
- B0 基线、灵敏度 S、等效位置噪声 σ_z = σ_f/S 在装配态重取；裸态数据只做 kill test。

### 真机前提假设

- Plant 的 τ=0.05s / n_delay=2 拍是假设值；**kp=1.2077 以执行器 τ≥20ms 为前提**——理想瞬时执行器（零滞后）下单拍闭环稳定界是 kp<1，真机执行器若显著更快必须重扫层 1，不能沿用回填值。
- 灵敏度 S 未标定（等 E2），当前标定表是合成直线；示范录制协议待硬件。

### 开放项

- **单笔画内 PI≈P**：ki 的积分时间尺度远超单笔画 ~6s 提按窗口，ki=0.134 只承诺跨笔画（~3 笔）收敛，不承诺单笔画内扰动抑制；瞬时误差判据在提按段内注定报"未恢复"，有信息量的是笔画级窗均偏差。
- **磁漂移无软件解**：机械臂低频磁漂移与提按信号同频段，滤波与反馈均无法区分（闭环被骗 ~54%）——差分测量（多磁通量计）是硬件正解。
- **多笔画 freeze 跳变 0.2434 mm**（开放项，不计入 Q4）：0.2 mm 上限约束的是 z_cmd 单步跳变，执行器 τ=50ms 会平滑实际笔尖运动；真机用实测笔尖运动重评。
