# 固定首尾笔画随机变化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for native implementation, or superpowers:subagent-driven-development if the user chooses delegation. Implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有机器人路径编辑器中生成首尾固定、每次重新随机抽样的 XY 与磁目标执行副本，并保持预检、导出、运行及归档一致。

**Architecture:** 用纯 NumPy 模块生成与保存随机场；用共同目标求值器把同一磁比例场施加到名义前馈和分段覆盖后的控制参考。编辑器保留标准状态，通过独立编排模块构建执行副本并完整预检；导出冻结输入和审计数组，运行入口只读取，不抽样。

**Tech Stack:** Python >=3.10、NumPy、现有 PyQt5 / pyqtgraph、pytest、现有 StrokePlan V3 与实验归档。无需新依赖。

**Spec:** [已确认的设计](2026-11-06-固定首尾笔画随机变化设计.md)，用户于 2026-11-06 明确确认；同时确认随机数值指每次抽样而非固定偏移。

本文沿用仓库八个项目文档目录的结构，保存在系统评价目录。当前仅有设计与计划文档，尚未实施。实施开始时使用 using-git-worktrees 检查 / 建立隔离工作区；不得覆盖用户未提交修改。

## Global Constraints

- 每笔路径起点、终点固定，只改变笔内形状；端点附加位移及附加一阶导数为零。
- 每次“生成本次变化”使用新种子；预览、预检、导出、运行不重新抽样。显式指定种子时允许复现。
- `A_xy = min(0.005 × L_mm, 0.30 mm)`；宽缓趋势和局部项分别占幅度预算 70% 与 30%。这是二维向量长度上限，不是每轴标准差。
- 磁整体系数均匀抽取于 `[-0.05,0.05]`，局部控制值均匀抽取于 `[-0.02,0.02]`；首尾包络为 `b(s)=16s²(1−s)²`。
- 随机量按标准有序弧长进度生成；不以最近 XY 匹配进度。只随机 XY 与磁目标，保留并记录编译派生的时间和姿态变化。
- 总开关默认关闭；旧存档缺少新字段时走现有流程。标准输入不被覆盖、不累加扰动，不修改实测传感器值。
- 名义前馈与有效控制参考分别在各自标准曲线基础上乘同一个比例场；禁止继承段乘两遍、明确分段值覆盖扰动或修改后跳过完整轨迹检查。
- 不扩大当前标定 / 已启用试验范围。超限整笔缩小，不换种子，不逐点截断；无法产生有效非零结果就失败。
- 本计划只授权离线开发与假硬件验证，不包含连接机器人、运动或实际采集。参数的分类效果等待实测确认。

## Review Focus

1. 只有两个端点、短笔或非单位 placement 的路径也必须产生物理单位正确的笔内变化；Task 1 / 3 有对应测试。
2. 明确分段值与继承段相邻时，两条目标都恰好应用一次扰动，原覆盖边界和继承规则保留；Task 2 / 3 测试。
3. 切换编辑笔画、调换执行顺序、关闭子项、撤销和恢复存档不能串用随机场或旧预检；Task 3 / 5 测试。
4. 移动导出目录、删除源模板后独立运行仍一致；缺失、篡改或不兼容的冻结数据在硬件连接之前报错；Task 4 测试。
5. 任意标准笔本来不合法、超限只能缩到零、控制点 / 配置损坏时不得生成看似可执行的版本；Task 1 / 3 / 4 测试。

### 共享数据契约

- `Parameters` 使用普通 JSON 字典，键为 `xy_relative_max=0.005`、`xy_absolute_max_mm=0.30`、`xy_broad_fraction=0.7`、`magnetic_global_max=0.05`、`magnetic_local_max=0.02`。数值有限、非负，布尔值不能冒充数字；整体加局部磁比例上限须 `<1`；首版宽缓占比固定为 0.7，其余四个幅度可设。
- `Fields` 为 JSON 字典：`version=1`、`algorithm='fixed_endpoint_quintic_v1'`、`stroke_id`、`root_seed`（十进制字符串）、`length_mm`、`parameters`、`broad_xy_mm`（二维）、`local_s`、`local_xy_mm`、`global_ratio`、`local_ratio`。保存实际控制值，不只保存种子。
- `MagneticVariation` 为严格字典：`version=1`、`fields`、`source_s`、`execution_s`、`magnetic_scale`。两组进度同长、严格递增且从 0 到 1，表示标准进度到执行弧长的映射。只在 `directional_character` 的顶层或逐笔 `stroke_profiles` 中以 `magnetic_variation` 保存；其他模式携带该项时明确报错，旧流程不受影响。
- `Batch` 为 JSON 字典：`version=1`、`root_seed`、`parameters`、`source_digest`、`stroke_fields`（按稳定 ID 映射）。`source_digest` 由标准几何、有效范围、分段目标、速度 / 节奏、姿态、placement 及全部有效执行设置生成，排除当前选中笔画、文件路径、列表顺序和扰动开关。执行顺序另存并参与完整编译缓存键。
- `Frozen` 为 JSON 字典：`version=1`、`batch`、`options`、`source_snapshot`、`execution_order`、`scales`、`statistics`、`source_digest`、`execution_digest`、`algorithm`、`arrays_sha256`。`options` 为总开关及两个子开关，`scales` 按笔画保存 XY / 磁缩小值及原因。
- 不改 StrokePlan V3 的格式版本或数组字段；名义基准磁曲线仍存 `g_target`，冻结磁场随 entry profile 提供。前馈与 PI 在共同求值器各应用一次；审计文件说明这个约定，避免未来再次预先乘入 `g_target`。
