# 08 · System Evaluation

本部分是论文研究任务和实验证据的汇合入口。正式系统评价仍以纯前馈、无容差反馈、有容差反馈三组对照为主；过程表征、完整分类和参考曲线应用分别维护自己的实验协议，不把它们混成一项总分。

完整阶段关系见[根计划](../../plan.md)。先读下面的主题文件；历史材料集中在 `archive/`，按记录日期解释。

实验结果集中维护在[实验总览](实验清单.md)，生成方法与正式评价设计继续独立保留。按论文研究问题阅读时，使用下面的 A/B/C/D 入口；按工程实现阅读时，回到各项目 README。

## 研究任务入口

| 入口 | 研究问题 | 方案与依赖 | 结论边界 |
|---|---|---|---|
| **A · 过程表征** | 横、竖的幅值曲线是否呈现预定义的阶段性下压调制；横折的方向曲线是否呈现转折过渡？ | [磁响应笔法操作分析方案](磁响应笔法操作分析方案.md)；依赖采集协议、阶段边界和有效区间 | 只支持所测笔画、装配和条件下的过程观察；不直接等同于绝对压力或笔锋角度 |
| **B · 完整笔画分类** | 时间归一化的完整磁响应曲线能否区分七类笔画？ | [磁响应曲线笔画分类方案](磁响应曲线笔画分类方案.md)；依赖运行级划分、预处理版本和独立测试 | 支持类别与条件范围内的曲线可区分性；不解释为自动恢复局部笔法 |
| **C · 书写参考应用** | 采集曲线能否经必要处理组装为 StrokePlan，并被执行或再次复用？ | [多笔画拆分实验计划](multi-stroke-experiment-plan.md)、[StrokePlan 前置工作](StrokePlan前置工作梳理.md)；依赖 `02`、`04`、`07` | 以执行记录、目标/实测曲线和同次成品界定应用可行性；少量实例不证明通用库 |
| **D · 结果与证据** | 每条主张对应哪些运行、指标、对照和失败记录？ | [实验总览](实验清单.md)、[评价设计](evaluation-design.md)、[XY 离线比较](xy-offline-comparison.md) | 统一追溯口径；`completed` 只表示流程结束，不等于效果达标 |
