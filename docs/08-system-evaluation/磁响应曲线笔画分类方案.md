# 基于实测磁响应曲线的七类完整笔画分类方案

本方案规定七类完整笔画的信号构造、长记录切割、预处理、模型比较和可复现评价流程。方案的目标是判断：在已定义的毛笔装配、采集协议和数据范围内，实测磁响应曲线是否包含足以区分完整笔画类别的信息。

本轮类别来自“永”的五笔，并加入独立的横、竖两类，共七类：`右点`、`横折钩`、`横撇`、`撇`、`捺`、`横`、`竖`。分类输出是七类中的一个完整笔画类别，不输出起笔、下压、转折或收笔等局部过程标签。

## 1. 研究对象和总体决定

本方案采用“完整字长记录切割为完整笔画样本”的数据获取方式。长记录按照预先核验的笔画边界切割，每个切割结果作为一条完整笔画曲线进入后续处理。

分类主输入由两条同步曲线组成：

1. **幅值曲线**：由 `dBx`、`dBy` 计算 `|ΔBxy|`，再对标量幅值进行 EMA，最后扣除每条曲线的参考基线；
2. **方向变化曲线**：由平面变化分量得到方向角，再使用相邻方向变化或相对方向编码，避免依赖传感器的绝对朝向。

幅值主表示采用：

```text
Δr(τ) = r_ema(τ) − median(r_ref)
```

选择它的理由不是假定所有采集都存在同样的偏移，而是已有五类先导试验表明原始 EMA 对整体加性偏移敏感，且实验目标主要依赖曲线形状。在测试曲线上人为增加 `+300 µT` 后，Macro-F1 从约 `0.980` 降至约 `0.067`；采用参考基线扣除后，该人为偏移被抵消。因此，原始 EMA 保留为敏感性对照，`Δr` 作为主幅值输入。

方向输入不使用绝对 `atan2(dBy,dBx)` 角度作为跨朝向主特征。方向部分优先比较相邻方向变化 `δφ` 和相对方向的 `sin/cos` 编码。

模型比较采用单模态和融合两层：先比较幅值、方向各自的分类能力，再比较早期融合和晚期融合。SVC 采用线性核和 RBF 核作为首要比较对象；其他 SVM 变体只在这两个基线出现明确问题时加入。

## 2. 分类任务定义

### 2.1 分类单位

一个样本是一条从统一起点到统一终点的完整笔画。长记录中连续采样点、局部窗口、同一笔画的不同重采样版本和数据增强版本，都不增加独立样本数。

同一次完整“永”字运行切出的五条笔画，在分类输入中是五条样本，但在独立评价中仍属于同一个 `run_id`，必须放在同一训练折或测试折。

### 2.2 七类标签

| 类别编号 | 标签 | 来源 |
|---:|---|---|
| 1 | `右点` | “永”的第一笔，使用项目当前标签名称 |
| 2 | `横折钩` | “永”的第二笔 |
| 3 | `横撇` | “永”的第三笔 |
| 4 | `撇` | “永”的第四笔 |
| 5 | `捺` | “永”的第五笔 |
| 6 | `横` | 独立采集的横笔画 |
| 7 | `竖` | 独立采集的竖笔画 |

标签在测试前冻结，由采集任务、路径或阶段记录和人工核验共同确定。

### 2.3 完整分类和局部过程分析

完整分类回答“整条实测曲线属于哪个完整笔画类别”。局部过程分析回答“完整笔画内部某个预定义窗口出现了什么变化”。两个任务可以复用同一条实测笔画，但输出和评价分开。完整分类不输出局部阶段标签，局部过程指标也不能替代完整类别分类结果。

## 3. 数据组织和长记录切割

### 3.1 长记录的基本结构

每次连续采集登记为一个 `run_id`，并记录：

```text
run_id, session_id, batch_id,
brush_id, installation_id,
source_path_sensor, source_path_control,
character_or_task, expected_stroke_count
```

完整“永”字运行的 `expected_stroke_count=5`；缺少首笔的四笔记录单独归档，不并入完整五笔主数据。

### 3.2 切割样本的字段

每个完整笔画建立唯一编号：

```text
sample_id = {run_id}_stroke{stroke_number:02d}
```

切割样本至少保存：

| 字段 | 作用 |
|---|---|
| `sample_id` | 完整笔画唯一编号 |
| `parent_run_id` | 对应的长记录 |
| `stroke_index_within_run` | 笔顺位置，仅用于审计，不作为特征 |
| `stroke_label` | 七类标签 |
| `seq_start/seq_end` | 原始传感器行范围 |
| `time_start/time_end` | 原始时间范围 |
| `boundary_rule` | 边界来源和版本 |
| `quality_status` | 有效、待核验或失败 |
| `exclusion_reason` | 排除原因 |
| `preprocessing_version` | 预处理配置版本 |

### 3.3 边界确定

边界优先使用经核验的同步标记、`measure_XX`、按钮或视频标记；自动门控仅用于开发阶段和边界审计。不得根据类别标签、模型预测或曲线是否“好看”事后移动边界。

每个笔画窗口分别记录：

```text
reference_window  # 接触前稳定参考区
contact_start     # 完整笔画起点
contact_end       # 完整笔画终点
post_lift_window  # 提笔后审计区，不进入分类输入
```

悬空准备、接触前转动和提笔后回落不进入分类向量。预期笔画数与可核验窗口数不一致、边界缺失或出现多段接触时，记录进入失败表。

### 3.4 固定笔顺的使用边界

把切割后的样本行打乱只改变训练输入顺序，不改变当前“永”字中“笔顺位置—标签”的确定关系。已有控制实验中，仅使用 `stroke_index_within_run` 即得到 Accuracy/Macro-F1=1.000。因此现有完整“永”字数据可以用于固定协议下的曲线分类和处理链验证，但不能仅凭打乱后的样本证明模型已经学到与笔顺无关的曲线形状。

如果目标是任意未知单笔分类，后续应增加单笔独立记录、跨位置记录或顺序随机化记录。当前方案不丢弃完整字切割数据，而是把其结论限定为固定笔顺、固定装配和固定采集协议下的协议内分类。

## 4. 信号定义

### 4.1 原始字段

原始 `sensor.csv` 可能包含：

```text
Bx_uT, By_uT, Bz_uT,
dBx_uT, dBy_uT, dBz_uT,
seq, sensor_t_us, sample_seq,
valid, invalid_reason
```

分类不使用绝对 `Bx`、`By`，也不直接将 `dBx`、`dBy` 两列作为幅值特征。它们只用于派生幅值和方向。

### 4.2 幅值曲线

对连续长记录的每个有效传感器行，先计算：

```text
Bxy_raw(t) = |ΔBxy(t)|
            = sqrt(dBx_uT(t)^2 + dBy_uT(t)^2)
```

然后在连续长记录上执行一次 EMA，固定 `α=0.3`：

```text
r_ema[0] = Bxy_raw[0]
r_ema[i] = α·Bxy_raw[i] + (1−α)·r_ema[i−1]
```

主定义不是 `sqrt(EMA(dBx)^2+EMA(dBy)^2)`。原始幅值、EMA 幅值和日志中已有的幅值字段保留作处理链审计。

### 4.3 方向曲线

方向角由平面变化分量派生：

```text
phi(t) = atan2(EMA(dBy)(t), EMA(dBx)(t))
```

方向的主候选表示为：

```text
delta_phi[i] = wrap(phi[i] − phi[i−1])
```

若采集协议有稳定参考方向，也可构造：

```text
phi_rel(t) = wrap(phi(t) − phi_ref)
```

角度可用 `sin(phi_rel)` 和 `cos(phi_rel)` 编码，以避免 `−π/π` 跳变。标量 EMA 幅值低于当前处理配置中的 `5 µT` 方向有效阈值时，方向点标记为无效；无效点按固定规则屏蔽或降权。

方向曲线表示磁响应向量的相对转动，不解释为真实笔锋角度。

## 5. 正式预处理流程

以下流程是进入分类的主流程：

```text
1. 对齐 sensor.csv 与 control.jsonl
2. 审计时间、seq、sample_seq、有效标记和缺口
3. 由 dBx、dBy 计算 Bxy_raw
4. 在连续长记录上执行标量 EMA（α=0.3）
5. 同步计算方向和方向有效标记
6. 按核验边界切割完整笔画
7. 删除悬空、接触前转动和提笔后回落区间
8. 计算每条笔画的参考基线并得到 Δr
9. 对 active 区间按 τ∈[0,1] 重采样为 128 点
10. 在训练折内拟合标准化器
11. 形成单模态或融合输入
```

### 5.1 参考基线和整体偏移

对每条切割后的完整笔画，使用参考窗口中位数：

```text
r_ref = median(r_ema in reference_window)
Δr(t) = r_ema(t) − r_ref
```

若整条曲线和参考窗口共同增加常数 `c`，则：

```text
(r_ema(t)+c) − median(r_ema(reference)+c)
= r_ema(t) − r_ref
```

因此 `Δr` 对整条曲线的常数偏移不变。原始 `r_ema` 保留为 `A0_raw_ema` 敏感性对照。若没有独立的接触前参考区，现有记录可使用预先登记的前 10% 区间作为 `first_10_percent_fallback`，并在样本表中标记该模式。

### 5.2 时间归一化

对 active 区间 `[t0,t1]` 定义：

```text
τ = (t−t0)/(t1−t0)
τj = j/(K−1),  j=0,…,K−1
```

主方案固定 `K=128`，将幅值和方向曲线插值到相同的 `τj`。总时长和原始点数保留为审计字段，不进入分类特征。未归一化的实际时间曲线只用于可视化或敏感性分析。

### 5.3 标准化和方向模态

幅值和方向分别在当前训练折内拟合 `StandardScaler`：

```text
z_A = scaler_A.fit_transform(Δr_train)
z_D = scaler_D.fit_transform(direction_train)
```

测试折只能调用训练折的缩放器。方向有效比例、屏蔽规则和模态权重写入配置。

## 6. 预处理和模态对比

### 6.1 幅值变体

| 编号 | 定义 | 作用 |
|---|---|---|
| `A0_raw_ema` | `r_ema(τ)` | 原始幅值敏感性对照，检验整体偏移影响 |
| `A1_baseline_delta` | `r_ema(τ)−median(r_ref)` | 主方案，保留相对形状并消除加性偏移 |
| `A2_robust_shape` | `(r_ema−median(r_ema))/(q95−q05)` | 只比较每条曲线的相对形状 |
| `A3_baseline_scale` | `Δr/max(s_ref,s_min)` | 检查整体增益变化的影响 |
| `A4_first_difference` | EMA 后的 `dr/dτ` 或相邻点差分 | 强调上升、下降和转折位置 |

主比较首先使用 `A0`、`A1`、`A2` 和 `A4`。`A3` 只有在数据表现出明显增益变化时加入。

### 6.2 方向变体

| 编号 | 定义 | 作用 |
|---|---|---|
| `D0_absolute_angle` | `phi(τ)` | 固定朝向诊断，不作为跨朝向主输入 |
| `D1_relative_angle` | `wrap(phi−phi_ref)`，可用 `sin/cos` 编码 | 观察相对参考方向变化 |
| `D2_turning_curve` | `wrap(phi[i]−phi[i−1])` | 观察方向转动发生的位置 |
| `D3_direction_unit` | `sin(phi_rel), cos(phi_rel)` | 避免角度跳变，提供双通道方向输入 |

方向主比较使用 `D1`、`D2` 和 `D3`；`D0` 只作为固定朝向下的诊断。

### 6.3 融合变体

| 编号 | 定义 | 作用 |
|---|---|---|
| `F0_amplitude_only` | 仅输入 `A1` | 测试幅值形状的独立能力 |
| `F1_direction_only` | 仅输入 `D1/D2/D3` | 测试方向变化的独立能力 |
| `F2_early_fusion` | `[z_A, λz_D]` 拼接后输入一个 SVC | 学习幅值与方向的交互关系 |
| `F3_late_fusion` | 两个 SVC 的校准判别分数加权 | 检查分开建模是否更稳定 |
| `F4_shape_derivative` | `[z_A, λz_{dr}]`，必要时加入方向 | 检查变化率是否提供增量信息 |

早期融合中的 `λ` 在开发分组内选择。晚期融合必须先在训练折内校准或标准化判别分数，不能直接相加两个未经校准的 `decision_function`。

## 7. 分类模型

### 7.1 首要模型

主比较使用：

```text
StandardScaler → SVC(kernel="linear")
StandardScaler → SVC(kernel="rbf", C=1, gamma="scale")
```

七类 SVC 默认采用 one-vs-one，训练 `7×6/2=21` 个两两分类器。`C` 和 `gamma` 的开发网格可设为：

```text
C ∈ {0.1, 1, 10, 100}
gamma ∈ {"scale", 0.001, 0.01, 0.1}
```

### 7.2 辅助模型

`LinearSVC` 用作线性实现对照；`SVC(kernel="poly")` 和 `NuSVC` 仅在标准线性/RBF SVC 出现不稳定时比较。`class_weight="balanced"` 只在类别支持数不平衡时启用。`probability=True` 用于概率校准，不代表分类性能自动提高。

## 8. 评价设计

### 8.1 数据划分

按 `run_id`、session 或 batch 分组。完整长记录切出的所有笔画必须在同一侧。训练前可以打乱样本行，但不能用随机逐笔拆分代替运行级留出。`stroke_index_within_run` 保留为位置控制变量，不进入分类特征。

开发集用于选择预处理变体、方向编码、模态权重、`K`、SVC 参数和融合方式。独立测试集只在配置冻结后使用一次。

### 8.2 对照和扰动

每个输入变体和模型在相同划分下评价：

1. 未加入扰动的实测测试曲线；
2. 测试曲线整体加入 `±100`、`±200`、`±300 µT`；
3. 有原始分量时，对 `dBx/dBy` 施加整体坐标旋转后重新计算方向；
4. 固定笔顺位置控制模型；
5. 幅值、方向和融合模型的相同测试折。

合成偏移和旋转只用于鲁棒性测试，不增加独立样本数。

### 8.3 指标和证据

主要指标为 Macro-F1 和 Balanced Accuracy；同时报告 Accuracy、每类 precision/recall/F1、支持数和混淆矩阵。每个结果都配套：

- 全部实测曲线及类别分布；
- 幅值和方向曲线叠加图；
- 逐样本真实标签、预测标签、运行、批次和模型版本；
- 误分类曲线、失败记录、方向有效比例和扰动后的预测变化；
- 多数类基线和位置控制结果。

模型分数用于量化曲线可区分性，不能替代实测曲线、类别分布和误分类证据。

### 8.4 选择规则

最终输入和模型按以下顺序选择：

1. 先确认变体在独立运行上的 Macro-F1 高于多数类基线；
2. 再检查各类别召回率和混淆矩阵，避免总体分数由单一类别贡献；
3. 再比较 `±300 µT` 偏移和朝向扰动下的稳定性；
4. 当线性和 RBF 表现相近时，优先选择线性 SVC；
5. 只有在方向融合对多个运行、多个类别都提供稳定增益时，才采用融合输入。

## 9. 当前数据的解释

当前已有的五类“永”字先导结果只覆盖完整五笔、固定毛笔装配和现有采集批次：

- 01–10 组原始 EMA RBF-SVC 的 Accuracy/Macro-F1 约为 `0.980`；
- 测试曲线整体增加 `+300 µT` 后 Macro-F1 约为 `0.067`；
- 参考基线扣除后，在该人为偏移实验中 Macro-F1 约保持 `0.980`；
- 仅使用固定笔顺位置的控制映射 Accuracy/Macro-F1 为 `1.000`。

这些结果支持采用基线扣除并保留位置混淆控制，但不构成七类方向融合的分类结果。七类结论需要按本方案重新建立类别覆盖、运行分组和独立测试。

## 10. 实验产物

每次运行完成后保存：

1. 长记录级审计表：预期/实际笔画数、边界规则和运行级失败原因；
2. 笔画级样本表：`sample_id`、父运行、标签、边界、质量和版本；
3. `Bxy_raw`、`r_ema`、参考基线、`Δr`、方向曲线和有效标记；
4. 固定长度幅值/方向特征表；
5. 每个预处理变体和 SVC 模型的逐样本预测、指标、混淆矩阵和误分类清单；
6. 原始长曲线边界图、切割前后图、幅值/方向叠加图和扰动对照图。

## 11. 结论范围

最终结论应限定在实际测试的七类笔画、毛笔装配、采集批次、方向变化范围、偏移范围和数据处理版本内。若模型在这些条件下稳定超过基线，并且曲线、类别分布、混淆矩阵和失败记录相互支持，可以表述为：实测完整磁响应曲线在所测范围内包含可用于七类完整笔画分类的信息。

该结论不延伸到未测试的毛笔、装配、操作者、自由手持条件、未知类别或局部笔法物理量。
