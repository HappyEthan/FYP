# 基于实测磁响应曲线的七类完整笔画分类与多模态 SVC 可复现评价方案

> **正式方案。** 本文件已根据审查意见正式确定完整笔画分类任务的研究问题、信号定义、长记录切割规范、实验流程和评价边界。已核实的五类永字先导结果只作为范围受限的背景记录，七类任务和方向融合结果仍需按本方案独立评价后报告。

## 0. 先确定本文回答什么问题

本文只回答一个分类问题：

> 在固定的毛笔装配、采集协议和预先定义的类别范围内，一条完整、实测的磁响应曲线是否包含足以区分完整笔画类别的信息？

这里的分类单位是一次独立书写的一条完整笔画。当前首批类别来自“永”的五笔，并加入独立的横、竖两类，共七类：`右点`、`横折钩`、`横撇`、`撇`、`捺`、`横`、`竖`。本文不把一条完整笔画拆成多个分类样本，也不输出“下压阶段”“起笔”“收笔”或“横折转折阶段”等局部标签。

本文的证据顺序是：

1. 先展示可追溯的实测完整笔画曲线、类别分布、批次覆盖和数据质量；
2. 再用固定处理流程把每条曲线表示成可复现的输入；
3. 最后用 SVC、混淆矩阵、Macro-F1、逐类结果和误分类审计量化曲线的可区分性。

因此，SVC 是对曲线区分性的统计检验工具，不是磁传感器的物理解释模型。没有实测曲线、类别分布、独立批次和失败记录的模型分数，不能单独构成分类证据。

## 1. 研究任务和两个分析层次的边界

### 1.1 完整笔画分类

完整笔画分类的研究单位、输入、输出和证据如下：

| 项目 | 定义 |
|---|---|
| 研究单位 | 一次独立书写中，从统一起点到统一终点的一条完整笔画 |
| 输入 | 该笔画的实测幅值曲线，以及可选的方向变化曲线；两种输入均经过统一边界处理、相对表示、时间归一化和固定长度重采样 |
| 标签 | 采集任务预先指定并经独立核验的完整笔画类别 |
| 输出 | 七类封闭集合中的一个完整笔画名称；模型不输出局部过程标签 |
| 主要证据 | 全部实测曲线、类别/批次分布、分组独立评价、混淆矩阵、Macro-F1、逐类结果、误分类和失败记录 |

分类任务不把总时长、原始点数、控制指令、目标磁幅值、路径文件名或计划阶段名称当作特征。时间归一化只是在表示层面取消显式的总时长输入，不表示书写速度对曲线形状完全没有影响。

### 1.2 局部笔画过程分析

局部过程分析研究一条完整笔画内部的预先定义窗口或阶段，例如阶段曲线、阶段间幅值变化和方向过渡。它可以描述“某个窗口内发生了什么”，但不等于让分类器输出局部动作标签。

| 项目 | 完整笔画分类 | 局部过程分析 |
|---|---|---|
| 对象 | 一条完整笔画 | 完整笔画内部的阶段或窗口 |
| 目标 | 区分完整笔画类别 | 描述阶段变化和过程指标 |
| 输出 | 一个完整笔画类别 | 阶段曲线、阶段差值、相对方向过渡等描述 |
| 证据 | 真实完整曲线和独立分类评价 | 真实曲线、阶段边界及逐笔过程指标 |
| 不承担的内容 | 不输出下压、起笔、收笔和转折标签 | 不承担完整笔画类别的自动分类 |

同一条真实笔画在满足两个任务的质量要求时可以被两个分析复用，但仍只算一个独立书写样本。局部窗口、采样点、重采样版本、平滑版本和同源复制都不能增加分类样本数。

## 2. 为什么要研究完整笔画分类

局部过程分析不能替代完整笔画分类。即使某个局部窗口存在可重复变化，也不能由此证明七个完整类别的整条曲线可以区分；反过来，即使分类器能够区分，也不能据此声称它识别了真实的下压阶段或笔锋转折物理量。

完整笔画分类的必要性有四点：

1. **直接检验类别相关信息是否存在。** 不预先把某个峰值命名为压力、压深或某种笔法动作，而是让整条实测曲线作为一个完整样本接受类别区分检验。
2. **避免把总时长当成类别替代标签。** 所有完整曲线映射到同一归一化进度轴，模型主要比较曲线随笔画进度的变化；总时长仍作为审计变量保留。
3. **把曲线观察转换为可复核的量化支持。** 模型预测和指标用于量化曲线可区分性、定位类别混淆和检查跨批次稳定性；它们不取代曲线本身。
4. **为论文提供独立于局部分析的证据链。** 论文可以分别讨论完整类别分类和局部过程特征，避免把一个任务的结果写成另一个任务的结论。

首版方案只使用可复现的固定长度曲线、SVC 和少量基线/对照。本文不加入 Transformer、复杂生成模型、人类示范学习、硬件制造细节或与当前分类问题无关的传感器原理。

## 3. 数据理解与不变性要求

### 3.1 原始数据中有什么

当前原始 `sensor.csv` 具有原始磁场和基线扣除后的分量字段，典型形式为：

```text
seq, sensor_t_us, host_rx_ns,
Bx_uT, By_uT, Bz_uT,
dBx_uT, dBy_uT, dBz_uT,
baseline_id, valid, invalid_reason
```

`control.jsonl` 还可能保存控制时刻、阶段名称、`sample_seq`、派生幅值和控制状态。它与 `sensor.csv` 应通过同一 `sample_seq`/`seq` 关系核对，不能把控制记录数直接当成独立传感器采样数。

当前数据**有 `Bx`、`By` 数值，但通常没有名为 `Bxy` 的独立原始列**。本文统一区分：

- `ΔBxy`：平面向量 `(dBx, dBy)`；
- `|ΔBxy|`：用户所说的 Bxy 标量幅值；
- 日志中的 `a_raw_uT`、`a_control_uT`：已有处理链写入的幅值字段，只能在确认其定义后使用。

### 3.2 分类主输入的信号定义

由于实际书写时毛笔和传感器朝向可能变化，分类不使用绝对 `Bx`、`By`，也不把 `dBx`、`dBy` 两列直接拼接为特征。对每个有效传感器样本，主幅值按以下顺序计算：

```text
Bxy_raw(t) = |ΔBxy(t)|
            = sqrt(dBx_uT(t)^2 + dBy_uT(t)^2)

Bxy_scalar_ema(t) = EMA(Bxy_raw(t); α=0.3)
```

在只发生平面坐标旋转的理想情况下，`(dBx,dBy)` 会一起旋转，但向量范数 `sqrt(dBx²+dBy²)` 保持不变；因此，`|ΔBxy|` 不依赖某一次记录中 x、y 轴的绝对对应方向。这个不变性只解决坐标旋转问题，不能消除基线漂移、传感器尺度、装配变化或 z 方向影响，所以仍需要统一的参考窗口、相对表示和批次审计。

这两个步骤的顺序必须固定为“先由 `dBx/dBy` 求标量，再对标量滤波”。不能把它改写成 `sqrt(EMA(dBx)^2 + EMA(dBy)^2)` 后继续称为同一个主幅值输入。原始 `dBx`、`dBy` 不直接拼接进幅值特征矩阵；方向模态可以按第 3.4 节的规则由它们派生相对方向或方向变化特征，并单独作为候选输入评价。

日志中已有的 `a_raw_uT` 可与自行计算的 `Bxy_raw` 做逐样本审计；日志中的 `a_control_uT` 若采用了不同的分量滤波顺序，只保留作处理链对照，不能未经核对替代上述主定义。当前“中”字处理已观察到自行计算的 `Bxy_raw` 与日志 `a_raw_uT` 仅有浮点误差级差异，而标量 EMA 与日志 `a_control_uT` 可能因滤波顺序不同而出现小差异。

### 3.3 相对幅值表示

绝对幅值水平还可能受装配、基线和朝向影响。因此，主分类输入优先使用每条完整笔画内部的相对变化。对完整区间内的 `Bxy_scalar_ema(t)`，在建模前冻结参考窗口和尺度：

```text
r_ref = median(Bxy_scalar_ema(t) in reference window)
Δr(t) = Bxy_scalar_ema(t) − r_ref

s_ref = robust scale of the same reference window
z_r(t) = Δr(t) / max(s_ref, s_min)       # 可选稳健变体
```

参考窗口可以是统一定义的前 10% 区间，或手持采集时明确记录的悬空基线窗口。前 10% 不稳定时，不能把相对曲线开头的突变直接解释成传感器损坏；应同时检查原始幅值、参考窗口稳定性、边界和设备状态。`Δr` 与 `z_r` 都是磁响应变化表示，不是物理压力、法向力、笔毫压入量或真实压深。

首版主输入建议冻结为 `Δr` 的 128 点曲线；正式执行顺序、字段和版本规则见第 7.4 节。`z_r`、256 点和其他滤波/参考设置只能在开发侧预先定义为候选变体，不能看过测试结果后挑选。

### 3.4 方向信息的定义与使用边界

方向信息可以作为第二条分类输入曲线，但不能把绝对磁方向等同于真实笔锋角度，也不能直接把绝对 `atan2(dBy,dBx)` 作为跨朝向分类特征。方向处理必须先消除整条记录的坐标旋转影响，并处理低幅值时方向不稳定的问题。

对每个有效样本，先由同一时刻的 `dBx`、`dBy` 计算平面方向：

```text
φ(t) = atan2(dBy(t), dBx(t))
```

优先使用相邻方向变化：

```text
δφ(t_i) = wrap(φ(t_i) − φ(t_{i−1}))
```

如果整条记录因传感器朝向变化而增加一个常数旋转角 `ψ`，则 `φ'(t)=φ(t)+ψ`，相邻差分 `δφ` 保持不变。若采集协议存在稳定且可核查的参考方向，也可使用相对方向：

```text
φ_rel(t) = wrap(φ(t) − φ_ref)
```

其中 `φ_ref` 用同一笔画的预先固定参考窗口计算。角度不得直接以连续的度数或弧度输入，以免在 `−π/π` 处产生人为跳变；可使用 `sin(φ_rel)`、`cos(φ_rel)`，或使用经过角度展开/包裹的 `δφ` 曲线。低幅值区间的方向应根据预先冻结的幅值阈值标记为无效、降权或屏蔽，因为此时方向主要反映噪声。

方向曲线只能说明磁响应向量在记录过程中的相对转动，不能证明传感器绝对朝向、真实笔锋绝对角度、笔锋几何轨迹或物理压力。它应与幅值输入分别保存，分别可视化，并作为单独输入变体进行评价。

### 3.5 幅值和方向的输入版本

两条曲线均按同一个完整笔画边界和归一化进度 `τ∈[0,1]` 重采样为 `K=128` 点。正式比较至少保留以下输入版本：

| 输入版本 | 特征构成 | 研究目的 |
|---|---|---|
| 幅值单模态 `X_A` | `Δr(τ)`，即参考基线扣除后的 EMA 幅值曲线 | 判断幅值形状本身的分类能力 |
| 方向单模态 `X_D` | `δφ(τ)`，或 `sin(φ_rel(τ))` 与 `cos(φ_rel(τ))` | 判断方向变化是否独立提供类别信息 |
| 早期融合 `X_E` | `[z_A, λ z_D]` 拼接为一个输入向量 | 让同一个 SVC 学习幅值与方向的组合关系 |
| 晚期融合 `X_L` | 幅值 SVC 和方向 SVC 的校准判别分数加权组合 | 检查不同模态分别建模时的稳健性和贡献 |

其中 `z_A`、`z_D` 在每个训练折内分别标准化，`λ` 是方向模态权重，只能在开发数据中预先选择或通过分组交叉验证冻结。若方向曲线有大量低幅值无效区间，应把有效比例、屏蔽规则和方向质量作为审计字段，而不是把无效角度补成一个看似正常的数值。

## 4. 类别、标签和样本登记

### 4.1 类别在测试前冻结

正式类别必须在查看独立测试结果前确定名称、采集任务、标签依据、允许变体和排除条件。本轮首批类别由“永”的五个完整笔画加独立采集的横、竖组成，共七类：

| 类别编号 | 完整笔画类别 | 来源或标签说明 |
|---:|---|---|
| 1 | `右点` | “永”的第一笔，采用项目当前标签名称 |
| 2 | `横折钩` | “永”的第二笔 |
| 3 | `横撇` | “永”的第三笔 |
| 4 | `撇` | “永”的第四笔 |
| 5 | `捺` | “永”的第五笔 |
| 6 | `横` | 独立采集的横笔画 |
| 7 | `竖` | 独立采集的竖笔画 |

如果后续发现同一名称下包含明确不同的几何或采集任务变体，应先记录为标签审查事项，不得根据测试分数临时合并或拆分。七类标签必须由采集任务、路径/阶段记录和独立人工核验共同确认。

标签来自采集任务、路径/阶段记录和独立人工核验，不由待分类曲线反推。有歧义、重写、缺段或无法确认完整性的记录标记为待核验或排除，并保留理由。

### 4.2 一个样本是什么

- 一次独立书写的一条完整笔画对应一个样本。
- 同一运行的多条笔画可分别编号，但继承共同 `run_id`、批次、毛笔和装配信息。
- 同一原始笔画的所有重采样、滤波、标准化和增强版本属于同一来源，必须在同一数据分组内。
- 同一运行内的连续采样点和局部窗口不是独立重复。
- 首版不依靠复制、插值或数据增强增加真实独立样本数。

### 4.3 样本索引

建议建立包含以下字段的样本表：

| 字段 | 用途 | 是否进入分类特征 |
|---|---|---|
| `sample_id` | 唯一完整笔画编号 | 否 |
| `run_id`、`stroke_index` | 追溯运行及笔顺位置 | 否 |
| `stroke_label`、`label_source` | 类别与标签依据 | 仅标签 |
| `session_id`、`batch_id` | 分组和批次审计 | 否 |
| `source_kind` | 机器人实测、手持实测等来源 | 否 |
| `brush_id`、`installation_id` | 毛笔和装配条件 | 否 |
| `parent_sample_id` | 关联同源派生版本 | 否 |
| `source_path`、`signal_field` | 原始文件与信号版本 | 否 |
| `start_time`、`end_time`、`boundary_rule` | 完整区间和截取依据 | 仅用于处理 |
| `quality_status`、`exclusion_reason` | 质量和失败审计 | 否 |
| `preprocessing_version` | 记录公式、滤波和重采样配置 | 否 |
| `amp_000 … amp_127` | `Δr` 的固定长度幅值向量 | 视输入版本而定 |
| `dir_000 … dir_127` | `δφ` 或预先定义的方向编码向量 | 视输入版本而定 |
| `direction_valid_fraction` | 方向有效点比例 | 否，作为质量审计 |

计划文件名、目标磁幅值、控制指令、阶段名称、路径几何、总时长和原始点数可用于分组、审计或边界核验，但不能作为分类特征。

## 5. 实验目标、输入到输出的完整流程

### 5.1 实验目标

本实验不是寻找最高分数，而是建立一条可以复核的证据链，回答：

1. 每个候选类别是否有足够的完整实测曲线和独立批次覆盖？
2. 去除悬空段、统一边界、构造 `|ΔBxy|`、相对化和时间归一化后，幅值曲线、方向变化曲线及其组合呈现什么实际分布？
3. 在不使用绝对坐标分量、绝对方向、总时长和控制指令的条件下，单模态和多模态 SVC 能否在未参与选择的新运行或新批次上识别七类完整笔画？
4. 整体常数偏移、传感器朝向变化和低幅值方向无效区间是否会改变分类结果？
5. 失败、类别混淆和批次差异是否足以要求收窄结论或补采数据？

### 5.2 总体流程

```text
原始 sensor.csv / control.jsonl
        ↓ 对齐、时间和有效性审计
由 dBx,dBy 计算 Bxy_raw = sqrt(dBx²+dBy²)
        ↓ 对标量 Bxy_raw 做 EMA；同步构造方向 φ 和相对方向 δφ
确定完整接触笔画边界，剔除悬空准备和提笔后区间
        ↓ 参考窗口相对化：Δr 或预先定义的 z_r
时间归一化到 τ∈[0,1]，幅值和方向分别固定长度重采样为 K 点
        ↓ 训练折内分别标准化模态；按输入版本单独或融合
单模态 SVC / 早期融合 SVC / 晚期分数融合
        ↓
七类完整笔画类别预测 + 曲线/批次/误分类/失败审计
```

### 5.3 分步实施和每步产物

| 步骤 | 为什么做 | 具体操作 | 每一步产生的结果 | 该结果能支持什么 | 不能支持什么 |
|---|---|---|---|---|---|
| A. 冻结任务和类别 | 防止用测试结果反向改标签 | 写明完整笔画定义、类别、标签依据和来源条件 | 类别表、标签协议、排除条件 | 说明本轮评价对象 | 不能证明类别已经可分 |
| B. 建立样本索引 | 区分独立书写、同源版本和失败记录 | 核对 `run_id`、批次、标签、父样本、来源和质量 | 样本清单、类别/批次计数、排除表 | 说明哪些记录有资格进入分析 | 不能把目录名当标签 |
| C. 核实完整边界 | 防止把准备或中止过程当成笔画 | 检查 `measure_XX`、接触起止、时间戳和阶段覆盖 | 每条曲线的 `t0/t1`、边界依据、缺段记录 | 说明曲线是否代表完整笔画 | 不能用模型错误反向裁切 |
| D. 固定信号定义 | 防止不同滤波顺序制造差异 | 由 `dBx/dBy` 先计算标量，再 EMA；同步计算方向、方向变化、角度包裹和低幅值无效规则 | `Bxy_raw`、标量 EMA、方向曲线、审计对照和配置文件 | 说明两条模型输入曲线如何得到 | 不能把幅值写成压力或把方向写成笔锋角度 |
| E. 处理悬空和质量 | 防止 SVC 学到悬空准备或设备故障 | 用同步边界或统一门控截取完整接触区间；检查断流、重复帧和缺口 | 门控曲线、`t_on/t_off`、失败原因、有效性表 | 说明输入是否为完整接触笔画 | 不能把低门控重叠直接当传感器故障 |
| F. 相对化、归一化和重采样 | 让样本在同一进度轴上可比较 | 幅值用 `r_ref` 计算 `Δr`；方向用 `δφ` 或相对方向编码；两条曲线映射到 `τ∈[0,1]` 并重采样为 K 点 | 固定长度幅值/方向曲线、配置和前后对照图 | 说明可复现的多模态输入表示 | 不能证明已消除速度影响 |
| G. 分组划分和开发选择 | 防止同源样本泄漏 | 按运行/批次/父样本分组；在开发侧选择 K、模态权重、尺度和 SVC 参数 | 分组清单、交叉验证记录、冻结配置 | 支持独立评价设计 | 不能用测试集调参 |
| H. SVC 训练和独立测试 | 量化单模态和融合曲线的类别区分性 | 训练折分别拟合模态标准化器、单模态/早期融合/晚期融合模型，冻结后预测测试运行 | 逐样本预测、融合方式、混淆矩阵、Macro-F1、逐类指标 | 支持所测范围内的分类判断 | 不能证明物理因果或开放集识别 |
| I. 误差、失败和敏感性审计 | 防止分数掩盖问题 | 查看误分类曲线、类别分布、批次差异、失败记录和方向诊断 | 误分类表、失败图、探索性观察 | 决定结论是否需要收窄 | 不能事后删除不利样本 |

## 6. 完整笔画边界和悬空段处理

### 6.1 机器人记录

机器人记录中的 `measure_XX` 只能作为候选完整窗口，必须核实它是否覆盖研究定义中的完整起笔、行笔和收笔。当前“中”字处理以已记录的 `measure_00`–`measure_03` 作为四个笔画窗口，作用是检查多笔画读取、信号派生和可视化；这不等于已经证明同一规则可以自动处理所有手持单笔记录。

若边界需要包含或排除额外起笔/收笔段，必须在建模前为所有类别统一定义。计划进度 `t_s` 不是无误差的实测时间；应优先检查实际传感时间戳、主机接收时间的批量效应、重复帧和断流。

### 6.2 手持单笔的悬空段剔除

手持记录可能包含“悬空准备—接触书写—提笔悬空”。悬空段剔除是独立的边界检测问题，不应让 SVC 自行学习。推荐采集协议：

1. 接触前保持固定时间的悬空参考窗口；
2. 只写一条完整笔画，记录接触到提笔的连续数据；
3. 提笔后继续保持短时间，记录回到悬空状态的过程；
4. 同步保存原始传感数据、时间戳、笔画标签、毛笔和装配信息。

若有按钮、脚踏开关、同步视频或人工标注的接触起止，应优先作为开发数据的边界真值。完全依赖磁响应自动分段只有在悬空和接触响应具有可重复差异时才可靠。

自动门控的候选流程如下，参数必须在开发侧冻结：

```text
r_ref  = median(r_base)
s_ref  = MAD/稳健标准差(r_base)
q(t)   = (Bxy_scalar_ema(t) − r_ref) / max(s_ref, s_min)
```

当 `q(t)` 连续超过 `q_on` 达到最小持续时间时标记接触开始；当它连续低于较小的 `q_off` 达到最小持续时间时标记提笔结束，其中 `q_on > q_off`。内部短空洞按预先规定的长度合并；多个长区间、区间过短或有效幅值比例不足的记录进入失败表，不强行输入分类器。

门控流程产生的 `t_on`、`t_off`、阈值、持续时间、空洞合并规则和门控失败原因必须保存。门控成功只说明边界检测通过，不能证明幅值是压力，也不能证明类别已经可分。

### 6.3 长记录切割为完整笔画样本的规范

当前采用“完整字长记录先保存，再按预先定义的笔画窗口切割”的方案。切割是把一条连续运行记录转换为多个完整笔画样本的过程；它不改变样本的来源关系，也不把同一运行中的多个笔画变成相互独立的运行组。

#### 6.3.1 长记录和切割对象

一条长记录必须登记为一个 `run_id`，至少包含：

```text
run_id, session_id, batch_id, brush_id, installation_id,
source_path_sensor, source_path_control,
character_or_task, expected_stroke_count
```

对当前完整“永”字运行，`expected_stroke_count=5`；对缺少首笔的四笔版本，`expected_stroke_count=4`，这类记录单独归档，不能因为切出了四条曲线就补成完整五笔运行。

每个切割结果对应一个完整笔画窗口，建立唯一的：

```text
sample_id = {run_id}_stroke{stroke_number:02d}
```

同时保存 `parent_run_id`、`stroke_index_within_run`、`stroke_label`、原始 `seq_start/seq_end`、`time_start/time_end`、`boundary_rule` 和质量状态。`stroke_index_within_run` 只能用于审计和分组检查，不能作为分类特征。

#### 6.3.2 边界来源和优先级

边界必须按以下优先级确定，并在每条样本上记录实际使用的规则：

1. 同步记录的、经过人工核验的完整笔画标记或控制阶段边界；
2. 由 `measure_XX`、同步按钮、视频或其他外部标记定义的起止点；
3. 仅在开发数据中使用、并且预先冻结参数的自动门控结果。

不能根据类别标签、SVC 预测、混淆矩阵或某条曲线是否“好看”事后移动边界。若一个长记录的预期笔画数与实际可核验窗口数不一致，记录进入失败表，不能用插值或补零制造缺失笔画。

每个笔画窗口应分别标出：

```text
reference_window  # 接触前或协议规定的基线参考区
contact_start    # 完整笔画开始
contact_end      # 完整笔画结束
post_lift_window # 可选，用于检查提笔回落，不进入分类输入
```

悬空准备、接触前转动、提笔后回落和其他非书写区间不进入完整笔画分类向量。若当前日志的 `measure_XX` 已经包含这些区间，应先依据统一边界规则截取 active 区间，再重采样；不能让模型自行判断哪些点是悬空。

#### 6.3.3 信号计算和切割顺序

对长记录，首版处理顺序固定为：

```text
sensor.csv 对齐与有效性检查
        ↓
由 dBx,dBy 计算 Bxy_raw = sqrt(dBx²+dBy²)
        ↓
在连续长记录上对 Bxy_raw 做一次 EMA（α=0.3）
        ↓
同步计算方向派生量和方向有效标记
        ↓
按已核验的完整笔画边界切割
        ↓
每个笔画单独计算参考基线、去除悬空、时间归一化和重采样
```

在连续长记录上先完成 EMA，可以避免在每个切割窗口边界重新初始化滤波器而产生人为跳变；滤波器是否跨窗口连续、初始状态如何设定必须写入 `preprocessing_version`。如果以后采集单个独立笔画，必须用协议规定的接触前参考段和相同滤波初始化方式，使其与长记录切割样本可比较。

方向量的计算顺序也必须固定。当前候选规则是先对 `dBx/dBy` 分量分别 EMA，再计算 `atan2`，或明确改用先求 `Bxy_raw` 再对标量 EMA；这两种顺序不能混写成同一个特征版本。每个版本都要保存原始派生字段、方向无效比例和配置。

#### 6.3.4 单个切割样本的有效性检查

每条切割曲线至少检查：

- 起止时间和采样序列单调；
- 原始窗口与边界标记能逐行追溯；
- `Bxy_raw`、标量 EMA 和方向字段的有限比例；
- 参考窗口是否稳定、是否覆盖规定的最小长度；
- active 区间是否达到最小持续时间和最小有效点数；
- 是否存在重复帧、断流、长缺口、异常尖峰或多段接触；
- 方向有效比例是否达到预先规定的最低值；
- 重采样后是否覆盖 `τ=0…1` 的完整区间。

检查结果写入 `quality_status` 和 `exclusion_reason`。完整但曲线形状难以区分的样本保留为分类难例；边界不完整、标签不确定或传感器状态异常的样本进入失败记录，不强行输入模型。

#### 6.3.5 切割后文件和审计图

每次长记录切割至少产生：

1. 长记录级审计表：`run_id`、预期/实际笔画数、边界规则和运行级失败原因；
2. 笔画级样本表：`sample_id`、`parent_run_id`、笔顺位置、标签、起止序号、质量状态和输入版本；
3. 原始长曲线叠加边界图：标出每个 `reference_window`、`contact_start`、`contact_end` 和失败区间；
4. 每条笔画的截取前后图：同时显示原始 `Bxy_raw`、标量 EMA、相对幅值和方向有效区间；
5. 固定长度特征表：幅值、方向、模态有效比例和预处理版本。

只有当长记录级笔画数量、边界和质量审计通过后，切割样本才进入 SVC 数据表。

### 6.4 固定笔顺、打乱样本和结论范围

把切割后的样本行打乱，只改变训练输入的排列顺序，不改变标签与笔顺位置的关系。在当前完整“永”字数据中，每个笔顺位置对应唯一类别；仅使用 `stroke_index_within_run` 的控制映射已经达到 Accuracy/Macro-F1=1.000。这说明现有数据不能单独辨别模型使用的是曲线形状还是与笔顺位置相关的采集状态。

因此，当前方案保留完整字长记录切割作为可执行的主处理方式，但把结论限定为：

> 在固定笔顺、固定毛笔装配、固定采集协议和当前批次范围内，将完整“永”字长记录切割为完整笔画后，可以评价这些切割曲线的协议内统计可区分性。

这并不等同于已经证明任意顺序、任意单笔或未知笔画都能被分类。如果目标是任意单笔分类，应在后续增加单笔独立采集、跨位置采集或顺序随机化记录，并用这些数据验证曲线形状的跨位置泛化。现有长记录切割数据仍可用于处理链验证、固定协议基线和误分类审计，不需要删除。

## 7. 固定长度表示和可复现预处理

### 7.1 时间归一化

对确定的完整区间 `[t0,t1]`，使用实际采集时间定义：

```text
τ = (t − t0)/(t1 − t0)
τj = j/(K−1),  j=0,…,K−1
xj = Δr(τj)
```

首版可将 `K=128` 作为预先规定的候选；若要比较 `K=256`，应在开发数据中完成选择。128 点不是 128 Hz，也不是 128 次独立实验。插值方法、边界处理、必要的抗混叠设置和缺口规则必须写入配置。

### 7.2 标准化和泄漏控制

每条曲线的 `r_ref` 和可选 `s_ref` 只由该曲线的参考窗口计算。模型输入的 `StandardScaler` 均值和标准差只能在当前训练折拟合，再应用于验证/测试折。不能在全体数据上先拟合缩放器，也不能按类别或测试结果选择某条曲线的最大/最小值进行归一化。

`Δr` 的每个采样点仍可能相关；128 个特征不等于 128 个独立样本。样本独立性由运行、批次和父样本分组保证，而不是由重采样点数保证。

幅值和方向是两个量纲、噪声结构和有效区间不同的模态。早期融合时必须先在训练折内分别标准化，再按预先冻结的权重拼接，例如：

```text
z_A = StandardScaler_fit_on_train(Δr)
z_D = StandardScaler_fit_on_train(δφ or [sin(φ_rel), cos(φ_rel)])
X_E = [z_A, λ z_D]
```

`λ` 不能根据测试集混淆矩阵临时调整。若不使用权重，仍需记录两条模态各自的尺度、有效比例和方向屏蔽规则。晚期融合则分别训练幅值模型和方向模型，只有在训练折内完成分数校准或标准化后，才能按权重组合；两个未经校准的 `decision_function` 不能直接相加。

### 7.3 质量规则

每条候选曲线至少检查：有限数值、时间单调性、有效传感行、基线有效性、完整区间、重复帧、明显断流、参考窗口稳定性和重采样覆盖。质量规则、可修复缺口阈值和排除条件必须在查看测试结果前写明。

完整但难以区分的曲线属于分类难例，不是质量失败；不能因为模型预测错误而删除。中止、缺段、标签不确定、门控失败和传感器状态异常应保留在失败记录中。

### 7.4 正式执行版预处理数据方案

本节规定进入七类完整笔画分类的主预处理链。任何处理顺序、参数或参考窗口的变更都必须增加新的 `preprocessing_version`，并作为独立输入版本重新评价；不同版本不能在同一结果中混用。

#### 7.4.1 输入文件和对齐

每条长记录同时保留原始 `sensor.csv` 和对应的 `control.jsonl`。两者按 `sample_seq`、`seq` 和时间戳逐行核对，形成统一的长记录表。控制记录条数不能直接当作独立样本数；每个完整笔画样本必须能追溯到原始传感器行范围。

主输入不使用绝对 `Bx`、`By`，也不把原始 `dBx`、`dBy` 直接拼接到分类矩阵。`dBx`、`dBy` 只用于派生幅值和方向两条候选输入。

#### 7.4.2 幅值计算和 EMA

对连续长记录的每个有效传感器行，先计算：

```text
Bxy_raw(t) = |ΔBxy(t)|
            = sqrt(dBx_uT(t)^2 + dBy_uT(t)^2)
```

然后在连续长记录上对标量幅值执行一次 EMA，固定 `α=0.3`：

```text
r_ema[0] = Bxy_raw[0]
r_ema[i] = α·Bxy_raw[i] + (1−α)·r_ema[i−1]
```

不得把主定义改写为 `sqrt(EMA(dBx)^2 + EMA(dBy)^2)`。连续记录先滤波，再按已核验边界切割，避免每个窗口重新初始化 EMA 造成边界人为跳变。原始幅值、EMA 幅值、日志已有幅值和滤波差异均保留为审计字段。

#### 7.4.3 长记录切割和悬空段处理

长记录按照第 6.3 节切割为完整笔画。正式优先使用经核验的 `measure_XX` 或同步边界；自动门控只用于开发阶段或边界审计。每个完整笔画分别保存：

```text
reference_window  # 接触前稳定参考区
contact_start     # 完整笔画起点
contact_end       # 完整笔画终点
post_lift_window  # 可选的提笔后审计区，不进入分类向量
```

悬空准备、接触前转动和提笔后回落不进入分类特征。若现有记录没有独立的接触前参考区，允许使用预先冻结的前 10% 参考区作为 `first_10_percent_fallback`，但必须在样本表中标记该版本，不能与真正的接触前参考混为同一方案。

#### 7.4.4 常数偏移消除和幅值主特征

对每条已切割的完整笔画，使用参考窗口的中位数作为基线：

```text
r_ref = median(r_ema in reference_window)
Δr(t) = r_ema(t) − r_ref
```

`Δr` 是幅值主分类特征。若整条曲线和参考窗口同时增加任意常数 `c`，则 `(r_ema(t)+c) − median(r_ema(reference)+c) = r_ema(t) − r_ref`。因此该表示对整条曲线的常数偏移具有数学上的平移不变性。原始 `r_ema` 仅作为敏感性对照，不作为偏移常态下的首选输入。

可选的稳健尺度版本为 `z_r(t)=Δr(t)/max(s_ref,s_min)`，其中 `s_ref` 由同一参考窗口计算。`z_r` 只有在开发数据中预先冻结并证明需要处理整体增益变化时才启用；它可能删除真实的相对幅值信息，不能在查看测试结果后替换 `Δr`。

#### 7.4.5 方向特征

方向特征不使用绝对方向角。正式候选方向链为：

```text
phi(t)       = atan2(EMA(dBy)(t), EMA(dBx)(t))
delta_phi[i] = wrap(phi[i] − phi[i−1])
```

当标量 EMA 幅值低于当前处理配置中的方向有效阈值 `5 µT` 时，将该方向点标记为无效；无效点按预先冻结的屏蔽、降权或缺失规则处理，不补成正常角度。`delta_phi` 或 `sin/cos` 相对方向编码只表示磁响应向量的相对转动，不表示真实笔锋角度。

#### 7.4.6 时间归一化和固定长度

对每个有效完整笔画的 active 区间 `[t0,t1]` 定义 `τ=(t−t0)/(t1−t0)`，再按 `τj=j/(K−1)` 插值到 `K=128` 个点。总时长、原始采样点数和采样率只作为审计字段，不进入分类特征。未做时间归一化的实际时间曲线可以用于可视化和敏感性分析，但不能与主方案的 128 点输入混为同一模型结果。

#### 7.4.7 训练折内标准化和模态组合

幅值向量和方向向量分别在当前训练折内拟合 `StandardScaler`，测试折只能调用训练折已经拟合的缩放器。早期融合输入为 `[z_A, λ·z_D]`，其中 `λ` 只能在开发分组中冻结。晚期融合分别训练幅值 SVC 和方向 SVC，再对训练折内校准后的判别分数进行加权；未经校准的两个 `decision_function` 不得直接相加。

#### 7.4.8 每条笔画必须输出的预处理结果

每个 `sample_id` 至少输出：

| 输出 | 内容 |
|---|---|
| 原始追溯 | `run_id`、原始文件、原始 `seq_start/seq_end`、边界规则 |
| 边界记录 | `reference_window`、`contact_start`、`contact_end`、`post_lift_window` |
| 幅值数据 | `Bxy_raw`、`r_ema`、`r_ref`、`Δr`、可选 `z_r` |
| 方向数据 | `phi`、`delta_phi` 或 `sin/cos` 编码、方向有效标记 |
| 固定长度特征 | `amp_000…amp_127`、`dir_000…dir_127` 或对应编码字段 |
| 质量审计 | 有限比例、参考稳定性、缺口、尖峰、方向有效比例、`quality_status` |
| 版本信息 | `preprocessing_version`、EMA α、参考模式、阈值和重采样配置 |

只有在长记录级审计、笔画边界审计和单条曲线质量检查均通过后，该样本才进入 SVC 训练或测试表。

### 7.5 幅值曲线、方向曲线和融合方法的对比设计

预处理对比的目的不是在测试集上挑选最高分，而是回答三个问题：

1. 分类信息主要来自幅值曲线的相对形状、方向变化，还是两者的组合？
2. 哪种表示能够抵抗每条曲线的整体常数偏移和传感器朝向变化？
3. 早期融合和晚期融合是否比单模态输入提供稳定、可复核的增益？

所有变体必须使用相同的完整笔画边界、相同的运行/批次分组、相同的 128 点时间轴、相同的训练折和相同的评价指标。每个变体都保存独立的 `preprocessing_version`，不能因为测试结果不理想而临时更换公式。

#### 7.5.1 幅值输入变体

| 编号 | 输入定义 | 对整体常数偏移 | 用途和限制 |
|---|---|---|---|
| `A0_raw_ema` | `r_ema(τ)` | 不具备不变性 | 原始 EMA 敏感性对照；用于验证整体偏移会造成什么影响 |
| `A1_baseline_delta` | `Δr(τ)=r_ema(τ)−median(r_ref)` | 对参考区和整条曲线共同加常数不变 | 幅值主方案；保留相对峰谷、斜率和转折幅度 |
| `A2_robust_shape` | `(r_ema−median(r_ema))/(q95−q05)` | 不变 | 只强调形状，进一步去除每条曲线的尺度差异；可能删除有用的幅值信息 |
| `A3_baseline_scale` | `Δr/max(s_ref,s_min)` | 不变 | 同时检查基线和增益变化；`s_ref`、`s_min` 必须预先冻结 |
| `A4_first_difference` | `dr/dτ` 或相邻重采样点差分 | 对常数偏移不变 | 强调曲线在哪些位置上升、下降和转折；容易放大噪声，必须在 EMA 后计算 |

`A1_baseline_delta` 是正式主方案。`A0`、`A2`、`A3` 和 `A4` 是预先定义的比较变体；它们的结果只能在同一分组评价下比较，不能只根据曲线叠加图决定优劣。

#### 7.5.2 方向输入变体

方向统一从平面变化分量派生。首先按预先冻结的顺序得到方向角：

```text
phi(t) = atan2(EMA(dBy)(t), EMA(dBx)(t))
```

低于方向有效阈值的点先标记为无效，再构造以下变体：

| 编号 | 输入定义 | 对整体坐标旋转 | 用途和限制 |
|---|---|---|---|
| `D0_absolute_angle` | `phi(τ)` | 不具备不变性 | 只作固定朝向下的诊断，不作为跨朝向主分类输入 |
| `D1_relative_angle` | `wrap(phi(τ)−phi_ref)`，可编码为 `sin/cos` | 对整体旋转不变 | 描述相对参考方向的变化；参考方向必须预先定义 |
| `D2_turning_curve` | `delta_phi[i]=wrap(phi[i]−phi[i−1])` | 对整体旋转不变 | 描述磁响应向量在哪些进度位置发生转动；对噪声和低幅值区间敏感 |
| `D3_direction_unit` | 由相对方向构造 `sin(phi_rel), cos(phi_rel)` 两个同步通道 | 对整体旋转不变 | 避免角度在 `−π/π` 处跳变；特征维度为 256 点 |

`D0_absolute_angle` 不进入跨朝向的正式主比较。`D1_relative_angle`、`D2_turning_curve` 和 `D3_direction_unit` 作为方向输入候选；低幅值无效点的屏蔽或降权规则必须在所有方向变体中保持一致。

#### 7.5.3 幅值与方向的组合变体

在同一 SVC 和同一分组划分下比较：

| 编号 | 组合方式 | 模型输入 | 主要回答的问题 |
|---|---|---|---|
| `F0_amplitude_only` | 幅值单模态 | `A1` 或其他一个幅值变体 | 幅值形状能否独立支持七类分类 |
| `F1_direction_only` | 方向单模态 | `D1`、`D2` 或 `D3` | 方向变化能否独立提供类别信息 |
| `F2_early_fusion` | 早期融合 | `[z_A, λ z_D]` | 幅值和方向的交互是否提高分类稳定性 |
| `F3_late_fusion` | 晚期融合 | `w_A S_A(c)+w_D S_D(c)` | 两个独立模型的判别分数融合是否更稳健 |
| `F4_shape_derivative` | 形状加变化率 | `[z_A, λ z_{dr}]`，必要时再加方向 | 变化率信息是否提供超出相对幅值曲线的增量 |

早期融合中的 `z_A`、`z_D` 和变化率特征必须分别在训练折内标准化，`λ` 只能由开发分组选择。晚期融合中的两个 `decision_function` 需要在训练折内校准或标准化后才能相加；未经校准的分数不得直接合并。

#### 7.5.4 每个变体都必须完成的比较

每个幅值、方向和融合变体均按以下条件输出结果：

1. 未加入扰动的原始测试曲线；
2. 测试曲线整体加入预先规定的 `+100`、`+200`、`+300 µT` 和相应负向偏移；
3. 在有原始分量数据时，对 `dBx/dBy` 施加预先规定的整体坐标旋转，再重新计算方向特征；
4. 按完整运行或批次留出的测试集，不把同一运行的其他笔画拆到训练侧；
5. 同一套 Accuracy、Balanced Accuracy、Macro-F1、逐类 precision/recall/F1、混淆矩阵和误分类样本记录。

对每个变体还要保存：类内曲线叠加图、类别分布、方向有效比例、预测改变数量、失败记录和参数配置。合成偏移只用于测试平移鲁棒性，不能增加独立样本数，也不能替代新的实测笔画。

最终模型应按“跨运行稳定性、跨批次稳定性、常数偏移鲁棒性、各类别召回率和失败记录”综合选择，而不是按未扰动测试集的单一最高分数选择。

## 8. 为什么首选 SVC，以及它如何处理多类别

### 8.1 SVC 不是只能做二分类

SVM 的基础判别面通常先写成二分类问题，但 `sklearn.svm.SVC` 支持封闭集合的多类别分类。默认训练方式是 one-vs-one（OvO）：若有 `K` 个完整笔画类别，就训练 `K(K−1)/2` 个两两类别的二分类器，再用投票和判别分数组合成一个类别输出。本轮七类 `右点`、`横折钩`、`横撇`、`撇`、`捺`、`横`、`竖` 对应 21 个两两分类器。

`decision_function_shape="ovr"` 主要改变返回分数的形状，不能被误解为底层训练已经变成单个多类别边界。无论使用 OvO 还是明确配置的 OvR，输出都只是预先定义类别中的一个完整笔画名称。SVC 不会自动发现新类别，也不会把输入拆成局部阶段。

### 8.2 SVC 与当前曲线数据的匹配

经过完整边界、相对化和时间归一化后，每条幅值曲线可以写成固定维度向量：

```text
x = [Δr(τ0), Δr(τ1), …, Δr(τ127)] ∈ R^128
```

方向输入经过同样的边界和进度处理后，可以写成 `δφ∈R^128`，或写成 `[sin(φ_rel), cos(φ_rel)]∈R^256`。因此，本方案需要同时评价幅值单模态、方向单模态以及早期融合向量 `[z_A, λz_D]`。若采用晚期融合，则两个模型仍分别接收各自模态，最后在训练折内校准判别分数后组合。模态拼接不会改变分类输出边界：每个样本仍只输出七类完整笔画中的一个类别。

`|ΔBxy|` 的方向不变性只说明坐标朝向变化不会直接改变这个标量；方向变化特征的旋转不变性还需要通过相对角度或角度差构造。它们本身都不保证类别可分。能够使用 SVC 的真正前提是：不同完整笔画在相同归一化进度轴上呈现足够稳定、可重复的相对幅值和/或方向变化差异。SVC 负责检验这种统计可分性，而不是预先假定它一定存在。

SVC 适合作为首版评价模型的理由是：

1. **输入结构直接匹配。** 它接收固定长度有序数值向量，不需要把曲线事先命名为下压、转折或收笔阶段。
2. **适合在样本量有限时使用正则化。** 当前任务的独立样本数由完整书写和批次决定，远小于采样点总数；SVC 的间隔和 `C` 提供了一个可冻结的复杂度控制方式。
3. **可以表示非线性曲线差异。** RBF 核比较整条归一化曲线的组合差异：

   ```text
   K(xi,xj) = exp(−γ ||xi−xj||²)
   ```

   `C` 控制训练误差和间隔之间的权衡，`gamma` 控制相似度随曲线距离衰减的范围。
4. **不要求峰值的物理解释。** SVC 只回答“这些实测曲线能否区分类别”，不把幅值直接解释为压力，也不把方向变化直接解释为笔锋角度。
5. **易于复现和审计。** `StandardScaler → SVC` 可放入同一流水线，在每个训练折内拟合；参数网格可保持小而明确。

SVC 的前提也必须写清：它把相同归一化进度位置的数值放入距离计算。如果同一过程在不同笔画中的时间位置严重错位，RBF 距离可能把时间错位当作类别差异。受约束 DTW 最近邻可以作为可选对照，检查这个限制；它不是局部过程分析。

### 8.3 需要比较的 SVM/SVC 模型

当前 `StandardScaler → SVC(kernel="rbf", C=1, gamma="scale")` 是一个合理的标准基线，但不是已经优化过的唯一模型。七类任务应在相同的输入版本、分组划分和评价指标下比较以下模型：

| 模型 | 主要作用 | 是否作为首版重点 |
|---|---|---|
| `SVC(kernel="linear")` | 线性分类基线；检查类别差异是否可由近似线性边界区分 | 是 |
| `SVC(kernel="rbf")` | 非线性曲线差异；当前小样本任务的主要非线性候选 | 是 |
| `LinearSVC` | 线性 SVM 的另一实现；适合比较训练方式和线性边界 | 是，作为线性对照 |
| `SVC(kernel="poly")` | 多项式非线性边界 | 低优先级，不作为默认最终模型 |
| `NuSVC` | 用 `nu` 控制支持向量和误差的另一 SVM 参数化 | 低优先级，只有在标准 SVC 不稳定时比较 |
| `class_weight="balanced"` 变体 | 处理类别支持数明显不平衡 | 仅在类别不平衡时启用 |

`SVC(probability=True)` 主要用于概率校准，不能自动提高类别准确率；`SVR` 是回归模型，`OneClassSVM` 是异常检测模型，不属于本次七类封闭集合分类的主模型。多模型比较的目的不是预先假定某一版本一定更好，而是检查结论是否依赖特定核函数或参数。

初始开发网格可以保持有限：

```text
C      ∈ {0.1, 1, 10, 100}
gamma  ∈ {"scale", 0.001, 0.01, 0.1}    # 仅用于 RBF/多项式等核
kernel ∈ {"linear", "rbf"}
```

网格、类别权重、`K`、参考窗口、方向编码和模态权重必须在开发分组内选择，并在独立测试前冻结。当前五类永字试验中线性 SVM 与 RBF SVM 都曾达到相近分数，但这不等于七类任务或方向融合任务已经证明某个核函数最优。

### 8.4 单模态、早期融合和晚期融合

在每种 SVM 版本上，至少保留以下输入比较：

1. **幅值单模态。** 使用 `X_A=z_A`，只检验基线扣除后的 EMA 形状。
2. **方向单模态。** 使用 `X_D=z_D`，只检验相对方向变化。低幅值无效区间应固定屏蔽或降权。
3. **早期融合。** 使用 `X_E=[z_A, λz_D]`，先分别标准化再拼接，训练一个 SVC。它可以学习幅值和方向之间的组合关系，是当前多模态任务的首选融合候选。
4. **晚期融合。** 分别训练幅值 SVC 和方向 SVC，在训练折内校准或标准化判别分数，再使用 `S(c)=w_A S_A(c)+w_D S_D(c)` 选择类别。它用于检查模态独立建模的稳健性和各模态贡献。

两个未经校准的 SVC `decision_function` 不能直接相加。晚期融合的权重、校准方法和缺失方向时的退化规则必须在开发侧冻结。若方向模态有效比例很低，应同时报告“仅幅值”和“幅值加方向”的结果，不能把无效方向补值后的分数单独写成方向证据。

主流水线的推荐起点是：

```text
幅值：|ΔBxy| → EMA → 参考基线扣除 → Δr
方向：atan2(dBy,dBx) → 相邻方向变化 δφ
        ↓ 各模态按训练折分别标准化
早期融合：[z_A, λ z_D]
        ↓
SVC(kernel="linear") 与 SVC(kernel="rbf") 并行比较
        ↓
七类完整笔画类别
```

受约束 DTW + 1-NN 可以作为额外的非 SVM 对照，用于检查时间错位是否主导结果；它不替代上述模型比较，也不承担局部过程标注。

## 9. 数据划分、训练和独立评价

评价目标优先定义为：在同一毛笔和装配条件下，对新的采集运行或批次识别预先冻结的完整笔画类别。

数据划分规则：

1. 同一原始笔画及其所有派生版本必须在同一侧；
2. 同一运行中的多条笔画在检验新运行时保持同组；
3. 测试批次与训练批次分开，批次定义应反映实际共享的纸面、装配、时间和采集条件；
4. 若要研究跨毛笔、跨装配、跨操作者或跨来源，必须把该条件作为明确留出组单独评价；
5. 类别若与批次完全重合，不能把批次差异解释为类别信息；
6. `stroke_index_within_run` 保留为审计变量和位置控制变量，不能进入分类特征；
7. 训练前可以随机打乱样本行，但必须理解这只改变样本顺序，不会消除固定笔顺造成的标签—位置混淆。

先建立开发集和测试集，再在开发集内做分组交叉验证，选择 `K`、参考/尺度变体、方向编码、低幅值屏蔽规则、模态权重、融合方式和 SVC 参数。配置冻结后，测试集只使用一次。批次太少时预先固定配置并把结果标为探索性，不用随机逐笔拆分替代跨批次评价。若要评价常数偏移鲁棒性，应在测试输入中按预先规定的范围加入整体偏移，训练折保持独立，不能把偏移后的同源曲线同时放入训练和测试。

标准输出包括：

- 逐样本真实标签、预测标签、运行、批次、预处理版本和判别分数；
- 输入版本（幅值、方向、早期融合或晚期融合）、模型版本、超参数和方向有效比例；
- 总体准确率和 Macro-F1；
- 每类 precision、recall、F1、支持数；
- 实际计数和按真实类别归一化的混淆矩阵；
- 各测试批次和各来源的独立结果；
- 未偏移及预先规定的整体常数偏移/朝向扰动下的稳定性结果；
- 多数类基线、实际实施的 DTW 对照和误分类曲线。

未经校准的 `decision_function` 只能称为判别分数，不能写成可信概率。若需要区间估计，重采样单位应是独立运行或批次；不能把采样点、局部窗口或交叉验证折当成额外实验重复。

## 10. 结果如何呈现：曲线为主，模型为辅

### 10.1 第一层：数据和完整性

先报告每个类别和批次的独立笔画数、有效数、排除数、排除原因、完整边界覆盖和标签来源。给出训练/测试覆盖，明确类别是否与批次、来源、毛笔或装配混淆。

### 10.2 第二层：实测完整曲线

正文优先展示：

- 各类别全部有效实测曲线的透明叠加或范围汇总；
- 原始标量 `Bxy_raw`、标量 EMA、参考窗口和相对曲线的前后对照；
- 在同一归一化进度轴上的相对方向变化曲线或 `sin/cos` 方向编码，并标出低幅值无效区间；
- 对同一笔画同时展示幅值和方向输入，说明早期融合使用的两个特征块；
- 至少一组“全程曲线—悬空/接触边界—截取后的完整笔画”图，并报告 `t_on/t_off` 和门控失败数；
- 类别内重叠、类别间差异、参考窗口不稳定、缺段和异常样本；
- 被排除的失败记录及排除理由。

代表性曲线只能帮助读者理解处理流程，不能代替所有独立重复。模拟曲线、示意图和单条曲线不能写成实测分类证据。图中的幅值不能直接标成压力或压深，方向图不能标成真实笔锋角度。

### 10.3 第三层：模型量化支持

在曲线和数据分布之后，再报告 SVC 预测、混淆矩阵、Macro-F1、总体准确率、逐类结果、批次结果和多数类基线。每个指标必须能追溯到独立测试样本和冻结的处理配置。

### 10.4 第四层：误分类、失败和探索性观察

逐样本保存真实类别、预测类别、运行、批次和曲线链接，展示最常见混淆的完整曲线。完整但误分的样本必须保留；中止、缺段、标签不确定、门控失败和传感状态异常应单列为失败记录。

128/256 点比较、幅值与方向变体比较、方向有效比例、参考窗口稳定性和批次效应属于探索性观察，除非已在开发阶段预先冻结，否则不能替代独立分类结论。

## 11. 预期观察和结论边界

本方案不预写准确率、Macro-F1、混淆矩阵、峰谷位置或分类性能数值。实际观察应按以下边界解释：

| 实际观察 | 可以支持的表述 | 不能据此表述 |
|---|---|---|
| 多个未参与训练的批次中，曲线分布有可复核差异，SVC 稳定超过多数类基线 | 在已测类别、毛笔装配、采集批次和数据范围内，实测完整磁响应曲线提供了可用于分类的信息 | 已建立通用毛笔识别器，或恢复了真实笔法物理量 |
| 同批次较好，新的批次明显下降 | 区分能力可能依赖批次、装配、采集顺序或基线；跨批次泛化尚未支持 | 曲线具有与条件无关的类别固有特征 |
| 某些类别持续混淆 | 在当前表示和条件下这些类别难以稳定区分，应保留混淆曲线 | 事后合并/拆分类别并把新标签结果回写为本次测试结论 |
| Macro-F1 接近多数类基线、结果波动大或类别支持数很少 | 当前数据和方法尚未支持可靠分类，需要补采、复核标签或收窄问题 | 磁响应绝无类别信息 |
| 只有一个批次或每类极少独立笔画 | 只能报告探索性处理结果或方法试运行 | 已建立稳定识别能力 |
| 指标很高但类别和批次/装配完全重合 | 优先审计泄漏和混淆，暂不能把指标归因于类别 | 直接宣称曲线具有类别固有可分性 |
| 失败记录多、完整区间不足或门控不稳定 | 报告有效数据范围和采集限制，必要时减少类别或暂缓分类 | 用补零、插值或目录名把失败记录改成有效样本 |
| 局部阶段出现可重复模式 | 这是局部过程分析的观察，可与分类结果并列讨论 | 分类器已经识别下压阶段或横折转折标签 |

推荐的正式结论句式是：

> 在所测的毛笔、装配、采集批次、完整笔画类别和数据处理范围内，实测完整磁响应曲线对预先定义的类别提供了（或尚未提供）可量化的区分信息。该结论由实测曲线、类别和批次分布、分组独立评价、混淆矩阵、Macro-F1、逐类结果、误分类和失败记录共同限定；它不外推到未测试的装配、来源、速度、类别或局部笔法物理含义。

## 12. 当前资料状态和待完成事项

### 12.1 已完成的信号和数据处理核查

- “中”字处理读取了 2026-09-25 第 8、9 次完整整字记录，每次四个窗口，共 8 条候选笔画；2026-09-26 通信故障记录作为失败审计保留，不进入主比较。
- “中”字处理对每个有效样本先计算 `Bxy_raw=sqrt(dBx²+dBy²)`，再对标量做 EMA，生成相对幅值和 128 点曲线；没有训练 SVC。
- 永字处理报告记录了 20 次已完成运行、92 条逐笔曲线，其中完整五笔组 60 条、四笔版本 32 条。完整五笔的初步 SVC 评价已在单独输出目录中完成，但它只覆盖“永”的五类，不能直接当作七类任务结果；四笔版本也不能无条件并入完整五笔主任务。
- 已有五类试验的范围限定为：完整五笔、固定毛笔装配、现有采集批次和当前预处理。01–10 组原始 EMA 的 RBF-SVC 留一整字运行评价约为 Accuracy/Macro-F1=0.980；对测试曲线单独加入 +300 µT 后，Macro-F1 约降至 0.067；在本次人为加性偏移对照中采用参考基线扣除后，Macro-F1 保持约 0.980。这些结果只说明当前五类数据对该特定偏移实验的敏感性和基线扣除的数学不变性，不能外推到七类、方向融合或真实手持场景。
- 同一五类数据的 `stroke_index_within_run` 控制映射 Accuracy/Macro-F1=1.000。该控制结果不证明 SVC 没有使用曲线形状，而是证明固定笔顺与类别完全绑定，当前协议不能单独识别曲线形状和位置相关采集状态的贡献。
- 当前已生成的曲线图、特征表、逐笔摘要和失败审计，以及五类初步 SVC 输出，应与七类方向融合实验分开归档；它们不能替代七类任务的独立评价。
