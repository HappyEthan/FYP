# 多笔画拆分实验简要计划

记录日期：2026-10-19。初版采用用户提出的正相关工作假设，以 brush2 历史数据建立磁响应档位与宽度意图的对照，再由图像、描述和 XY 阶段生成候选磁目标曲线；具体真机实验条件待讨论确定。

## 阶段位置

真机正式实验须先明确适用的前馈关系、校准参考和有效范围；[brush2 首轮独立验证](实验清单.md#g17)仍暴露模型失配与重复性问题。笔法描述整理、XY 阶段定位和候选磁趋势表可先离线完成，再用于 proposal 中的多个笔画拆分与分析实验。

已有 XY 路径与笔画模板作为几何基础；每种笔画的磁响应目标曲线仍需建立。

## 待讨论重点

1. **怎样根据经验得到初步磁响应曲线——最高优先级。** 首版用 brush2 数据与正相关假设建立少量档位，将图像中的粗细变化和描述中的提按安排转为沿程档位，再生成平滑的 `g_target`。控制点位置、具体分档与过渡形状通过逐笔复核和试写修订。
2. **怎样制作可视化实验结果图。** 讨论需要展示哪些结果，如何关联 XY 路径、磁目标与实测响应、墨迹图像及笔宽变化，以及怎样比较不同笔画和重复试写。时间／弧长对齐、图的布局、指标和绘图方式后续确定。

## 第一版：brush2 磁响应档位与宽度意图对照

采用工作假设：在所选条件内，名义压深 `d` 增大、磁响应增强、笔画变宽。这里统一定义 `d = Zref − Zcmd`；下压越深，Base 命令 Z 越小。正相关描述的是压深与磁幅值／宽度的关系。

历史数据取自 [brush2 非线性前馈表](../../runs/brush2/plans/05_慢扫非线性前馈表/feedforward.json)，限定其 +X、10 mm/s、15° 行笔姿态、EMA α=0.3 和原装配。按用户要求，在 100–240 µT 内按相同倍率分成五档，相邻档位比为 `(240/100)^(1/4) ≈ 1.244666`，均在该历史表的可反查范围内。档数和范围可以按试写调整。

| 档位 | 初始宽度意图 | 磁目标 / µT | 名义压深 / mm | 命令 Z / mm |
|---|---|---:|---:|---:|
| L1 | 较细 | 100 | 6.754 | 33.246 |
| L2 | 偏细 | 124.47 | 7.857 | 32.143 |
| L3 | 基准 | 154.92 | 9.614 | 30.386 |
| L4 | 偏粗 | 192.82 | 11.536 | 28.464 |
| L5 | 较粗 | 240 | 13.106 | 26.894 |

磁目标由首版选定，压深由历史表反查，Z 使用该表的 `Zref=40 mm` 换算；宽度意图按用户的单调假设赋予。该源表没有实测墨迹宽度列，实际宽度暂留空。数据保存在[档位 CSV](../../runs/brush2/plans/width_level_reference_v1/width_levels.csv)，来源、假设和尺度定义见[参考元信息](../../runs/brush2/plans/width_level_reference_v1/reference.json)。

五档另有意图分数 `q = 0、0.25、0.5、0.75、1`，按 `g(q) = 100 × 2.4^q µT` 映射。表中磁值保留两位小数，CSV 和元信息保存计算精度。q 表示有序的粗细意图，不是实测宽度比例；q=0 对应最细的接触档。图像中的真实／相对宽度另列保存，离纸状态单独处理。

这五档属于 9 月 25 日 brush2 的基线扣除／滤波后原始幅值尺度。后续公共 G 参考使用其自身的定义和数值；移用时保留阶段和宽度意图，重新确定相应磁档与 Z。

### 图像与描述如何生成曲线

1. **图像安排宽度等级。** 在同一批样例中固定粗细参照，先人工将可对应的局部轮廓分为 L1–L5，并记录图像位置和依据。保持共同参照，避免把每笔各自的最细／最粗处都重新拉满五档；后续再固定自动分档阈值。
2. **描述安排阶段变化。** “渐提”安排档位逐步降低，“渐按”安排档位逐步升高；图像帮助选择起止等级。“较细／较粗”决定局部水平，具体升降结合相邻段；转向和停驻分别保留 XY 与时间要求。
3. **档位变成平滑目标。** 在阶段边界和动作事件处设置带来源的控制点，对磁目标平滑插值，得到 `g_target(s)`；加入速度与停顿时间后形成 `g_target(t)`。Z 由与该磁尺度匹配的表反查，非线性表先插值磁目标再查表。
4. **用试写修订。** 先检查磁目标跟踪，再比较墨迹粗细与图像要求，修订档位、边界和过渡。后续可用配对墨迹测量替换初始宽度等级，逐步得到实测宽度对照。

## 从描述与 XY 得到阶段表的方案

采用“程序提取已有字段 → 按统一规则整理动作 → 人工定位和复核”的方式。每段磁趋势保留候选属性，先用上述 brush2 五档填写原型磁目标；执行参数须与适用的标定和试写条件一致。

### 1. 固定输入版本

先选当前资料库的长横和斜捺，分别记录笔画类型、写法、`template_id` 和模板路径。若整理的是整字中的某一笔，还需绑定 `geometry_id`、笔画 ID 和实际采用的 XY。每张表附着于明确的几何版本，边界点号与该版本的点列对应。

引导线模板读取 `guide_trace.writing_hint`、`prototype.anchors`、`prototype.landmarks` 和有序 XY；规则模板补读 `teaching.recipe.rule_notes`、`teaching.events` 及其动作／速度提示。图像轮廓和相对宽度意图作为辅助依据，注明来源。

### 2. 先保留已有大阶段，再整理动作子段

源模板用四个锚点保留起笔、行笔、收笔三个大阶段；已适配的 XY 按该输出自己的 `phase_id`／`phase_ranges` 定位，源模板点号仅用于源点列。将描述拆成有顺序的动作短句，例如“渐提”“较细”“渐按”“稍驻”“转向收笔”，每个子段保留原句及其所属大阶段。文字拆句可由模型辅助，结果仍需逐句复核。

描述不充分的起笔、转折或收笔单列为待补项。已有边界是人工解释的候选，复核时允许提出修订并记录依据。

### 3. 将动作落到路径位置

先使用已有阶段锚点、事件点和特征点；其余边界在原图与 XY 检查页中逐项对照，记录起止点号及归一化累计弧长 `s`。事件优先读取已解析的点号和 `s`；配方事件的 `t` 是局部曲线参数，不是秒数。仅有“前半段”“中段”等模糊措辞时，先保存所属范围，细分边界留待人工标注，不自动按固定百分比切段。

定位遵循路径的点序，回折或重叠位置保留各自的经过顺序。“稍停／驻”另记时间需求，时长待定；不能用弧长区间直接推算停顿时间。

### 4. 分别填写动作意图、磁趋势和时间要求

以下为首版整理规则，磁趋势与宽度档位按正相关工作假设设定，实写效果待试写检验。

| 描述线索 | 动作或形态意图 | 候选磁目标记录 |
|---|---|---|
| 渐按、逐渐下按 | 接触逐渐加重 | 幅值逐渐升高；幅度待定 |
| 渐提、逐渐提锋 | 接触逐渐减轻 | 幅值逐渐降低；幅度待定 |
| 保持提按、匀稳行笔 | 保持所选接触状态 | 可提出维持水平的候选，并记录假设 |
| 较细、较粗 | 期望局部宽度 | 结合图像选择较低／较高档；升降趋势由相邻阶段确定 |
| 停、驻、慢行 | 停顿或速度安排 | 磁趋势待定，另列时间／速度要求 |
| 转、折、回锋、出钩 | XY 方向或局部动作 | 结合明确的提按描述决定；缺少提按依据时标为待定 |

### 5. 阶段表的列

| 列组 | 内容 |
|---|---|
| 来源 | 笔画／写法、模板版本、几何版本、描述所在字段及原句 |
| 阶段 | 大阶段、动作子段、执行顺序 |
| 路径区间 | 起止点号、`s_start/s_end`、边界依据；未定位项留空并说明 |
| 动作意图 | XY 动作、提按意图、期望粗细分别记录 |
| 磁目标候选 | 档位 L1–L5、对应参考与 µT；升高／降低／维持／待定，以及具体控制点 |
| 时间要求 | 正常行笔、减速、停驻等；具体时长可待定 |
| 依据与状态 | 描述直接给出／规则推断／待补；人工复核状态及实验验证状态分别保存 |

阶段表作为独立附表保存，绑定源模板和几何版本。首版可先手工整理，固定字段后再实现 CSV／JSON 的批量提取。

### 6. 长横示例与复核

当前[长横模板](../../outputs/stroke_templates/strokes/sohu_heng_20261017_final/templates/heng_long/template.json)的描述为“前半段渐提、中段较细，后半段渐按；末端转向收笔”。已有大阶段锚点为 `[0, 3, 34, 45]`，对应 `s` 约为 `[0, 0.0725, 0.8065, 1]`；这些位置来自现有几何解释。

示例暂将“渐提—较细—渐按”放在行笔大阶段内，这一归属本身也需要结合原图与路径复核。

| 大阶段／子段 | 原句依据 | 路径区间 | 提按或形态意图 | 候选磁趋势 |
|---|---|---|---|---|
| 起笔 | 当前描述未说明 | `0–0.0725` | 待补 | 待定 |
| 行笔／渐提 | 前半段渐提 | `0.0725–a` | 逐渐提笔 | 可先试 L4→L2，即约 192.82→124.47 µT |
| 行笔／较细段 | 中段较细 | `a–b` | 局部较细 | 可先试 L2，即约 124.47 µT 平台 |
| 行笔／渐按 | 后半段渐按 | `b–0.8065` | 逐渐按笔 | 可先试 L2→L4，即约 124.47→192.82 µT |
| 收笔／转向 | 末端转向收笔 | `0.8065–1` | 转向，提按待补 | 待定 |

其中 `a、b` 是待在原图和路径上标注的边界，满足 `0.0725 < a < b < 0.8065`，不预设为某个百分比。L4/L2 及中段平台是首版工程初值，后续按图像和试写调整。这张表是整理示例，尚未完成边界复核或物理验证。

先人工复核长横表，再用斜捺检查“至粗处稍停后向右渐提平出”是否能同时表达宽度、停驻、方向和提笔。复核关注原句是否完整保留、区间是否连续有序、每项磁趋势是否有依据，以及未知项是否明确。人工确认的是描述与几何解释，磁趋势是否成立由后续试写另行检验。
