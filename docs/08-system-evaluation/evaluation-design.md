# 系统评价：协议、指标与正式对照

## 项目目的

建立统一的实验协议和证据链，量化触觉感知、前馈/闭环控制、计划生成和整字执行的收益，使各小项目的结果能够汇总为研究结论。

## 当前状态

已有分散在计划和研究计划书中的指标与对照要求，但尚未形成统一评价协议。正式三组对照以研究计划书为准：纯前馈、无容差反馈、有容差反馈。当前初步对应关系与前馈表工作先于正式对照评价。

## 范围

- 定义数据划分、重复次数、随机化原则、环境条件和异常样本处理规则。
- 统一控制层、触觉层、视觉层和安全层指标。
- 设计纯前馈、无容差反馈、有容差反馈三组正式对照及关键消融；固定 Z 可作为补充基线，但不取代正式三组。
- 设计纸面、光照、墨色、蘸墨量和装配变化下的鲁棒性实验。
- 用 `run_id` 汇总 StrokePlan、ExecutionLog、墨迹图像、标定和实验元数据。
- 维护可复现的结果表、图和结论边界。

本项目不拥有控制算法、生成算法或采集驱动；它规定公平比较方式并消费各项目产生的结果。

## 输入、输出与依赖

- 输入：StrokePlan、ExecutionLog、原始/处理后传感数据、墨迹图像、标定和实验元数据。
- 输出：评价协议、指标定义、对照/消融结果、鲁棒性结论和论文所需结果图表。
- 依赖：Data Acquisition 保证数据链完整；各算法项目提供可复现配置；所有比较使用一致的样本和环境条件。


## 最近一个可验收里程碑

在对应关系、前馈表和可执行 StrokePlan 成立后，为同一个计划明确纯前馈、无容差反馈、有容差反馈三组对照的重复次数和环境条件，并报告磁目标跟踪、XY 轨迹、Z 命令、安全事件及墨迹差异。具体指标口径应在采集前确定。

## 已知限制与后续讨论

- 指标必须在采集前定义，避免看过结果后选择有利口径。
- 图像大面积背景可能主导相似度，需要同时使用中心线、轮廓和局部结构指标。
- 仿真结果用于软件与趋势验证，不能代替真机触觉和墨迹结论。
