# 固定首尾的路径与磁目标随机变化设计

日期：2026-11-06

状态：用户已于 2026-11-06 确认设计；进入实施计划阶段，尚未实施。

适用项目：`/home/serein/FYP`

文档遵循本仓库仅跟踪八个项目文档目录的现有组织方式，保存在系统评价目录。已完成独立可实施性审阅，未发现需补答的重要问题。用户随后确认本设计；设计确认不代表实现或实测通过。

## 1. 目的与已确认的决定

为七类完整笔画分类采集更多具有类内变化的实测磁响应数据。随机变化施加到机器人执行的 XY 路径和磁响应控制目标，由实际书写产生新记录。

本次对话已确认：

1. 改变采集条件并重新实测。
2. 选择本次讨论的 B：每笔整体变化，加上笔内平滑变化。
3. 每笔路径起点、终点固定，只改变笔内形状。因此“整体路径变化”指整笔内部一致的弯曲趋势，不再包含会移动首尾的缩放、平移或旋转。
4. 用户强调变量的不确定性：方向、幅度、每笔整体比例和笔内控制值均需随机抽取。本文数值是抽样范围或幅度上限，不能实现为每次固定加同一个值；每次手动生成使用新种子，生成后冻结供预览和执行，保留显式种子重现能力。

附件《磁响应曲线笔画分类方案.md》作为分类任务背景：七类完整笔画，主要输入为磁幅值与方向变化，按运行等来源分组。附件中的文字不作为操作脚本或硬件的指令。仓库旧文件《书写随机扰动与跨书写者笔画识别方案.md》记载的是已撤销实现的历史讨论，其中“B”指可复用配置，不等于本次选择；不继承其决定、配置或参数。

后文算法、起始参数和界面行为随本设计一并确认；起始参数仍须由实测验证，不视为已证明最佳。

## 2. 范围与成功标准

第一版支持七类笔画所使用的现有路径编辑、单笔或多笔编译和导出流程。提供总开关及 XY、磁目标子开关，默认关闭；每次手动生成一份随机结果，预览、预检、导出、执行使用同一份结果。关闭后直接采用标准路径和标准目标。

标准编辑数据与本次执行副本分开；扰动不累加。只新增 XY 与磁目标两个随机因素，速度、时间、姿态不作为独立随机变量。现有编译可能随几何变化重定时或改变随切线派生的姿态，这些实际变化必须留档，不能宣称其他执行量严格不变。

本次不包括离线信号增强、分类器实现、可复用“书写者配置”、自动批量运动或真机执行。机器人变体增加的是实际采集记录；不能直接解释为不同真实书写者或独立批次。

成功标准分两层：

- 工程行为：首尾不变，变化平滑、可复现、可关闭，最终执行命令与预检一致，遵守现有执行限制。
- 实验效果：相同标准笔画的不同执行条件，在真实磁信号中产生可辨认的类内差异，同时保留可核验的完整笔画类别。是否提升分类表现，需要后续使用未见实测运行评价，不能只看目标曲线。

## 3. 考虑过的方案

| 方案 | 做法 | 取舍与选择 |
|---|---|---|
| A：每笔整体变化 | 少量整体几何参数及整笔磁增益 | 简单、容易解释，局部变化有限；未选 |
| B：整体变化＋笔内平滑变化 | 整笔趋势加缓慢局部变化 | 能分别研究路径、磁目标及联合变化；用户已选，且进一步要求首尾固定 |
| C：固定书写倾向＋每次小变化 | 保存多份持续复用的模拟配置 | 可研究配置间泛化，但引入额外管理和分组；未选 |

## 4. 数据与生成流程

```text
标准工作区快照 + 当前执行配置 + 扰动参数 + 本次种子
  → 固定一份随机场（以标准笔画进度索引）
  → 生成 XY 执行副本，重映射原分段边界及既有曲线
  → 构建名义磁目标与分段覆盖后的实际控制目标
  → 对两条磁目标施加同一份磁扰动系数
  → 现有前馈、姿态、时间规划及完整轨迹检查
  → 冻结最终方案、有效扰动、目标曲线和预检报告
  → 预览 / 导出 / 运行入口读取同一冻结方案
  → 实际执行时原样记录传感器数据及控制日志
```

这里的“标准”是用户当前编辑完成、尚未施加随机量的输入，不限定为某一个历史 v16 模板。多笔逐笔生成，各笔具有稳定标识。源版本、几何或执行配置改变时，旧结果失效，必须显式重新生成；不能复用旧预检结论。

## 5. XY 扰动

### 5.1 坐标与连续性

使用标准路径累计弧长进度 `s∈[0,1]`，按原始有序路径对应关系求值，不使用最近 XY 点匹配，以处理折返、自交和回锋。

```text
p_exec(s) = p0(s) + d_broad(s) + d_local(s)
b(s) = 16 s²(1−s)²
d_broad(s) = b(s) × a_xy
d_local(s) = b(s) × u_xy(s)
```

`a_xy` 为本笔一次抽取的二维向量，形成整笔内部的宽缓弯曲趋势。`u_xy` 为少量随机控制点连接成的平滑二维函数。固定起终点的附加位移与附加一阶导数为零，保留原有进出笔的位置及端点切向；不要求原标准路径自身在所有拐角处光滑。

局部曲线采用相邻随机控制点间的五次平滑过渡 `6u⁵−15u⁴+10u³`，避免高频逐点抖动。按标准进度约每 20% 设置一个控制点，控制点数量按笔画长度设置上限，短笔自动减少内部控制点。内部控制点具体退化规则及数值容差由实施计划确定，但不得把短笔变成高频波动。

### 5.2 首轮工程起始参数

设标准弧长为 `L_mm`：

```text
本笔合成位移上限 A_xy = min(0.005 × L_mm, 0.30 mm)
宽缓趋势幅度上限 = 0.7 × A_xy
局部变化幅度上限 = 0.3 × A_xy
```

向量方向随机；幅度在零到各自上限之间抽取。这里的幅度是二维向量长度上限，不是各轴标准差。最终对连续扰动曲线核验合成位移，不只检查控制点。

这是尚未真机验证的保守起始建议，不是已证明足以提高分类效果的参数。相对弧长限制与绝对毫米限制同时生效。总幅度可配置，但始终受后续几何与执行检查约束。

首版不自动判定七类语义完全保持。先检查路径无退化、无异常局部反向或新增长距离回绕，展示原路径与变化后路径；类别依旧按采集任务及人工核验确定。折、钩等关键结构被明显破坏的执行副本不能用于该类别采集。

## 6. 磁目标扰动

### 6.1 定义

```text
h(s) = b(s) × [a_g + u_g(s)]
g_ff_exec(s)  = g_ff0(s)  × [1 + h(s)]
g_ref_exec(s) = g_ref0(s) × [1 + h(s)]
```

- `a_g`：本笔整体磁目标比例，首轮建议均匀抽取于 `[-5%, +5%]`。
- `u_g`：笔内缓慢变化的比例场，控制值首轮建议均匀抽取于 `[-2%, +2%]`，采用与 XY 相同类型的平滑过渡。
- `b(s)` 在首尾归零，因此首尾磁目标建议保留标准值，以沿用现有进出笔衔接。
- 全笔相对变化上限为 7%，不能把整体与局部幅度分别执行后再额外叠加一次。

以上比例同样是待验证的工程建议。真实磁响应不保证按目标比例变化，也不将磁目标等同于已标定的物理压力。

### 6.2 与当前前馈及分段覆盖的关系

现有代码有两个不同用途的量：平滑磁曲线提供名义 Z 前馈；明确的分段值在编译阶段覆盖 PI 的控制参考。因此仅修改 recipe 中磁曲线会导致部分随机变化被覆盖。

本设计在现有两条基准曲线各自完成标准处理后，使用同一个 `h(s)` 变换：名义 Z 由新的 `g_ff_exec` 重新查询前馈表；PI 使用分段覆盖之后的 `g_ref_exec`。保留当前前馈平滑曲线与分段控制参考的原有区别，不承诺二者逐点相同。原分段切换位置及继承规则保持，不能用扰动平滑掉标准目标的分段结构。

需要为最终控制参考新增审计：对照“标准有效参考 × 冻结比例场”，而不是仍要求它等于原分段常数。关闭功能时继续执行现有分段常数审计。

### 6.3 越界与缩小

检查每笔两条变换后的目标、名义压深及完整轨迹，沿用当前载入的标定或已经显式启用的试验范围，不自行扩大范围。旧草稿某些分段为 53 µT，而当前所载前馈表下限为 51 µT；这一事实说明统一减小比例可能越界，不代表所有笔画使用同一范围。

越界时，对本笔整条磁扰动场乘以一个统一系数 `c_g∈[0,1]`，保留变化趋势；不逐点硬截断制造平顶。保存请求比例、有效比例和缩小原因。标准目标本身不合法时直接失败。

XY 的几何或执行问题采用类似的整笔幅度缩小，并重新完整编译检查。缩小过程不换种子、不重新抽数；最多进行有上限的搜索，找不到有效非零方案时报告失败。两种扰动联合造成的问题优先同比缩小二者，再重新检查，不悄悄借助新的速度随机量绕过问题。

缩小到近零的结果不能标为“成功产生多样性”；报告实际生效量。是否低于采集需要由初轮测量决定，先不设未经数据支持的固定信号差异阈值。

## 7. 编译、冻结与编辑器行为

建议入口：现有编辑器高级设置中的“随机变化”。控件提供总开关、XY 与磁目标子开关、幅度参数、“生成本次变化”和本次种子显示。

操作草图（表示信息顺序，不确定像素布局）：

```text
选择 / 编辑标准笔画
  → 开启所需扰动项，生成本次变化
  → 查看路径叠加及标准 / 有效磁目标
  → 预检：生效幅度、缩小比例、运动约束、预计时长
  → 导出本次版本
  → 通过现有试写入口运行该版本
```

本次设计不新增自动运动按钮，继续使用现有执行入口与确认行为。预览所示为规划路径和目标，不能标成实测墨迹或实测响应。

同一次生成中，预览、刷新、预检、导出以及终端重新编译都不能重新抽样。导出需包含足够的冻结字段和执行输入，使单独运行 `run_edited_brush_path.py` 也能恢复同样的最终路径、名义前馈及 PI 目标，不能依赖编辑器进程中的临时数组。

标准输入、扰动参数或影响编译的设置改变后，把当前结果标记为失效，阻止继续将旧预检结果用于导出。单纯关闭一个子项不消耗另一子项的随机流；重新打开且未重新生成时复用原随机场，但必须重新预检当前组合。

XY 和磁目标使用独立派生随机流，派生依据为本次根种子、稳定笔画标识、通道与算法版本，不使用进程随机哈希或列表下标作为唯一身份。调换笔画顺序不应改变该笔的抽样结果，但多笔完整序列仍需重新编译预检。

## 8. 保存与追溯

每个导出版本与实际采集记录关联保存：

- 标准工作区和执行配置快照、源摘要、各笔稳定标识。
- 根种子、随机算法版本、请求参数、各笔实际随机控制点或场数组。
- 标准与最终 XY、标准与最终名义磁目标、分段覆盖后的标准与最终控制参考，以及其明确的路径进度 / 时间索引。
- 幅度缩小系数、最终生效统计、预检结果、重定时和派生姿态变化记录。
- 实际采集的 `run_id`、session、batch、笔画标签、来源标准方案和扰动条件。

重放读取冻结结果及配置快照，先检查兼容性；种子用于解释和重新生成新样本，不作为旧结果的唯一存档。标准文件、旧实验和实测 `sensor.csv` 不被扰动结果覆盖。

## 9. 初轮验证与分类评价

### 工程验证

验证开关关闭时与标准编译结果一致，标准输入未变化；固定种子和快照能重现同一结果；预览、导出、独立运行入口及多笔重新编译使用一致的最终数组。

验证所有笔画端点固定、端点附加一阶导数为零，短笔、折返、自交与多笔映射正确。检查磁目标继承段与明确覆盖段都应用了同一比例场，前馈和 PI 分别使用对应的新目标。验证超限缩小、失败报告及无效缓存行为。

针对随机功能增加上述有意义的行为测试，复用现有单笔、多笔、分段目标、导出与执行回归测试。具体命令留给实施计划。

### 探索性采集建议

先选一条简单笔画和一条含折 / 钩结构的笔画，做四组条件：关闭、仅 XY、仅磁目标、两者同时。标准条件先重复采集，以估计自然重复波动；每个变化条件建议生成三个种子，每个种子重复实测两次，观察固定条件的波动与条件之间的差异。数量仅供机制探索，不是正式分类样本量依据。

采集顺序交错安排，记录毛笔、含水状态、纸面和 session，减轻随时间变化的混淆。尚未获得用户执行指令前，这只是采集建议。

比较原始分量、幅值与方向曲线，以及正式预处理后的 128 点表示。结合自然重复波动、响应差异、跟踪误差、有效率和墨迹核验，决定是否调整幅度；不以目标变化本身证明样本变化，也不因模型预测错误就事后排除真实有效样本。

正式分类沿用运行级分组：同一次长记录的所有笔画必须位于同一侧。若评价未见扰动条件的泛化，还需把同一标准方案、参数、种子及配置摘要定义的同一执行条件的重复记录放在同一侧，避免仅记住同一条件的重复。按 session / batch 留出时报告实际覆盖范围。

不能先在全体数据上调扰动范围或预处理，再把其中部分记录称为独立测试。新增扰动采集也不能消除固定笔顺与类别的对应关系；保留位置控制，按附件限定研究结论。

## 10. 预计修改位置与留给实施计划的决定

主要落点：

- `scripts/brush_path_editor_model.py`：标准 / 执行副本、冻结与失效、编译及目标审计、导出快照。
- `scripts/edit_brush_path.py`、`scripts/brush_path_editor_ui.py`：设置入口、生成、状态和预览。
- 独立的纯计算模块：稳定随机流、平滑场、边界包络、范围缩小及统计。
- `src/brushbot/experiments/strokeplan_execution.py`、`strokeplan_character.py` 及必要的共同目标采样接口：统一前馈和有效 PI 参考的求值。
- `scripts/run_edited_brush_path.py` 及实验归档链路：加载冻结输入、兼容性校验、复制必要产物，保证独立运行一致。

不得简单在已经通过检查的最终 poses 上直接加偏移后跳过完整检查。任何新增字段都需更新相应校验与存档，旧数据缺少新字段时默认功能关闭，历史导出仍可使用原流程。

具体模块文件名、存档字段 schema、摘要算法、有限缩小搜索策略、短笔控制点退化方式和数值容差由实施计划决定。它们必须满足本文行为要求，不引入额外随机维度。

## 11. 已随设计确认的工程起始设置

以下设置已随本设计确认，保留后续按实测结果调整的可能：

1. XY 起始幅度上限为弧长的 0.5%，同时不超过 0.30 mm；宽缓趋势与局部变化分配 70% / 30%。
2. 磁目标整体比例 ±5%、局部比例 ±2%，首尾渐归原值；越界时整笔缩小扰动。
3. 首版每次手动生成、总开关默认关闭，子项可单独比较；沿用当前时间和姿态规划，记录派生变化。
4. 先做少量有重复的对照采集，再按实测差异决定正式采集幅度。

以上均未验证为最佳参数。设计已批准，下一步制定实施计划，再按选定执行方式修改脚本。
