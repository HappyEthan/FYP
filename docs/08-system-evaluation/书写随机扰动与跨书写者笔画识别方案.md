# 书写随机扰动与跨书写者笔画识别方案

起始日期：2026-11-05  
最后更新：2026-11-05  
状态：用户已选择 B 方案；本文具体设计待审查，尚未进入实施。

本文从本次选择 B 方案开始记录。后续方案讨论和修改集中在本文件中进行。

## 1. 目的与范围

用户希望模拟不同人手写时的路径和用力差异，使采集的磁响应数据更丰富，为后续识别不同人的笔画提供训练与研究材料。

用户已明确的功能范围：

- 在高级设置中提供随机功能，可随时设置开关。
- 只向本次执行副本的 XY 坐标和磁响应控制目标附加随机量。
- 原标准路径、标准节点及标准磁目标不被随机结果覆盖。
- 关闭功能后恢复原标准笔画的执行命令。
- 使用 B 方案：保存可复用的书写倾向，每次书写另有小幅变化。

本次不增加速度、停顿、笔杆姿态等独立随机变量，不实现笔画识别模型或人类采集系统。原时间轴和姿态设置保留，但 XY 扰动引起的实际速度和加速度变化仍需检查。

本功能产生的是机器人在不同设定下的实测样本。它可以模拟部分手写变量，不能单独证明能识别所有人的笔画；长期效果需要由未参与训练的真实书写者数据检验。

## 2. 方案选择

| 方案 | 生成方式 | 取舍 | 结论 |
|---|---|---|---|
| A：每次独立随机 | 每次重新抽取所有偏移和轻重系数 | 简单，但不同次之间没有持续的书写倾向 | 本次不采用 |
| B：可复用书写配置＋每次小变化 | 配置保留固定的路径偏差与轻重倾向，重复书写时只更新附加小变化 | 能分别观察配置之间的差异和同一配置内的重复差异，需要配置和随机结果管理 | 用户已选择 |

B 的含义示例：配置甲一直略重，同一标准笔画保持相近的偏移趋势；甲连续写三次，各次有小差异。切换配置乙后，可以整体偏轻并采用另一种偏移趋势。这些是模拟配置，不等同于已采集到真实的甲、乙两位书写者。

## 3. 两层随机量

### 3.1 书写配置：跨多次书写保留

建议每份配置包含以下内容：

| 内容 | 同一配置内的行为 |
|---|---|
| 配置 ID、名称、版本、配置种子 | 保存后固定，支持重新载入和跨会话使用 |
| 整体轻重倾向 | 固定的正负系数，跨笔画、跨重复书写复用 |
| 固定 XY 偏差的幅度与种子 | 固定；同一标准笔画产生同一条平滑偏移趋势 |
| 每次变化的幅度限制 | 固定；实际随机结果每次重新生成 |

固定 XY 偏差按该笔画的归一化路径进度生成，首尾为零，沿笔画平滑变化。它依附于“配置版本＋标准笔画标识及几何摘要”，不依赖一次运行的时间戳，也不使用 Python 的进程随机哈希。对同一笔画重复书写时复用同一条固定偏差；换成另一标准笔画时生成对应偏差，保留配置的幅度倾向。

这只模拟有限的个人倾向，不宣称生成了适用于所有笔画的人类书写风格模型。

### 3.2 本次书写：每次重新生成

建议区分三个尺度：

- 整次书写的小幅轻重变化：一次多笔运行共享，下一次可以改变。
- 各笔额外的轻重变化：每笔一个小系数。
- 笔内变化：平滑 XY 偏移和缓慢的局部磁目标变化。

同一配置连续试写时，只更新这一层；不得重新抽取固定的整体轻重倾向和固定 XY 偏差。为支持对照，配置固定量、本次 XY、本次磁目标使用独立随机流，关闭一个子功能不能改变另一个子功能的随机结果。

## 4. 执行副本与叠加关系

设标准路径为 `x0(t), y0(t)`，标准磁目标为 `g0(t)`，路径进度为 `s(t)`：

```text
x_exec(t) = x0(t) + dx_profile(s(t)) + dx_repeat(t)
y_exec(t) = y0(t) + dy_profile(s(t)) + dy_repeat(t)
g_exec(t) = g0(t) + dg_profile(t) + dg_repeat(t)

dg_profile(t) = w(t) × a_profile × g_weight(t)
dg_repeat(t)  = w(t) × [(a_repeat + a_stroke) × g_weight(t) + local(t)]
```

- `a_profile` 保存于配置；`a_repeat`、`a_stroke` 和 `local(t)` 属于本次书写。
- `w(t)` 在每笔首尾平滑归零，中段接近 1。
- `g_weight(t)` 是仅用于计算附加量的平滑幅值参考。它不能替换或平滑掉 `g0(t)` 原有的分段变化。
- 固定 XY 与本次 XY 的首尾位置和附加速度均归零，以衔接标准进出笔。
- 所有附加量都从原标准结果计算，不在上次扰动结果上继续累加。

只在落笔书写阶段叠加。进笔、抬笔和悬空转场沿用标准流程。首尾渐入、渐出各建议约 0.2～0.3 秒，单侧不超过笔画时长的 10%；短笔按此比例缩短。

### 4.1 磁目标与实测磁响应

本方案将磁随机量加到控制目标，由现有前馈和 PI 控制产生真实的执行变化。前馈名义压深随新磁目标一致更新，已有书写提笔量等设置保留，不另加独立的随机 Z。

传感器原始磁数据和时间戳照实保存，不向实测值注入人工随机数。“目标较大”是用力差异的代理设定，不表示已建立力的物理单位标定；实际响应还受接触、毛笔状态等因素影响。

## 5. 建议参数：先验证，再决定采集幅度

以下均为本次设计的工程起始建议，未获得本功能真机试验验证，不视为用户已批准的参数。

| 参数 | 保守验证档 | 候选常规档 |
|---|---:|---:|
| 配置固定 XY：各轴标准差上限 | 0.02 mm | 0.04 mm |
| 本次 XY：各轴标准差上限 | 0.01 mm | 0.02 mm |
| 固定＋本次 XY 的二维合成位移硬上限 | 0.10 mm | 0.15 mm |
| 固定 XY 平滑控制点间隔 | 路径进度约 15% | 路径进度约 15% |
| 本次 XY 平滑控制点间隔 | 0.5 秒 | 0.5 秒 |
| 配置整体轻重 `a_profile` | ±3% | ±5% |
| 本次整体轻重 `a_repeat` | ±0.5% | ±1% |
| 单笔额外轻重 `a_stroke` | ±0.5% | ±1% |
| 笔内局部磁变化 | ±0.5%，且不超过 ±1 μT | ±1%，且不超过 ±2 μT |
| 局部磁变化平滑控制点间隔 | 0.8 秒 | 0.8 秒 |
| 总开关初始状态 | 关闭 | 关闭 |

XY 控制点建议从零均值高斯分布抽取后平滑连接，再整体缩小至标准差和合成位移约束。表中标准差是幅度上限，首尾归零和后续缩小可使实际值更小，必须记录实际值。

磁系数建议在给定区间内均匀抽取。配置系数仅在新建配置时抽取；本次与单笔系数分别按运行、笔画抽取。所有百分比均为最大正负范围，不是标准差。局部变化同时满足百分比和绝对值限制，两者取更小者；所有分量相加后再次按原标准磁目标约束总幅度。

在 150 μT 的平稳区间，候选常规档的配置、本次、单笔及局部项同方向达到最大时，分别为 7.5、1.5、1.5、1.5 μT，合计不超过约 12 μT，即 8%。保守档对应约 6.75 μT，即 4.5%。首尾包络和边界预检可能进一步降低幅度。

固定偏差与本次变化叠加后若超限，保留固定偏差，优先整体减小本次变化。固定偏差本身超限时，对该标准笔画的固定偏差确定性缩小并保存；后续重复书写继续复用缩小后的结果。不得因某一次随机抽样改变已保存配置的轻重系数。

若最终附加量过小而不能达到采集目的，显示实际幅度并由用户重新生成或调整配置，不把它当成足够的多样性样本。

## 6. 预检与形状保留

目标是在同类笔画内增加差异，保留主要趋势、峰谷和类别特征。第一阶段建议采用以下目标曲线预检要求：

1. 在原时间轴上比较标准与扰动后磁目标，每笔相关系数不低于 0.98；标准化 RMSE 同时记录。近似常量目标不以相关系数判断，改查幅度与附加变化速度。
2. 对位置明确的主要峰谷，位置变化不超过笔画时长的 2%。平顶平台和近乎等高的多个峰不以单个最大值下标判定。
3. 新目标满足当前允许的前馈范围以及运动、深度和高度限制。已有实验扩展沿用原授权边界，不自动扩大，不把未实测扩展称为已标定范围。
4. 不改变原时间轴，不用时间拉伸或动态对齐消除比较误差。原始目标的分段变化保留，不用逐点硬截断制造削顶。
5. 所有预检在最终执行副本上进行。先验证配置固定层，再加入本次层；若本次层导致不通过，整体缩小本次层后重检。固定层不能通过则提示该配置与当前标准笔画不兼容，不暗中更换配置或种子。
6. 预览展示实际生效幅度、缩小系数和失败原因。预览、导出和执行冻结为同一份最终结果，执行前不能重新抽样。

0.98 和 2% 是待验证的工程阈值，约束目标曲线；实测波形需单独评价，不能保证因目标预检通过就逐点保形。

## 7. 高级设置的操作行为

建议入口为 `高级设置 → 书写随机扰动`，包含总开关、XY 子开关、磁目标子开关、配置选择与保存、生成本次变化、锁定本次结果、参数设置及预览预检。界面布局留给后续设计，不在本文确定像素或排版。

日常顺序为：选择标准笔画 → 选择或新建书写配置 → 生成本次变化 → 预览预检 → 执行并留档。再次试写时默认保留配置，仅生成新的本次变化；需要精确重复时锁定本次结果。切换书写倾向时显式选择另一配置。

- 新建配置：分配独立 ID 与配置种子，固定其整体倾向。
- 保存配置：跨会话复用；修改已保存配置时产生新版本，已有实验中的快照不变。
- 生成本次变化：仅更换本次种子，固定层保留。
- 锁定本次结果：在标准输入和配置版本不变时复用全部最终偏移。
- 关闭总开关：直接走标准执行流程，不通过减去历史随机量恢复，也不删除配置。
- 子开关：只影响对应变量；开关前后保持其他随机流和参数一致。
- 执行中修改：从下一次运行生效，当前执行结果保持冻结。

关闭功能保证标准命令恢复；再次实机书写的墨迹与磁响应仍可能受纸面和毛笔状态影响，不承诺逐点相同。

## 8. 保存与重放

每次运行至少保存：标准方案及输入摘要、配置 ID 和版本及内容快照、配置种子、本次种子、算法版本、各笔固定与本次偏移数组、最终执行目标、原始实测数据、实际扰动统计、预检及控制记录。

配置文件用于生成新样本；实验中的配置快照和最终偏移用于重放旧样本。重放不能只依赖种子重新抽取。标准路径、标定或执行配置变化后，旧随机结果需要兼容性校验；不允许直接套用并仍宣称是同一次结果。

标准笔画更改后，以新摘要管理固定偏差，旧偏差保留在旧实验中。保存格式、摘要字段、配置存储目录及极短笔画的退化处理由后续实施计划明确，均不得破坏标准恢复和配置复用语义。

## 9. 首轮验证与后续识别评价

### 9.1 验证 B 的行为

- 固定标准方案和配置，生成至少三次不同本次变化：固定磁系数和固定 XY 偏差必须一致，本次变化应不同。
- 切换配置：固定倾向应能改变；切回原配置后应恢复该配置的原固定倾向。
- 仅 XY、仅磁目标、两者同时开启时，对应随机分量应能复用，便于单因素比较。
- 关闭、开启、再次关闭后，标准编译结果一致，原标准文件未被扰动覆盖。
- 锁定结果后，预览、导出和重放的最终偏移与执行目标一致。

先使用保守档做探索性采集：标准对照，以及至少三份书写配置各重复三次；单因素与联合因素分组记录。上述数量用于验证机制，不代表足够证明识别泛化。记录毛笔、纸面、含水状态和采集会话，避免把接触条件变化误当成配置效果。

沿用每笔 128 点作为派生展示方式，比较原幅值与标准化形状，同时检查原始时序、传感器有效率及控制限幅。128 点不改变原采集点或执行点。

### 9.2 面向不同人的笔画识别

数据需保留笔画类别、标准方案、来源类型、配置 ID／版本、真实书写者 ID（若有）、采集会话和重复序号；种子与身份标签用于管理和分组，不作为笔画识别输入。

后续验证分别回答两个问题：未见模拟配置上的识别是否改善；未参与训练的真实书写者上的识别是否改善。两种结论分开报告，不把模拟配置当成真实人数。

同一原始样本的重采样、窗口和增强派生结果归入同一数据分组。按模拟配置评价时，同一配置不能同时进入训练和测试；按真实书写者评价时，按书写者分组，预处理参数仅从训练集确定。另做未见标准笔画实例或模板的评价时，按标准方案分组，避免同源变体泄漏。

真实人类采集方式、识别输入通道和训练规模属于后续识别工作的待定项，不扩大当前随机功能的实施范围。

## 10. 当前项目中的落点

复用现有 Python／Qt 路径编辑器、标准编译流程和前馈／PI 执行链路。预期涉及高级设置入口与试写衔接、编辑器模型中的配置和副本管理、执行编译后的叠加与预检，以及现有实验存档。
