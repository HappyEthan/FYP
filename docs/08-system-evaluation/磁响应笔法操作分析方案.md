# 磁响应毛笔基本笔画的过程特征分析方案

## 副标题

**横、竖笔画的阶段性下压调制与横折笔画的磁方向过渡**
调
> 本草案只讨论实验目标、研究动机、实验步骤、分析指标和预期结果。逆锋、顺锋、转笔调锋、起笔、收笔以及稳定性评价不属于本轮实验的主要内容。

## 1. 实验目标

本实验以横、竖、横折三类完整笔画为对象，研究磁响应是否能够呈现传统笔画内部的过程差异。

实验分为两个相互独立的分析任务：

1. **幅值过程分析：**比较长横、短横、长竖和短竖的阶段性下压调制，观察磁响应幅值是否按照预定的内部阶段发生变化。
2. **方向过程分析：**分析横折在转折前、转折中和转折后的磁方向变化，观察磁响应是否能够呈现完整笔画内部的方向过渡。

本实验不以“识别所有笔画”为目标，而是考察磁响应能否为完整笔画提供可解释的过程描述。

## 2. 为什么进行这个实验

### 2.1 同一基本笔画中的笔法差异

传统书法中的基本笔画并不是只有一种固定写法。同一类笔画可以通过不同的下压、提按、行进和转向过程完成；这些过程上的细微差异会改变线条的力度、厚薄、节奏和形态质感，并进一步形成不同的审美效果。因此，研究一个基本笔画时，不能只比较最终轮廓，还需要观察它在书写过程中的变化方式。

本项目选择横、竖和横折作为分析对象，正是因为它们能够分别呈现内部下压调制和方向转折。长横、短横、长竖、短竖具有不同的内部下压轨迹；横折则在同一条完整笔画中包含明确的方向变化。这些差异构成了传统笔法中可以被分析的过程特征。

### 2.2 仅依靠视觉观察的局限

传统书法研究通常通过观察书写动作和最终墨迹来判断下压程度及其变化。墨迹的宽度、浓淡、边缘形态和局部轮廓可以提供有价值的线索，但这些线索仍然是对书写过程的间接推断。

这种方法存在几个限制：

1. 视觉判断受到观察者经验和主观标准影响，难以形成统一的数值描述；
2. 最终墨迹是整个书写过程的结果，不能完整保留下压变化的时间顺序；
3. 墨量、笔毫状态、纸面条件和行进速度可能同时改变墨迹形态，单凭图像难以区分这些因素；
4. 同一笔画的多次书写难以通过视觉结果进行连续、精细和可复现的过程比较。

因此，视觉观察适合描述成品形态和审美效果，但不足以单独回答“下压过程如何变化”以及“转折发生在何处、持续多久”等过程问题。

### 2.3 磁传感器提供的过程观测

本项目引入磁传感器，对集成在毛笔中的柔性磁性元件进行连续记录，将笔毫接触和形变相关的变化转换为随时间变化的磁响应。磁响应幅值可以作为下压相关接触变化的量化观测量，磁响应方向可以作为转折过程的时序观测量。

这里的磁响应不是未经标定的绝对压力读数，也不直接等同于真实笔锋角度。它的价值在于：相对于只观察最终墨迹，磁响应能够保留书写过程的时间顺序，使预先定义的阶段性下压和方向转折可以用连续曲线、阶段差值和过渡宽度进行分析。

### 2.4 本实验要回答的问题

因此，本实验不是要用磁曲线替代书法中的视觉和审美评价，而是要检验一种现代过程观测方式能否揭示传统笔画中难以从成品直接量化的信息：

- 对横和竖，磁响应幅值能否呈现长、短笔画内部预先定义的下压调制；
- 对横折，磁响应方向能否呈现完整笔画中的方向过渡；
- 这些过程特征是否能够以逐笔曲线和指标形式保存、比较和复核。

如果实验得到支持，磁响应可以作为传统书法笔法研究的补充过程证据；如果某些过程无法稳定反映，也可以明确哪些笔法特征仍不能由当前装配和观测量解释。

## 3. 研究对象和分析口径

### 3.1 横、竖的幅值条件

横和竖各设置长、短两种完整笔画：

| 笔画 | 内部下压调制的学术表述 | 主要分析对象 |
|---|---|---|
| 长横 | 第一、第三阶段的名义下压水平高于第二阶段的三阶段调制 | 三个内部阶段的磁响应幅值顺序和差值 |
| 短横 | 由较低名义下压水平向较高水平递进的两阶段调制 | 两个内部阶段的磁响应幅值差异 |
| 长竖 | 第一、第三阶段的名义下压水平高于第二阶段的三阶段调制 | 三个内部阶段的磁响应幅值顺序和差值 |
| 短竖 | 由较低名义下压水平向较高水平递进的两阶段调制 | 两个内部阶段的磁响应幅值差异 |

这里的“名义下压水平”表示实验中预先定义的书写条件。实际结果使用“磁响应幅值”表述；在没有独立力标定时，不把磁响应幅值直接写成物理压力值。

起笔和收笔不进入上述内部阶段。它们可以在完整曲线中保留，但不参与主要幅值指标。

### 3.2 横折的方向条件

横折作为一条完整笔画，分为三个内部区间：

1. **转折前区间：**横向行笔阶段；
2. **转折区间：**方向改变发生的局部区间；
3. **转折后区间：**竖向行笔阶段。

本轮主要研究磁方向从转折前区间到转折后区间的变化，不把横折的幅值变化与横、竖的下压调制放在同一个假设中检验。

## 4. 实验步骤

### 4.1 第一步：冻结笔画定义

分别确定长横、短横、长竖、短竖和横折的完整路径，并为每条路径标出内部分析区间。

- 长横、长竖标出三个内部下压阶段；
- 短横、短竖标出两个内部下压阶段；
- 横折标出转折前、转折中和转折后三个区间；
- 起笔和收笔区间单独标记为排除区间。

阶段边界来自预先定义的路径、控制点、事件记录或同步视频，不能根据磁幅值峰值或磁方向突变事后移动。

### 4.2 第二步：采集完整笔画

分别采集五种条件的完整笔画，并保存每条笔画与其路径版本、分析区间和成品记录的对应关系。

每条完整笔画作为一个独立实验重复。一个笔画中的多个内部阶段只用于计算该笔的阶段指标，不增加独立样本数。

### 4.3 第三步：计算幅值和方向曲线

对每条记录使用同一处理口径得到：

- 磁响应幅值曲线；
- 磁响应方向曲线；
- 路径进度或归一化时间；
- 各内部阶段的有效数据范围。
短横：观察后段幅值是否高于前段；

横和竖主要使用磁响应幅值曲线。横折主要使用磁响应方向曲线，幅值只作为转折区间的辅助记录。

### 4.4 第四步：计算阶段指标

对横和竖，在每个内部阶段计算幅值中位数或阶段平均值，得到阶段间幅值差。

对横折，在转折前和转折后区间计算圆均值方向，并计算：

- 转折前后的磁方向差；
- 方向变化从 10% 到 90% 所占的转折区间宽度；
- 转折区间内方向有效数据的比例。

### 4.5 第五步：形成逐笔比较

先在每一条笔画内部比较各阶段，再比较同一笔画族的长短条件：

- 长横与短横；
- 长竖与短竖。

横折单独展示方向过渡，不把横折的转折指标与横、竖的幅值指标混合成一个总分。

## 5. 各笔画的预期结果

### 5.1 长横

**实验目标：**

检验磁响应幅值是否能够呈现长横内部的三阶段下压调制。

**预期观察：**

若磁响应能够反映预设的下压变化，则长横内部应出现以下幅值关系：

- 前段幅值高于中段；
- 后段幅值高于中段；
- 前段和后段不要求完全相等，但应共同高于中段，满足第一阶段和第三阶段的幅值均高于第二阶段的三阶段幅值关系。

**主要结果：**

- 三个阶段的幅值中位数；
- 前段与中段的幅值差；
- 后段与中段的幅值差；
- 完整内部幅值曲线是否呈现预定的阶段顺序。

**不作出的判断：**

不把该结果直接解释为真实法向力曲线，也不评价长横的起笔和收笔质量。

### 5.2 短横

**实验目标：**

检验磁响应幅值是否能够呈现短横由较低下压水平向较高下压水平过渡的内部过程。

**预期观察：**

若磁响应能够反映预设的下压变化，则短横后段的幅值应高于前段，内部曲线呈现由低到高的阶段性变化。

**主要结果：**

- 前、后两个内部阶段的幅值中位数；
- 后段相对前段的幅值差；
- 后段幅值是否高于前段。

**不作出的判断：**

不把短横与长横之间的全部幅值差异归因于下压变化，因为二者的几何长度和行程也不同。

### 5.3 长竖

**实验目标：**

检验与长横相同的三阶段下压调制，在竖向路径中是否呈现相应的磁响应幅值模式。

**预期观察：**

若磁响应对该下压调制具有响应，则长竖应表现为：

- 前段幅值高于中段；
- 后段幅值高于中段；
- 前后两段共同高于中段，满足第一阶段和第三阶段的幅值均高于第二阶段的三阶段幅值关系。

**主要结果：**

- 三个内部阶段的幅值中位数；
- 两个高—低阶段差值；
- 长竖的幅值模式与长横是否具有相同的阶段顺序。

**不作出的判断：**

不预设长竖的绝对幅值必须与长横相同。路径方向和装配响应可能导致幅值基准不同，首要比较是阶段顺序和相对变化。

### 5.4 短竖

**实验目标：**

检验短竖由较低下压水平向较高下压水平过渡时，磁响应幅值是否呈现相同的阶段变化。

**预期观察：**

若磁响应能够反映预设下压变化，则短竖后段幅值应高于前段，满足后段幅值高于前段的内部幅值关系。

**主要结果：**

- 前、后两个内部阶段的幅值中位数；
- 后段相对前段的幅值差；
- 短竖与短横是否具有相同的幅值变化方向。

**不作出的判断：**

不把短竖与短横的绝对幅值直接视为相同的压力水平，也不将差异直接解释为笔锋姿态差异。

### 5.5 横折

**实验目标：**

检验完整横折笔画中的方向变化是否能够在磁响应方向曲线中被定位和量化。

**预期观察：**

若磁响应方向能够反映该转折过程，则应观察到：

- 转折前区间具有一组可计算的方向参考；
- 转折后区间的方向与转折前存在明确差异；
- 方向变化主要集中在预先定义的转折区间附近；
- 方向曲线可以呈现连续过渡，不要求出现理想化的瞬时跳变。

转折前方向可与横向参考段比较，转折后方向可与竖向参考段比较。该比较只用于说明磁方向过程的对应关系，不把磁方向直接命名为笔锋绝对方向。

**主要结果：**

- 转折前后的磁方向差；
- 方向过渡宽度；
- 转折区间方向数据的有效比例；
- 横折方向曲线的完整形态。

**不作出的判断：**

不把横折的方向变化直接解释为精确的笔锋转角，也不把横折幅值曲线当作本轮的主要下压模式结果。

## 6. 结果组织方式

### 6.1 幅值结果

先分别报告横和竖的长短条件，再进行同方向比较：

1. 长横与短横的阶段幅值模式；
2. 长竖与短竖的阶段幅值模式；
3. 长横与长竖的三阶段模式比较；
4. 短横与短竖的两阶段模式比较。

比较重点是阶段顺序、阶段差值和曲线形态，不是单个峰值的大小。

### 6.2 方向结果

横折单独报告：

1. 转折前方向；
2. 转折区间方向过渡；
3. 转折后方向；
4. 转折前后方向差和过渡宽度。

## 7. 结论边界

如果预定阶段顺序与磁响应幅值顺序一致，可以表述为：

> 在所测毛笔装配和书写条件下，磁响应幅值能够记录横、竖笔画内部的阶段性下压调制。

如果横折出现可重复的方向过渡，可以表述为：

> 在所测横折条件下，磁响应方向能够描述完整笔画中的方向转折过程。

不能直接表述为：

- 磁传感器已经测得了真实压力值；
- 磁方向就是笔锋绝对方向；
- 三类实验已经建立了通用的毛笔书写模型；
- 磁响应已经证明成品质量或书写效率得到改善。

## 8. 审查项目

- [ ] “阶段性下压调制”是否作为正式论文术语；
- [ ] 长横和长竖是否确定为第一、第三阶段幅值高于第二阶段的三阶段轨迹；
- [ ] 短横和短竖是否确定为“由低至高”的两阶段轨迹；
- [ ] 起笔和收笔排除区间由哪些路径点或事件定义；
- [ ] 横折是否首轮只研究方折方向过渡；
- [ ] 横折的转折前、转折中、转折后窗口如何冻结；
- [ ] 是否将物理“压力”统一改写为“名义下压水平”或“下压相关磁响应幅值”；
- [ ] 是否需要增加同长度、不同下压轨迹的控制实验，以单独分离长度因素和下压因素。
