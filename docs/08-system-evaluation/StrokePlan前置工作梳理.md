# 前馈研究进展与 StrokePlan 生成前置工作

## 1. 当前研究定位

2026-10-19 状态核对：每套前馈关系限定于**同一支毛笔及其装配**。brush2 的历史建表和验证限定于当时条件，不将参数直接迁移到其他装配，也不增加跨毛笔泛化任务。研究仍聚焦前馈关系、不同笔画的过程特征及高质量 StrokePlan 生成。

当前主线为：

**brush2 建表、离线评价与首轮独立验证（已完成，但可靠性未成立）→ 现有前馈可靠性与执行条件复核、候选磁目标准备（当前阶段）→ 参考笔画调试与重复采集 → 不同笔画的特征研究 → 有依据的高质量 StrokePlan 生成与评价。**

几何和候选磁目标可以并行离线准备。当前已有 XY 模板及 brush2 五档磁目标／宽度意图参考，长横等笔画的阶段边界、曲线与实际笔宽关联仍待完成；这套经验初值不等于已有可靠的笔宽控制。

已有直接生成 StrokePlan、单笔执行和整字试验属于工程探索。按用户确定的论文定位，直接指定路径、磁目标和动作配方的做法不作为论文提出的生成方法。当前也没有启动为 Transformer 收集训练数据的任务。

完整阶段关系见 [plan.md](../../plan.md)。测试前馈时可以使用简单目标计划，但它的作用是验证前馈，不能代替论文需要的高质量生成方法。

### 2.1 前馈研究已经回答的问题

已有数据支持在明确条件下建立“命令高度/名义压深—磁响应”的经验关系。不同方向在相同命令高度下可以有不同原始响应，因此需要在测量端校准到统一 Bxy 特征，再使用一张公共前馈表。方向曲线用于校准内部，不以不同高度强求四方向原始幅值相同；这类原始差异本身不是重复性不足。重复性应比较同方向、同速度、同高度的重复笔次。

方向、倾斜方位和路径条件共同变化，当前校准是这些实测条件下的经验对应关系，不要求先拆分全部物理原因。Z 是命令高度，名义压深由接触参考减命令高度得到，不能直接写成真实笔毫压缩量或法向力。

目前还没有证明速度可以忽略，也没有得到适合所有方向的速度修正。brush2 首轮验证已经暴露候选失配；后续先按固定条件处理可靠性与适用范围，不先扩大到任意速度、角度与连续转向。依据：[四向实验定义](实验清单.md#four-direction)、[方向校准设计与结果](实验清单.md#directional-calibration)。

### 2.2 最新前馈的离线结果意味着什么

离线比较使用当前 X 参照 M0、增益＋偏置 M1、方向分段曲线 M2，并按完整笔次划分训练与测试。方向相关模型降低了本批磁响应预测误差；M2 总体响应预测较好，但命令 Z 反查未明显优于 M1，也不是每个方向都更好。

仍需保留三点限制：

- 边界样本和部分沿程分箱无法反查；只对成功反查部分计算的误差，不能代表全部数据。
- 中段代表值较好，不表示整个笔画稳定。主窗口已避开起笔前段，沿程分析仍发现 −X 定高笔内变化；起笔峰值和收笔没有因此得到校准。
- 核心多高度记录含不同采集阶段的节点。已有留出测试支持本批候选，不能当作全新批次或所有条件下的通用验证。

最新候选的主要离线证据范围为已采四个离散方向、相应倾斜、10 mm/s、Z35/Z30/Z27 节点及中段窗口。具体误差、覆盖和测试划分见 [完整离线测试](实验清单.md#directional-calibration) 与 [结果报告](../../runs/brush2/2026-10-05/四方向速度下压实验/analysis/directional_calibration_benchmark/index.html)。

**2026-10-08 已观测到独立执行产生的新磁响应，但冻结候选未能稳定实现公共目标。** 8 笔结果见[正向验证报告](实验清单.md#g17)。早期前馈/P/PI 成绩不能替代这次结果，离线预测改善也不能直接写成墨迹改善。

## 3. 当前缺口：可靠前馈与通用笔画接入

要解决的问题仍是：**同一支笔在相同命令高度下，各方向校准后的 Bxy 是否接近，并能否用一张公共前馈表实现可重复的目标？** brush2 的 +X/+Y 首轮结果尚未支持可靠使用；后续须在明确条件内处理已暴露的失配和重复性问题。这一阶段检验标定与执行关系，不承担笔画特征研究或论文生成方法的验证。brush2 的公共参考与冻结验证条件见[总览](实验清单.md#public-feedforward)；任意角度与连续转向仍待验证。

| 欠缺 | 需要得到的结果 |
|---|---|
| 最新候选与执行器衔接 | 明确实际加载哪份曲线、目标使用什么幅值语义、如何反查命令高度及如何处理越界。离线候选不能直接改名当作现有单方向配置加载。 |
| 可靠的目标跟踪证据 | brush2 已有固定条件验证但未验证可靠；修订关系后仍须独立测试。变化目标尚未完成，完整瞬态与稳态分别评价。 |
| 同条件重复证据 | 比较相同方向和设置下的重复执行，判断整体偏移及沿程变化是否仍妨碍使用。 |
| 结果与模型的对应 | 将目标、所用表、实际命令、磁响应和可用的实际 TCP 关联到同次运行；涉及墨迹结论时再关联本次成品。 |

建议先用**纯前馈**隔离最新映射的作用；加入反馈后的改善应另行解释。测试目标可以由现有脚本生成，这是校验工具，不意味着采用这些脚本作为论文生成方法。对照或重复时保持所用目标与主要条件一致，避免将目标变化误当作前馈改善。

当前不要求先补齐所有方向、速度和加载历史。测试后可以限定表的可用范围；若结果不能支持使用，则处理暴露出的具体问题，再决定是否需要补充针对性数据。没有预先要求扩大采集总量。

brush2 校准与公共表已接入[专用 A/B 入口](../../scripts/run_feedforward_calibration_validation.py)，+X/+Y、两个工作点、每条件两笔的 8 笔已于 10 月 8 日完成并分析。该入口不等于通用 StrokePlan 已接入；校准目标契约和旧配方迁移仍未完成。依据：[方向模型实施边界](实验清单.md#directional-calibration)、[当前通用前馈接口](../../src/brushbot/feedforward.py)。

## 4. 测试前馈后的准备与目标：参考笔画及特征研究

### 4.1 先获得形态达标、可重复的参考笔画

在研究磁响应能否提供更多信息之前，先让机械臂写出可用于采集的参考笔画。这里的“完美”落实为：**符合明确的目标形态，且同一计划重复执行仍能保持质量。** 当前尚未完成这一阶段，不能将已有整字试验直接当作达标参考。

可以先选择一个典型单笔，例如横，明确目标轮廓、沿程宽度和起收笔形态。用现有路径、阶段参数和人工控制点生成试验计划，通过实际墨迹调整路径、节拍和提按相关命令，直至达到参考要求。后续通过独立验证的前馈表只在其支持条件内提供映射；当前候选尚不能视为可靠。起收笔等尚无标定支持的阶段仍需实际调试，不能直接套用中段离线结论。

调试依据是本次实际墨迹是否实现目标，而不是磁误差小就算写得好。这个过程允许人工调参，也不要求先证明磁信号比宽度或命令高度包含更多信息：磁记录可以先作为同步观测量保存，其研究价值在后续分析中检验。

获得满意笔画后，固定计划、前馈表及主要执行条件，重复执行并将每笔的过程记录与成品配对。重复达标的记录用于建立参考过程；调试中的失败笔画和有意改变参数的试验也应保留，用于解释哪些过程变化影响了形态。并非所有记录都必须先达到参考质量，但需要区分参考、调试和对照记录。

先前 brush2 参考方案按横、竖、横折、撇、捺调试，每种达标后固定配方、NPZ、校准模型、公共 G 和现场设置，再采两笔过程—成品配对；五种全完成才是 10 笔，该采集尚未完成。调试与失败记录不冒充正式重复，不只挑选较好的一笔。每个 run 关联目标图、实际墨迹、模型与输入快照、操作变化及质量备注，保持图像方向和尺度可比。

这一步是**参考样本获取与数据准备**。人工调出的参考计划不自动成为论文提出的生成方法；用于选定参数的记录，也不能再作为证明生成方法或磁信息优势的独立测试证据。

### 4.2 从参考与对照记录研究不同笔画的特征

已有方向、高度和速度实验主要回答标定问题。**±X/±Y 四方向不等于横、竖、撇、捺四种笔画；同一条直线的高度响应也不是完整笔法特征。** 不应把现有标定数据写成已经完成不同笔画的过程研究。

在参考笔画及其过程—成品配对形成后，研究重心转向：不同笔画有哪些可重复的过程特征，这些特征如何支撑生成目标。可沿用现有研究决策中的横、竖、撇、捺范围，先分析典型单笔，再比较同类写法和跨笔画的相关动作。参考记录给出期望过程，对照记录帮助检验特征与形态的关系；观察到相关性仍不等于证明磁响应提供额外信息。依据：[研究决策](../其他/research-decisions-and-todo.md)、[研究计划的过程量化部分](../其他/proposal_ethan_260925.md)。

| 研究内容 | 希望得到的知识 | 对后续生成的用途 |
|---|---|---|
| 起笔、行笔、收笔及必要动作衔接 | 各阶段的幅值变化、时序、持续长度和重复差异。 | 确定目标曲线的阶段结构，而非任意指定控制点。 |
| 提按相关变化 | 明确条件下，加载/卸载与磁响应、成品形态之间的对应及边界。 | 约束目标包络和阶段参数；没有标定时不直接把宽度换成磁值。 |
| 方向与动作转换 | 哪些磁分量变化来自行笔方向，哪些在校准后仍与动作过程相关。 | 避免把装配方向响应误用为笔画独有特征。 |
| 同类写法与跨笔画比较 | 同一类内部的变化，以及相似动作在不同笔画中的共同性与差异。 | 判断哪些规则可共用，哪些需要分笔画参数。 |
| 过程与本次成品配对 | 过程目标实际形成了什么形态，哪些特征与目标实现有关。 | 为“高质量”生成提供形态依据。 |

阶段与动作应事先定义，再结合执行记录和独立复核分析；不能仅凭磁曲线的峰谷反过来宣称识别了真实笔锋状态。比较笔画特征时，还需分开解释方向、长度和速度等条件差异。

这一阶段的交付应是**阶段—动作—特征说明、重复性与适用边界，以及可用于生成的参数或模板**。这些数据服务于笔画研究，不自动等于 Transformer 训练集；当前也不要求预设网络结构、训练规模或人类示范数量。

## 5. 后续研究目标：形成有依据的高质量生成方法

### 5.1 此前直接生成的定位

已有生成方式从字形中线或指定路径出发，再通过人工磁目标控制点、动作配方、方向姿态和时间规划组装 StrokePlan。它验证了目标格式与执行流程，但目标为什么这样安排、参数怎样适用于其他笔画，以及是否能够实现目标形态，还缺少系统依据。依据：[现有字符生成设计](../04-robot-control/character-strokeplan-design.md)。

按当前论文定位，这些尝试保留为工程探索，并可继续用于调试和获取参考笔画，不作为论文提出的生成方法。尚未完成的研究工作是建立**可解释、由笔画特征支撑、能够在其他目标上检验的生成规则**。

### 5.2 可推进的生成路线

结合已确认的研究方向，可以研究以下路线；这是候选方法结构，尚未完成或验证：

**目标笔画几何/轮廓与类型 → 过程阶段和动作结构 → 由实测特征约束阶段参数 → 联合组织 XY、时间与磁目标 → StrokePlan → 执行与成品评价。**

规则和参数化模板可以表达动作结构；不同笔画研究提供目标包络、阶段位置、节拍及参数边界。生成器应根据目标几何与所学到的规律确定过程要求，避免为每一个目标重新手工调一整套曲线。几何无法唯一确定的动作选择应保留为方法假设，不声称恢复了原作者唯一的真实动作。

最新前馈表在这里负责将目标转成命令，而不是独立决定“好的笔画应该是什么样”。前馈研究提供执行基础，笔画特征研究提供生成依据，两者共同支撑方法，但作用不同。该路线与 [现有研究计划的生成与执行部分](../其他/proposal_ethan_260925.md) 一致，不依赖先训练 Transformer。

### 5.3 怎样证明生成质量

| 评价层次 | 需要回答的问题 |
|---|---|
| 计划质量 | 阶段和目标来源是否明确，轨迹/时间/磁目标是否一致，是否满足所选映射范围与执行约束。 |
| 执行质量 | 生成的目标能否被实际跟踪，重复执行是否一致，有哪些越界、限幅或阶段偏差。 |
| 成品质量 | 本次墨迹是否实现预定轮廓、局部宽度和起收笔要求，改善是否在重复中保持。 |

应在没有用于拟定参数的目标几何上验证；同一来源的缩放或扰动版本不能分别充当独立训练与测试来源。若要主张“笔画特征提高生成质量”，还需比较使用/不使用这些特征的方法，并保持执行器、前馈和主要条件一致，避免把反馈收益归因于生成器。

若新方法只在原先手调的目标上有效，或在一致对照中没有改善，应收窄生成主张；若缺少匹配成品，只能报告计划或跟踪结果。没有独立的过程参照时，也不能声称精确复现了真实笔法。这些条件区分方法成立、不成立及证据尚不足，不预设结论。

“高质量”需要同时说明计划合理性、执行表现和目标形态实现，不能只用文件生成成功或磁误差较小代替。具体评价标准将在对应研究实施中明确，本文不虚构阈值或保证改善。

## 6. 对现有文档口径的修正

| 现有说法或容易误解的状态 | 当前应采用的口径 |
|---|---|
| 前馈建表和离线验证完成，似乎执行效果也完成。 | brush2 已有首轮独立执行结果，但当前冻结模型未验证可靠。 |
| 做过 StrokePlan 和整字，似乎论文生成方法已经具备。 | 这些属于工程探索；研究特征并建立高质量生成方法仍未完成。 |
| 前馈之后直接生成计划即可。 | 前馈测试之后先调出可重复的参考笔画并采集，再研究不同笔画的特征，将特征转成生成依据。现有生成脚本可用于校验和数据准备。 |
| 历史不同毛笔或条件被列为当前必须解决的泛化缺口。 | 每套标定限定对应毛笔及装配；不同标定分别建表和评价，不增加跨毛笔泛化任务。 |
| 方向、高度采集被当作笔画特征研究或学习训练集。 | 现有主用途是前馈标定；不同笔画的过程量化是下一阶段目标。 |
| 根计划仍安排 Transformer 完整计划生成。 | 本轮澄清没有启动 Transformer 数据采集或训练；生成方法先由笔画特征与可解释规则支撑。 |

当前阶段以[根计划](../../plan.md)和独立验证结果共同说明。**校验用目标计划**与**论文生成方法**继续区分；[StrokePlan 主题说明](../02-strokeplan/strokeplan.md)中的示教／模型路线属于后续研究，不是当前数据采集任务。五档经验曲线方案见[多笔画拆分计划](multi-stroke-experiment-plan.md)。
