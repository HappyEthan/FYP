# 磁响应笔画分类工作台

## 启动

在项目中运行：

```bash
bash scripts/run_stroke_classifier.sh
```

启动器优先使用项目的`.venv/bin/python`，否则使用`python3`。Linux Wayland会自动使用对应Qt后端，保留用户已指定的QT_QPA_PLATFORM。等价入口：

```bash
.venv/bin/python scripts/train_stroke_classifier.py
```

依赖缺失时使用同一Python安装`requirements-stroke-training.txt`。窗口不会自行联网安装。可以用`--store /绝对路径`选择另一模型历史目录，默认在项目的`outputs/stroke_classifier`。

## 五页工作流程

1. 数据集：选择一份或多份`.brushrun`，也可通过原有“导入实验目录”按钮选择实验文件夹。在目录选择窗口按住Ctrl点选多个文件夹，或用Shift连续选择，再点击“导入选中目录”；每个所选文件夹应为包含manifest.json的实验目录。程序自动检查，合格实验默认勾选；不合格记录显示问题并禁止参与训练。勾选不会直接启动训练。
2. 训练：勾选幅值、方向、特征融合、分数融合、形状／变化率融合中的任意组合，在高级设置中调整候选参数，点击开始。至少3次完整实验；分数融合至少4次，方向条件也须通过。
3. 训练结果：选择模型查看混淆矩阵、逐类及逐实验表现、留出错分及当轮分数、PCA二维／三维投影和真实两类判别值。圈出的支持向量对应所选模型／分支；投影不是完整决策边界。图表可导出PNG。
4. 模型历史：一次训练一条记录，展开后分别加载各子模型。收藏整条记录置顶；可以重命名、删除某个模型或整次记录，回收区可恢复。训练数据与原始实验不受删除影响。批量清理跳过收藏记录。
5. 模型识别：加载模型，添加新实验或单笔CSV，点击识别。显示每笔预测、真实任务标签对照和各类判别分数；分数不是概率。新测试另存，不重新训练或覆盖模型。训练来源重叠时标为回放，不计新数据准确率。

## 输入协议

新训练每次七笔，固定顺序为右点、横折钩、横撇、撇、捺、横、竖，即先永字后横竖。任务标签来自用户预先约定顺序；不能自动核验所有人工错序。存在显式分类协议／标签声明时检查冲突，缺少事件边界时拒绝导入，不把整条曲线等分七段。

按`measure_00`至`measure_06`首末关联`sample_seq`切段，包含其间所有原生传感器样本。原始采样至少包含seq、sensor_t_us、dBx_uT、dBy_uT；active内不得无效或跨基线、时钟／序号缺口。每笔前至少100个连续有效预热采样。来源快照覆盖manifest、sensor、control及可用协议记录，复制归档不会增加实验数。

每笔输入统一为128个归一化时间点，标量先取模后连续EMA，默认alpha=0.3。A1减去每笔前10%原生EMA中位数；这是替代基准，不代表接触前零压力。方向有效阈值默认5µT、有效覆盖不少于90%，相对方向锚点另检查稳定性。处理规则随模型保存，新识别按该规则导入。

单笔CSV必须保留写前采样，并配同名JSON，例如`stroke.csv`配`stroke.json`：

```json
{"seq_start": 210, "seq_end": 340}
```

边界必须对应CSV实际seq，不允许猜测起笔。没有真实类别也能预测，此时不统计正确率。

## 验证与推荐顺序

十次实验执行十轮，每轮九次训练、一次测试，同次七笔始终同侧。核、参数、融合权重及标准化只在当轮训练实验内部选择。留出评价完成后，使用全部开发数据拟合各选中方法的最终模型并保存。

推荐顺序依次按总错分少、最差类别召回率高、最差实验正确笔数高排序。三项相同则并列。默认只比较同一训练记录，跨不同实验队列不能据绝对错误数判优。主排序不是显著性结论；Macro-F1和Accuracy保留于报告。方向不可用不会静默删除难样本后排名。

## 模型保存、导出和历史五类基线

训练结果放在`outputs/stroke_classifier/tasks/<任务ID>`。`task.json`含模型列表、来源、配置、OOF预测和指标；每个子模型目录中的`bundle.joblib`包含固定处理配置、缩放器、SVC／融合组件、PCA、训练来源及依赖版本。SHA256在加载前核对。

模型历史中可以导出整次成果或某一子模型为ZIP，并通过“导入模型成果包”重新导入本工具。依赖和分类模块仍需安装，ZIP不是独立可执行程序。只使用自己生成或来源可信的模型包。

“导入已核验的历史五类基线”只读适配`outputs/stroke_model_random10_20261106`中的已知SHA模型，不重训或修改原件。它只支持前五类，不能当七类模型。查看新七笔实验时，仅对支持类别给分，横／竖显示超出范围，不计为普通误判、不计算伪七类准确率。历史固定linear回测与新嵌套候选验证标明来源。

## 研究范围及已知条件

F0比较A0/A1/A2/A4，F1比较D1/D2/D3，F2为幅值与方向特征融合，F3为训练侧交叉拟合分数标准化融合，F4为A1与A4融合。默认linear/RBF及研究候选范围可在高级设置收缩；不是每次必须训练五种。

A3缺少独立共同参考响应／增益证据，记录为条件不足；默认不执行辅助LinearSVC及F4额外方向扩展。数学偏移与相对旋转对照可选，属于数值试验，不代表真实机械扰动。条件项、未选分支和失败原因记录于研究记录及报告，不声称原研究所有扩展已经全部完成。

程序完全离线，不连接机械臂，不改变路径或磁目标，不自动开始真实数据训练。`outputs/stroke_classifier_verification`中的模拟数据和界面截图仅用于软件验证，不是实验分类成果。

## 学习曲线与参数验证（2026-11-10）

从“模型历史 → 查看结果”选择任务和子模型。在“学习曲线”设置训练实验次数与重复种子，再点击“生成分析”。16次来源默认比较4、6、8、10、12、15次训练，每次实验七笔整体进出。每个外层训练子集内部重新选择参数，外层留出的实验不参与选参。图中训练线为回代成绩，留出线为完整实验轮流留出成绩；每组重复先汇总所有留出预测再评分。阴影为重复结果的最小值到最大值，不是置信区间。最大规模的重复集合相同，不代表零不确定性。

在“参数验证”选择C验证、F4差分权重验证或二者联合比较。C使用对数横轴；单因素分析固定原模型其他参数。默认C候选0.001、0.01、0.1、1、10、100；修改中心值再点“生成附近2倍候选”只更新候选列表，不自动计算。例如中心0.1生成0.025、0.05、0.1、0.2、0.4。联合比较显示Macro-F1或正确率热力图；逐行结果含最差类召回、错分数与各类召回，点击行可查看混淆矩阵和类别表现。

高级设置将F2方向权重和F4差分权重分开，旧项目共用的weights自动作为两项的回退值。差分权重放大标准化差分特征块，不是百分比；候选必须为有限正数。F3分数融合幅值权重仍独立。线性核不使用gamma。本版不包含gamma验证曲线。

运行前显示未计缓存的拟合次数上界；F3每次模型拟合还包含分支校准。分析在独立进程运行，可取消；来源文件缺失或指纹改变时拒绝计算。记录保存在原任务的`analyses/<分析ID>`，不将临时拟合加入模型历史。用“查看分析记录”回看，“导出分析”输出PNG、PDF、逐组指标CSV、完整结果JSON和配置JSON。取消及失败记录不会列为成功结果。

选中参数验证表中的一行，点击“将所选候选写入下次训练设置”：同时采用分析来源的预处理配置、该候选的核/表示/参数，并只勾选对应子模型；如果预处理改变，已导入实验自动重新检查。此操作不会启动训练，仍需点击原有“开始训练”。现有模型保留。

这些图用于开发调参与判断是否继续采集，最高点不是独立测试成绩。不要因小训练规模分数高而丢弃合格实验。按run留一不保证未见随机配置泛化（011、012的随机目标配置相同）；同配置一起留出的对照留作后续。方法确定后需另采未参与选择的新实验验收。历史五类模型保留结果与投影查看，不开放七笔分析。

## 2D／3D模型空间交互

“模型空间”保留最终模型保存的PCA，只切换显示，不重新训练或重算降维：

- 2D可选PC1–PC2、PC1–PC3、PC2–PC3；3D可拖动旋转、重置视角及选择三个正视方向。筛选与大小/透明度调整保留视角。
- 勾选笔画名称或点击图例显示/隐藏类别。“高亮实验”使所选实验突出，其余样本变淡以保留背景。“仅看留出错分”只显示原留出错误；支持向量外圈默认关闭。
- 真实类别固定配色，×为留出错分，星形为新样本；点位和坐标范围不会因为类别筛选重新缩放。
- 点击散点或使用右侧列表定位样本，查看实验名、真实类别、原留出预测、幅值/相邻差分曲线及判别分数（不是概率）。切换模型会清空上一模型的样本详情。
- 识别页复用同一展示，新样本只用保存的变换定位；列表首项可返回新样本详情。图表工具栏支持保存，结果页“导出图表”同时输出PNG和PDF。

点的位置来自最终模型PCA；错分来自原当轮留出模型，两者来源不同。累计解释方差显示当前投影保留的信息，投影重叠不代表完整特征中的分类失败，分开也不保证新实验能识别正确。本版不绘制二维决策背景或聚类。窗口较小时，结果页与识别页可滚动查看，避免控件挤压。
