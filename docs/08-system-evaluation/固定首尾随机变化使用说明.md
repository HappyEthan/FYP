# 固定首尾随机变化使用说明

## 入口与基本操作

打开路径编辑脚本 `scripts/edit_brush_path.py`，在 **高级设置 → 随机变化…** 中操作。

1. 选择或编辑标准笔画，可使用单笔或当前多笔工作区。
2. 勾选“启用随机变化”，选择路径 XY、磁目标中的一项或两项。
3. 设置幅度上限，点击“生成本次变化”。程序为当前工作区各笔生成新的随机值并完整预检。
4. 在“规划路径”“磁响应目标”页查看标准与本次结果，切换笔画查看有效变化和缩小原因。
5. 点击“应用设置”，再按现有流程预检、导出或打开试写终端。是否执行仍由原试写入口控制。

取消对话框不修改当前设置。总开关关闭时使用标准执行命令，已抽取的随机结果保留，标准编辑数据不被覆盖。

## 每次随机与重复采集

每次点击“生成本次变化”会使用新的根种子，分别抽取各笔的宽缓偏移、局部控制值、整笔磁目标比例和局部磁目标比例。数值可以正负变化，XY 方向也会变化。

一次生成后，预览、预检、导出及运行使用同一份冻结结果，不自动重抽。同一导出版本再次执行，重复同一控制条件；需要新的随机条件时，在高级设置中重新生成并导出新版本。这可以分别测量条件之间的差异和相同条件的自然重复波动。

种子是追溯编号；导出同时保存实际控制值、最终执行输入和审计数组，旧记录不只依赖种子重算。

## 起始范围

| 变量 | 默认抽样范围或上限 |
|---|---|
| XY 合成位移 | `min(标准笔画弧长×0.5%, 0.30 mm)` |
| XY 宽缓 / 局部预算 | 合成上限的 70% / 30% |
| 每笔整体磁目标比例 | 均匀抽样于 −5% 至 +5% |
| 局部磁目标比例控制值 | 均匀抽样于 −2% 至 +2% |

XY 起终点固定，内部随机偏移及磁比例场在首尾渐归零。局部控制值以平滑曲线连接，不逐个执行点独立乱跳。上述是工程起始设置，尚未通过真机实验证明最适合分类。

改变路径会影响现有编译器推导的切线姿态和时间规划，系统保存实际变化；不单独随机速度或姿态。

## 预检、缩小与失效

目标范围、名义压深、完整路径和原有运动限制继续检查。遇到范围问题，整笔缩小对应随机场，保留控制值与趋势，显示请求值与有效比例；不逐点削顶、不更换种子来绕过预检。

若标准方案本身非法、有效变化只能为零或有限缩小仍失败，不生成可执行导出。需要调整标准输入、减小上限或显式重新生成。

改动标准节点、目标、有效范围、速度 / 节奏、姿态或执行配置后，旧结果会标记过期。先完成标准编辑，再重新生成；撤销回完全一致的标准输入后可以恢复该批结果的有效状态。

## 导出与归档

标准 `editor_state.json` 保留原工作区及随机批次，`strokeplan.npz` 和执行配置提供本次执行输入。新增：

- `variation.json`：来源摘要、算法版本、实际随机控制值、每笔缩小值、有效统计及文件校验信息。
- `variation_arrays.npz`：标准 / 本次时序、路径、名义磁目标、最终控制参考、姿态及深度等审计数组；禁止 pickle 对象。

独立运行入口会重新编译并比较冻结结果。文件缺失、改动或算法不兼容时要求重新生成导出。旧的无随机功能版本继续沿用标准流程。成功归档与失败保留记录均随运行保存必要输入；传感器记录照实写入，不注入人工随机值。

## 采集与分类使用

建议交错安排标准对照、仅 XY、仅磁目标及两者联合四组条件。每个条件包含重复实测，记录纸面、毛笔、含水状态、session 和 batch，用自然重复波动判断随机条件是否产生额外变化。

分类主输入仍是实测幅值与方向。按 run 分组切分训练和测试；评价未见随机条件时，同一标准版本、参数和种子的重复记录放在同一侧。固定笔顺的混淆控制继续保留。

离线预检与假硬件测试只证明软件链路的行为；实际响应是否丰富、笔画类别是否保留和分类性能是否改善，需要后续实测核验。
