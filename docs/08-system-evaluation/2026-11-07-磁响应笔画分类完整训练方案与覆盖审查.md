# 磁响应笔画分类完整训练方案与原方案覆盖审查

**当前仅审阅和设计。未开始新训练，不修改控制代码、原始数据或已有模型。**

本文重新完整核对原文第1—11节。原文是研究方法依据；本次实施授权仍以用户请求为准。下文所有新增阈值、候选网格和采集数量都是待确认的设计决定，不冒称为已被原文规定或已获用户同意。

## 1. 审阅结论：上一轮完成了什么，还缺什么

原方案本来就包含幅值、磁向量相对方向、单模态、早期融合、晚期融合和鲁棒性对照。补齐方向与融合属于落实原方案，不是另提一套研究目标。

上一轮 `/home/serein/FYP/outputs/stroke_model_random10_20261106/` 实际完成的是：

- 五类、10次运行、50笔的 **A1幅值128点单模态基线**。
- 标量先取模后EMA、前10%参考基线回退、整运行留出及训练侧选linear/RBF核。
- 固定linear为48/50、固定RBF为47/50、含内层选核的流程为47/50；最终全50笔训练为linear。

因此96%只能称为该批数据上的幅值基线开发验证成绩，不能称为完成七类多模态原方案。缺项主要是A0/A2/A4、方向D1/D2/D3、F1/F2/F3/F4、训练侧参数和模态权重开发、完整偏移／旋转对照、跨session/batch评价以及七类数据覆盖。

已有两次固定linear误判——实验002右点→撇、实验003捺→横撇——已被详细检查。以后依据这些结果改特征、参考窗、核或权重，均属开发决策。不得把旧十次数据重新包装成未见过的独立测试，也不因个例末段贡献大就裁掉末段或认定物理原因。

## 2. 目标、输入和实施范围

**目标：** 判断完整实测磁响应曲线中，幅值、相对方向及其融合能否稳定区分完整笔画，并确定一套可以重放的单笔分类处理链。

唯一传感输入是实测磁数据及其派生信息：dBx/dBy → 幅值与磁向量相对方向。方向不是机器人路径方向、笔尖移动方向、真实笔锋角度，也不需要额外传感器。

模型不得使用机器人XY、目标磁值、笔顺、实验编号、文件名、时长、采集日期等作为特征。上述信息仅用于边界、标签、分组与审计。每笔独立输出标签，不施加“一次永字恰好各类一笔”的分配约束。

### 2.1 建议采用的路线及取舍

采用 **五类完整方法开发 → 冻结 → 新批次验收；七类按数据门槛扩展**：

- 先让现有五类数据覆盖原方案全部可执行的合理分支，保留条件项的明确数据闸门。
- 七类另加独立横、竖；没有足够数据时不伪造样本、不借重采样补“独立次数”，也不删除七类目标。
- 等七类数据齐备时，沿用相同处理框架重新开发、冻结与验收，分别保存五类和七类模型。

直接把未核验的历史横／竖混入训练，可以凑齐标签，但会把类别与日期、装配或采集协议混淆；等待全部七类采齐再做任何方向开发，则会拖住现有数据可支持的工作。因此不采用这两种路线作为当前主路径。

本轮不实施实时分段、图像识别、未知类别拒识、神经网络或机器人界面改动。

### 3.2 五类与七类门槛

- 五类：右点、横折钩、横撇、撇、捺；“斜撇／斜捺”保留原名并映射为撇／捺。目前D0可支持五类方法开发。
- 七类：再加入横、竖。每类需要经核验的独立采集身份、完整边界、重复运行及跨组覆盖；每个训练折必须包含全部七类。某类仅一条独立记录时，不能用它既训练又验证，更不能以复制、窗口或增强补独立样本数。
- 七类开发和T验收中应在相同session/batch采到各类，减少“横竖只来自另一天”的类别—批次混杂。
- 若七候选模型只测试永字五类，只能报告该五类在七候选下的预测／召回，不能声称完成七类总体测试。

### 3.3 后续采集的起始规划，需用户确认后实施

当前50笔足以启动五类完整开发比较，但不足以单独证明跨session稳定性。建议跨session开发具备至少4个可核验的开发session，另留至少2个配置冻结后的新session作初步独立验收；每个session每类先规划不少于5条独立完整笔画。五类可由每session至少5次永字运行形成；七类还需同session的横、竖独立重复。

这是便于分组、内层选择及晚期融合训练侧交叉拟合的起始设计，不是统计功效保证，也不是本次启动的采集操作。旧session若有可靠补录可计入；否则保留unknown分组。新session要有实际采集间隔／重新准备等来源记录，不通过修改ID制造独立性。测试session少时只作有限批次验收，不声称已充分估计跨session置信区间。

## 4. 切割、边界和质量审计

### 4.1 连续记录级审计

每次登记run_id、session_id、batch_id、brush_id、installation_id、sensor_mount_id、任务、expected_stroke_count、源文件和配置哈希。session指连续采集会话；batch指更高层的采集批次／准备条件，不能与随机种子等同。字段不明时记录来源与不确定性。

对齐sensor.csv与control.jsonl：核验seq、sample_seq、传感器时钟回绕、主机单调时钟、有效标记、baseline_id、重复、缺口与数据段连续性。基线建立前没有记录的dBx/dBy不伪造为历史实测值。连续有效区段初始化EMA；遇真实缺口／基线更换等断点，登记滤波重启，不跨断点拼接。

### 4.2 完整笔画窗口

优先用已核验的measure_XX或同步标记，按首末关联sample_seq之间的全部原生传感器行提取。每笔记录sample_id、父run、标签来源、原生seq/time边界、reference_window、contact/active边界、post_lift_window、boundary_rule/version、质量和排除原因。

现有协议的“完整笔画”暂指完整measure书写运动段；它之前已经发生接触转动／预加载，不能冒称覆盖了从首次接触到离纸的全部物理过程。审核时把入笔加载、measure、lift分别画在长曲线上；原协议没有可靠标记的首次接触点不通过预测反推。若未来研究全部接触过程，另行冻结新边界协议，不能为了修复旧误判移动当前边界。

预期笔数不符、缺首笔四笔记录、边界缺失、多段接触无法解释、active原始分量无效、时钟异常或采样缺口的记录进入失败表。当前先沿用保守规则：active内不允许缺失／插补；大于该记录有效正间隔中位数2倍记缺口。保留可读取的诊断图，不能静默删除。断点后进入active前需有至少100个连续有效采样，幅值和方向采用同一有效段。

质量排除只依据预登记规则，不依据是否分错。所有方法共享基础合格样本集；方向不可用单独标记，不连带删除有效幅值样本。

## 5. 统一信号处理：先完整计算，再切笔画

### 5.1 幅值主定义

```text
r_raw(t) = sqrt(dBx(t)^2 + dBy(t)^2)
r(t) = EMA_alpha=0.3(r_raw(t))
```

必须先取模再做标量EMA。原生幅值、标量EMA、日志a_raw/a_control分别保存并核对定义；不能用“分量EMA后取模”替代主幅值。

### 5.2 参考窗：真实参考与回退分开

主定义A1为Δr=r−median(r in reference_window)。真实参考窗必须在接触前、已知姿态／位置条件下静止且足够稳定，并有标记、窗口长度、有效性及稳定性证据。下压中的lower_fast、已接触的load_workpoint不能直接称为稳定空载参考。

当前D0没有独立静止参考保持段，保留原方案允许的first_10_percent_fallback：按active实际时间前10%的原生EMA中位数扣除，明确它不是空载零力，也可能移除真实起始加载水平。

保留两个协议分支：

1. legacy-fallback：D0及按同一定义处理的新记录；A1应复现旧128点特征（容差1e-9 µT）。
2. verified-reference：仅用存在核验参考窗的数据。新记录同时可提fallback供同一队列上的公平比较。

不把两种参考方式无标记混用。若样本集合不同，分开报告，不能把数据集合变了造成的提升归因于参考窗方法。未来参考窗采集若现有操作不支持，则继续冻结fallback协议；本次不修改控制时序。

### 5.3 时间和幅值表示

固定τ=(t−t0)/(t1−t0)，τ_j=j/127，K=128。依据传感器实际采样时间插值；时长、点数和路径进度不进入特征。不得为对齐峰谷做水平移动或用DTW替代主时间轴。

| 编号 | 明确定义 | 本轮安排 |
|---|---|---|
| A0 | r(τ) | 保留原µT水平的敏感性对照 |
| A1 | r(τ)−r_ref | 主幅值基线 |
| A2 | [r(τ)−median(r(τ))]/[q95(r(τ))−q05(r(τ))] | 形状对照；统计量统一取128点，近常量标记，分母数值下限1e-8 µT |
| A4 | 对128点A1取相邻差分，首项0 | 全笔变化率对照；不额外挑选旧误判窗口 |
| A3 | A1/max(s_ref,s_min) | 有近似增益变化证据且s_ref可独立定义时加入，见下文 |

A3不因随机磁目标上限变大就自动启用：目标变化并不证明实测只是共同增益缩放。先在训练侧审计同类曲线的比例变化、形状残差与跨类一致性；统计比例关系本身也不能证明传感器增益或力学原因。

建议A3的s_ref来自**所有类别共享、与标签无关的标准参考响应事件**：同一参考加载窗口的实测中位幅值减去空载参考中位幅值。该事件与分类active分离；不能用各类不同的load_workpoint目标值充当s_ref。s_min依据训练侧空载噪声稳健尺度预登记，例如max(1 µT, Q95_train[3×1.4826×MAD(空载EMA)])，测试只调用冻结值。没有共同参考事件时A3暂缓并注明原因，A2仍可检验幅值缩放敏感性。s_ref不稳定、非正或低于可辨识噪声的样本必须标记，不靠极小分母放大。

## 6. 磁向量方向分支

### 6.1 派生与低幅屏蔽

```text
u(t)=EMA_0.3(dBx(t)); v(t)=EMA_0.3(dBy(t))
phi(t)=atan2(v(t),u(t))
direction_valid(t) = [r(t) >= 5 µT] AND 原始分量／时间有效
```

另外对sqrt(u²+v²)接近数值零的点屏蔽，因为分量抵消时atan2方向仍不可定义；数值epsilon固定并记录，不用类别调阈值。方向阈值使用未额外扣参考基线的标量r，不使用可能为负的A1。

在每段连续有效方向内解缠角度、按共同τ网格插值，再生成角度／单位向量；不直接跨±π插值，不跨无效段补点，不向缺失端点外推。保存原生方向、有效段ID、128点mask和全部屏蔽原因。

### 6.2 D1、D2、D3全部进入比较

| 编号 | 定义与参考 | 限制／处理 |
|---|---|---|
| D1 | wrap(phi−phi_ref)，单通道相对角 | 保留原方案候选；圆周插值后再wrap，报告分支跳变；不作为跨朝向绝对角输入 |
| D2 | wrap(phi_j−phi_(j−1)) | 主比较在固定128点τ网格计算，共127个相邻转角，首项0；相邻两点及中间段都有效才有效 |
| D3 | sin(phi−phi_ref)、cos(phi−phi_ref) | 两通道相对方向，避免D1的±π数值跳变 |
| D0 | phi的绝对方向 | 只作固定朝向诊断，不作为跨朝向推荐主输入 |

D2工程调整需明确：原生相邻转角随采样率改变而改变，因此主比较用固定τ步长的相邻转角；原生δphi仍保存作审计。它是相邻转角，不冒称真实笔锋角速度。

phi_ref优先来自核验的稳定、有效磁方向参考窗；幅值参考有效不代表方向参考必然有效。D0没有此类窗口时，D1/D3允许另登记“active前10%有效方向圆均值”作为笔内方向锚点，名称为active_first10_direction_anchor；这是明确的工程调整，不称为接触前物理参考。该锚点同样来自磁数据、与类别无关；D2不需要phi_ref。

建议锚点质量门槛：至少5个有效原生点、圆均值合成长度R>=0.2；方向128点有效比例>=90%。这些是初始质量配置，若需改变只在开发侧改变并版本化。D1/D3锚点不合格时标记该模态不可用，不能强造方向；D2若满足自身有效性仍可独立评估。

### 6.3 屏蔽与公平比较

方向标准化每个通道／τ列只使用训练侧有效值估计均值方差；无效点在变换后置零。训练侧完全无有效值的列禁用；测试不能补拟合该列。mask不作为主模型额外特征，方向有效比例仅审计。

所有比较同时报告：

- 全部基础合格笔画上的幅值结果；
- 各方向分支的可评估覆盖率及失败原因；
- 同一可评估样本交集、同一分组划分上的幅值／方向／融合配对比较。

如方向缺失随类别显著不同，增加mask-only质量混杂诊断，不能把缺失模式带来的分类能力解释为方向内容增益。实际交付若允许方向不可用时回退幅值，回退规则和幅值子模型必须在训练侧确定，并在所有样本上另报端到端覆盖／正确数；不能只展示方向良好样本的高分。

## 7. 模型族：把单模态与融合完整分开

| 编号 | 输入 | 核心比较目的 |
|---|---|---|
| F0 | A1；另列A0/A2/A4 | 幅值独立能力和预处理敏感性 |
| F1 | D1、D2、D3分别输入 | 相对方向／转角独立能力 |
| F2 | [scaler_A(A1), λ scaler_D(Dk)] | 三种Dk分别与A1早期融合 |
| F3 | 两个独立SVC的训练侧交叉拟合标准化分数加权 | 晚期融合与早期融合的差别 |
| F4 | [scaler_A(A1), λ scaler_derivative(A4)]；必要时再加D | 全笔形状／导数的增量；不靠个别错例裁窗 |

F4先做A1+A4；只有训练侧证据支持时增加一个预登记方向分支，不展开所有幅值×方向×导数的无限组合。该条件项仍有状态及结果记录，不静默消失。

### 7.1 线性与RBF及辅助模型

首要核为linear和RBF。训练侧候选按原文：linear的C∈{0.1,1,10,100}；RBF的C相同，gamma∈{scale,0.001,0.01,0.1}。固定C=1、gamma=scale保留为可复现基线，不再只跑固定参数就声称完成参数开发。

早期融合λ∈{0.25,0.5,1,2}；晚期幅值权重w∈{0.25,0.5,0.75}，方向权重1−w。权重仅在开发训练侧选择，记录特征维数和标准化定义。

LinearSVC作为线性实现辅助对照，结果单列，不把它与linear SVC的实现差别解释成模态增益。poly-SVC／NuSVC仅在标准linear/RBF存在记录明确的不稳定问题时加入，不因某个旧错例就扩大算法搜索。class_weight=balanced仅在训练侧支持数不平衡时与None作内层对照。主流程probability=False，分数不是概率；若以后需要概率，必须按运行分组做训练侧校准，不能直接切换SVC内部未按run分组的概率流程。

五类SVC有10个两两分类器，七类有21个。分数融合须把各模型classes_对齐到同一冻结标签顺序；不能混合五类与七类输出。

### 7.2 F3晚期融合的防泄漏顺序

默认用训练侧交叉拟合分数标准化，避免小样本下把未经校准分数当概率：

1. 对一个参数已指定的候选，在“当前训练侧”内部按组交叉拟合幅值、方向模型，获得未拟合该子组的OOF判别分数。
2. 用这些训练侧OOF分数按类别拟合分数均值／尺度，下限和标签次序写入配置。
3. 用当前训练侧全部数据重训两个子模型；预测当前验证／测试侧时，只调用已冻结的分数变换。
4. 加权S=w×S_A_std+(1−w)×S_D_std，再独立给每笔取类别，不加笔顺约束。

这套过程必须在每个内层训练分割中重新建立，不能用当前内层验证或外层测试的分数拟合尺度。跨拟合的每个参数候选先固定，不能用该校准子组的标签先挑参数再称它为完全未见OOF。超参数、方向编码及w通过当前外层训练侧的内层验证选择；外层重拟合时再从外层训练侧交叉拟合建立分数变换。

训练侧有效分组太少、某校准训练子折缺类时，该F3评估记数据不足，不能改成逐笔随机拆分绕过。标准化分数仍不是校准概率；若报告概率，需要额外的分组校准与可靠性证据。

## 8. 分组、开发、冻结和独立验收

### 8.1 开发评价

- D0运行级回测：外层leave-one-run-out；所有同run笔画同侧。内层仅在外层训练运行中选择表示、核、参数和权重，所有缩放器只拟合相应训练侧。
- 这仍属于已被查看过数据上的开发回测。嵌套CV能约束本次计算泄漏，不能消除此前根据D0结果做设计的历史适应性。
- 按用户最新选择，当前方案统一固定为整次实验留一验证（leave-one-run-out）。十次实验每轮九次训练、一次测试，轮流留出全部十次，共十轮；同次七笔始终同侧。session/batch仅作来源审计，不作为当前可选验证方式，也不据此宣称已验证跨会话／跨批次能力。其他实验数量按N次的N−1次训练、一次测试执行。
- 每次划分先检查所有训练及校准子折是否有全部目标类别和足够分组。条件不满足则限制结论／推迟该分支，不悄悄把分组级别降为逐笔。

所有模型族使用同一外层分割清单；每族在训练侧完成自身选择，再输出外层预测。实现可缓存无标签派生曲线、采用预登记的分阶段候选筛选来控制计算量，但筛选仍必须留在当前训练侧；不得先用全部D0筛“最佳特征”再把后续外层成绩称为无选择偏差验证。

### 8.2 选择原则与方向增益判据

按原文顺序：先超越多数类；再看逐类召回／混淆；再看±300偏移和坐标旋转稳定性；性能相近时偏好线性和较简单输入。主模型评价以Macro-F1与Balanced Accuracy为主，Accuracy辅助。

本次建议把“稳定增益”变成预登记的开发筛选条件：

- 在同一可评估队列与分割下，相对A1幅值基线，融合Macro-F1绝对提高至少0.02；Balanced Accuracy不下降。
- 改善不是仅来自一个旧误判：至少两个类别召回改善；任何类别召回下降超过0.10必须明确报告并且不通过自动推荐。
- 至少两个外层运行组改善，改善组数多于退化组数，并报告全部组的配对差值；基线已经全对的组允许持平，不要求它们也提高。建议至少80%的运行组不退化。若已有session级评价，还要看到多个session支持，而不是只在一个session获益。基线已到顶或样本不足时，不强行声称融合增益。
- 方向覆盖率／失败率、参考模式以及鲁棒性不出现抵消收益的明显恶化。

这些阈值是待确认的工程选型门槛，不是统计显著性结论，不保证方向／融合会胜出。数据不支持时，正确结果可以是继续采用幅值模型，同时保留所有方向及融合实验结果。

### 8.3 新批次T的锁定规则

在读取T曲线或模型成绩前，冻结：样本数量／采集停止规则、类别和标签核验办法、组ID、边界和质量规则、参考协议、全部特征定义、屏蔽门槛、候选选择流程、最终模型及比较基线、主要指标和增益判据。

五个模型族可各冻结一个开发侧选定的代表模型；原方案要求的各表示诊断也可冻结后一次性跑同一测试清单。事前指定主模型与A1比较基线，不在T上重新挑最高分。若T失败后需改方案，则T改为开发材料，下次需新的独立验收数据。

主要报告逐类计数、逐run／session表现、混淆和配对差值。误差区间须按run/session/batch等实际独立单位估计，不把50条同源笔画当50个完全独立运行。组数很少时不以窄区间或显著性包装结论。

## 9. 原方案的对照与鲁棒性试验

所有试验使用同一冻结模型、分割和样本ID，不重训、不重新选择参数，不把派生版本增加到独立样本数。

| 对照 | 操作 | 能回答的问题／不能推断的内容 |
|---|---|---|
| 未加人工变换的实测曲线 | 含真实随机书写设置的数据保持原样 | 真实采集条件下的分类表现；“未加扰动”不代表机器人随机开关关闭 |
| 标量偏移±100/200/300 µT | 对连续标量EMA及其参考窗共同加c，再重建幅值输入；方向和方向有效mask保持原真实分量定义 | 数学加性偏移稳定性；负值可保留为数学试验，不能冒充物理非负模长 |
| 坐标旋转 | 对整段dBx/dBy及参考段施加固定平面旋转，再从头重算幅值、分量EMA、方向和mask；θ={±30°,±60°,±90°,180°} | 坐标表示旋转稳定性；不等于真实传感器重装或真实笔杆旋转实验 |
| 多数类 | 只按当前训练折最多类别预测，并列按固定标签顺序 | 基本分类对照；不能看测试分布选多数类 |
| 固定笔顺位置 | 训练侧建立位置→类别控制映射；永字五类子集单列 | 揭示协议混杂；不是磁分类能力，七类不能照搬五类位置100% |
| 同折F0/F1/F2/F3/F4 | 相同有效队列和分割，报告覆盖率及配对差值 | 模态和融合的增量；不能用不同样本集合的最高分直接比较 |

补充说明：

- 标量+c试验固定方向mask，是因为它只变换幅值表示，不是修改dBx/dBy的真实向量基线。若重新用r+c阈值改变mask，就变成另一种试验，不能据此否定或宣称A1整体管线数学不变性。
- 若要研究原始分量常量偏置，应另登记dBx/dBy向量偏置并重算全部分支；它与标量+c不同，不以二者结果互相替代。
- A3启用时增加预登记的乘性敏感性检查；这仍是数学变换，真实增益／加载结论仍需实采证据。
- mask-only、时长等元数据只可作为诊断对照，绝不并入主磁特征模型。
