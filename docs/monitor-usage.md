# ΔB 实时监控窗口 · 使用手册

> 设计见 `docs/superpowers/specs/2026-07-24-deltab-monitor-design.md`。
> 离线交互回放（浏览器版）见 `docs/deltab-v0-analysis.md` §9。

## 安装

```
conda activate brushbot && pip install -e ".[monitor]"
```

## 启动

```
python -m brushbot.monitor
```

## 三种信号源

| 源 | 用途 | 录制 |
|---|---|---|
| 串口 | 实时读 ESP32+MLX90393（默认 `/dev/ttyUSB0` @115200） | ✅ |
| 回放 | 读已录制的 V0 数据集 CSV | ❌（不产生新数据） |
| 合成 | 解析模型产生的虚拟信号，无需硬件 | ✅（JSON 中 `sensor` 标为 `synthetic`） |

## 界面

- **左**：ΔBx–ΔBy 相图，等比例，XY 圆方向点用选中滤波器平滑，带 3 s 拖尾轨迹。
- **右**：ΔBx / ΔBy 两个**独立 Y 轴**的时序图；ΔBz 勾选后出现。选了非"原始"滤波时，每个时序图叠加一条淡灰细线（原始值）与一条亮色曲线（滤波后）；选"原始"时只显示单曲线（不重复画同一条线）。
- **状态栏**：`|ΔB|`、`|ΔBxy|`、方位角 φ、极角 θ、三轴瞬时值、缓冲计数、门控阈值。

## 滤波

工具栏「滤波」下拉，五档：

| 档位 | 说明 |
|---|---|
| 原始 | 不滤波，显示传感器原始 ΔB |
| EMA 0.3 | 一阶指数滑动平均，α=0.3 |
| Butter 5Hz | 二阶 Butterworth 低通，截止 5 Hz |
| Butter 8Hz | 二阶 Butterworth 低通，截止 8 Hz |
| OneEuro | One Euro 自适应低通，静止更稳、快速动作更跟手 |

切换即时生效，仅影响显示（时序图叠影、XY 圆方向点），**不影响录制**——CSV 中写入的始终是原始 ΔB。

## 回放进度条

仅回放 / 合成源出现（工具栏下方新增一行滑条 + 时间标签），串口源隐藏。拖动滑条松手后跳转到对应位置；跳转不改变当前暂停状态。seek 后时序图窗口内可能短暂残留旧段（与「⟳ 重放」的行为一致，数帧内自然刷新为新位置的数据）。

## 基线与方向门控

每次连接（无论何种源）都会整体重置基线：连上后 1 秒自动取基线；任何时候可按「取基线」重取。
**回放源的特殊处理**：连接时立即从记录 JSON 读取 `b0` 为初值（使 ΔB 从第一帧起正确），但方向门控保持**抑制**（φ/θ 显示 `—`、不画方向线）直到 1 秒后的自动重取基线完成——因为初值 `b0` 之外还需测得噪声 σ 才能设门控。
取基线时同时测得噪声 σ，门控阈值 = `3·‖σ‖`。
当 `|ΔB|` 低于门控时，φ/θ 显示 `—` 且不画方向线——此时方向由噪声主导，显示出来是假信息。

## 录制

先取基线 → 「● 录制」→ 动作开始时按「标记 START」、结束按「标记 STOP」→「■ 停止」。
输出到 `recordings/`，格式与 `delta_b_v0_20260724/` 一致，可直接被分析脚本消费：

```
python scripts/analyze_deltab.py recordings out.png
```

## 排错

| 现象 | 处理 |
|---|---|
| `打不开信号源` | 确认串口路径与权限：`ls -l /dev/ttyUSB0`；必要时 `sudo usermod -aG dialout $USER` 后重新登录 |
| 曲线不动 | 确认已点「连接」；串口源需固件正在输出 |
| φ/θ 一直是 `—` | 正常——信号未超过噪声门控；或重新取基线 |
| `Could not load the Qt platform plugin "xcb"` | 需要图形界面，不能在纯 SSH 无 X11 下运行 |

## 手动验收清单（2026-07-29 滤波 UI 改造）

在有显示器的机器上 `python -m brushbot.monitor` 逐项勾选：

- [ ] 滤波下拉五个选项可切换，切换即时生效
- [ ] 叠影：淡灰原始毛刺在下、亮色滤波曲线在上；选"原始"时只有一条曲线
- [ ] OneEuro 档：静止段明显比 EMA 稳，快速动作跟手
- [ ] XY 圆有 3 s 拖尾轨迹，⟳ 重放 / 进度条 seek 后拖尾在数秒内刷新为新轨迹（短暂新旧混合属正常，与时序图残留行为一致）
- [ ] 回放模式出现进度条，拖动跳转正确、时间标签正确；串口模式无进度条
- [ ] 录制一段后检查 CSV 是原始 ΔB（换滤波档重录，数值不变）
- [ ] 状态栏接触判定行为与改造前一致
