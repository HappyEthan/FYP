## 推荐

**EMA a=0.3** — 选型规则: 动态 RMS ≤ 最优×1.25 且阶跃 ≤100 ms 者中取 idle |σ| 最小.

handoff §2.5 四问 (以推荐配置回答):

1. 3 Hz 相位滞后: **22.8°** (慢态等效)
2. 噪声: |σ| 从全带宽 6.94 µT → **3.31 µT**
3. 等效 Z 噪声: σ_z = σ_filtered/S = 2.73/S mm (S 待装配态 E2 标定, µT/mm)
4. 滤波器延迟: 群延迟 **17.2 ms** @ 3 Hz (延迟预算 ≲10 ms)
