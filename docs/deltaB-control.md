# ΔB 空间控制方案 · 可行性与有效性评估

> **议题**：既然形变量/力都是从磁场变化 ΔB 标定换算而来，能否**直接在 ΔB 空间做闭环**（不换算成 mm 或 N）？
> **定位**：对 `reference/执行方案-力控.md §1「反馈表示决策」` 的再评估与细化，含定量可行性核算。
> 关联：`docs/control-architecture.md`（三层架构）、`note.md §8`（E1–E4 门禁）。
> 生成 2026-07-21。**结论中标注了哪些是推理、哪些必须实测**。

---

## 0. 结论摘要（TL;DR）

| 问题 | 结论 |
|---|---|
| ΔB 空间闭环**在原理上**成立吗？ | ✅ **成立**。ΔB→δ 是单调换元，不增信息；控制器只要求前馈与反馈**同单位** |
| 该用**标量 ΔB** 吗？ | ❌ **不行**。必须用**三轴向量**，否则提按与拖拽不可分（E4 报废） |
| 推荐表示 | **ΔB 向量投影到标定压入曲线**：弧长=提按量（LSB），垂距=拖拽污染。**全程零单位换算** |
| 最大隐忧 | ⚠️ **不是表示法，是三条物理**：①环路带宽/延迟 ②噪声-带宽权衡 ③迟滞。换表示**一条都救不了** |
| 用户前提"磁场很稳、抖动小"是否可依赖？ | ⚠️ **需在控制采样率下重测**。低速采样的低噪声**不能外推**到 ≥100Hz（见 §6.3），建议新增 **E0** |
| 最终建议 | **A（向量投影）+ E（基线治理）起步；前馈学习化、反馈保持经典**；D/C 视 E3/E1 结果再加 |

## 1. 信号链与控制目标

```
z_cmd ──►[机械臂伺服]──► z_act ──►[毛笔/纸接触]──► 触角形变 δ ──►[磁学]──► ΔB (实测三轴)
         (Elfin, ~50Hz?)          (刚度非线性)      (粘弹迟滞)      (非线性 + 漂移)
```

- **目标**：复现人写示范时录下的提按曲线。**示范录的本来就是 ΔB。**
- **架构（既定）**：前馈为主 + 低增益积分反馈（`执行方案-力控.md §3.2`）。
  `z_cmd = z_surface + z_ff(target) + Kv·∫(target − meas)dt`

---

## 2. 核心论证：为什么 ΔB 空间闭环成立

设静态映射 `δ = f(ΔB)`，`f` 单调可逆。

- **稳态等价**：跟踪 `ΔB → ΔB_d` ⟺ 跟踪 `δ → f(ΔB_d)`。**换元不改变稳态目标。**
- **动态差异只在环路增益**：闭环行为由**总环路增益** `L = Kv · ∂(反馈量)/∂z` 决定。
  - 选 ΔB 作反馈量 → `L = Kv · ∂ΔB/∂z`
  - 选 δ 作反馈量 → `L = Kv · ∂δ/∂z`
  两者差一个 `f'`。**所以"选哪个变量"本质是"把非线性补偿放在哪里"，不是对错问题。**

**⭐ 支持 ΔB 的最强论据（工程性的，不是理论性的）**：
示范采集记录的是 ΔB，控制反馈也是 ΔB → **目标曲线、训练标签、实时反馈三者天然同单位、零换算**，整条链路留在传感器空间。每多一层换算就多一层标定误差与漂移放大。

**文献佐证**：AnySkin（磁化弹性体+磁力计，与触角同原理）明确报告为**未标定（uncalibrated）** 传感器且能跨实例泛化；tactile servoing 框架（RSS 2013）直接在传感器空间闭环，不转换成力。

> **但请注意一个反向事实**：`δ ≈ (z_surface − z)`（穿透深度）对 z 近似**线性**，而 `ΔB(δ)` 叠加了磁学非线性。
> 也就是说 **δ 才是对 z 更"良态"的变量**。选 ΔB 的代价 = 环路增益随压深变化更剧烈（§6.2 给出应对规则）。

## 3. 换表示救不了的三件事（诚实清单）

| # | 问题 | 为何与表示无关 | 量化于 |
|---|---|---|---|
| 1 | **带宽/延迟** | 物理链路（触角粘弹 + 通信 + 伺服率）决定，与你如何解读读数无关 | **E1** + §6.1 |
| 2 | **噪声** | 噪声在 ΔB 里产生；任何换算只是缩放它 | **E0(建议新增)** + §6.3 |
| 3 | **迟滞** | 粘弹性使同一 ΔB 对应加载/卸载两态；换单位不改变多值性 | **E3** + §6.4 |

## 4. 表示法评估：为什么必须用向量而非标量

| 表示 | 提按/拖拽可分 | 标定成本 | 可解释 | 评估 |
|---|:---:|:---:|:---:|---|
| 单轴 ΔB 标量 | ❌ | 零 | ❌ | **不可用**：E4 拖拽污染无法剥离 |
| `‖ΔB‖` 模长 | ❌ | 零 | ❌ | **不可用**：同上，且丢失方向 |
| **ΔB 向量投影（推荐）** | ✅ | 低 | ⚠️ | **推荐**：保留方向、零单位换算 |
| 形变量+偏移角(mm/度) | ✅ | 中 | ✅ | 等价，多一层换算；仅"可解释"占优 |
| 独立 F/T 牛顿 | ✅ | 中 | ✅ | 失败安全网；但力不再由触角驱动，削弱卖点 |

**结论**：ΔB 与形变量之争是**伪命题**；真命题是**标量 vs 向量**。推荐"ΔB 向量投影"= 保留了形变量+偏移角的全部信息优势，同时去掉单位换算层。

## 5. 方案 A：ΔB 向量投影（推荐主方案）

### 5.1 原理
E2 做**纯法向压入**（不拖行）时，`ΔB(z)` 在三维磁场空间中扫出**一条曲线** `C`（不是一个固定方向——触角压深时偏转方向本身会转，单一方向向量会失真）。

运行时把实测 `ΔB` **投影到 C** 上：
- **沿 C 的弧长参数 `s`** → 提按量 `g_press`（单位 LSB，不换算）
- **到 C 的垂距 `d⊥`** → 拖拽/污染量（正好是 E4 要量的东西）

### 5.2 可行性评估
| 维度 | 评估 |
|---|---|
| 计算量 | ✅ 无问题。C 离散成 ~50 点折线，每拍最近点投影 ≈ 数百次浮点运算，100–200Hz 毫无压力 |
| 可观性 | ⚠️ **勉强可分**：3 个测量 → 未知量为压入 1 维 + 拖拽 2 维 = 3 维。**恰定**，无冗余裕度，噪声/漂移直接吃掉分离质量 |
| **前提①：C 是良定义的 1 维曲线** | ⚠️ **被 E3 制约**。有迟滞时加载/卸载走**不同路径** → C 实为一条**回环带**而非曲线。投影到均值曲线的固有误差 ≈ **半个回环宽度** |
| **前提②：拖拽方向与 C 切向可分** | ⚠️ **被 E4 制约**。设两者夹角 `θ`，则拖拽窜入提按估计的量 ≈ `‖ΔB_drag‖·cos θ`。**θ 越接近 90° 越干净；若近乎平行，任何投影法都无解** |

> **判据（写进 E3/E4）**：
> - E3：回环宽度 / 灵敏度 → 换算成等效 z 误差，要求 ≪ 提按分辨率
> - E4：**量 θ**。建议 `θ > 60°` 才认为方向解耦可靠

### 5.3 伪码
```python
# 标定期(E2): 纯法向压入, 记录 C = [(ΔBx,ΔBy,ΔBz), ...] 及各点对应的 z
# 运行期:
dB = B_raw - B0                       # 基线校正(见方案 E)
s, d_perp = project_onto_curve(dB, C) # 弧长 + 垂距
g_press = s                           # 提按量, 单位 LSB
if d_perp > DRAG_LIMIT:               # 拖拽污染过大 -> 该拍读数不可信
    freeze_integrator()               # 冻结积分, 只靠前馈
```

## 6. 定量可行性核算（本文档的核心价值）

### 6.1 带宽预算 ⚠️ 最大风险
| 项 | 数值 | 来源 |
|---|---|---|
| 需求：提按跟踪带宽 | **~3 Hz** | E1 判据 |
| Elfin Servo 设定值更新率 | **50 Hz**（`HRIF_StartServo` 手册示例 `dServoTime=0.02`） | SDK 手册；**上限未实测** |
| 经验规则：闭环带宽 ≤ 1/5~1/10 采样率 | → **5–10 Hz** | 控制常识 |

**判定**：50Hz 伺服 → 约 5Hz 可达闭环带宽 → **对 3Hz 提按"勉强够，无裕度"**。
**行动**：**实测 Elfin servo 频率上限**（`dServoTime` 能否降到 0.005–0.01）。这是 `note.md §6` 已列的待办，本分析将其**升级为控制可行性的前置条件**。

> ⚠️ **额外发现**：SDK 示例 `dLookaheadTime = 0.2` s。前瞻平滑通常**引入相位滞后**，0.2s 对 3Hz 信号是致命的（0.2s×3Hz = 0.6 周期）。**闭环使用时必须把前瞻调小并实测其相位影响**，不能沿用示例值。

### 6.2 环路增益与整定规则
`L(z) = Kv · S(z)`，其中 `S(z) = ∂g_press/∂z`（LSB/mm）由 E2 曲线求导得到。

- `S` 随压深变化（磁学 + 刚度双非线性）→ 固定 `Kv` 时环路增益漂移。
- **整定规则（保证全域稳定）**：**在 `S` 最大的工作点整定 `Kv`**。
  代价：`S` 小处响应偏慢——但因架构是**前馈为主**，反馈只纠残差，可接受。
- **可选改进（增益调度）**：`Kv_eff = Kv_nom / S(z)`，用 E2 曲线的导数在线归一化 → 全域响应一致。**推荐实现，成本极低。**

### 6.3 噪声预算 ⚠️ 需推翻或确认你的前提
把 ΔB 噪声折算到**等效位置噪声**：`σ_z = σ_ΔB / S`。

- 设计要求：`σ_z ≪ 提按分辨率`（建议 `σ_z ≤ 1/5` 目标分辨率）。
- ⚠️ **关键警告**：你观察到的"磁场很稳、抖动很小"**很可能是在低速/高过采样配置下测得的**。MLX90393 的**噪声与带宽是权衡关系**：为达 ≥100Hz 必须降低 OSR/分辨率 → **噪声必然上升**。低速下的低噪声**不能外推**到控制采样率。
- **因此建议新增门禁 E0**（见 §9）。

### 6.4 延迟预算
相位滞后 `φ = 360° · f · T_delay`。在 f = 3Hz：

| 总延迟 | 相位滞后 |
|---|---|
| 10 ms | 10.8° |
| 20 ms | 21.6° |
| **30 ms** | **32.4°** |
| 50 ms | 54° |

积分作用本身贡献最多 90° 滞后，触角一阶动态再贡献最多 90°。要留 ≥45° 相位裕度 →
**总回路延迟预算 `T_delay ≲ 30 ms`**。

分解（需逐项实测）：MLX90393 转换+I2C → MCU→PC(USB) → PC 计算 → PC→Elfin(TCP+SDK 前瞻)。
**其中 SDK 前瞻是最大不确定项（见 §6.1）。**

## 7. 推荐架构

```
目标提按曲线 ΔB_d(s)  ── (示范录制, 原生 LSB)
        │
        ├──────────────► 前馈 z_ff = C 曲线的逆 (E2 标定; 可离线学习化)
        │                                    │
ΔB_raw ─► 基线校正(方案E) ─► 投影到 C ─► g_press, d⊥
        │                        │
        │                        ├─ d⊥ 过大 → 冻结积分(拖拽污染保护)
        │                        ▼
        └──► e = ΔB_d − g_press ─► 低增益积分 Kv(带抗饱和) ─► z_fb ─┐
                                                                    ▼
                              z_cmd = clamp(z_surface + z_ff + z_fb)
```

**必备工程细节（易漏）**：
1. **抗积分饱和**：`z_fb` 被限幅 → 必须做 back-calculation 抗饱和，否则解除限幅时会冲。
2. **限幅**：`z_fb ∈ [−DZ_MARGIN, +DZ_MARGIN]`；`z_cmd ∈ [Z_MIN, Z_MAX]`。
3. **拖拽保护**：`d⊥ > DRAG_LIMIT` 时冻结积分（读数不可信）。
4. **抬笔时**：目标在纸面之上 → 应**关闭积分**并归零 `z_fb`（无接触时误差无意义）。
5. **符号一致性**：z 正向、压深正负、ΔB 极性——`执行方案-力控.md §3.5` 列为"最常见 bug"，务必单测覆盖。

## 8. 其余方案评估（何时该加）

| 方案 | 治什么 | 可行性 | 有效性 | 我的判断 |
|---|---|:---:|:---:|---|
| **E · 基线治理** | 漂移 | 高 | 高 | **必配，立即做**（见下） |
| **F · 增益调度** | 非线性 | 高 | 中 | **推荐**，成本极低（§6.2） |
| **D · 迟滞逆补偿(PI 模型)** | E3 迟滞 | 中 | 中 | **E3 判定后再决定**。注意触角是**粘弹（率相关）**，经典 PI 是率无关的，需率相关变体+多速率数据 |
| **C · 学习式映射** | 非线性+迟滞+耦合 | 中 | 高 | ⚠️ **只学前馈，别把学习模型放进反馈环**（见下） |

### 8.1 方案 E：基线治理（必配）
- **软件（零成本，强烈推荐）**：**抬笔时自动重估 B0**。抬笔时你**知道**无接触 → ΔB 应≈0 → 残差即基线误差。书写笔画间抬笔频繁（0.3–1s 一次）→ 持续校准。
  - ⚠️ **注意粘弹回弹**：刚抬笔时触角仍在恢复，**不可立即重估**。规则：命令 z 高于纸面 + 信号稳定持续 τ（τ 取自 E1/E3 实测的回弹时间）后才更新。
- **硬件（建议尽早告知队友）**：加一颗**参考磁力计**，装在远离触角处，只测环境场，实时相减做**差分测量**。
  - **有效性**：对远场（地磁、房间、电机）共模干扰抑制很好；对**近场梯度**抑制有限。
  - **为何重要**：Elfin 钢法兰+电机使 B0 **随位姿变化**，纯软件难治；差分是标准解法。
  - ⏰ **时效性**：这是硬件改动，**必须在毛笔本体/PCB 定版前提出**，否则返工。

### 8.2 方案 C 的控制工程学警告
把学习模型放进**反馈回路内**会使稳定性无法分析（增益/相位不可界定）。
**推荐做法**：**用学习改进前馈 `z_ff`（离线），在线反馈保持经典低增益积分**。
既吃到学习对非线性/迟滞的拟合能力，又保住闭环可分析性与安全性。

### 8.3 一个利好：同笔复现的误差自消
目标 ΔB 曲线是**同一支触角**在示范时录的，复现时又用同一支 → **迟滞、标定偏差等系统性误差部分自消**（`执行方案-力控.md §1` 已指出"同一支笔录了再复现，三者单调等价"）。
⚠️ **但只是部分自消**：人手持书写与机械臂书写的**加载历史/速度不同**，且模型生成**新提按曲线**（B4）时该利好消失。

## 9. 对门禁实验的影响 + 建议新增 E0

| 实验 | 本方案带来的变化 |
|---|---|
| **E1** | **不变**，仍是分水岭。本方案改不了物理带宽 |
| **E2** | **改为直接标定 `ΔB ↔ z`**，产出：① 压入曲线 `C`（三维）② 前馈 `z_ff` = C 的逆 ③ **灵敏度 `S(z)`（曲线导数，整定 Kv 用）**。牛顿换算**只留给报告**对标 0.34N |
| **E3** | 新增量化项：**回环宽度 / S → 等效 z 误差**，判定投影法前提①是否成立 |
| **E4** | 新增量化项：**拖拽方向与 C 切向夹角 θ**（建议 `θ > 60°`），判定前提② |
| **E0（建议新增）** | **噪声-带宽表征**：在**实际控制采样率**（≥100Hz）与拟用 OSR/分辨率配置下，静置测 ΔB 噪声底 `σ_ΔB`；结合 E2 的 `S` 算 **等效位置噪声 `σ_z = σ_ΔB/S`**。<br>**判据**：`σ_z ≤ 1/5 × 目标提按分辨率`。<br>**为什么必须加**：整个"直接用 ΔB"的前提是"信号稳定"，而该前提在控制带宽下**未经验证**（§6.3） |

## 10. 落地步骤（对接 B2）

1. **契约1 调整**（与队友对齐）：`g_meas` 流应同时给 **原始三轴 ΔB** 与 **投影后的 `g_press`、`d⊥`**。原始值必存（一切可重算）。
2. **仿真先行**（不等硬件）：在 `AdmittanceController` 中把反馈量换成 `g_press`(LSB)，用**合成 ΔB 信号**（含可配置噪声/迟滞/漂移）验证：抗饱和、限幅、拖拽保护、抬笔关积分。
3. **硬件到位后**：E0 → E2（拿 `C`、`z_ff`、`S`）→ E3/E4（判定投影法前提）→ E1（分水岭）。
4. **实测 Elfin servo 频率上限与前瞻相位影响**（§6.1）——这是控制可行性的前置条件，建议**优先于**其它实机工作。

## 11. 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| **Elfin servo 仅 50Hz / 前瞻引入大滞后** | 闭环带宽不足 3Hz，B 级提按不可达 | 实测上限；调小前瞻；必要时降低目标提按带宽并如实写进 limitation |
| **控制带宽下噪声远高于预期** | 等效位置噪声淹没提按分辨率 | E0 先测；必要时降采样率+接受更低带宽，或提高触角灵敏度 |
| **E3 回环宽 → 投影法前提破** | `g_press` 估计含固有误差 | 上方案 D（率相关 PI 逆）或方案 C（学前馈） |
| **E4 夹角 θ 小 → 拖拽不可分** | 提按标签与反馈被污染 | 无表示法可救；需硬件改动（改变触角嵌入姿态）或退 F/T 安全网 |
| **B0 位姿相关漂移** | 机器人写与人写不可比 | 参考磁力计差分（尽早提，硬件定版前） |
