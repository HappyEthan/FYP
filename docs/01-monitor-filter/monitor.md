# Monitor：信号、录制与独立返回

## 功能与数据流

本文对应 `src/brushbot/monitor/`，默认入口为 `python -m brushbot.monitor`。窗口读取串口或既有录制，扣除悬空静止基线，显示磁场变化并保存未经过显示平滑或显示裁剪的 ΔB。它与 `src/brushbot/exhibition_monitor/` 展示客户端不是同一个界面。

## 当前软件状态

前期 Monitor/Filter 的设计与软件基础已完成；以下说明现有代码行为，不把界面可用性等同于装配态真机验收。

- 数据源只保留串口和回放；monitor 不再提供合成源。
- XY 图以 `ΔBx/ΔBy` 为输入，不做增益、白化、归一化或转圈标定；它与时序图共用可选 EMA 显示平滑，超出参考圆时只在画面上沿方向钳位。
- 参考圆使用 μT，默认半径为 400 μT。
- 显示滤波默认选择“原始”，操作者可显式切换普通时间滤波。
- 录制区只有“开始录制/停止录制”按钮，没有动作名称或人工标记。
- 窗口创建实验和“回到开始位置”两个独立面板；只有调用方注入同一个 `ExperimentService` 后才能提交动作。默认 `python -m brushbot.monitor` 没有注入该服务，两个面板处于离线状态。

仓库有串口实测录制；这只能证明采集文件存在，不能代替基线漂移、显示尺度或实验／返回面板的现场验收。面板和返回路径有假设备与离线测试，本文不提供真机动作批准。

## Monitor 操作

默认启动不会建立机器人或传感器连接，但会尝试建立本地监控控制 socket。界面数据源：

- **串口**：操作者填写端口后显式点击连接；窗口默认 `/dev/ttyACM0`、115200 baud。
- **回放**：选择已有 CSV 及同名 JSON；选择文件本身不产生运动，也不会生成新录制。

连接后保持毛笔悬空静止，monitor 约 1 秒后自动取得一次基线；也可点击“取基线”重取。回放时先读取配套 JSON 的基线，再自动估计门控噪声。滤波选择只影响显示；CSV 始终保存基线扣除后的 ΔB 和质量标志，异常原始数值不因显示处理而删除。

录制流程：

1. 连接串口并确认基线有效。
2. 点击“开始录制”。
3. 需要结束时点击同一按钮“停止录制”。

本地控制 socket 还接受 `start_record`／`stop_record` 请求，供外部动作脚本触发同一录制流程；窗口没有动作标记快捷键。

每次生成一对唯一命名的 CSV/JSON。CSV 字段为：

```text
t_us,t_s,dBx_uT,dBy_uT,dBz_uT,sample_valid
```

JSON 保存创建时间、有效性、信号源、基线、样本数、质量统计、采样率和对应 CSV 文件名。新格式不包含 `action`、`repetition`、`action_window_s` 或动作起止时间戳；回放读取器可读取带这些字段的旧记录。串口断开或读取失败时，已录数据仍可保存，但 JSON 标记 `valid=false` 并写入原因。

## 实验与独立笛卡尔返回

以下是注入 `ExperimentService` 后的可选功能；默认命令行入口只显示离线面板。注入服务时，窗口的数据源连接控件会被禁用，实验采样由服务持有。ExperimentPanel 读取的是实验 JSON，起点 X/Y 和等待 Z 会在提交实验时写入现场设置。选择 JSON 或编辑这些值不会运动。

独立返回面板每次要求完整目标：X/Y/Z 使用 mm，Rx/Ry/Rz 使用度；提交后才在服务边界冻结为 m/rad。返回不读取 StrokePlan，也不从当前实验 JSON 推断目标。服务只允许实验或返回其中一个处于活动状态。

路线顺序为：在当前 XY/姿态抬到 `max(当前 Z, 目标 Z)`，在高位平移到目标 XY，在目标 XY/高位切换目标姿态，最后在需要时下降到目标 Z。代码校验六个目标值有限、路线 XYZ 在工作空间内、返回速度不超过配置上限，并在每段运动后核对位姿；没有独立的姿态工作空间边界。任何真实执行仍要求可用的当前位姿和已验证安装／工作空间配置。

## 分析与回放

窗口中选择 CSV 与同名 JSON 即可回放。`scripts/analyze_deltab.py` 和 `scripts/make_replay.py` 主要沿用旧 V0 数据集的动作标签与分析口径；当前 `recordings/` 不写动作标签，不能把这些脚本的动作对照图当作现行实验结论。旧 V0 数据和历史分析仍可用于理解裸态噪声，不能代表装机环境。同步目录中的旧版 monitor 操作说明只作历史参考。

## 安全边界与后续工作

- Monitor 不负责自动使能、复位、松爪或发送未经操作者确认的运动。
- 笔与夹爪长期固定；任何结束、停止和返回均不自动松爪。
- 闭环实测标定属于 Robot Control，不因删除 monitor 显示标定而删除。
- 候选接触 Z、行程、速度、压深、显示尺度和滤波参数必须分别由现场实测验证。
- 默认 monitor 入口没有连接实验／返回服务；这些面板的真机启用需要单独接入服务并核对现场安装配置。



## 设计约束与实现位置

实验和独立返回共用服务持有的机器人连接与请求线程。服务分别报告实验状态与返回 operation ID、冻结目标、错误，禁止两个动作同时运行。重复提交正在进行的返回请求应保持幂等。

返回路线检查有限数、XYZ 工作空间和配置速度，并在每段结束后核对位姿；关闭已注入服务的窗口时请求活动操作停止并等待确认。数据源、显示与记录分别位于 `monitor/sources.py`、`window.py`、`recorder.py`；独立返回对应 `experiments/cartesian_return.py` 与 `monitor/cartesian_return_panel.py`。

2026-09-09 精简设计撤下了合成源、转圈标定、增益/白化、归一化预设、动作名和人工标记。旧录制元数据仍可读取；它们不再是新录制的必填字段。闭环研究使用的磁标定仍归 Robot Control。

现有软件测试覆盖新旧记录兼容、按钮与快捷键、返回单位转换／路线顺序、实验互斥及故障停止；这些测试不代替实际安装条件下的验证。
