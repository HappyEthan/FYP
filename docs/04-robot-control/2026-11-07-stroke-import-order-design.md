# 笔画导入与执行排序

用户已确认增加通用导入功能，并要求可调整每笔执行顺序，直接开始修改。

- 在现有 Qt 编辑器增加“导入笔画”，读取编辑存档或 recipe；多笔来源可勾选，按来源顺序追加，分配独立 ID。
- 默认放到现有笔画右侧，间隔 10 mm、上下居中；支持左侧、原位、X/Y 偏移。按纸面坐标计算后转换到当前画板坐标，保留物理大小和姿态。
- 保留节点、细路径、速度、磁目标、笔杆角度、区域节奏和测试范围。读取来源目录配置优先于历史外部路径，绑定配置快照。导入前列出差异，明确采用当前工作区全局配置，并保留来源信息。
- 当前笔画旁提供上移、下移按钮。只改变 stroke_order，同步全局点号、执行范围、导出顺序；原几何和参数不变。排序保留已有按笔画 ID 生成的随机场，导入则使旧随机批次过期。
- 导入、排序支持撤销、自动保存和恢复；错误或取消不得部分修改工作区。未完成独立起点时禁止这两种操作。
- 延用既有完整预检、自动适速、笔间悬空转场与 run 执行入口，不自动连接硬件。

方案比较：一次性组合文件改动少，但不能反复导入；用户选择通用导入。排序用上移/下移，适合当前少量笔画，也避免新增复杂列表拖拽。
