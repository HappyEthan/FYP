# Z 控制设计：前馈表与 PI 修正

> 历史设计快照：下文“当前仅 P、PI 待启用”描述的是早期阶段。2026-09-25 已实现条件积分 PI 并完成短平台实验，现行机制见[前馈＋PI 控制实现](../nonlinear-feedforward-pi-summary-2026-09-25.md)，历史实测结果见[实验总览 G06–G13](../../08-system-evaluation/实验清单.md#z-identification)。

本文件只解释本项目的 Z 控制思路。**前馈表负责主要压深，PI 只修正磁目标跟踪的残差。**当前单笔 StrokePlan 真机入口已使用独立前馈表和受限 P 修正，`ki=0`；积分项是下一步需要按实测验证的设计，不能把历史仿真默认增益当作现行真机参数。具体操作入口见[StrokePlan 执行说明](../strokeplan-execution.md)。

## 控制量和信号

- StrokePlan 提供随时间变化的 XY、时间戳和目标磁幅值 `g_target`，不把实测量写回计划。
- 当前控制特征是去基线后的水平磁场分量分别滤波，再求 `g_meas = hypot(ΔBx_filtered, ΔBy_filtered)`，单位 µT。它是毛笔接触/形变的代理量，**不是测得的法向力**。
- 独立前馈表把目标磁幅值映射到正向下的压深 `d_ff`；表要附标定 run、毛笔、装配、姿态、方向、速度、滤波和有效范围。目标超出表范围时拒绝外推。
- `contact_z` 是本次现场接触参考高度。本文用压深 `d` 向下为正，机械臂 Base 坐标的 Z 向上为正，因此压深增加使 Z 命令减小。

## 前馈加 PI

在每个书写控制周期，先按 StrokePlan 的时间戳插值 `g_target(t)`，再查表得到前馈压深：

```text
d_ff[k] = table(g_target[k])
e[k]    = g_target[k] - g_meas[k]
I[k]    = bounded_integral(I[k-1] + Ki · S · e[k] · dt)
d_fb[k] = Kp · S · e[k] + I[k]
d_cmd[k] = d_ff[k] + d_fb[k]
z_cmd[k] = contact_z - d_cmd[k]
```

`S` 是标定得到的磁误差到压深修正的换算斜率，单位 m/µT；`Kp`、`Ki` 为待整定增益。误差为正表示实测响应偏低，正的反馈修正增加下压；误差为负则减小下压。对非书写阶段，不跟踪磁目标，按下笔、抬笔和高位移动轨迹执行。

PI 的积分必须有边界与条件：只在有效接触、有效传感器数据和允许反馈的书写阶段更新；达到压深、工作空间或动态限幅而继续同方向积分时，应冻结或回算积分，防止 windup。每笔开始、故障或重新取基线时须明确重置规则。最终命令还要满足压深、单步、Z 速度、加速度及工作空间限制；无可行命令时应中止本次运行，而不是绕过约束。

## 为什么采用这个分工

1. **前馈承担主运动。**标定表直接表达本次毛笔和姿态下“目标磁响应需要多大命令压深”，不要求反馈从零开始追赶；变化目标也能先生成完整命令轨迹。
2. **P 修正即时误差。**软毛笔、纸面和装配的实际响应与标定条件可能不同，P 项根据当前磁误差做有限修正。增益过大或信号延迟会引起抖动，因此需使用与表一致的滤波特征并限制修正幅度和动态变化。
3. **I 修正持续偏差。**接触零点、小幅漂移或标定残差可能让 P 控制留下长期同向误差；积分可缓慢消除它。积分也会累积噪声、基线错误和执行饱和，因此必须在真实数据上验证时间尺度、限幅和重置策略后才启用。

磁目标本身不能唯一决定实际笔画宽度或笔锋形态。前馈表、P/PI 跟踪和最终墨迹需要分别评价；命令 Z 也不能代替实测 TCP Z。

下一步若启用 PI，应在相同 StrokePlan、前馈表、毛笔和纸面条件下，与纯前馈、前馈＋P 做重复比较；记录目标与实测磁幅值、误差、积分状态、Z 命令、限幅和异常。先确认 P 模式的跟踪与数据质量，再确定非零 `Ki`、积分使能条件、抗饱和和跨笔画重置方式。仿真支持算法机制，不等于真机增益已经定稿。
