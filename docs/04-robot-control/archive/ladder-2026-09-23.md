# 2026-09-23 brush2 梯子实验记录

这是一份按当日 run 和分析产物整理的**实验记录**，不是下次上机的固定配置。2026-09-17 的[旧梯子方案](ladder-2026-09-17.md)曾要求不同的数据链与路径，不能代替本批实测。原始 run、设置、事件和传感器数据保存在各自目录；本文只记录可追溯的范围、方法、观察和限制。

## 条件与数据范围

- 毛笔：brush2；四组笔刷/传感器姿态，每组两次完整运行。四组标为 `+x/+y/-x/-y`，分别约为 Ry+15°/Rz0°、Rx+15°/Rz90°、Ry−15°/Rz180°、Rx−15°/Rz270°。
- **方向标签是姿态类别**。四组机器人测量轨迹均命令沿 +X 行进，不能表述为机器人分别沿世界 ±X/±Y 书写。
- 每次完整 run 有 8 条 +X、200 mm 测量路径；接触参考 Z=40 mm，命令 Z=36→24 mm，共 8 档（命令压深 4→16 mm）；测量速度 10 mm/s，实验原点 X=−200、Y=500 mm。以上均为本批条件。
- 完整 run ID：`+x` 为 `df7649`、`c575e5`；`+y` 为 `7d1a59`、`486bc3`；`-x` 为 `9666d5`、`2f3488`；`-y` 为 `43a39c`、`3b670b`。八份 [run 目录](../../../runs/brush2/2026-09-23/)中的 manifest 均标记 `completed`。较早故障 run `901492`、`4c8ffa` 只完成前六档，未纳入四方向比较。

## 分析口径

稳态响应取每条路径**命令行程** X=30–170 mm 内 `control.jsonl` 的 `a_control_uT` 中位数，再对同姿态的两个 run 中位数求平均；每条路径稳态窗口约 700 个样本。沿程曲线用 `sample_seq` 对齐 `sensor.csv` 和控制记录，计算 `sqrt(dBx²+dBy²)`，在 0.5 mm 网格插值并以 21 点 Hann 窗平滑。位置轴来自命令 TCP 轨迹，日志没有同步的实测 TCP 位姿。完整方法、逐档表格与图见[四方向分析](../../../runs/brush2/combined/2026-09-23/four_directions/four_directions_analysis.md)、[来源和统计元数据](../../../runs/brush2/combined/2026-09-23/four_directions/four_directions_metadata.json)。

## 观察

1. 磁响应的方向排序随命令压深改变，不能用一个方向固定高于其余方向概括全部档位。在 4 mm 压深，各组约 20–49 µT。
2. 最深 16 mm 档差异较大：`-x` 两次稳态中位数的平均约 849.3 µT，约为 `+x` 的 2.59 倍；`+y` 约 516.5 µT，`-y` 约 372.6 µT。
3. 重复性并非各档一致；`+y` 的 14.286 mm 命令压深档，两次稳态中位数差约 189.0 µT。两次重复不足以为该档给出稳定的单一标定值。

这些差异是逐路径基线处理后的水平磁场变化 `|ΔBxy|`，不能直接换算成法向力、实测笔尖压深或墨迹质量。姿态组同时改变倾斜和轴向角度，且按时间顺序采集；笔毫状态、沾水和漂移也可能影响差异。因此不能把结果单独归因于 Rx/Ry 的正负。`completed` 只表示运行完成，不证明每档都适合建立前馈映射。
