# 毛笔 XY 路径开发窗口

当前“局部速度”默认打开区域节奏窗口：框选路径区域，选择顿笔／行笔／收笔，用滑块调整参考速度比例；精确mm/s设置收在高级按钮中。当前版也支持“在最前新建独立笔画”，具体操作见文末2026-10-29说明。

启动：

```bash
cd /home/serein/FYP
.venv/bin/python scripts/edit_brush_path.py
```

恢复上一次自动保存的编辑：

```bash
.venv/bin/python scripts/edit_brush_path.py --resume
```

默认加载 v16；“打开路径版本”可选择历史版本的 recipe.json，包括原路径 v5。虚线为载入版本，浅色点线为原路径 v5，仅供比较。蓝线是待导出的路径，不是实测 TCP 或墨迹预测。

- 拖动编号圆点：改变一个端点，相邻两段随之变形。
- 点击表格选中段，修改“段长 mm”：按比例缩放该段原有细路径，并平移后续各段。段长是路径弧长，不是起终点直线距离。
- 修改“角度 °”：绕起点旋转该段，并平移后续各段；0° 向右、90° 向上、−90° 向下、180° 向左。
- 修改“终点 X/Y”：直接改变端点，与拖动相同。起点可拖动节点0。
- 每段保持原有细路径形状。控制节点由原路径简化提取，但导出仍保留细路径采样；这不是把细路径替换成一条粗折线。
- “尾端放大”便于调整顿笔、回收；“全图”查看整条横画。
- “撤销”支持最近100步；编辑后和关闭时自动保存 outputs/brush_path_editor/draft_v3.json。“恢复编辑存档”也可打开各次导出的 editor_state.json。

## 预检与试写

磁目标可在“磁响应目标”页签逐项修改，位置按新路径弧长重映射；速度请求保持，但 XY 改动会改变重定时和随切线变化的姿态。预检会重新生成完整轨迹并检查既有运动限制；未通过不生成可执行导出。

“导出实验版本”保存到 runs/brush2/plans/interactive/日期/时间__唯一标识/，包括 recipe.json、strokeplan.npz、editor_state.json、preflight.json 以及前馈、PI、现场设置、进笔配置快照。历史版本不覆盖。可以将该目录发给助手作后续分析。

“导出全部笔画并打开试写终端”先生成新版本，再打开终端等待输入 run。点击按钮不会立即连接或运动。准备好蘸水、空白纸面、路径净空，关闭占用串口的录制器；输入 run 后按点序号执行全部笔画，笔间抬笔悬空平移，末笔结束后回等待位。除控制参数之外，执行器仍校验硬件坐标配置、基线和传感器数据。

手动执行已导出版本：

```bash
.venv/bin/python scripts/run_edited_brush_path.py /绝对路径/导出版本目录 --execute
```

去掉 --execute 仅做离线预检。实验日志保存在 runs/brush2/日期/，包含版本输入快照、磁信号和独立实际 TCP。

参考照片仅供目视比较，窗口未执行图像配准或标定，不能由照片推断精确笔尖位置。纸面 XY 的上扬与最终 Z 抬笔是不同量；本编辑器调整 XY，不修改最终安全抬笔。

## 当前版：同一表格内调整每段磁响应和书写起落

恢复最初的单表格布局。每行对应节点 k 到 k+1，直接显示：段长、角度、终点XY、磁目标μT、段首提笔mm、段尾提笔mm。不再有初始高度控件或磁目标页签。

- 磁目标：输入该段的μT值；“继承”或留空沿用原磁曲线。连续设定区域的入口平滑衔接；内部相邻段直接衔接设定值，同值保持恒定；若连续区域直到收笔则末值保持到抬笔，不回到原曲线；仍须通过Z速度/加速度等预检。
- 段首/段尾提笔：相对原磁前馈产生的名义书写Z，向上增加指定毫米数，沿段平滑变化。相邻段共用同一节点高度，所以本段段尾同步更新下一段段首。0表示原高度；逐渐减小到0即回落，不是改变等待位或进笔高度。第一节点固定0。
- 提笔以writing_height参数存于entry_profile.json，仅作用于measure书写段。磁目标与名义Z偏移分别保存，不将提笔量转换成另一个磁目标。PI仍参与受限修正，因此实际Z还会受磁误差影响；这不是能任意独立同时满足高度和磁值的双闭环。
- 预检拒绝使名义TCP到达/高于接触平面、或违反既有工作区、速度、加速度限制的设置；实际触纸情况仍需验证。
- 草稿保存draft_v3.json，兼容恢复旧XY存档。旧V2中按降低磁目标解释的提笔值不会被当成新名义Z偏移自动加载，避免语义混淆；旧文件原样保留。

示例：第20段“段首提笔=0、段尾提笔=0.2”表示在该段书写过程中平滑上提0.2mm；交换两者表示回落。磁目标栏可独立填写130μT。示例仅解释用法，并非最优实验参数；全部参数需重新预检。

磁目标显示更新：原来显示“继承”的单元格现在填入原曲线在该段中点的目标μT（蓝色），仅显示、不覆盖原曲线；悬停可查看原曲线起点/中点/终点数值。手动修改后显示橙色，才成为该段目标；清空恢复原曲线。

磁目标输入下限现为0 μT（负数仍拒绝）。低于现有前馈表下限约72.52 μT可编辑、保存草稿；执行预检仍拒绝未标定范围，不外推或伪造0点标定。

## 低响应试验模式（用户明确授权）

勾选“允许0μT低响应试验”后，可以导出并试写低于实测下限的目标。原前馈表的实测amplitude_uT/depth_mm不变；额外的low_response_trial字段说明临时模型：从(0μT,0mm名义压深)到原表最低点作线性连接。这个连接不是实测标定，也不表示0μT一定离纸或持续触纸。原表范围内仍使用原映射，不允许负值或超过原上限。

低响应模式默认保存于本次编辑存档并随实验导出，终端显示试验标记，仍需run开始。首次按用户要求打开时已勾选；取消勾选恢复原来“不允许低于标定范围执行”的方式。

为保留原速度/加速度等上限，低响应模式遇到轨迹动态越界时可自动尝试减速（最低为原速度的20%）；预检显示最终时长，导出preflight.json记录retiming_factor。强烈的低目标变化可能使整条横画明显变慢，需看预检时长再决定是否试写。所有工作区、深度、初始进笔约束、传感器质量检查和PI限值不放宽。仍不满足检查时禁止执行。

段间磁目标衔接修复：旧版本会在每段交界回到原磁曲线，产生额外峰值。当前版本将相邻显式设置视为连续区域，69→69→69不再回升到原130/140μT。只有进入显式区域或转入确实继承原曲线的下一段时作原曲线衔接。旧实验目录和快照不修改；需重新导出版本使用修复。

## 整段恒定磁目标（执行层严格覆盖）

手动填写磁目标或点击“将选中段的显示数值设为整段磁目标”后，该段每一个控制采样点都使用所设μT，不在段首/段尾混回原磁目标。边界点归下一段，最后终点归末段。蓝色原曲线中点仅是参考值；点击应用后转为橙色显式恒定值。

为了避免名义Z跳变，recipe.json与strokeplan.npz中的平滑磁曲线只用作名义前馈高度引导；真实执行的恒定分段磁目标存于entry_profile.json的segment_magnetic_targets，并在编译出的timeline.g_ref_uT与compiled_plan的g_press中严格覆盖。磁目标恒定不表示实测磁响应瞬时恒定，PI仍作受限修正。

预检逐段审计最终控制目标，一旦任一采样点与设定值不符就禁止导出。每个导出版本附segment_target_audit.json，记录各段请求值、控制采样点数、实际控制目标最小/最大值。改变段目标后会尝试在原运动限值内减速；无法通过仍禁止执行，不通过修改磁目标来绕过检查。

旧导出和旧终端不自动更新，需重新导出新的版本。蓝色继承曲线仍按原曲线变化；只有明确设置的橙色段受恒定规则约束。

## 添加和删除控制点

在表格中选中一段，点击“选中段中间添加点”：在该段曲线弧长中点添加控制点，原XY曲线保留；两段都继承原段的显式磁目标（原为蓝色继承时仍沿用原磁曲线）。新点提笔量取两端中值，拆分后的各段独立平滑插值，因此起落时序可能变化。随后可拖动新点，或编辑两段的长度、角度和磁目标。

“新点插入编号”指定路径中的顺序，X/Y指定位置：编号0表示加在原起点之前；编号等于当前点数表示末端追加；其他编号表示插入该节点之前。填写X/Y点击“按坐标添加点”，或开启“图中点选添加”后在图上点击位置。每次添加后插入编号自动递增，便于连续追加；再次点击按钮退出点选模式。中段插入沿原段弧长中点拆分细路径，再将新控制点移动到指定坐标，原有端点保持原位置。相邻点至少相隔0.02mm；短段也可以向侧面添加新点，无需先找到可用的弧长中点。

点击“删除选中段终点”：删除该行终点，包含整条路径的末端点。点击图中节点或框选多个点后，“删除图中选中点”可删除起点、任意中点和末端。中间点删除后直连前后节点，保留前段磁目标；删除起点或末端时仅裁去相邻整段，保留剩余路径的原位置，并重映射磁目标和速度进度。新追加段继承相邻段磁目标及相邻节点速度、角度；旧式按进度定义的尾端角度先解析到保留节点，转为可编辑的显式角度，避免裁剪后错误套用原进度。

整条路径及当前测试区间都至少保留两个节点；批量删除不能满足条件时整次操作取消，不留下部分删除结果。编号、速度、笔杆角度、磁目标和隐藏状态同步更新。新增点若在隐藏区间，也保持隐藏；可恢复全部点后查看。所有操作支持撤销及存档恢复，编辑区可滚动以适配较小屏幕。增删后必须重新预检、导出；“恢复原始路径”恢复本次打开版本时的路径和参数，也可撤销。历史实验文件不改动。

## 速度设置窗口（当前界面）

点击顶部“速度设置”，修改基础线速度、线加速度、角速度、角加速度，以及速度节点表。节点第一列为当前XY路径弧长百分比，第二列为请求速度mm/s；首尾须为0%和100%，进度严格递增，速度大于0。支持添加、删除中间速度节点。当前使用节点曲线，只改基础线速度不会整体缩放节点速度；要改变末端速度，请修改相应节点行。点击“保存速度”后自动保存草稿，支持撤销，重新预检和导出后生效。速度仍受原运动限值及编译减速约束。

本版移除低响应试验复选框、段首/段尾提笔列及对应命令行启用入口。打开旧草稿时保留XY、磁目标、速度和前馈表选择，将书写提笔偏移归零、低响应授权关闭；新导出不携带writing_height及low_response_trial。低于前馈标定范围的磁目标仍可暂存，但不能通过执行预检。旧实验导出和历史记录不改动。此前文档关于低响应及提笔控件的说明仅适用于旧界面。

## 尾端独立朝向

orientation.heading_knots_s_deg可配置尾端的倾斜方向角，格式为[[接入进度,null],[顿笔进度,-45],[回锋进度,-90],[1,-90]]。首值null表示从自动朝向平滑接入；后续角度以+X向右为0°、+Y向上为90°。-45°到-90°表示顺时针转45°，最终向下，不是朝左。相邻朝向节点间使用五次平滑插值，固定倾角仍为15°；这不是将TCP的RZ直接设为-90°，也不是绕笔杆自身轴线捻笔。该局部朝向在原16mm自动平滑之后覆盖，避免尾端指令再次被大范围平滑改变。速度规划同时考虑新姿态的角速度及角加速度。

朝向进度随XY编辑与新增/删除节点的弧长映射更新；窗口显示当前朝向节点摘要。磁反馈仍只修正Z，实际刷毛转锋及墨迹形态须由实验确认。

### 笔杆角度编辑入口

点击路径编辑器顶部“笔杆角度”（位于“速度设置”旁边）打开专用窗口。书写倾角表示偏离竖直的角度，当前15°，须大于0且小于进笔倾角30°；修改后执行层writing_tilt_deg与新倾角同步。自动朝向平滑尺度仅作用于自动朝向部分。

启用尾端独立朝向后，可修改进度百分比和朝向角，增删中间朝向节点。首行“自动接入”表示从原自动朝向开始平滑过渡，进度须大于0%；末行进度须100%。−45°为右下，−90°为向下；填入角度按实际数值连续插值，不自动改成最短旋转方向。修改倾角或朝向会影响姿态、运笔速度和触纸效果，需重新预检、导出，保存角度本身不执行机械臂。

启动时直接打开：`.venv/bin/python scripts/edit_brush_path.py --resume --orientation-settings`。

## 当前版：按点与点之间编辑笔杆角度

笔杆角度改为与XY路径节点绑定，不再要求用户填写百分比朝向节点。主表最后四列为：段首倾角、段尾倾角、段首朝向、段尾朝向；也可以选中一段后点击顶部“选中段笔杆角度”打开该段专用窗口。倾角是偏离竖直的角度（0°<倾角<30°），朝向为右0°、上90°、下−90°，不是XY行进角或TCP的RZ。

蓝色数值为当前继承方案在端点处的参考值；橙色表示显式设置，清空恢复继承。相邻两段共享节点，修改本段段尾角度会同步为下一段段首。两端都显式填写时，段内按路径弧长作五次平滑插值；同值表示保持。不自动选择最短转向，例如−45°→−90°按顺时针转45°。只有一端填写时平滑接入/退出原方案，两端都继承时保留原方案。

node_angles_deg随草稿保存；导出recipe.orientation.node_angles_s_deg包含当前节点进度、倾角和朝向，执行姿态与速度规划均使用这些设置。新增中点在原段存在显式角度时采样原姿态作新节点角度；删除中间节点时保留其前后节点值，重新在合并段插值。支持撤销、存档恢复；角度修改后须重新预检并导出，可能触发减速，全部原运动限值保持。

本节替代上节的百分比朝向编辑窗口说明；历史底层朝向曲线仍作为可继承方案保留。界面改版本身不修改已有XY、磁目标、速度或笔杆角度。

## 为什么改路径后又降速

速度节点随XY弧长位置映射，并不自动重新求解新磁前馈高度、新转向所需的局部限速。因此改变段长、磁目标、笔杆角度后，旧减速位置和速度可能不再适合。编译器发现完整XYZ或姿态动态超限时，会尝试全局系数1、0.8、0.6、0.4、0.25、0.2；修改磁目标或节点角度均允许这种降速尝试。安装上限保持不变。

当前窗口在路径参数变化后显示“速度待预检”；预检/导出后明确显示全局速度比例、导出线速度上限、书写时间。比例100%表示未触发全局降速，不表示每处都达到请求速度；转向和起止加减速仍可能局部降低实际规划速度。

## 当前版：自动局部适速（默认启用）

现在点击顶部“自动适配速度”、底部“自动适速并预检”，或直接导出/打开试写终端，都会按当次XY、磁目标和笔杆节点角度重新编译速度。无需等待人工重调速度节点。速度设置中的数值是请求上限，自动适速只下调，不提高用户指定速度；若请求超过前馈表支持速度，导出时限制在该范围内。

编译检查抛出带控制采样位置、限值和实际峰值的TrajectoryLimitError。书写编译器将该位置对应到原始书写时间轴的路径进度；自动适速据此降低附近的速度，不使用最近XY点来猜位置，避免自交/回锋路径匹配错误。角速度/角加速度超限时也可降低姿态规划请求，使转向区更平缓。每次候选都完整经过原工作区、深度、步长、XYZ速度及加速度、角速度及角加速度检查，最终再次审计分段磁目标。

不再通过全局时间缩放尝试整条降至25%/20%；复杂路径可能使许多局部区间都需减速，结果以预检时长为准。适速不修改XY、磁目标、笔杆角度、前馈标定、安装限值或PI限值；不自动执行硬件。非书写阶段超限、标定范围错误、无法收敛等情况仍阻止导出。

## 在原0点之前新建独立笔画（2026-10-29）

主窗口右侧点击“在最前新建独立笔画”，在空白处放置第一点，再放置第二点。它生成一条独立新首笔，与原笔画之间不形成书写连接段；不是“插入／追加到当前笔画”的起点前插。

新首笔从0编号。未完成时独立起点显示0，旧编号临时顺延一位；添加第二点后新笔0→1，旧笔各点整体顺延两位。继续追加新首笔时，后续旧点继续顺延。旧笔XY、磁目标、速度、节奏区域、笔杆角度与隐藏范围保留。末尾新建功能仍可用。

未完成起点可取消或撤销，编号随之恢复；未完成时阻止导出和执行。选择顺序与未完成插入位置随草稿保存，恢复、撤销和导出一致。执行先写新增首笔，再抬笔悬空转移至原第一笔最小有效点，之后按序完成所有笔画。仍需重新导出并在终端输入run；编辑不启动机械臂。
