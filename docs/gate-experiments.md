> **一句话**：真机到位后，用这几个实验回答"触角到底能不能拿来做闭环提按"。
> **E1 是分水岭**——不过就不写正式触角闭环代码，改上 F/T 安全网。
> 关联：`note.md §7/§8`、`plan.md A3`、`docs/deltaB-control.md §9`、`reference/执行方案-力控.md`。

## 0. 两条总原则（先读这两条）

### 原则一：关键路径只需 `z + ΔB`，**不需要力传感器**

控制律是

```
z_cmd = z_ff(g_d) + Kv·∫(g_d − g_meas)dt
        ↑ 前馈输出的是 z（毫米），不是牛顿
```

前馈回答的是「想要这个形变 → 压到哪个 **z**」，所以标定曲线的自变量**必须是 z**，灵敏度
`S = ∂ΔB/∂z` 单位是 **LSB/mm**。牛顿**不进控制环**——这一点 `reference/执行方案-力控.md`
自己就写死了（L61「控制量是运动学量（形变）→ 无需绝对力标定」；L81「牛顿…**仅报告用**」）。

**力只剩两个可选用途**：

| 用途 | 要多少 | 必需吗 |
|---|---|---|
| 论文对标种子论文 0.34N | **一次性**几个锚点，借压力计几十分钟 | 可选，**建议做**（否则论文里没有可比的牛顿数） |
| 安全上限 | 可用 ΔB 饱和值代替 | 否 |
| 进控制环 | — | ❌ **明确不要** |

> ⚠️ **说法提醒**：全程不测力的话，严格说做的是「**触觉形变闭环提按**」而非「力控」。
> 建议：说法改成形变/触觉闭环（诚实、零成本）+ 补一个牛顿锚点做对标。

### 原则二：`z` 的基准就是机械臂自己，不用买设备

1. Elfin 缓慢下降，找接触起点 `z0`（ΔB 开始动的那一刻）；
2. 从 `z0` 起按**指令 z** 分档（如每档 0.2mm），每档待稳记 ΔB；
3. 穿透深度 `= z0 − z_cmd`。机械臂重复定位精度远优于 0.1mm，**这就是基准**。

只要台面/纸够刚，指令 z 就是可信的压深轴。**零成本，且天然装配态（in-situ）。**

> 「in-situ」= **装配态**，和"力"无关。见 §3 E2。

## 1. 为什么要有门禁

仿真能证明的只有**结构/趋势**（哪个轴变、迟滞形态、压/拖能否分），
**证明不了**真实触角的 ΔB 数值、带宽、迟滞、磁漂移——这些是硬件的事，任何仿真替代不了。
所以在写核心力控代码前，先用真机跑一串**判据明确**的实验，结果直接决定控制方案：

```
E0 噪声-带宽 ─┐
E2 ΔB↔z 标定 ─┼─► 拿到 C / z_ff / S / σ_z
E3 迟滞回环  ─┤        │
E4 压拖夹角  ─┘        ▼
E1 阶跃/扫频 ─────► ★分水岭：过→触角闭环；不过→F/T 安全网
E5 数据集采集 ─────► 喂标定 & 后续模型（算法侧此刻就能开始）
```

## 3. 逐个实验

### E0 · 噪声-带宽表征
- **为什么**：整个"直接用 ΔB 做控制"的前提是"信号稳定"，但你观察到的"抖动很小"很可能是在**低速/高过采样**下测的。MLX90393 的**噪声与带宽是权衡**：要到 ≥100Hz 必须降 OSR/分辨率 → 噪声必然上升。低速的低噪声**不能外推**到控制采样率。
- **怎么做**：在**实际控制采样率**（≥100Hz）+ 拟用 OSR/分辨率配置下，触角静置不动，采 10–30s，三轴各求标准差 `σ_ΔB`。
- **判据**：结合 E2 的灵敏度 `S`，算等效位置噪声 `σ_z = σ_ΔB / S`，要求 `σ_z ≤ 1/5 × 目标提按分辨率`。
- **裸触角**：⚠️ **可先初测**——噪声底主要由传感器电子学 + 采样配置决定，裸态测得的量级基本可信。**但装配态必须复测**：Elfin 电机/驱动器的 EMI 与法兰磁场会抬高噪声、拉漂基线。裸态结果是**乐观下界**。
- **不过怎么办**：降采样率+接受更低带宽，或提高触角灵敏度（见 §4）。

### E1 · 位移阶跃 + 扫频 ★分水岭
- **为什么**：论文演示是准静态（~100s 级），真写字快 100–300 倍；触角在真实书写速度下能否跟上快速提按**未知**。这是全项目**最大风险**。
- **怎么做**：给触角一个**位移阶跃**（机械臂 z 阶跃，不需要力）看稳定时间；再**扫频**（0.5→5Hz+）看幅值到几赫兹开始塌。同时测抬笔后触角**回弹时间 τ**。
- **判据**：稳定时间 ≪ 0.1s；提按跟踪需求带宽 ~3Hz 内幅值不塌。
- **裕度提醒**：50Hz 伺服 → 约 5Hz 可达闭环带宽 → 对 3Hz 提按"勉强够，无裕度"。
- **裸触角**：✅ **强烈建议先做——最便宜的 kill test**。裸触角没有刷毛/墨的附加阻尼与质量，动态**只会更快**，所以裸态结果是**带宽上界**。
  **裸态就不过 → 装配后必然更差 → 直接判死，省下整套装配和标定台的功夫。** 裸态过了仍须装配态复测。
- **过 / 不过**：
  - **过** → 走触角闭环（`B2` 导纳外环 + 触角反馈）。
  - **不过** → 通知队友上**独立 F/T 力环安全网**，触角退回"管接触状态/切笔画/偏移角"。

### E2 · in-situ（装配态）ΔB↔z 标定
- **"in-situ" 是什么意思**：**装配态**——触角已嵌进毛笔、笔已装上机械臂、钢法兰和电机就在旁边。**和"力"无关**。
- **为什么必须装配态**：

  | 原因 | 说明 |
  |---|---|
  | **基线 B0 被拉偏** | Elfin 钢法兰+电机有磁场，装上后 B0 与裸触角完全不同 |
  | **边界条件变了** | 触角嵌在笔杆/刷毛里，根部约束与可弯长度都变 → 刚度变 → **S 变** |
  | **几何只有装配后才是真的** | 传感器到磁端的距离/角度，磁场 ∝ 1/r³，差 1mm 灵敏度差一大截 |

  **裸触角标出来的曲线，装上去就作废。**
- **怎么做**：按 §0 原则二，用机械臂做**纯法向压入**（不横拖），从 `z0` 起 **0 → z_max 分 8–10 档**（不是 0→3N），每档待稳记 `(z, Bx, By, Bz)`。
- **关键认知**：纯压入时 `ΔB(z)` 在三维磁场空间扫出**一条曲线 `C`**（不是固定方向——压深时偏转方向本身会转，单一方向向量会失真）。
- **产出**：① 压入曲线 `C`（三维）② 前馈 `z_ff = C 的逆` ③ **灵敏度 `S(z) = ∂ΔB/∂z`**（LSB/mm，曲线导数，整 Kv 用；可做增益调度 `Kv_eff = Kv_nom/S(z)`）。
- **判据**：`ΔB↔z` 单调、不饱和（勿顶 ±32767）、斜率够。⚠️ **S 不是一个数是一条曲线** `S(z)`；判据要用工作区间内**最小的 S**（通常在深压端），用均值会骗自己。
- **力怎么办**：**可选**，顺带做——借压力计在 2–3 个档位记一下牛顿，只为报告对标 0.34N。**不进控制环。**
- **裸触角**：❌ **不能替代**。但裸态可用来**摸底与迭代硬件**：先在裸触角上试传感器位置/磁化强度，看 S 的量级是否离谱，定下装配方案后再做正式 in-situ。裸态数字**不可用于整定控制器**。

### E3 · 加载-卸载回环（迟滞/蠕变）
- **为什么**：触角是**粘弹（率相关）**，同一 ΔB 对应加载/卸载两态 → C 实为一条**回环带**而非单曲线，投影到均值曲线有固有误差 ≈ 半个回环宽度。
- **怎么做**：多种速率下 z 压入再抬起，记回环；测蠕变（恒压深下 ΔB 随时间漂移）。**全程只需 z，不需要力。**
- **判据**：回环宽度 / S → 等效 z 误差，要求 ≪ 提按分辨率。
- **裸触角**：✅ **可先做，也是便宜的 kill test**。迟滞源于触角材料本身的粘弹性，裸态就能测出**下界**（刷毛+墨只会再加一层迟滞与阻尼）。**裸态回环就已经大到超预算 → 直接判死。** 通过则装配态复测。
- **不过怎么办**：上率相关 PI 逆补偿，或学习式前馈。**注意粘弹回弹**：刚抬笔时触角仍在恢复，不可立即重估基线——命令 z 高于纸面 + 信号稳定持续 τ（取自 E1/E3）后才更新。

### E4 · 恒压深横向拖行（压/拖可分性）
- **为什么**：投影法要能把"拖拽污染"从"提按"里剥出来，前提是两者方向可分。
- **怎么做**：机械臂**锁定 z**（恒压深，不是恒力——恒力需要力环，恒压深锁个坐标就行）横向拖行，量拖拽产生的 ΔB 方向。
- **判据**：拖拽方向与 C 切向**夹角 `θ`**，建议 `θ > 60°` 才认为方向解耦可靠。拖拽窜入提按估计的量 ≈ `‖ΔB_drag‖·cos θ`；θ 越接近 90° 越干净，近乎平行则任何投影法都无解。
- **裸触角**：⚠️ **指示性，不作准**。θ 由**装配后的触角姿态几何**决定；而且装配后拖拽力是经**刷毛**传给触角的，方向可能被改写。裸态可以先看"大致能不能分"，真值必须装配态。
- **不过怎么办**：无表示法可救——需硬件改动（改触角嵌入姿态）或退 F/T 安全网。
- **仿真侧已备**：`python -m brushbot.tactile.separability sep.png` 用合成模型先看结构（投影法需 θ≥85° 才 <10% 误差），真值仍等真机。

## 4. E5 · 标定数据集采集（新增，算法侧此刻就要）

> **目的**：给 ΔB→提按标定 & 后续模型提供**真数据**。这是你（算法）现在的输入源——
> 队友照本节格式采，你拿到就能直接跑标定，不必等其他门禁。

### 4.1 采什么
- **单元 = 一条笔画**：如"一横 / 一竖 / 一撇 / 一点"，每条一段时间序列。
- **每段内容**：`t, Bx, By, Bz`（**原始三轴，务必留原始，别只给算好的幅值 |ΔBxy|**——三轴是分离提按/拖拽的唯一依据）。
- **每段一个标签**：笔画类型、大概压深（浅/中/深 或 mm）、是否匀速。
- **基线**：每段开头留一段**静止悬空**（笔未触纸）用来做零点；或单独存一份静置 B0。归零方式：`ΔB = B - B0`。
- **变体**：同一笔画多采几遍；至少覆盖 **浅压 / 深压**、**慢 / 快** 两个维度，才够看提按和拖拽。

### 4.2 文件格式（CSV，每笔画一段）
```
# meta 放文件名或首行注释: stroke=heng, press=mid, speed=uniform, fs=200Hz, sensor=MLX90393
t,Bx,By,Bz
0.000, 1234, -567,  8901
0.005, 1230, -560,  8902
...
```
- `t`：秒（或采样序号，标清采样率 `fs`）。
- `Bx,By,Bz`：**原始 LSB**（别在采集端换算成 mT/牛顿，保留 LSB，标定阶段再定标度）。
- 文件命名建议：`heng_mid_uniform_01.csv`（笔画_压深_速度_序号）。

### 4.3 采集要点
- **采样率**：≥100Hz（和拟用控制率一致），并在 meta 里写清 `fs` 与 OSR/分辨率配置——和 E0 呼应。
- **机器人姿态下取基线**：Elfin 钢法兰/电机会让 B0 漂；人写 vs 机器人写要可比，基线必须在**同一机械臂姿态**下取。
- **同步**：若同时有笔尖位置/z 指令，标清时间对齐方式（对后面 E2 标定和"闭环 vs 开环"对比很关键）。
- **一段就是一段**：抬笔→落笔→抬笔完整包含，方便切"接触区间"。

### 4.4 裸触角版（✅ 现在就能开采）
没有装配、没有机械臂时，**手持裸触角模仿笔画**（横/竖/撇 + 轻重快慢）照样按上面格式存，
用途是**让算法管线提前跑通**：基线归零、幅值/方向分解、切接触区间、可分性初估。
⚠️ **只用于联调管线与看结构，标定系数不可沿用**——装配态一变，S 和 θ 全变。

### 4.5 拿到数据后（算法侧要做的）
1. **基线归零**：段首静止段求 B0 → `ΔB = B - B0`。
2. **幅值/方向分解**：`|ΔBxy|`（提按强度）与方向（拖拽），对每类笔画看结构是否和合成模型一致。
3. **建标定曲线**：`ΔB → 提按`（保留 LSB 单位）。
4. **量可分性**：估压/拖夹角 θ，喂 E4 判据。

> 现有合成管线可作对照：`src/brushbot/tactile/writing_tactile.py`（写字→合成 ΔB）与
> `separability.py`（压/拖分解）已实现同样的分解逻辑，真数据直接套。

## 5. 裸触角 vs 装配态 · 总览

**一句话**：裸触角能做的都是**早期否决 / 数量级摸底 / 管线联调**；
凡是**要进控制环的数字**（`S`、`z_ff`、`θ`、`σ_z` 终判）**必须装配态**。

| 实验 | 裸触角结果的性质 | 能否据此判死 | 装配态是否必须复测 |
|---|---|---|---|
| E1 带宽 | **上界**（裸态无刷毛/墨阻尼，只会更快） | ✅ **裸态不过 = 直接判死** | 过了要复测 |
| E3 迟滞 | **下界**（刷毛+墨只会再加迟滞） | ✅ **裸态超预算 = 直接判死** | 过了要复测 |
| E0 噪声 | **乐观下界**（缺电机 EMI / 法兰磁场） | ⚠️ 仅参考 | ✅ 必须 |
| E4 夹角 θ | 指示性（装配后姿态几何与传力路径都变） | ❌ | ✅ 必须 |
| E2 标定 | 仅摸底/迭代硬件方案 | ❌ | ✅ **定义上就必须** |
| E5 数据 | 管线联调用；系数不可沿用 | — | ✅ 正式数据集必须 |

**推荐做法**：硬件装配还没就绪时，**先用裸触角跑 E1 + E3**——这两个是最贵的风险，
而裸态给的恰好是"最有利的一面"。**裸态都不过，后面全免谈**，能省掉整条装配+标定台的投入。

## 7. 诚实边界

- 仿真（`docs/tactile-fem-sim.md`）复现的是**结构/趋势**，不是真机数值。
- E0–E4 的判据数字（0.1s、3Hz、θ>60° 等）是**工程起点**，真机实测后按结果调整并写进 limitation。
- 裸触角结论是**边界（上/下界）**，不是真值；除 kill test 外不可当结论用。
- E5 的原始三轴一旦丢失就无法回溯——**采集端永远存原始 LSB**。
