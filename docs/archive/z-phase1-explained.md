# Phase 1 设计通俗版：让毛笔机器人"边写边感觉"

> 这份文档面向没学过控制理论的同学，解释 Z 控制环 Phase 1 在做什么、为什么这样设计。
> 严谨版设计文档见 `docs/superpowers/specs/`（spec），工程交接见 `docs/handoff-z-phase1.md`。
> 状态：设计阶段（2026-07-30），代码尚未实现。

---

## 1. 背景：这个机器人在干什么

我们在做一个写毛笔字的机器人。毛笔字的灵魂是**提按**——笔画粗细由毛笔下压的深度决定：压得深，笔毫铺开，笔画粗；提起来，笔画细。所以机器人必须精确控制"往下压多少"，这就是 Z 轴控制。

问题是：机器人怎么知道自己压了多深？看电机位置不够——纸面高度有误差、毛笔会变形磨损。我们的方案是给笔杆装一颗小磁铁，笔毫受压弯曲时磁铁跟着动，旁边的磁传感器测到磁场变化 **ΔB**。压得越深，|ΔB| 越大。换句话说：

> **磁传感器就是机器人的"手感"。** 人写字时靠指尖感觉笔的反弹力，机器人靠 ΔB。

Phase 0 已经证明了一件最基本的事：给一个**固定的**目标手感（比如"保持 |ΔB| = 120 µT"），控制器能让实测手感稳定跟上目标，误差约 2%。相当于机器人学会了"按住不动"。

Phase 1 要学的是"边写边动"——目标手感随时间起伏（提按），而且要在真实的噪声环境下做到。

## 2. Phase 1 要解决的三个新问题

### 问题一：传感器很吵

真实磁传感器的读数不是平滑曲线，是毛刺丛生的锯齿——环境电磁干扰、传感器自身噪声，量出来 σ ≈ 7 µT。提按信号本身才几十 µT，噪声占了不小比例。控制器要是直接信这些毛刺，就会跟着毛刺乱动，笔画边缘会抖。

解法是**滤波**：把最近的读数"揉"在一起取平滑值。我们已经在上一阶段选好了滤波器（叫 One Euro 滤波器，一种"信号动得快就少平滑、动得慢就多平滑"的自适应滤波），能把噪声从 7 µT 压到 2.7 µT。

### 问题二：滤波是有代价的——滞后

滤波的原理是"参考过去的读数"，所以滤波后的信号永远**慢半拍**。就像你透过延迟 0.1 秒的直播画面打乒乓球——延迟小还能打，延迟大了你的每次挥拍都在纠正"已经过去的错误"，越纠越错，最后动作失控发散。

控制理论里这叫**稳定性问题**：反馈环里的延迟越大，控制器就必须越"温柔"（增益调低），否则会振荡。Phase 0 没接滤波器，等于在无延迟的理想世界里调好了动作幅度；Phase 1 把滤波器接进来，延迟变了，**原来的参数不能直接用**，必须重新找安全范围。这是本期最核心的实验。

### 问题三：目标不再是定值

写字时目标手感是一条起伏的曲线：落笔（从 0 升上来）→ 提按起伏（0.5–3 次/秒）→ 收笔（降回 0）。控制器要**追**这条曲线，而不是守住一个定值。追动目标比守定值难：目标动得越快，滞后的影响越明显。

## 3. 核心架构：肌肉记忆 + 临场手感

Phase 1 的控制器输出由两部分相加（这个结构 Phase 0 就有，本期不变）：

```
下压深度指令 = 纸面高度 + 前馈(查表) + 反馈(纠错)
```

**前馈 = 肌肉记忆**。事先做过标定实验："压 1 mm → |ΔB|=50，压 2 mm → 100，……"存成一张表。写字时想要多少手感，直接反查表得到该压多深。这一步不看传感器，快、稳、无延迟——就像熟练的书法家不用想就知道手该压多低。**前馈干大部分活。**

**反馈 = 临场手感修正**。查表不可能完全准（毛笔磨损了、纸换了、标定本身有误差），实测手感和目标的差距 e 由反馈慢慢补上：比例项（Kp·e，误差大就立刻多压一点）加积分项（Ki·∫e，持续偏小就逐渐加深）。**反馈只补小差额**，所以它可以调得很温柔，不容易被延迟搞失稳。

滤波器接在哪？**只接反馈这一路**：

```
传感器 dB_raw ──→ [实时滤波器] ──→ 控制器反馈端
目标曲线 g_d ────────────────────→ 控制器前馈端（不经过实时滤波）
```

目标曲线是事先准备好的，数据完整，可以用"上帝视角"的零相位离线滤波洗得又干净又不滞后（那是下一期 §3.2 的活）。实时滤波器只处理不得不实时面对的传感器噪声。**两种滤波各司其职，不混用。**

一条铁律顺带解释：滤波必须在三轴向量 (x,y,z) 上做，滤完再算长度 |ΔB|。如果先算长度再滤，噪声会被"整流"——想象一个绕零点抖动的数，取绝对值后全变成正的,平均下来凭空多出一个正偏置。先滤后取模就没这个问题。

## 4. 这次要改/要建什么

### 4.1 控制器小改：增益"无量纲化"

Phase 0 有个尴尬的遗留：增益 Kp 的单位是"米每微特斯拉"，合理取值在 0.00001 这种量级——反直觉、易出错，而且换一张标定表就得重调。

本期改法：控制器构造时自己从标定表算出一个换算斜率（"1 µT 的误差相当于多少毫米压深"），增益变成无量纲的比例数，比如 Kp = 0.3 表示"每拍把误差的 30% 折算成压深修正"。好处：数字直观（0～1 之间）、换标定表不用重调、仿真里扫出的安全范围能直接迁移到真机。

### 4.2 新建仿真台：`sim_loop`（假想敌训练场）

真机还没装好，所有验证都在仿真里做。我们建一个"假机器人 + 假环境"：

- **Plant（被控对象）**：模拟真实执行链——指令先延迟 2 拍（模拟通信+计算延迟），再经过一个"追不上急变"的一阶执行器（电机不是瞬间到位的），再按标定曲线换算出 ΔB。
- **真噪声回放**：不用数学生成的假噪声，直接把真实传感器录的静止数据切片叠加进来。真噪声有"低频占比高"的特征（1/f 谱），假噪声模拟不像，用真的最诚实。
- **一个关键的小心机**：Plant 内部的"真实标定曲线"和控制器手里的"标定表"是**两份**。平时两份一样；做扰动实验时偷偷把真实曲线改掉 ±20% 而不告诉控制器——这就模拟了"标定不准"的真实场景，看反馈能不能把这个坑补上。

### 4.3 唯一的闭环代码路径

所有实验（有无滤波、开环闭环、各种扰动）都跑同一个 `run_loop` 函数,只换参数。特别地，**"开环对照组"就是把 Kp=Ki=0 的同一套代码**——两组实验除了"有没有反馈"完全逐位相同（连噪声序列都用同一个随机种子）。这样最后论文里说"这两条曲线的差异就是触觉反馈的贡献"时，是代码结构在背书，不是人肉对齐。

## 5. 两个实验

### 实验一（层 1）：找安全的"油门范围"

固定一条合成提按目标曲线（含落笔、0.5–3 Hz 起伏、收笔），叠加真噪声，然后跑一个大矩阵：

> {不滤波, EMA, Butterworth, OneEuro 四种滤波} × {Kp 从小到大} × {Ki 从小到大}

每格记录：跟踪误差 RMS、有没有振荡、有没有发散。画成热力图后能看到一条**稳定边界**——增益超过它系统就振荡（就像麦克风离音箱太近会啸叫）。工作点选在边界的一半以内，留足安全余量。

这个实验同时回答两个问题：
1. **滤波值不值**：对比"不滤波"列和其他列的跟踪误差；
2. **OneEuro 定不定得下来**：它是非线性滤波器，教科书的频域稳定性分析对它失效，只能靠这种时域仿真投票。如果它的闭环表现不输 EMA，选型就正式定稿。

### 实验二（层 2）：捣乱测试（论文数字的来源）

用实验一选出的滤波器和工作点，开环臂 vs 闭环臂各跑四种场景：

| 场景 | 模拟什么 | 预期 |
|---|---|---|
| 无扰动 | 理想情况 | 两臂都好，闭环略优 |
| 标定曲线偏 ±20% | 标定不准/毛笔磨损 | 开环整体偏粗/偏细，闭环补回来 |
| 纸面突然 ±0.5 mm | 纸下有异物/桌面不平 | 开环笔画突变，闭环几拍内恢复 |
| 传感器慢漂移 | 机械臂运动带来的磁干扰 | **闭环反而被骗**（漂移混进手感里），开环免疫 |

注意最后一行：这是**故意设计的诚实对照**。漂移和提按信号频段重叠，滤波器分不开、反馈也分不开——这个实验会量化"漂移能把闭环骗偏多少"，从而论证下一步为什么需要差分测量（硬件方案）。做研究不能只展示自己方法赢的场景。

另外还有一个细节检查：落笔/收笔瞬间，目标曲线穿越"接触阈值"，控制器的积分器会在冻结/解冻之间切换。要放大看这些瞬间的波形，确认指令没有毛刺（突跳）——毛刺到了真机上就是笔尖戳纸。

## 6. 怎么算成功

Phase 1 结束时必须能用数字回答四个问题：

1. 接了滤波后，时变目标的跟踪误差是多少？比不滤波好多少？
2. 增益的稳定边界在哪？选的工作点离边界有多远？
3. 各种扰动下，开环 vs 闭环各偏多少？（论文核心对比）
4. 落笔/收笔的冻结切换处有没有毛刺？

外加一条硬规矩：现有全部测试（滤波器 31 项 + 控制器 6 项 + 其他）继续全绿。

## 7. 小词典

| 术语 | 白话 |
|---|---|
| ΔB / \|ΔB\| | 磁场变化（三轴向量）/ 它的长度，代表按压手感强弱 |
| 前馈 (feedforward) | 不看传感器、按预先知识直接给出的动作（肌肉记忆） |
| 反馈 (feedback) | 根据"目标−实测"的差距做的修正（临场手感） |
| 增益 (Kp/Ki) | 修正的力度；太小纠错慢，太大会振荡 |
| 滤波 (filter) | 把带毛刺的信号揉平滑；代价是慢半拍 |
| 滞后/延迟 (lag) | 滤波和传输造成的"你看到的是过去"效应，反馈环稳定性的头号敌人 |
| 开环/闭环 | 不用/用传感器反馈的控制方式 |
| Plant | 控制理论黑话：被控制的那个对象（这里指"机器人+毛笔+传感器"的仿真模型） |
| freeze（冻结） | 笔没接触纸时，误差没意义，把积分器暂停以免它瞎积累 |
| 1/f 噪声 | 低频成分特别多的真实噪声，和白噪声不同，必须用真实录音回放来模拟 |
| RMS | 均方根误差，衡量整段时间平均偏差的常用指标 |
