# 首轮数采与前馈控制验证

> 这是后续验证方案，不是当前梯子 RUN 的逐拍实际位姿采集要求。当前命令线程不得为采集实际 TCP 位姿而逐拍同步读取；没有独立实际位姿证据时，只分析命令位置与磁响应，不计算真实 TCP 跟踪误差。

## 目的

用一段短数据验证“采集 → 读取 → 前馈执行 → 结果记录”的最小链路。此次实验只验证数据格式和当前控制基线，不建立完整训练集，也不评价 Transformer。

## 最小采集内容

每个采样点至少保存：

| 字段 | 要求 |
|---|---|
| 原始时间戳 | 保留采集设备给出的原始值和单位 |
| 相对时间 | 以本段开始为零，单位秒 |
| 指令位姿 | 至少包含当前控制器实际消费的位置分量 |
| 机械臂观测状态 | 仅在不阻塞命令周期的采集方式已验证时另行保存；否则明确标记不可用 |
| 采样周期 | 保存设定值，并由时间戳计算实际分布 |
| 坐标系 | 明确基坐标、工具坐标或纸面坐标，不允许只写 XYZ |
| 标定编号 | 指向本次使用的 XY、Z、工具和纸面标定版本 |
| 起止条件 | 记录开始姿态、结束姿态和停止原因 |

如果同步采集触觉信号，还必须保存未经滤波的 `Bx, By, Bz` 和独立时间戳；滤波结果属于派生数据。

## 执行步骤

1. 选择一段幅度小、速度低、工作空间明确的轨迹。
2. 固定机械臂、工具、纸面和坐标系标定版本。
3. 空载运行一次，检查轨迹范围、速度和停止路径。
4. 开始记录后执行一次前馈回放，不在本轮加入反馈控制。
5. 保存原始数据、执行配置和异常信息。
6. 离线计算实际采样周期、指令与观测状态的对齐情况及轨迹误差。

## 验收输出

结果报告必须包含：

- 数据文件与配置文件的相对路径；
- 轨迹长度、持续时间和样本数量；
- 实际采样周期的均值、标准差、最小值和最大值；
- 指令状态与观测状态使用的坐标系和单位；
- 可计算时给出跟踪误差，否则明确缺少哪项观测；
- 丢帧、超时、非有限值、限幅和安全停止次数；
- 是否可以进入下一轮，以及下一轮只修改一个主要变量。

## 第一轮明确不做

- 不采集大规模、多字、多书写者数据集；
- 不训练或比较 Transformer；
- 不把仿真中的反馈增益直接用于真机；
- 不在字段来源不明时推断笔杆姿态。
