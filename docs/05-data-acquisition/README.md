# 05 · Data Acquisition

当前记录原始磁信号、命令位姿、时间、baseline 和毛笔／装配／姿态条件，支撑重复性与前馈关系。逐拍实际位姿不作为命令线程的同步采集要求。

完整阶段关系见[根计划](../../plan.md)。先读下面的主题文件；历史材料集中在 `archive/`，按记录日期解释。

## 项目目的

建立可复现的数据采集流程，当前服务命令 Z 与 `|ΔBxy|` 的对应关系及重复性验证，再逐步扩展到 StrokePlan 执行记录和 Transformer 所需的数据集。

## 范围

- 定义时间戳、坐标系、采样频率、标定编号和元数据。
- 记录控制指令与必要的触觉信号；实际机械臂状态若可用，应注明采集时机与来源，不以同步读取阻塞命令周期。
- 管理原始层、处理层和结果报告之间的关系。
- 对缺帧、时序抖动、量纲和坐标系进行质量检查。

原始视频和大体积时序数据不放进 `docs/`；`docs/` 只保存协议、清单、少量验收样例和结果报告。

## 已知限制与后续讨论

- 第一轮不建设 Transformer 训练数据集。
- 触觉和机械臂状态若来自不同设备，必须验证共同时间基或对齐误差。
- 当前实验应记录笔杆／TCP 姿态并与前馈表适用条件关联；逐点姿态是否进入 StrokePlan 留待 Transformer 阶段。原始信号应保留以支持以后重算。
