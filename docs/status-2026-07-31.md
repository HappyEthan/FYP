## 3. 已定结论（数字表）

以下结论均为**裸态仿真条件**下的定稿，装配态复测前不视为最终（见 §4）。

| 结论 | 数字 | 出处 |
|---|---|---|
| 控制环滤波器 = **EMA α=0.3** | 闭环 RMS 9.47%，优于不滤波 10.76%、OneEuro 11.83% | z-phase1-sweep.md Q1 |
| 显示/离线滤波器 = OneEuro mc=0.5 β=0.03 | σ 6.94→2.67 µT（孤立指标口径，与上一条**不矛盾**：滞后在环内按稳定性汇率兑换成增益损失，环外没有这笔账） | filter-comparison.md |
| 出厂默认增益 kp=1.2077 / ki=0.134（无量纲） | kp 出自层 1 扫描（2 倍裕度内 RMS 最优），ki 出自层 2 多笔画收敛（3 笔） | z-phase1-sweep/results |
| 相位裕度 | 116°+（≥45° 目标大幅富余；旧"滤波延迟 ≲10ms 预算不可达"顾虑解除） | z-phase1-sweep.md Q2 |
| 反馈价值（论文核心数字） | 标定偏差 ±20%：开环全吃 ~25 µT，闭环-P 残留 45%（=1/(1+kp) 理论吻合）；多笔画 PI 三笔收敛到 2σ 带内 | z-phase1-results.md Q3 |
| 反馈代价（诚实负面对照） | 传感器漂移：开环免疫，闭环被骗 ~55%——差分测量的立项论据 | z-phase1-results.md |
| freeze 期间 Kp 保持作用 | Q4 单笔画 PASS（毛刺 0.194 mm ≤ 0.2 mm） | z-phase1-results.md Q4 |
| 控制律路线 | 滤波后 \|ΔB\| 标量 + 标定表前馈反查 + 无量纲 PI（`deltaB-control.md` §5 的向量投影法留作 Phase 2+ 候选） | z_control.py |

两个可复算的解析锚点（所有仿真数字都能从它们推出来）：稳态残差 **e_ss = d/(1+kp)**；积分时间常数 **τ_i = (1+kp)/ki**。

## 4. 待验证清单（按性质分类）

### 4.1 装配态数据到位后必须复测（决定定稿）

- [ ] **E0 装配态噪声**：重跑 `compare_filters.py`（孤立口径）+ `sweep_z_gains.py`（在环口径）——1/f 谱形变化可能让**任一口径翻盘**，两个都要跑，重跑前别预设结论。
- [ ] **E2 灵敏度标定 S (µT/mm)**：目前全部标定曲线是合成的；S 定了才有 σ_z 等效噪声、真实标定表、真机增益。
- [ ] 装配态复测后按需重扫增益（脚本吃 CSV 参数，一条命令）。

### 4.2 真机前提假设（仿真结论的适用条件）

- [ ] **执行器滞后 τ≥20ms**：kp=1.2077 以此为前提（理想瞬时执行器稳定界 kp<1）。真机执行器显著更快 → 必须重扫。
- [ ] Plant 的 τ=50ms/n_delay=2 拍是假设值，层 1 敏感性抽查覆盖 τ∈{20,50,100}ms × delay∈{1,2,4}，真机标定后核对落在范围内。
- [ ] 机械臂运动低频磁漂移与信号同频段（滤波无解）——漂移场景已量化"被骗 55%"，**差分测量硬件方案**待评估。

### 4.3 开放项（已记录，待真机裁决）

- [ ] **多笔画 freeze 毛刺 0.247 mm 超 0.2 mm 暂定上限**（与 ki 无关，Kp 切换固有行为 + 极值效应）。判据约束的是 z_cmd 单步跳变，执行器会平滑实际笔尖运动——真机用实测笔尖运动重评（z-phase1-results.md 开放项节）。
- [ ] ki=0.134 面向跨笔画自适应（~3 笔），**不承诺单笔画内扰动抑制**——这是能力边界不是 bug，论文表述时注意口径。
