# CalliRewrite 精读 —— 无监督从书法字图恢复书写行为

> **论文**：CalliRewrite: Recovering Handwriting Behaviors from Calligraphy Images without Supervision
> **作者**：Yuxuan Luo, Zekun Wu, Zhouhui Lian（北京大学王选所 / 元培学院）
> **arXiv**：2405.15776v1（2024-03-20）　**PDF**：`/home/ethan/vtla/2405.15776v1.pdf`
> **代码/主页**：https://luoprojectpage.github.io/callirewrite/ （含代码 + 补充材料）
> **在本项目中的定位**：⭐⭐⭐ 头号借鉴对象——**"字形→有序 Bézier 笔画"这一段的最佳蓝本**；但它在"力/提按"处正好空白，那是本项目要补的核心。

---

## 0. 一句话总结

用 **CNN+LSTM（无监督）** 把一张**静态书法字图**分解成一串**带笔宽的 Bézier 笔画**（形状+顺序），再用 **强化学习(SAC)** 针对具体书写工具微调轨迹，最后在 **4-DoF Dobot 开环**机械臂上复写。**全程无笔顺标注、无力觉**——复现的是**外观**，不是**提按力度**。

---

## 1. 它要解决什么问题

- **输入**：一张书法字的图（可以是没见过的字体、古文字、甚至像涂鸦的字）。
- **输出**：一条**合理的书写轨迹**（笔画顺序 + 每笔路径 + 笔宽），让机械臂能拿**不同工具**复写出来。
- **两大难点**：① 笔画分解 + 书写顺序恢复（无标注）；② 不同工具（毛笔/秀丽笔/平头笔）的灵巧控制。
- **核心主张**：**无监督、低资源**——不依赖费力的人工笔顺标注，从"白纸图像"里自己挖出书写策略。灵感来自"小孩没学过笔顺也能照着写字"。

---

## 2. 方法总览（两阶段，粗到精）

```
字图 I
  │
  ▼  阶段一: 粗轨迹提取 (CNN + 无监督 LSTM)
一串二次 Bézier 笔画 {B_t}
  │
  ▼  阶段二: 工具感知微调 (RL / SAC, 在 CalliEnv 里)
精细化的、带工具笔法的控制点序列 {P'_t}
  │
  ▼  4-DoF Dobot: (x,y,r) → (x,y,z) 标定后复写
```

---

## 3. 阶段一：粗轨迹提取（CNN + 无监督 LSTM）

### 3.1 结构与输出
- **骨干**：CNN 编码字图 + LSTM 逐步解码（借用 Mo et al. "General Virtual Sketching" 的**动态窗口 + 可微裁剪-粘贴**组件）。
- **每个时间步 t 输出一个二次 Bézier 笔画**：
  ```
  B_t = (p, x0, y0, x1, y1, x2, y2, w0, w1)_t
  ```
  - `p`：落笔(1)/抬笔(0)
  - `(x0,y0),(x1,y1),(x2,y2)`：二次 Bézier 的 3 个控制点
  - `w0, w1`：这一笔**起始/结束的笔宽**（提按的视觉表现）
- 逐步渲染 + 粘贴到画布，直到重建出整字。

### 3.2 四个无监督损失（都是"像人写字"的先验）
1. **感知损失 L_perc**（VGG-16）：渲染结果 ŷ 与目标字 y 在 relu1_2/2_2/3_3/5_1 层特征的 L1 差，按层归一化防抖。
   `L_perc^j = 1/(D_jH_jW_j)·‖φ_j(ŷ)−φ_j(y)‖_1`
2. **正则损失 L_reg**：惩罚抬笔 `L_reg = 1/T·Σ(1−p_t)` → 笔画尽量少、连续。
3. **平滑损失 L_smo**（格式塔连续性）：相邻方向向量余弦相似 → 顺滑；带 0.5 缩放防误罚真实弯曲。
4. **角度损失 L_ang**：约束起笔方向在人手自然范围（约 +75°~−165°）；相邻笔画方向与参考方向余弦相似，<0.5 则罚。

### 3.3 渐进训练（低资源关键技巧）
- **先**在 **QuickDraw** 上预训练（75k 步）获得基本分解能力；
- **再**在 **KaiTi-GB2312 + KanjiVG** 抽的 **1000 个字**上微调（30k 步，`L_phase2 = L_perc + L_reg + λ2(0.5·L_smo + L_ang)`），学会处理书法笔画粗细变化。
- 消融证明：直接在 1000 字上硬训不如"预训练→微调"；L_smo + L_ang 组合出最佳 SNR/CD。

## 4. 阶段二：工具感知微调（强化学习 SAC）

> 因为**无示范**，只能靠试错去"发现"每种工具怎么用 → 所以用 RL。**（这一段本项目不需要，见 §7。）**

- **环境 CalliEnv**（OpenAI Gym + Tianshou）：
  - **即插即用工具模型**：把工具用**接触面几何 (r 半径, l 长度, θ 角度) + 动力学**近似。建了三种：秀丽笔(fude)、平头马克笔、毛笔（圆形~四边形）。
  - **状态 S_t**（≈9 维）：`(h, r, l, θ, δx, δy, vx, vy)` —— h=书写进度，r/l/θ=工具几何，δ=先前动作偏移，v=运动方向。
  - **动作**：控制点位移 `a_t=(δx,δy)`；平头笔多一个角度自由度 θ。
- **奖励设计**：
  - **自适应形状奖励 R_ada**：笔画中段鼓励顺滑探索、端点惩罚越界（书法笔法变化多在起收笔）。
  - **终局奖励 R_fin = 80·IoU(I', I)**：重画结果与原字的交并比 ×80，提升 SAC 对相似度的敏感。
  - `R = 1/T·ΣR_ada + R_fin`
- **算法**：Soft Actor-Critic（稳定、收敛快、双 critic 防高估），α=γ=0.95，Adam，lr 1e-4，150 epoch。
- **作用**：把阶段一的粗 Bézier 修成**带工具笔法**的轨迹（毛笔转锋、马克笔转向、起收笔的提按转笔动作）；还能**纠正**阶段一的分割错误（连断点、拉伸错位）。

## 5. 机器人复写（关键：它怎么控制笔画粗细）

- **硬件**：4 自由度 **Dobot Magician**，**开环**（无力觉、无反馈）。
- **宽度→高度标定**：把控制点 `(x, y, r)` 里的**笔宽 r** 转成**笔高 z**——
  > 让笔在不同 z 高度划线、量出笔画宽度、拟合出 **z–r 线性关系**，于是"要多宽的笔画"就"压到多低"。
- **即：用抬压笔杆(位置)来凑笔画粗细，而不是用力。**
- 中文用真毛笔、写"千字文"前 24 字（8×8 cm）；英文用秀丽笔/平头笔；还测了古埃及、泰米尔文。

## 6. 实验与指标

- **指标**：
  - **SNR**（Stroke Number Ratio = N_s/N_gt）：越接近 1，笔画分割/连续性越好。
  - **Chamfer Distance (CD)**：轮廓点云相似度。
- **结果**（200 楷体字）：

  | 方法 | 监督 | SNR↓ | CD↓ |
  |---|---|---|---|
  | LTP (Learning to Paint) | RL | 5.660 | 6.978 |
  | GVS (General Virtual Sketching) | 无监督 | 5.602 | 2.092 |
  | **CalliRewrite (Ours)** | **无监督** | **1.199** | **1.979** |
  | VectorNet | 有监督 | 1.039 | 1.614 |

  → **无监督里最好，逼近有监督**。
- **泛化**：中文（甲骨/篆/隶/楷/行/草）、英文两种手写体、古埃及、泰米尔文都能复写。

## 8. 最关键洞察：它给"形状+顺序"，力/提按是空白 = 我们的贡献

- CalliRewrite **没有任何力**；"笔画粗细"只是**视觉宽度**，靠**抬压笔高(z)**去凑 → 复现**外观**而非**提按动力学**。
- **这正是本项目要填的洞**：触觉给**真实接触力曲线**，用**力控**复现提按，比"z 高度凑宽度"更忠实。
- **由此得到最有力的对比实验**：
  > *CalliRewrite = 开环 · 位置控宽度 · 无力觉* **vs** *本项目 = 闭环 · 力控提按 · 有触觉*
  > —— 这就是相对它的**改进点与卖点**，答辩站得住。

### 顺带巧思：笔宽 ↔ 力 的双约束
CalliRewrite 从图里恢复了每笔**笔宽 w**（提按的视觉表现）。而我们有**真实力**。于是可以：
- 把**视觉笔宽**当**力的辅助监督/一致性校验**（"学出的力曲线，渲染出的笔宽对不对？"）；
- 建立"**力↔笔宽**"对应，让提按既有触觉真值、又有视觉约束 → 比它单靠视觉更强。

## 9. 它怎么插进本项目架构

```
成品墨迹照片
   │  ← 借 CalliRewrite 阶段一（但用 OCR+笔顺模板约束，避开它最大失败模式"分割不准"）
   ▼
有序 Bézier 笔画（形状 + 顺序 + 笔宽 w）      ←── 视觉这一半
   │  + 触觉力曲线 f(t) 按笔顺序号配对          ←── 我们独有的力这一半
   ▼
每笔 = {路径 Bézier + 笔宽 + 力曲线} → 训练 Transformer 翻译器
   ▼
UR5 + 触觉力控复现提按   （替代它的 Dobot 开环 z-高度）
```

**两个集成注意点：**
1. 它输入是**干净字体图**，我们输入是**真实墨迹照片**（毛边、洇墨）→ 跑阶段一要适配（目标从"字体字"换成"你的墨迹"）。
2. 我们**知道是什么字**（OCR）→ 用**笔顺模板约束**它的分解，避开它 #1 失败原因（无监督分割错、误差累积）。**我们是"带答案"的更稳版本。**

## 10. 局限（作者自陈）与对我们的提示

- **失败源**：笔画分割不准 + 机械臂**误差累积** + **sim2real gap**（无真实训练场景）。
- **对我们的提示**：
  - 用**笔顺模板**规避分割错；
  - 用**触觉闭环**对抗误差累积（它开环，我们有反馈）；
  - 我们**直接在真机采真实触觉**，天然缩小 sim2real。
