## §0-A 「形变量控制能不能成功」——分级诚实结论

> 把"成功"拆成两级，别把 A 级证据当 B 级证据用。

| 级别 | 含义 | 能否成 | 依据强度 |
|---|---|---|---|
| **A 级（基础）** | 用形变量+偏移角做**准静态**闭环，复现规划好的"路径+形变曲线" | **大概率能** | 论文 Fig.7 直接背书（强） |
| **B 级（核心）** | 在**真实写字速度**（0.3–1s 一笔）下复现大师级**快速提按** | **未知，待 E1 验证** | 无直接证据（弱） |

**A 级为何大概率能（已证实）**：论文 Fig.7 把 3mm×24mm 触角嵌进毛笔、装 UR3e、**只用触角形变/接触角闭环**维持恒力 4.5N（方差 0.34N）——"形变量当控制量、跑在机械臂上"这件事**被论文证明可行**，非推断。控制量是运动学量（形变）→ 无需绝对力标定；偏移角天然解耦提按 vs 侧向拖拽。

**B 级为何待验证（诚实风险）**：论文演示是**准静态（~100s 级）**，写字快 100~300 倍；论文**没证明**触角在写字速度下仍准。风险=① 迟滞回环使静态标定失准 ② 刷毛刚度非线性（蘸墨/含水/笔画类型）③ 带宽是否够快速提按。

**唯一把"待验证"变"已确认"的动作 = E1（阶跃/扫频，见 §4）**：
- E1 过 → 形变量方案成立，B 级可做。
- E1 不过 → **换任何表示（ΔB/牛顿/形变量）都救不了**（同一根触角、同一条物理链）→ 降级用独立 F/T 力环，触角退回管接触状态/切笔画/偏移角。

> 一句话：**方案逻辑自洽、A 级有硬证据，但做完 E1 之前不能声称 B 级一定成——目前它是"有依据的赌注"，不是"已验证的结论"。**

## §0 任务定义与 s→t 换算

- 模型输出的提按是**关于弧长** `g(s), s∈[0,1]`（与运笔快慢解耦）。
- 执行时用该笔时长 `T_i` + 速度剖面得到 `s(t)`，于是实时目标 `g_d(t) = g(s(t))`。
- 平面 `(x,y)` + 姿态：位置控，直接走规划路径（v1 笔杆姿态固定）。
- 法向：闭环跟踪 `g_d(t)`（`g` 用什么表示见 §1）。

## §1 决策一：法向反馈用什么表示？（ΔB / 牛顿 / 形变量）

### 关键事实：三者是同一条链上的三个点
```
力 F  →(力学:挠度∝F·L³,有迟滞)→  形变量 δ  →(磁学)→  ΔB (实测)
 └ 离物理最远,最可解释        中间,一步         最原始,0变换
```
- 对"复现我自己的提按"（同一支笔录了再复现），**三者单调等价**；区别在标定成本、抗漂移、拖拽解耦、可解释。
- **核心**：形变量、牛顿(触角标定)**都从 ΔB 换算** → **ΔB 一漂它俩跟着漂，换表示救不了漂移**。唯一免疫漂移的牛顿是**独立 F/T 直接测**——但那样力不再由触角驱动（弱化卖点）。

### 逐维度对比

| 维度 | ΔB(原始标量) | **形变量+偏移角**(多轴ΔB) | 牛顿(触角标定) | 牛顿(独立F/T) |
|---|---|---|---|---|
| 怎么得到 | 直接读 | 多轴ΔB→幅值+方向 | ΔB→力,1条标定 | 装F/T直接测 |
| 标定成本 | ✅ 零 | 低 | 中 | 中(买/装F/T) |
| 抗漂移/UR磁干扰 | ❌ | ❌ 同ΔB(方向可自校) | ❌ 同ΔB | ✅ 免疫 |
| **拖拽解耦**(提按vs侧向) | ❌ 混一起 | ✅ **按方向分开** | ⚠️看是否多轴 | ✅ 6维取法向 |
| 作训练标签(人写时录) | ✅ | ✅ 更结构化 | ⚠️需标定 | ❌ 手持不便挂F/T |
| 作控制反馈 | ✅ | ✅ **论文用这个** | ✅ | ✅ 最干净力环 |
| 带宽/迟滞 | ❌ 含触角迟滞 | ❌ 含触角迟滞 | ❌ 含触角迟滞 | ✅ 无迟滞,高带宽 |
| 可解释/对标0.34N | ❌ | ⚠️ mm/度半懂 | ✅ 牛顿 | ✅ 牛顿 |
| **贴合卖点**(触角驱动提按) | ⭐⭐ | ⭐⭐⭐ 最纯 | ⭐⭐ | ❌ 力其实F/T做的 |
| 论文用没用 | 感知(Fig4/6) | ✅ 控制(Fig7) | 表征(Fig7A-iii) | 记录(Fig7G) |

### 三者优劣速览
- **ΔB(原始)**：零标定、最原始；但**提按/拖拽混一起**、别人看不懂。→ 当**底层信号**，别用单轴标量直接控。
- **形变量+偏移角**：论文正解；幅值=提按、方向=**拖拽解耦**；触角驱动、卖点最纯；仍继承 ΔB 的漂移/迟滞/带宽。→ **核心表示**。
- **牛顿(触角标定)**：可解释、能对标0.34N；但多一层标定、漂移迟滞照旧，为核心环加它性价比低。→ **仅报告用**。
- **牛顿(独立F/T)**：免疫漂移、无迟滞、带宽高、法向解耦最干净；但要F/T、示范不便、**力不再由触角驱动**。→ **失败安全网**。

### ★ 决策（用在哪）

| 用途 | 选谁 | 理由 |
|---|---|---|
| **训练标签 + 控制反馈** | **形变量 + 偏移角** | 论文验证、触角驱动(卖点最纯)、自带拖拽解耦、免牛顿 |
| **报告 / 对标 0.34N** | 粗略 ΔB→牛顿(触角标定) | 可解释、可比较；**不进控制环**，几十分钟做完 |
| **底层信号** | 多轴 ΔB | 一切来源；在其上解算幅值+方向 |
| **失败安全网** | 独立 F/T 测牛顿 | 仅当 E1 证明触角带宽不够时启用；代价=弱化卖点 |

> **提按 = 目标形变量曲线**；偏移角维持接触角 + 解耦拖拽（= 复刻实验6）。全程可不换牛顿。

## §2 决策二：用什么控制律？（三方案）

> 反馈信号用 §1 选定的**形变量**（下文 `g` 泛指该"提按信号"，可以是形变量，也可换牛顿，数学同构）。

### 方式1｜混合位置/力控（UR 原生 `force_mode`）— 最快落地
- **原理**：任务空间分方向，法向力控、平面位置控。奠基：**Raibert & Craig, ASME JDSMC, 1981**。
- **UR3e**：`force_mode(task_frame, [0,0,1,0,0,0], [0,0,f_d,0,0,0], type, limits)`。
- **反馈来源**：`force_mode` **默认用腕部 F/T** —— ⚠️ 经柔软刷毛传导会失真（论文批评点）。
- **定位**：MVP/基线（跑通"边走边控法向"），但不贴卖点。

### 方式2｜导纳控制 + 触角形变（★ 本项目主攻）— 见 §3

### 方式3｜笛卡尔柔顺控制（FDCC / ROS2 `cartesian_controllers`）— 最省造轮子
- **文献**：Scherzinger et al., FDCC, **IEEE/RSJ IROS 2017**（资料库#20）；开源 **FZI `cartesian_controllers`**（ROS2，含 UR 集成示例，#21）。
- 给它参考位姿 `x_d(t)` + 目标法向量，内部混合求解下发 UR；触角信号需写适配接入。
- **定位**：想少造轮子/要正规柔顺控制时用；代价=搭 ROS2 + 适配层。

### 三方案对比
| | 方式1 force_mode | **方式2 导纳(触角形变)** | 方式3 FDCC/ROS2 |
|---|---|---|---|
| 反馈 | 腕部F/T | **触角形变(笔尖)** | F/T或触角(需适配) |
| 落地速度 | ⭐⭐⭐ | ⭐⭐ | ⭐ 需ROS2 |
| 贴卖点 | ❌ 刷毛失真 | ⭐⭐⭐ 核心 | ⭐⭐ |
| 定位 | MVP/基线 | **主攻** | 备选/升级 |

**推荐路线**：方式1 跑通链路 → **方式2 换触角形变（你的贡献）** → 需扩展时上方式3。

## §3 方式2 深入（主攻）：导纳控制 + 触角形变

### 3.1 原理
测反馈信号 `g_meas`（形变量）→ 虚拟"质量-阻尼(-弹簧)"→ 输出位置修正 → 发 UR 位置接口。
（阻抗奠基 **Hogan, ASME JDSMC, 1985**；UR 无力矩接口 → 导纳外环算位置修正，天然适配。）
**触角形变直接作 `g_meas` 注入外环** —— 这是本项目区别于腕部 F/T 的核心。

### 3.2 控制律（法向 1-DoF，跟踪提按信号）— 前馈标定 + 低增益反馈
约定 z 指向纸内（下压为正）。

> **修正（2026-07-09）**：形变量是**运动学量、不是力**，把"形变误差"直接塞进虚拟质量-弹簧当"力"物理上别扭，且纯反馈在**时变提按 + 迟滞 + 延迟**下会滞后（早前"纯跟踪 k=0、一阶天然稳定/零稳态误差"的说法是错的）。既然目标形变 `g_d(s)` 已知，就该用**前馈扛主运动、反馈治残差**。详见 `导纳控制+触角形变-详解与论文带读.md` Part 2。

$$
z_{cmd}(s) = \underbrace{z_{\text{ff}}\big(g_d(s)\big)}_{\text{前馈:标定曲线,扛快速提按}} \;+\; \underbrace{K_v\!\!\int (g_d - g_{meas})\,dt}_{\text{低增益反馈,只纠残差}}
$$

- **前馈** `z_ff = z_from_calib(g_d)`：标定"想要这个形变 → 大概压到这个 z"，负责跟上快速提按（`g_d(s)` 已知，可提前给量）。
- **反馈** `K_v∫(g_d−g_meas)dt`：**低增益慢积分**，只纠前馈没算准的残差（迟滞、蘸墨变软、纸面起伏）。
- `x,y` 来自规划路径；姿态 v1 固定（进阶：用**偏移角**调姿态维持接触角，=实验6）。
- **A 级（恒定形变）**退化情形：设定值不变时滞后问题消失，可先用纯二阶导纳缓冲（大 m 大 d 抑纸面刚性振荡）验证链路；**一旦上 B 级时变提按，必须加前馈**。

### 3.3 离散实现（100–200 Hz 外环即可）
> **更正过度要求**：书法接触是准静态低带宽，**外环 100–200 Hz 足够**，不必 500 Hz。MLX90393(Burst+DRDY)可达此量级。`servoL` 可跑更快，中间插值。

```python
# 伪代码；API 请对照 ur_rtde 官方文档核对
from rtde_control import RTDEControlInterface
from rtde_receive import RTDEReceiveInterface
rtde_c = RTDEControlInterface("192.168.x.x")

dt = 1/150.0
Kv = SMALL_GAIN                               # 低增益,只纠残差
z_fb = 0.0
t = 0.0
while t < T_stroke:
    B = read_antenna_3axis()                 # (Bx,By,Bz)
    B = rebaseline(B)                         # 减去当前基线 B0 (关键: 处理漂移;UR磁干扰待实测)
    g_meas = deform_magnitude(B)             # 多轴→形变量(提按分量, 已按方向解耦拖拽)
    # angle = deform_direction(B)            # 可选: 偏移角→维持接触角

    s   = arclength_at(t)
    g_d = deform_curve(s)                     # 模型输出的目标形变量曲线

    z_ff  = z_from_calib(g_d)                 # ★前馈: 标定曲线,扛快速提按
    e     = g_d - g_meas                      # 反馈误差
    z_fb += Kv * e * dt                       # ★低增益慢积分,只纠残差
    z_fb  = clamp(z_fb, -DZ_MARGIN, DZ_MARGIN)

    z_cmd = z_surface + z_ff + z_fb
    z_cmd = clamp(z_cmd, Z_MIN, Z_MAX)        # 安全限深
    x, y  = path_xy(s)
    rtde_c.servoL([x, y, z_cmd, *ORI_FIXED], VEL, ACC, dt, LOOKAHEAD, GAIN)
    t += dt
    sleep_until_next_tick()
```

### 3.4 调参（纸面刚度大，先保守）
| 参数 | 作用 | 起步 |
|---|---|---|
| `z_from_calib` 前馈曲线 | 主运动，扛快速提按 | 由 E2 标定得到 |
| `Kv` 反馈增益 | 只纠残差 | **先小**（低增益慢积分） |
| m/d（仅 A 级二阶缓冲） | 抑纸面刚性振荡 | **先大 m、大 d** |
- 纸+桌刚度大 → 易自激振荡 → A 级恒形变阶段用**大 m、大 d** 保守起步；`Kv` 宁小勿大（大了会和迟滞打架发散）。
- 变刚度提按：让前馈曲线/`Kv` 随笔画类型变（参考 #19）。

### 3.5 工程坑（必处理）
1. **基线 re-baseline**：ΔB=B−B0，B0 会因温漂/重装/**UR 钢法兰+电机磁干扰**而漂 → 人写 vs 机器人写要可比，**机器人姿态下重取基线**，必要时背景磁场扣除。
2. **形变量/偏移角解算**：多轴 ΔB → (幅值, 方向)，据此**解耦提按与侧向拖拽**（论文方向识别 1.76° 支持）。
3. **迟滞/蠕变**：触角有粘弹性（论文用 LSTM 预测回弹）→ 快速提按下会污染估计（见 §4 E3）。
4. **带宽**：见 §4 E1（最大风险）。
5. **自重 tare**：毛笔+模块重量给形变偏置，接触前归零。
6. **初始接触**：缓慢趋近 + 斜坡，别砸下去。
7. **纸面 z_surface**：示教三点定平面，固定夹具。
8. **安全**：DZ_MAX、最大形变限幅、UR 保护停止阈值。
9. **符号/坐标系**：z 正向、形变正负，与解算一致（最常见 bug）。

### 3.6 对标
论文 UR3e 触觉恒力刷涂：力 4.5N、方差 **0.34N**、覆盖 99.92%。你先复现"恒定形变"，再升级为"跟踪时变形变量曲线（提按）"。

## §4 前置门禁实验（做完才决定方案，别先写控制代码）

> **E1 是分水岭**：决定触角能否直接做提按闭环，还是要上 F/T 安全网。

| # | 实验 | 方法（借实验2的标定台思路） | 回答什么 | 判据 |
|---|---|---|---|---|
| **E1** | **阶跃 + 扫频响应** | 给触角施加力阶跃，看形变量多久稳；扫频到 3–5 Hz | **能否做快速提按**（最关键） | 稳定时间 ≪ 0.1s、3Hz 内幅值不塌 → 可行 |
| **E2** | in-situ 标定 | 装配态毛笔压力计，**快速**分档加载 0→3N，记 ΔB | ΔB↔形变↔力 曲线、斜率、单调、饱和 | 单调、不饱和(勿顶±32767)、斜率够 |
| **E3** | 加载-卸载回环 | 同一力升再降，看形变量回环 | **迟滞/蠕变**多大 | 回环面积小 → 可直接反馈 |
| **E4** | 恒力横向拖行 | 固定法向、按书写速度拖笔，看 ΔB/方向变化 | **拖拽混淆**幅度 | 拖拽分量可按方向分离 → 可忽略 |

**决策树**：
- E1 通过 + E3 迟滞小 → **走方式2（触角形变闭环）**，卖点最纯。
- E1 不过（触角跟不上快速提按）→ **上安全网**：F/T 跑力环、触角退回管接触状态/切笔画/偏移角。
- E4 拖拽大 → 必须用**偏移角按方向解耦**后再进环。
