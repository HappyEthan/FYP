> 配套文件：`硬件方案-handoff.md`（§4 需求、§6 双模式、§8 数据接口契约）。
> 论文依据：Ren et al., *A robust and omnidirectional-sensitive electronic antenna for tactile-induced perception*, Nat. Commun. 16:3135 (2025)。
> 生成日期：2026-07-06。本文档定位：**给硬件/固件 session 直接照做**——选型、配置、接线、固件、标定一次讲清。

## 0. 一句话结论

**选 MLX90393（Melexis 三轴磁强计，I2C）**。这就是论文用的那颗（Methods「Fabrication」原文："assembled on a tiny Hall sensor (MLX90393, Melexis, Inc.)"），也是 handoff §4 指定的。它读磁化触须变形产生的三轴磁场 **Bx/By/Bz**，软件端据此解算「提按力度 + 笔画切分」。

**为什么是它而不是普通磁强计**：毛笔触须里嵌了 NdFeB 强磁粉，靠近传感器的磁场是**毫特斯拉级（mT）**，会让常规地磁级磁强计（LSM303 之类，±0.81 mT 就饱和）直接爆表。MLX90393 量程 **±5 ~ ±50 mT**，专为「测磁体、测磁体姿态」设计，正好对上。

## 2. 工作原理（在本项目里到底测什么）

```
人提按毛笔 → 笔毫受力弯曲 → 嵌在笔毫里的磁化触须一起变形
        → 触须（NdFeB）相对 MLX90393 的位置/角度改变
        → 传感器测到的三轴磁场 B=(Bx,By,Bz) 改变
        → I2C 读出 → 时间戳 → BLE/USB → 软件端: ΔB → 力/方向
```

- 静止（未受力）时触须有一个**基线磁场 B0**。受力后读到 B，软件用**归一化变化量 ΔB/B0** 反推力度与方向。
- 论文的关键量化指标（给你标定/验收对表）：
  - 静态力-磁响应近似线性，主敏感区约 **±120 mN**，斜率 ~40 mN/%（即 ΔB/B0 每变 1%≈40 mN）。
  - 典型书写载荷下 ΔB/B0 变化量约 **4%–8%** 量级。
  - 机器人刷涂闭环里力方差做到 **0.34 N**——这是你「提按复现」精度的对标线。
- **本项目只要传原始 Bx/By/Bz**（handoff §8 契约），力标定、方向解算、滤波全放软件端。硬件只负责「稳、等间隔、带时间戳」。

## 3. 关键配置：量程 / 增益 / 分辨率（决定灵敏度）

MLX90393 的灵敏度不是固定的，由 **GAIN（增益）× RES（每轴分辨率）** 共同决定。**增益越高、量程越小、但每 LSB 对应的磁场越小（越灵敏）**。这是本项目最需要调的一组参数——要在「量程够（触须不打饱和）」和「灵敏度高（提按力分辨得出来）」之间取平衡。

### 灵敏度对照表（µT/LSB，HALLCONF=0xC，RES=0 基准）

| GAIN_SEL | 增益 | XY 轴 µT/LSB | Z 轴 µT/LSB |
|---|---|---|---|
| 7 | ×1（默认） | 0.150 | 0.242 |
| 6 | ×1.33 | 0.200 | 0.323 |
| 5 | ×1.67 | 0.250 | 0.403 |
| 4 | ×2 | 0.300 | 0.484 |
| 3 | ×2.5 | 0.375 | 0.605 |
| 2 | ×3 | 0.451 | 0.726 |
| 1 | ×4 | 0.601 | 0.968 |
| 0 | ×5 | 0.751 | 1.210 |

- **RES（分辨率）缩放**：RES_0=×1，RES_1=×2，RES_2=×4，RES_3=×8（数值越大，每 LSB 磁场越大=越粗，但量程越大、且高 RES 会有偏置需处理）。
- Adafruit Arduino 库里的 `MLX90393_RES_16 / RES_17` 就是在调这个；官方 basicdemo 用 **X/Y=RES_17、Z=RES_16、GAIN_1X**，目标是让三轴灵敏度都拉到 **~0.3 µT/LSB** 附近、且量程均衡。

### 本项目推荐起步配置

> **先用 Adafruit 官方 basicdemo 的配置跑通**，再按实测微调：

```
GAIN     = 1X            // 论文实测同款；量程大，触须重压不易饱和
RES(X)   = RES_17        // ~0.3 µT/LSB
RES(Y)   = RES_17
RES(Z)   = RES_16        // Z 本底灵敏度高，配 RES_16 与 XY 均衡
OSR      = 3             // 过采样，压噪声（换取转换时间）
DIG_FILT = 5~7           // 数字滤波，压噪声
HALLCONF = 0xC
```

**调参口诀**：
- 提按力分辨不出来（信号太糊）→ **调高 GAIN 或调低 RES**（更灵敏）。
- 重压时读数「撞墙/翻转」（饱和）→ **调低 GAIN 或调高 RES**（更大量程）。
- 拿真触须压一遍标定砝码，看 ΔB 是否在 16-bit 范围里留了余量（别顶到 ±32767）。

## 4. 采样率与转换时间（怎么保证 ≥100 Hz）

handoff §4 要求 **≥100 Hz 优先、≥50 Hz 最低**。拆清楚瓶颈：

- **传感器本体**：单次测量最快 **1.84 ms/次**（OSR=0, DIG_FILT=2, HALLCONF=0xC）→ 理论 ~500 Hz。**传感器不是瓶颈。**
- 转换时间随 **OSR↑、DIG_FILT↑** 变长（噪声更低但更慢）。三轴各转一次会叠加。**推荐配置（OSR=3, DIG_FILT=5~7）单轮大概几 ms~十几 ms 量级**——仍足够 ≥100 Hz，但要实测确认，别盲配最高滤波。
- **真正的瓶颈是 BLE 主机端**：论文 bleak 客户端多线程读，**实测平均只有 ~50 Hz**（论文 Data-receiving 原文）。原因是 BLE 连接间隔 + 逐样本 notify 的开销，不是传感器慢。

**要冲 ≥100 Hz 的做法**：
1. **传感器侧用 Burst 模式**（连续自动测量，DRDY 中断触发读取），别用「发命令→等→读」的单次轮询。
2. **BLE 侧**：调低 connection interval（7.5 ms）、**打包多样本再发一个 notify**（例如攒 5~10 个样本一包），能把有效吞吐拉上去。
3. **有线（USB）模式**：直接绕过 BLE 限制，轻松 ≥200 Hz，给机器人闭环用（见 §7、handoff §6）。

## 5. I2C 接口 · 引脚 · 地址

### breakout 引脚（Adafruit 版）

| 脚 | 作用 | 接法 |
|---|---|---|
| VIN | 供电输入（3–5V） | XIAO/ESP32 的 3V3 |
| 3Vo | 板载 3.3V 输出 | 一般不用 |
| GND | 地 | 共地 |
| SCL | I2C 时钟（板载上拉，5V 容忍） | MCU SCL |
| SDA | I2C 数据（板载上拉，5V 容忍） | MCU SDA |
| INT | **数据就绪 DRDY 中断**（默认单次模式下有新样本就触发） | 接 MCU GPIO，**高速取数强烈建议接** |
| A0/A1 | I2C 地址选择（默认拉低） | 挂多颗时才用 |
| CS / TR / MIS | SPI/触发/MISO，I2C 用不到 | 悬空 |

> 板载 SCL/SDA 已内置上拉，**不用再外接上拉电阻**。

### I2C 地址

| A1 | A0 | 地址 |
|---|---|---|
| 0 | 0 | **0x0C（默认）** |
| 0 | 1 | 0x0D |
| 1 | 0 | 0x0E |
| 1 | 1 | 0x0F |

本项目单颗触须 → 用默认 **0x0C** 即可。

## 6. 寄存器与工作模式（固件要点）

### 三种测量模式

| 模式 | 说明 | 本项目用途 |
|---|---|---|
| **Single Measurement (SM)** | 发命令测一次→DRDY→读→再发命令 | Adafruit 库默认；简单但有命令往返开销 |
| **Burst Mode** | 芯片按内部节拍**连续测量**，DRDY 每次就绪触发 | **推荐**，稳定等间隔、抖动小，正好满足 §8「尽量等间隔」 |
| **Wake-Up-On-Change (WOC)** | 磁场变化超阈值才唤醒 | 本项目连续采曲线，不用 |

### 命令流（I2C）

1. **上电/复位**：`RT`（reset）→ `EX`（exit）确保干净状态。
2. **写配置寄存器**：GAIN_SEL、RES_X/Y/Z、OSR、DIG_FILT、HALLCONF、BURST_SEL（选 X/Y/Z 参与）。
3. **启动**：`SB`（Start Burst，选 zyxt）或 `SM`（Start Single）。
4. **等 DRDY**：INT 脚拉高 / 或读状态字节。
5. **读数据**：`RM`（Read Measurement）一次读回 X/Y/Z（各 2 字节，有符号 16-bit）。
6. **转物理量**：`B_µT = raw × 灵敏度(µT/LSB)`（按 §3 表，随 GAIN/RES 取值）。

> **关键寄存器**：0x00（含 GAIN_SEL、HALLCONF）、0x02（含 BURST_SEL、OSR、DIG_FILT、RES_XYZ）。具体位域查 Melexis 数据手册 §15.1，Adafruit 库已封装好，一般不用手撸。

### 直接抄论文固件

论文固件是**改自 Adafruit 的开源 MLX90393 驱动（Kevin Townsend 写）**，MIT 许可，代码在 Code Ocean `10.24433/CO.3143395.v2`。→ **别从零写，拉论文固件 + Adafruit 库改。**

## 7. 与 MCU 接线（路线 A：XIAO ESP32-C3）

```
MLX90393 breakout        XIAO ESP32-C3
   VIN  ───────────────  3V3
   GND  ───────────────  GND
   SDA  ───────────────  D4 (SDA)
   SCL  ───────────────  D5 (SCL)
   INT  ───────────────  D2 (任意 GPIO，DRDY 中断)   ← 高速取数用
```

- 4 根 I2C + 1 根 DRDY，面包板先验证。用 STEMMA QT/Qwiic 版可**免焊**（一根 4-pin 线）。
- 论文用 ESP32-S3-WROOM-1；你用 XIAO ESP32-C3 完全够（BLE 5.0 + 板载锂电充电，见 handoff 路线 A）。

### 固件双模式（对齐 handoff §6，必须做）

```
[MLX90393] --I2C(burst,DRDY)--> [ESP32-C3]
                                    ├── BLE 模式(示范): Nordic UART Service, 打包多样本 notify
                                    └── USB 串口模式(机器人): 高速逐帧输出, 低延迟
```

- **示范采集**：BLE 无线（人写字不被线缆干扰）。
- **机器人闭环**：切 USB 有线，喂 UR5 力控回路（~500Hz、延迟敏感）。
- **固件里留一个模式开关**（编译宏或运行时命令都行），别只做 BLE，否则接机器人要返工。

## 8. 数据输出（对齐 handoff §8 契约）

**每样本输出**（首选原始值）：
```
{ t, Bx, By, Bz }     # t=单调时间戳(ms/µs); Bx/By/Bz=三轴原始16-bit读数
```
- **必须能拿到原始 Bx/By/Bz**（标定/滤波/解算全放软件）。
- 板算力有余可附带 `force_mag, force_dir`，但原始值不能省。
- BLE：一个 GATT 特征串流（NUS）；有线：USB 串口逐帧（文本 `t,Bx,By,Bz` 或二进制）。
- PC 侧每次示范落一段 CSV：`t,Bx,By,Bz`。

**时间戳在 MCU 侧打**（用芯片计时器），别依赖 PC 收到的时刻——BLE 抖动会污染时间轴，而软件端要靠这个时间轴切笔画。

## 9. 标定：磁场 → 接触力（N）

handoff §8 要一条 **B→力** 标定曲线，对标论文力方差 0.34 N。做法：

1. 触须+MLX90393 装好，固定笔尖朝下。
2. 用**已知砝码/力计（如 HANDPI HP-2，0.001 N 精度，论文同款思路）**沿书写方向逐级加载：0 → 30 → 60 → 90 mN…（覆盖你实际书写力范围）。
3. 每个载荷记录稳定后的 (Bx,By,Bz)，算 ΔB/B0。
4. 拟合 **力 = f(ΔB/B0)**（论文该段近似线性，斜率 ~40 mN/%）。
5. 存成标定文件给软件端。**此步可后做**，但硬件/结构定型时就把触须-传感器相对位置固定死，否则标定作废。

## 11. ⚠️ 本项目特有风险 / 注意事项

1. **UR5 法兰是钢 + 关节电机有强磁体**——机器人写字阶段，磁强计离金属法兰太近会**引入磁干扰/基线漂移**，可能污染 Bx/By/Bz。对策：① 传感器尽量远离法兰、加非磁（塑料/铝）适配件；② 在机器人姿态下**重新做一次基线标定**；③ 必要时记录「空载磁场图」做背景扣除。**这是示范→机器人迁移最容易翻车的点，务必提前测。**
2. **饱和**：重压把某轴顶到 ±32767 → 信息丢失。装配后拿最大书写力试一遍，留余量（见 §3 调参）。
3. **温漂**：长时间采集/发热会让基线漂。用芯片内温感做参考，或每段示范前重取 B0。
4. **触须-传感器相对位置必须刚性固定**：一旦松动，标定曲线全废。结构设计（handoff §7）里把这段做死。
5. **杂散磁体/铁器**：桌面上的磁性物、含铁墨水台等会干扰。采集环境保持洁净。
6. **5V 电平**：只有 SCL/SDA 5V 容忍；INT/DRDY 在 5V MCU 上要电平转换。用 3.3V 的 XIAO/ESP32 则无此问题。

## 12. 一页速查（TL;DR）

- **芯片**：MLX90393，I2C，三轴 ±5~50 mT，16-bit，地址 0x0C。
- **配置起步**：GAIN_1X + X/Y RES_17 + Z RES_16 + OSR_3 + FILTER_5（≈0.3 µT/LSB），照 Adafruit basicdemo。
- **要 ≥100Hz**：传感器用 **Burst + DRDY 中断**；瓶颈在 BLE，靠「7.5ms 连接间隔 + 打包多样本」解决；机器人用 USB。
- **输出**：`{t,Bx,By,Bz}` 原始值，时间戳在 MCU 侧打。
- **固件**：拉论文 Code Ocean `10.24433/CO.3143395.v2` + Adafruit MLX90393 库改，别从零写。
- **最大坑**：UR5 金属/电机磁干扰——机器人阶段要重标定。
