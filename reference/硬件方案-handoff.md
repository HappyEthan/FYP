# 触觉毛笔 · 硬件方案交接文档（给另一个 session）

> 用途：本文件把「触觉毛笔」的**硬件设计与制作**独立出来，交给另一个 session 决策/执行。
> 阅读对象：一个**不知道前情**的会话——所以下面把背景、需求、接口都写全了。
> 生成：2026-07-06。软件/算法主线在本项目另一条对话里推进，两边靠本文末的**数据接口契约**对齐。

---

## 1. 项目一句话背景

用一支**嵌入了仿生触角（电子触须）的毛笔**，让**人先写一遍字**、采集**触觉/力信息**（尤其"提按"力度）+ 字形，训练一个 **Transformer** 把「字形 → 逐笔画运动轨迹+力曲线」翻译出来，最终让 **UR5 机械臂**在纸上**复现提按、模仿人类笔触**，并**泛化写新字**。

参考论文：Ren et al., *A robust and omnidirectional-sensitive electronic antenna for tactile-induced perception*, Nature Communications 16:3135 (2025)。它的 Fig.7 已把触角嵌入毛笔装在 UR3e 上做曲面刷涂——本项目沿用其硬件思路，但用于**写字**。论文固件/代码：Code Ocean `10.24433/CO.3143395.v2`。

**触觉在本项目的作用（决定硬件不能凑合的原因）**：不是简单的"下笔/提笔开关"，而是要**定量复现书写时的接触力曲线（提按力度）**。所以传感器必须能稳定、连续地输出力/形变信号。

---

## 2. 要做的东西

一支**无线的触觉毛笔**：外形像毛笔、能像毛笔一样蘸墨写字，笔杆里集成一块**小电路板**，搭载：**触角（霍尔读数）+ 蓝牙 + 电源**。

**为什么要无线**：人执笔写示范时，**线缆会拖累手感、影响自然书写**。所以人写示范阶段要无线。（注意：机器人写字阶段可以有线，见 §6 延迟问题。）

---

## 3. 现有条件与约束（来自项目负责人）

- ✅ **已有触角**（磁化好的仿生触须）——**磁化这一关已过**，不需要脉冲磁化设备。
- ❓ **待确认**：触角是否**已集成 MLX90393 霍尔传感器**？
  - 若已集成 → 板子只需把它的 I2C（SDA/SCL/VCC/GND）接出来
  - 若只是触须 → 板上需加一颗 MLX90393
- ⚠️ 负责人**此前不熟 PCB 设计、不熟 3D 打印** → 方案要么绕过、要么当作学习任务来做（见路线 A/B）。
- ✅ 有 UR5 机械臂、相机、电脑。
- 这是一个 **FYP（毕业设计）**：定位是**借鉴复刻并应用**，不追求突破性研究；但硬件做成实物对答辩有加分。

## 4. 关键需求规格（Functional Requirements）

| 项 | 要求 | 说明 |
|---|---|---|
| 传感原理 | 霍尔（MLX90393，I2C）读磁化触须形变 | 沿用论文 |
| 采样率 | **≥100 Hz 优先，≥50 Hz 最低** | 论文 ~50Hz；提按力曲线+笔画切分够用，越高越好 |
| 无线（示范用） | BLE 串流到 PC | 人写示范不被线缆干扰 |
| 有线/低延迟（机器人用） | 见 §6，需预留 | 机器人闭环力控对延迟敏感 |
| 时间戳 | 每个采样带一致时间基 | 用于"力阈值切笔画"和后续对齐 |
| 供电 | 锂电 + 板载充电，续航≥2h | 一次采集会话够用 |
| 尺寸/重量 | 模块尽量小、轻，装笔杆顶端 | 论文板 23×40×2mm；重量影响手感 |
| 输出 | 见 §8 数据接口契约 | 保证软件端能直接用 |

## 5. 两条实现路线（择一，建议先 A）

### 路线 A（推荐、快、无需画 PCB）：现成一体化模块
用一块指甲盖大的开发模块把"蓝牙+电源"一次解决，**零 PCB 设计、零打样等待**。

**推荐 BOM（约 ¥100+）：**
| 部件 | 选型建议 | 作用 |
|---|---|---|
| MCU+BLE+充电 | **Seeed XIAO ESP32-C3**（21×17.8mm，BLE，板载锂电充电，有 BAT± 焊盘） | "小长方形板"本体 |
| 传感 | 触角（若无霍尔，加 **Adafruit MLX90393 breakout**，可 STEMMA QT 免焊） | I2C 读数 |
| 电源 | LiPo 3.7V ~150–300mAh + JST | 无线供电 |
| 外壳 | 笔杆顶端小卡扣（外包 3D 打印） | 固定模块+电池 |

接线：4 根 I2C + 2 根电池，面包板即可先验证。
> 备选模块：Adafruit QT Py ESP32-C3（STEMMA QT 免焊接传感器）、Adafruit Feather ESP32（锂电最省心但略大）。

### 路线 B（可选、当 FYP 硬件交付物）：自制 2 层 PCB
若想把"设计这块板"作为动手成果。最小功能块：
```
[USB-C] → [充电IC TP4056/MCP73831] → [LiPo]
              │
          [3.3V LDO] → [ESP32-C3-MINI 模组(BLE)] ──I2C── [触角/MLX90393 接口]
```
- 工具：KiCad（入门级 2 层板）；打样：JLCPCB 约 ¥20 + 贴片，约一周。
- 论文附录参考 BOM 可抄：ESP32-S3-WROOM、LDO **SY8089**、USB-UART **CH340N**、FPC 连接器（FH34SRJ）。
- **权衡**：更完整好看，但要学 KiCad + 等打样 + 调试，有时间风险。**建议先用路线 A 跑通，PCB 后期再做。**

### Fallback（若霍尔/磁式方案出问题）：视觉式触须
资料库 #6：碳纤维杆插硅胶底座，**用相机追踪偏转**测力/方向。不用霍尔、不用 PCB、不用磁化，只用已有相机。作为保底方案留档。

## 6. ⚠️ 一个必须提前设计的点：无线 vs 有线（延迟）

- **人写示范（离线采集）**：BLE @ 50–100Hz **完全够**，无线体验好。
- **机器人写字（闭环力控）**：触角力要喂进 UR5 的**导纳/力控回路**，该回路跑 ~500Hz、对延迟敏感（理想 <5–10ms）。**BLE 的速率/抖动可能不够。**
- **建议**：硬件预留**两种取数方式**——
  - 示范模式：BLE 无线
  - 机器人模式：**USB 有线**（机器人不在乎拖线）或更低延迟链路
- 至少确保固件能切换成"高速有线输出"模式。请在设计时考虑这个双模式，别只做 BLE。

## 7. 毛笔本体（机械组装）

参考论文 Fig.7：
1. **触角嵌进刷毛内部**（论文用 ~3mm 直径触角插入笔毫），使其随刷毛一起变形 → 才测得到真实笔锋受力。
2. **笔杆中空**，顶端装电路模块 + 小锂电。
3. 机器人写字时，笔杆经一个**夹持适配件接 UR5 法兰**（这个小件可外包 3D 打印/用管夹）。
4. 注意重量分布与蘸墨：模块别太重、别影响蘸墨与运笔。

## 8. 🔑 数据接口契约（硬件↔软件对齐，务必遵守）

软件/算法端期望从毛笔拿到**带时间戳的连续数据流**，据此做"力阈值切笔画 + 提按力曲线 + 机器人力反馈"。请硬件端保证：

**输出内容（每个采样）：**
```
{ t,  Bx, By, Bz }          # 时间戳 + 三轴霍尔原始磁场读数（首选：传原始值，标定/滤波交软件）
```
- **首选传原始 Bx,By,Bz**（力标定、方向解算、滤波都放软件做，硬件只管稳定采样）。
- 若板算力允许，可附带处理后的 `force_mag, force_dir`，但**原始值必须也能拿到**。

**采样与时间：**
- 采样率 ≥100Hz 优先；**尽量等间隔**、抖动小。
- 每样本带**单调时间戳**（ms 或 µs）；软件靠触觉流自身时间轴切笔画，**不强依赖与相机的硬同步**（相机只提供字形形状，靠标准笔顺配对，见软件端方案）。

**传输格式：**
- BLE：一个 GATT 特征串流（可用 Nordic UART Service NUS），PC 端能连上并逐样本收。
- 有线：USB 串口，逐行文本或二进制帧均可，给出协议说明。
- 给软件端一个**每次示范一段的记录**（可 PC 侧落成 CSV：`t,Bx,By,Bz`）。

**标定任务（硬件/联调阶段产出）：**
- 需要一条 **磁场读数 → 接触力(N)** 的标定曲线（用已知砝码/力计压触角，记录 B 变化）。软件端复现"提按"要用到，对标论文力方差 0.34N。此标定可后做，但请预留。
