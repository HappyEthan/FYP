## Part 1 · 导纳控制是什么（从零讲清）

### 1.1 阻抗 vs 导纳：谁当输入、谁当输出

机器人接触环境时，"力"和"运动"是一对因果量。控制方式按**因果方向**分两类：

| | **阻抗控制 (Impedance)** | **导纳控制 (Admittance)** |
|---|---|---|
| 输入（测量） | 位置/速度偏差 | **力/接触偏差** |
| 输出（下发） | **力/力矩** | **位置/速度** |
| 需要的机器人接口 | 力矩接口 | **位置/速度接口** |
| 直觉 | "你推我多少，我软多少" | "我感到多少力，就让开多少位移" |

奠基文献：**Hogan, "Impedance Control: An Approach to Manipulation," Parts I–III, ASME J. Dyn. Syst. Meas. Control, 1985**（阻抗/导纳同源，Hogan 把它们统一为"调节末端的动态关系"）。

### 1.2 为什么你的 UR 必须用导纳，不能用阻抗

**UR 只接受位置/速度指令**（`movel/servoL/speedl`），**没有关节力矩接口**。
- 阻抗控制要直接下发力矩 → **UR 做不了**。
- 导纳控制：外环用**力/接触反馈算出一个位置修正 Δz**，再通过 `servoL` 下发 → **UR 天然适配**。

所以对 UR 而言，"柔顺"只能靠导纳（外环软、内环仍是 UR 的位置伺服）。这也是资料库 #20 FDCC、#21 `cartesian_controllers` 的做法本质。

### 1.3 经典导纳律（力驱动版）

约定 z 指向纸内、下压为正。经典导纳把"力误差"喂给一个**虚拟质量-阻尼-弹簧**，解出位置修正 Δz：

$$
m\,\Delta\ddot z \;+\; d\,\Delta\dot z \;+\; k\,\Delta z \;=\; F_d - F_{meas}
$$

- `m` 虚拟质量：越小越灵敏但越易振。
- `d` 虚拟阻尼：抑振，接触刚性面时要大。
- `k` 虚拟刚度：`k=0` → 纯力跟踪（无位置回正）；`k>0` → 位置有回中弹性。
- 物理直觉：把末端想象成一个"虚拟的弹簧阻尼滑块"，力越大它退让越多，退让由 m/d/k 的动态决定，**天生平滑**（二阶系统，不会跳变）。

**这一版的输入是"力误差"。** 你的问题恰恰出在这里——见 Part 2。

⚠️ 以上是教科书公认范式，本文只述原理，**不编任何数值**。

## Part 2 · 把"力"换成"触角形变"——关键转折与陷阱（本项目核心）

### 2.1 陷阱：你测的不是力，是形变（运动学量）

经典导纳（§1.3）吃的是**力误差 `F_d − F_meas`**。但你决定用**形变量 `g`** 做反馈（§决策见 `执行方案-力控.md` §1）。于是很自然会写成：

$$
m\,\Delta\ddot z + d\,\Delta\dot z + k\,\Delta z = g_d - g_{meas} \quad(\text{形变误差})
$$

**这个式子能跑，但物理上别扭，而且是我之前的过度乐观来源。** 问题在于：
- **形变 `g` 是运动学量，不是力。** 把"形变误差"当"力"塞进虚拟质量-弹簧，量纲和物理意义都被偷换了——你其实只是在做一个**二阶滤波的积分跟踪器**，不是真正的导纳。
- **纯积分跟踪在"时变设定值 + 迟滞 + 延迟"下会滞后**，不是我早前说的"一阶天然稳定、零稳态误差"。快速提按（0.3–1s 一笔）时，设定值一直在变，纯反馈永远慢半拍。
- **缺前馈。** 你其实**已经知道**目标形变 `g_d(s)`，也能事先标定"要这个形变→大概压入多少 z"。不用前馈、纯靠反馈现推，是浪费了已知信息。

### 2.2 两条正确路线

**路线 A：先把形变标定成力，再跑真·导纳。**
- 做一次 `g → F` 标定（E2），把形变换成牛顿，然后严格按 §1.3 的力驱动导纳跑。
- 优点：数学干净、是"真导纳"。缺点：多一层标定、继承标定漂移、且力其实还是从形变来的（没有独立信息量）。

**路线 B（★推荐）：前馈标定曲线 + 低增益反馈修正。**
- **前馈**：标定一条 `z_ff = z_from_calib(g_d)`——"想要这么多形变，大概压到这个 z"。它负责**扛快速提按**（因为 `g_d(s)` 已知，可提前给量）。
- **反馈**：`e = g_d − g_meas`，用**低增益慢积分**只纠前馈没算准的残差（迟滞、蘸墨变软、纸面起伏）。
- 这才是把"形变是运动学量"这件事诚实对待的写法：**前馈给主运动，反馈治不确定性**。

$$
\boxed{\;z_{cmd}(s) = \underbrace{z_{\text{ff}}(g_d(s))}_{\text{前馈:标定曲线}} \;+\; \underbrace{K_v\!\!\int (g_d - g_{meas})\,dt}_{\text{低增益反馈,只纠残差}}\;}
$$

> 什么时候纯导纳（§2.1 式）也够用？——**当你只做 A 级"恒定形变"**（设定值不变）时，纯反馈的滞后问题消失，那个二阶式子当"柔顺缓冲"反而好用（大 m 大 d 抑制纸面刚性振荡）。**一旦上时变提按（B 级），必须加前馈。**

### 2.3 诚实小结

- "导纳"这个名字，在**路线 B** 里其实退化成了"带虚拟阻尼的位置修正"；严格叫它"**前馈 + 柔顺反馈**"更准。但工程圈常把这类外环位置柔顺都笼统叫导纳，沟通时说清即可。
- **别再说"形变控制一阶天然稳定/零稳态误差"**——那是错的（迟滞+延迟+时变设定值会破坏它）。
- 稳不稳，最终**由 E1（带宽/迟滞）决定，不由控制律漂亮与否决定**。

**⑤ Fig.7G（力是"record"，不是控制反馈）**

- ⚠️ **诚实留白**：主文没说这个"desired 4.5N"是不是设成了一个真正的**牛顿力环设定值**，还是"调到某个目标形变、事后测得约 4.5N"。两种读法都讲得通，论文**没写清**。所以别断言"论文跑了牛顿力环"，也别断言"完全没有力目标"——**如实说"论文以触觉/接触角为反馈，力为记录与目标对标量"**即可。

## Part 4 · 落地控制律（最终版，与 `执行方案-力控.md` 对齐）

```python
# 方式2 · 前馈标定 + 低增益反馈（法向 1-DoF 提按）
# 伪代码;API 对照 ur_rtde 官方文档核对。z 指向纸内,下压为正。
dt = 1/150.0
Kv = SMALL_GAIN          # 低增益,只纠残差
z_fb = 0.0
t = 0.0
while t < T_stroke:
    B      = rebaseline(read_antenna_3axis())     # 减基线 B0(处理漂移;UR磁干扰待实测)
    g_meas = deform_magnitude(B)                  # 多轴ΔB→形变量(已按方向解耦拖拽)

    s      = arclength_at(t)
    g_d    = deform_curve(s)                       # 模型输出:目标形变量曲线

    z_ff   = z_from_calib(g_d)                      # ★前馈:标定曲线,扛快速提按
    e      = g_d - g_meas                           # 反馈误差
    z_fb  += Kv * e * dt                            # ★低增益慢积分,只纠残差
    z_fb   = clamp(z_fb, -DZ_MARGIN, DZ_MARGIN)

    z_cmd  = z_surface + z_ff + z_fb
    z_cmd  = clamp(z_cmd, Z_MIN, Z_MAX)             # 安全限深
    x, y   = path_xy(s)
    rtde_c.servoL([x, y, z_cmd, *ORI_FIXED], VEL, ACC, dt, LOOKAHEAD, GAIN)
    t += dt
    sleep_until_next_tick()
```

- **A 级（恒定形变）**：可先退化成纯二阶导纳缓冲（大 m 大 d 抑纸面刚性振荡），验证链路。
- **B 级（时变提按）**：必须上前馈 `z_from_calib`，否则快速提按滞后。
- 坑（基线 re-baseline / 形变解算 / 迟滞 / 自重 tare / 初始接触 / 安全限幅）见 `执行方案-力控.md` §3.5，此处不重复。
